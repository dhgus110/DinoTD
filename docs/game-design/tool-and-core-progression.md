## 1. 목적과 범위

판매로 번 코인이 다음 탐험 능력을 실제로 열게 하고, 플레이어가 여러 도구를 직접 꺼내 바꾸는 조작 없이
자원에 맞는 행동을 자연스럽게 수행하게 한다. 대장간은 손에 드는 장비를, 야영지 코어는 캐릭터와 동료
운영 한도를 성장시켜 두 시설의 방문 이유가 겹치지 않게 한다.

### 확정

- 나무는 도끼, 돌과 광석은 곡괭이로만 채집한다.
- 자원에는 요구 도구 단계가 있고, 보유 도구가 낮으면 채집할 수 없다.
- 같은 자원도 상위 등급일수록 기본 작업 시간이 길며 도구를 강화하면 작업 시간이 줄어든다.
- 대장간은 도끼·곡괭이·무기의 제작과 강화를 담당한다.
- 야영지 코어는 체력·운반능력·동행 수용량·기지 수용량처럼 캐릭터와 활동 인원 성장을 담당한다. 전체 소유 한도인 보관 수용량은 동료 보관소가 담당한다.
- 이동과 대기 중에는 빈손이며, 유효한 상호작용을 하는 순간에만 필요한 도구나 무기가 나타난다.

### 검증 필요

- 도구 단계 수, 단계별 비용, 자원별 요구 단계와 기본 작업 시간의 최종값
- 상위 도구 한 단계가 작업 시간을 얼마나 줄여야 성장 체감과 애니메이션 가독성을 함께 지키는지
- 도구가 나타나고 사라지는 시간이 연속 작업에서 번쩍임처럼 보이지 않는지

## 2. 시설별 성장 역할

| 시설 | 담당 성장 | 플레이 결과 | 담당하지 않는 성장 |
| --- | --- | --- | --- |
| 대장간 | 도끼·곡괭이·무기 제작과 단계 강화 | 상위 자원 채집 가능, 기존 자원 작업 시간 감소, 무기 공격력·외형 변화 | 체력, 운반능력, 동료 활동 인원 |
| 야영지 코어 | 체력·운반능력·동행 수용량·기지 수용량 강화 | 더 오래 탐험, 한 번에 더 많이 운반, 더 많은 동료를 동행·기지 배치 | 자원 채집 자격, 도구·무기 제작 |

- 두 시설은 동굴 안의 서로 다른 고정 건물로 보인다. 하나의 통합 강화 화면으로 합치지 않는다.
- 완성된 시설의 상호작용 범위에 들어가면 해당 시설 전용 팝업을 자동으로 연다. 닫은 뒤 같은 범위에서는
  다시 열지 않고, 범위를 완전히 벗어났다 재진입하면 다시 연다.
- 대장간 팝업에는 도끼·곡괭이의 현재 단계, 다음 단계의 채집 위력, 필요 코인과 부족·최대 상태를 표시한다.
- 야영지 코어 팝업에는 체력·운반능력·동행 수용량·기지 수용량의 현재값, 단계와 필요 코인을 나란히 표시한다.
- 성장 항목을 선택한 뒤 재화를 투입하는 공통 방식은 `비콘` 규칙을 따른다.
- 대장간에서 도구를 강화해도 운반능력은 오르지 않으며, 야영지 코어를 강화해도 상위 자원 채집 자격은 열리지 않는다.
- 의상 제작·구매 장소는 후속 장비 기획에서 정한다. 현재는 대장간이 의상 능력치를 대신 올리지 않는다.

세로 슬라이스의 임시 강화 비용은 도끼·곡괭이 다음 단계별 `20·60·180·500코인`,
코어 각 항목은 `25·75·200·500코인`을 사용한다. 코어 한 단계 효과는
체력 `+20`, 운반 한도 `+5`, 동행 `+1`, 기지 수용량 `+2`이며 출시 수치는 밸런스 문서에서 재검증한다.

## 3. 도구와 자원 단계

### 3.1 채집 자격

1. 플레이어가 자원 가까이에 가면 해당 자원의 요구 도구와 단계를 확인한다.
2. 보유 단계가 요구 단계 이상이면 자동 목표로 선택하고 자원에 맞는 도구를 꺼낸다.
3. 보유 단계가 낮거나 도구가 없으면 자원의 내구도와 작업 진행은 변하지 않는다.
4. 이때 자원 위에 `필요: 곡괭이 2단계`처럼 부족한 도구·단계를 표시하고 대장간 방향을 안내한다.
5. 요구 단계를 충족한 뒤 같은 자원에 돌아오면 별도 장착 조작 없이 바로 채집할 수 있다.

요구 단계 미달 자원을 보이지 않는 벽으로 완전히 숨기지 않는다. 현재는 캘 수 없는 자원이 시야에 보이고,
대장간 강화가 다음 탐험 목표가 된다는 관계를 이해할 수 있어야 한다.

현재 확정된 자원 순서는 동굴 `돌 1 → 철 2 → 금 3 → 다이아 4`, 숲 `시작 나무 1 → 단단한 나무 2`다.
3단계 이상 나무의 이름과 수는 후속 범위이며, 공간 배치와 상세 상태는
[`world-layout-and-resource-progression.md`](world-layout-and-resource-progression.md)를 따른다.

### 3.2 작업 시간

- 각 자원은 자체 기본 작업 시간을 가진다. 상위 나무·광석일수록 기본 시간이 길다.
- 도구 단계가 요구 단계와 같으면 해당 자원의 기본 작업 시간을 사용한다.
- 도구 단계가 요구 단계보다 높으면 작업 시간이 줄어든다.
- 도구가 요구 단계보다 낮으면 시간을 늘려 억지로 채집하게 하지 않고 채집 자체를 막는다.
- 정확한 감소율과 최소 작업 시간은 플레이테스트 전까지 `검증 필요`이며
  [`progression-balance.md`](progression-balance.md)의 단일 수치 표에서 관리한다.

## 4. 상황별 도구 장착

- 플레이어는 이동·대기·운반 중 빈손이다. 도끼·곡괭이·무기를 등에 여러 개 노출하거나 빠른 선택 버튼을 두지 않는다.
- 나무 자동 행동이 시작되면 도끼가 손에 나타나고 벌목 동작이 끝나면 사라진다.
- 돌·광석 자동 행동이 시작되면 곡괭이가 나타나고 채광 동작이 끝나면 사라진다.
- 생물 자동 공격이 시작되면 현재 무기가 나타나고 전투가 끝나면 사라진다.
- 연속 행동에서는 매 타격 사이에 도구를 완전히 숨기지 않는다. 현재 목표가 유지되는 동안은 같은 도구와 자세를 이어 가고,
  목표를 잃거나 이동을 시작한 뒤 빈손으로 돌아간다.
- 도구의 외형은 현재 대장간 단계와 일치해야 한다. 판정에 쓰는 단계와 화면에 보이는 파츠가 달라서는 안 된다.

## 5. 초반 퍼널 연결

1. 동굴에서 깨어난 플레이어는 낡은 손도끼를 시작부터 소지한다. 이동할 때는 빈손으로 보이고 벌목할 때만 도끼를 든다.
2. 숲의 나무 가까이에 가면 손도끼가 나타나고, 목재를 모아 숲 장터 가판대를 짓고 두 번 판매한다.
3. 가판대 옆 적재칸에서 코인을 회수한 뒤 필요 코인과 네모 영역만 보이는 대장간 건설지로 안내한다.
4. 영역 안에서 코인 10개를 하나씩 투입해 대장간을 완성하면 첫 곡괭이가 생기고 돌 군락의 `필요: 곡괭이 1단계` 표시가 사라진다.
5. 돌 1개를 야영지 코어 건설 영역에 투입해 코어를 완성하면 체력·운반능력과 두 동료 수용량의 성장 경로가 보인다.
6. 이후 첫 생물 전투와 영입·재화 선택을 열고, 영입한 동료를 기지 작업 또는 탐험 전투원으로 배치한다.

첫 곡괭이의 정확한 코인 비용과 코어 활성화 비용은
[`progression-balance.md`](progression-balance.md#21-초반-퍼널-기본값)의 출시 기본값을 따른다.

## 6. 정상·예외·실패 확인 사례

| 구분 | 확인 상황 | 기대 결과 |
| --- | --- | --- |
| 정상 | 도끼 1단계로 요구 1단계 나무에 접근 | 도끼가 나타나 자동 벌목하고 완료 뒤 빈손으로 돌아간다 |
| 정상 | 곡괭이 2단계로 요구 1단계 돌을 채집 | 채집 가능하며 곡괭이 1단계보다 작업 시간이 짧다 |
| 정상 | 코어에서 운반능력 강화 | 등짐 한도만 늘고 도끼·곡괭이 단계는 유지된다 |
| 예외 | 곡괭이 없이 돌 군락에 접근 | 채광하지 않고 필요한 곡괭이 단계와 대장간 방향을 즉시 표시한다 |
| 예외 | 요구 3단계 광석에 곡괭이 2단계로 접근 | 진행률을 만들지 않고 `필요: 곡괭이 3단계`를 표시한다 |
| 실패 | 코인이 부족한 상태로 대장간 강화 시도 | 코인을 소비하지 않고 부족량과 현재 판매 목표를 표시한다 |
| 경계 | 연속으로 같은 나무를 타격 | 타격 사이에 도끼가 깜빡이지 않고 목표 종료 뒤에만 빈손으로 돌아간다 |
