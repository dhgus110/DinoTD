## 1. 게임 정의

### 1.1 한 줄 설명

플레이어가 개척지 방어대장이 되어 고지대 타워를 배치·재배치하고, 현장 채집 경제와 한 판 안의 카드 성장을 조합해 계절별 개척지로 몰려오는 공룡을 막는 가로형 2D 모바일 타워디펜스 게임이다.

### 1.2 제품 목표

- 목표 D1 리텐션: `40%`
- 목표 플레이 감각: 미드코어 전략
- 목표 스테이지 시간: `8~12분`
- 화면 방향: 가로
- 장기 콘텐츠 목표: 봄·여름·겨울·가을 4개 월드, 총 40개 스테이지
- 1차 개발·검증 범위: 봄·여름·겨울 3개 월드, 총 30개 스테이지
- 수익화: 사용하지 않음

D1 재방문율 40%의 동일 조건 사용자 집단 정의와 측정 도구는 별도 분석 기획에서 확정한다.

### 1.3 성장 원칙

- 영구 공격력, 영구 체력, 영구 경제 보너스와 반복 파밍형 아웃게임 성장을 만들지 않는다.
- 스테이지 클리어로 새로운 타워·건물·전술 선택지만 수평 해금한다.
- 해금된 타워는 이전 스테이지에서도 사용할 수 있다.
- 타워 강화, 궁극, 목재, 일꾼, 채집 효율, 방벽은 현재 판 안에서만 유지한다.
- 다음 맵 공개, 새 전술 해금, 새로운 타워 조합으로 이전 맵 재공략을 재방문 동기로 사용한다.

### 1.4 디자인 기둥

1. **배치보다 중요한 재배치**: 제한된 공간에서 타워 위치를 바꾸며 웨이브 변화에 대응한다.
2. **전투 중 완성되는 타워 조합**: 처치 경험치 카드와 알파 공룡 보상으로 매 판 다른 타워 조합을 만든다.
3. **현장 경제의 선택**: 목재를 타워 이동, 일꾼, 채집 효율, 방벽 중 어디에 사용할지 선택한다.
4. **한눈에 읽히는 지형과 위협**: 공룡 경로, 고지대, 타워 슬롯, 나무가 작은 모바일 화면에서도 즉시 구분된다.
5. **실력과 전략 중심**: 아웃게임 수치 성장 없이 맵 이해, 카드 선택, 재배치 판단으로 승리한다.

## 2. 플레이어 역할과 세계관

- 플레이어 역할은 공룡의 습격으로부터 정착지를 지키는 `개척지 방어대장`이다.
- 방어 목표는 `개척지 관문`이다.
- 공룡은 실제 종의 식별 가능한 실루엣을 유지하되 전투 역할에 맞게 속도, 체력, 장갑과 행동을 과장한다.
- 공룡 처치 후 타워를 얻는 규칙은 `알파 공룡 처치 → 건설 기회 확보 연출 → 건설 카드 선택`으로 표현한다.
- 공룡은 피와 절단 표현 없이 쓰러진 뒤 빠르게 사라지는 비유혈 카툰 연출로 퇴장한다.
- 목표 이용 연령은 클라이언트 개발 담당이 최소 Android 환경과 성능 기준을 정할 때 함께 결정한다.

## 3. 핵심 루프

### 3.1 스테이지 루프

1. 스테이지와 현재 해금된 타워를 확인한다.
2. 스테이지에 설정된 초기 건설권 수만큼 기본 타워를 선택해 빈 타워 슬롯에 배치한다.
3. 준비 완료 버튼으로 웨이브를 시작한다.
4. 타워가 자동 공격하고, 일꾼은 활성 웨이브 중 목재를 채집한다.
5. 처치 경험치가 가득 차면 카드 4장 중 1장을 선택해 타워 조합을 강화한다.
6. 알파 공룡을 처치하면 건설 카드 중 하나를 선택한다.
7. 웨이브 사이 정비 시간에 보유 목재로 타워 이동과 경제·방벽 관리를 한다.
8. 다음 웨이브를 수동으로 시작한다.
9. 마지막 웨이브 처리 후 라이프가 남으면 승리한다.

### 3.2 승리와 실패

- 기본 스테이지는 `8~10웨이브`로 구성한다.
- 모든 스테이지는 한 판을 라이프 `10`으로 시작한다.
- 모든 공룡은 개척지 관문 도달 시 라이프 `1`을 감소시키고 전장에서 제거된다.
- 마지막 웨이브의 모든 공룡이 처치되거나 관문 도달로 처리된 뒤 라이프가 `1 이상`이면 승리한다.
- 라이프가 `0`이 되는 즉시 실패한다.
- 실패 화면에는 도달 웨이브, 누수 공룡 등 전투 통계와 `즉시 재도전`, `로비로 이동` 버튼을 제공한다.

### 3.3 클리어 평가

| 등급 | 조건 |
| --- | --- |
| 브론즈 | 라이프가 남은 상태로 클리어 |
| 실버 | 라이프 5 이상을 유지하고 클리어 |
| 골드 | 라이프 손실 없이 클리어 |

- 다음 스테이지와 타워 해금에는 브론즈만 요구한다.
- 실버와 골드는 수치 성장 보상이 아닌 숙련·재도전 목표다.

## 4. 웨이브와 시간 제어

- 첫 웨이브와 이후 웨이브는 플레이어가 준비 완료 버튼으로 수동 시작한다.
- 전투 중 `1배`, `2배`, `일시정지`를 지원한다.
- 카드 선택 중에는 공룡, 타워, 일꾼과 모든 게임 시간을 완전히 정지한다.
- 건설 카드를 선택하면 타워 슬롯을 확정할 때까지 정지를 유지한다.
- 웨이브가 종료되면 시간 제한 없는 정비 상태로 전환한다.
- 정비 시간에는 공룡과 타워뿐 아니라 일꾼의 이동 및 채집 진행도 멈춘다.
- 이동 중이던 일꾼은 현재 위치에서 정지하고 다음 웨이브 시작 시 같은 작업을 이어간다.
- 정비 시간에는 이미 보유한 목재만 사용할 수 있다.

## 5. 맵과 카메라

### 5.1 상위 원칙

- 기본 화면에서 세로 방향의 공룡 경로, 고지대와 주요 전투 정보를 한눈에 구분할 수 있어야 한다.
- 카메라가 자동으로 움직이는 상황에도 플레이어가 직접 조작하면 즉시 조작권을 되찾아야 한다.

### 5.2 상세 규칙 원본

- 맵 배율, 카메라 이동 방향·경계, 공룡 경로, 출현 지점, 고지대와 화면 밖 알림의 세부 규칙은 `stage-map-rules.md`를 따른다.
- 화면 밖 알림을 선택했을 때의 카메라 이동과 플레이어 조작에 따른 취소 규칙도 `stage-map-rules.md`를 따른다.

## 6. 타워 배치와 이동

### 6.1 초기 배치

- 스테이지 데이터가 초기 건설권 수를 결정한다.
- 기본 타워는 건, 블레이드, 캐논, 파이어 타워다.
- `초기 배치 카드 세트`의 후보는 현재 스테이지 시작 시점까지 해금된 기본 타워 중 아래 주력 3종 제한을 충족하는 타워로 구성한다.
- 플레이어는 카드 한 장을 선택하고 빈 타워 슬롯에 설치한다.
- 설치가 끝나면 남은 초기 건설권 수만큼 같은 카드 세트를 다시 제시하고 선택·설치를 반복한다.
- 같은 기본 타워를 여러 번 선택할 수 있다.
- 활성 주력 타워가 3종 미만이면 해금된 기본 타워를 모두 표시한다.
- 활성 주력 타워가 3종에 도달하면 이미 활성화된 기본 타워만 표시하고 새로운 네 번째 종류는 제외한다.
- 초기 배치 카드 세트에는 새로고침과 카드 등급 확률을 적용하지 않는다.
- 1-1에서 건 타워만 해금되고 초기 건설권이 2개라면 건 타워 한 장만 있는 세트를 두 번 제시한다.
- 기본 타워 4종이 모두 해금되고 초기 건설권이 3개라면 매회 4종을 다시 표시하고 세 번 선택·설치한다.
- 초기 배치로 해당 타워 종류가 이번 판의 활성 주력 타워가 된다.

### 6.2 자동 공격

- 타워는 새 공격 대상을 선택할 때 사거리 안에서 관문에 가장 가까운 공룡을 우선한다.
- 플레이어가 선두·후미·강한 공룡과 같은 공격 대상 우선순위를 별도로 변경하는 기능은 제공하지 않는다.
- 공격 대상 유지, 피해·장갑 공식, 타워별 공격 판정과 상태 효과의 상세 규칙은 `combat-system-rules.md`를 따른다.

### 6.3 타워 이동

1. 이동할 타워를 탭한다.
2. `이동` 버튼을 선택한다.
3. 이동 가능한 빈 타워 슬롯을 강조한다.
4. 목표 슬롯을 선택하면 목재 비용과 이동 결과를 보여준다.
5. 이동 확인 버튼을 누르면 비용을 차감하고 즉시 이동한다.

- 이동에 별도 건설시간은 없다.
- 타워 판매와 기존 타워 덮어쓰기는 지원하지 않는다.
- 이동 비용은 밸런스 데이터로 관리한다.

## 7. 활성 타워 구성

- 사전 로드아웃은 사용하지 않는다.
- 초기 배치와 전투 중 건설 카드로 이번 판의 활성 타워 종류가 결정된다.
- 주력 타워는 한 판에 최대 `3종`, 보조 타워는 최대 `1종`이다.
- 주력 타워: 건, 블레이드, 캐논, 파이어, 레이저, 일렉트릭.
- 보조 타워: 독, 아이스.
- 전투 정보 화면에 활성 주력 `현재/3종`과 보조 `현재/1종`을 표시한다.
- 주력 제한에 도달하면 활성화되지 않은 새 주력 타워의 건설 카드를 카드 풀에서 제외한다.
- 아이스 또는 독을 건설하면 반대 보조 타워의 건설·능력 카드를 제외한다.
- 같은 종류의 업그레이드 효과는 현재 설치된 타워와 이후 건설되는 같은 종류 타워 모두에 적용한다.

## 8. 처치 경험치와 카드 선택

### 8.1 카드 세트 구분

| 카드 세트 | 발생 조건 | 카드 후보와 보장 |
| --- | --- | --- |
| 초기 배치 카드 세트 | 스테이지 시작 | 주력 3종 제한 안에서 해금된 기본 타워를 표시하고 스테이지에 설정된 초기 건설권 수만큼 순차 선택·설치 |
| 일반 카드 세트 | 처치 경험치 게이지 충족 | 건설·업그레이드 혼합 4장. 활성 주력 타워의 적용 가능한 업그레이드 1장 보장 |
| 알파 카드 세트 | 알파 공룡 처치 | 현재 건설 가능한 서로 다른 건설 카드를 최대 4장 표시 |

- 잠긴 타워의 카드는 모든 카드 세트 후보에서 제외한다.
- 초기 배치 카드 세트는 6.1의 순차 배치 규칙을 따른다.
- 일반 카드 세트와 알파 카드 세트는 서로 다른 발생 원인과 카드 풀을 사용한다.
- 카드 세트 생성, 후보, 확률, 새로고침, 궁극 확률 보정과 카드 대기열 처리의 공식 원본은 `card-draw-rules.md`다.

### 8.2 일반 카드 세트

- 공룡마다 처치 경험치 값을 가진다.
- 경험치 게이지가 가득 차면 전투를 정지하고 카드 4장 중 1장을 선택한다.
- 스테이지별 예정 일반 카드 선택 횟수는 `10~16회`로 설정한다.
- 경험치는 처치한 공룡에게서만 얻으며 누수된 공룡에게서는 얻지 않는다.
- 모든 공룡을 처치하면 예정 횟수를 정확히 달성하고 마지막 기준은 최종 웨이브 전에 달성할 수 있도록 경험치 요구량을 설계한다.
- 카드 세트에는 현재 조건에서 유효한 타워 건설 카드와 업그레이드 카드가 섞여 등장한다.
- 타워 건설 카드는 별도 목재 비용 없이 건설권으로 사용한다.
- 일반 카드 세트는 활성 주력 타워의 적용 가능한 업그레이드 카드 1장을 보장하며 건설 카드는 보장하지 않는다.
- 세부 추첨 순서와 확률은 `card-draw-rules.md`를 따른다.

### 8.3 알파 카드 세트

- 1-2 이후 모든 스테이지에 알파 공룡을 스테이지 데이터로 정한 고정 횟수만큼 배치한다.
- 알파 공룡은 기존 종의 크기, 색, 장식과 오라를 변경한 강화 변형이다.
- 알파 처치 시 전술 포인트 획득 연출 후 알파 카드 세트를 제시한다.
- 알파 카드 세트에는 현재 건설 가능한 타워의 건설 카드만 등장한다.
- 업그레이드 카드, 보조 능력 해금 카드와 궁극 카드는 알파 카드 세트에 등장하지 않는다.
- 빈 타워 슬롯이 없으면 알파 카드 세트를 추가 일반 카드 세트로 전환한다.
- 알파 출현 횟수는 빈 타워 슬롯이 있을 때 얻는 확정적인 추가 건설 기회의 수를 조절한다.
- 한 판의 최종 타워 수는 타워 슬롯 수와 일반 카드 세트·알파 카드 세트의 건설 카드 선택 결과가 함께 결정한다.

### 8.4 새로고침

- 한 판마다 무료 새로고침 `5회`를 제공하며 다음 판으로 이월하지 않는다.
- 새로고침 버튼에는 `고급 등급 등장 확률 증가`를 표시한다.
- 일반 카드 세트 화면당 최대 1회만 사용할 수 있다.
- 새로고침 뒤 첫 슬롯은 활성 주력 타워의 고급 등급 업그레이드 카드 1장을 보장한다.
- 새로고침 확률과 이전 세트 대비 카드 변경 규칙은 `card-draw-rules.md`를 따른다.

### 8.5 일반·고급 등급 업그레이드 카드

- 일반·고급 등급 업그레이드 카드의 공식 목록과 효과는 `tower-upgrade-card-spec.md`를 단일 원본으로 사용한다.
- 주력 타워마다 일반 3종, 고급 2종을 가진다.
- 일반·고급 등급 업그레이드 카드는 원칙적으로 무제한 반복 획득하며 같은 증가량이 선형 누적된다.
- 블레이드의 `칼날 크기 증가`와 각 보조 능력 해금 카드는 판당 1회 예외다.
- 개발자는 성능이나 밸런스를 이유로 임의 상한 또는 효율 점감을 추가하지 않고 검증 결과를 결정 항목으로 보고한다.

### 8.6 보조 타워 카드 흐름

- 아이스·독 건설 카드는 해당 타워 해금 이후 일반 카드 세트와 알파 카드 세트의 건설 후보에 포함한다.
- 보조 건설 카드는 타워 1개를 설치하지만 감속·중독 능력을 즉시 부여하지 않는다.
- 아이스는 `감속 능력 해금`, 독은 `중독 능력 해금` 카드를 사용한다.
- 능력 해금 카드는 일반 카드 세트의 고급 등급 업그레이드 카드 후보이며 보장하지 않는다.
- 능력 해금 전 보조 타워는 상태 효과가 없는 기본 공격만 수행한다.
- 능력 해금 카드는 판당 1회만 획득하고 선택 후 제거한다.
- 보조 종류가 확정된 뒤에도 같은 종류의 건설 카드는 유효한 빈 슬롯이 있는 동안 다시 등장할 수 있다.
- 남은 일반 카드 세트가 없는 시점에 보조 타워를 건설하면 능력을 자동 지급하지 않고 판 종료까지 기본 공격만 허용한다.
- 세부 카드 효과는 `tower-upgrade-card-spec.md`, 카드 풀 처리는 `card-draw-rules.md`를 따른다.

## 9. 궁극 카드

### 9.1 등장 자격과 확률

- 타워 궁극 시스템은 주력 타워 6종에만 적용한다.
- 활성화된 주력 타워는 별도 선행 강화 없이 즉시 궁극 후보가 된다.
- 궁극은 타워마다 2개 중 하나만 선택할 수 있다.
- 한 궁극을 획득하면 반대 궁극은 해당 판의 카드 풀에서 제외한다.
- 한 판에 타워 궁극 평균 `2장`을 목표로 하며 정확히 2장을 강제하지 않는다.
- 궁극 교체 확률, 최대 표시 수와 누적 궁극 확률 보정은 `card-draw-rules.md`를 따른다.

### 9.2 타워별 궁극

| 타워 | 궁극 A | 궁극 B |
| --- | --- | --- |
| 건 | 오버드라이브 | 도탄 탄환 |
| 블레이드 | 칼날 폭풍 | 귀환 칼날 |
| 캐논 | 집속탄 | 공성탄 |
| 파이어 | 화염 폭풍 | 전염 화상 |
| 레이저 | 프리즘 광선 | 과충전 광선 |
| 일렉트릭 | 연쇄 폭풍 | 과부하 |

- 궁극 12종의 발동 조건, 대상, 수치, 중첩, 종료와 실패·예외 처리는 `ultimate-card-spec.md`를 단일 원본으로 사용한다.

### 9.3 전술 궁극

- `가시 방벽`: 현재 및 이후 건설되는 모든 방벽이 인접한 공룡에게 초당 피해를 준다.
- 1-7에서 방벽 시스템이 열린 뒤부터 등장한다.
- 특정 타워 선행 강화가 필요 없는 별도 전술 궁극이다.
- 타워 궁극 평균 2장 계산에는 포함하지 않는다.
- 주력 궁극과 같은 궁극 교체 확률을 사용하지만, 등장하거나 선택돼도 주력 궁극 확률 보정을 초기화하지 않는다.
- 현재 설치된 방벽이 없어도 등장할 수 있으며 선택 후 같은 판의 궁극 후보에서 제거한다.
- 후보 선택, 한 화면 표시 제한과 궁극 확률 보정 처리의 공식 원본은 `card-draw-rules.md`다.
- 방벽이 공격 타워를 대체하지 않도록 피해량을 플레이테스트한다.

## 10. 목재와 채집 경제

### 10.1 해금과 기본 상태

- 채집 경제는 1-5 시작 시 해금한다.
- 1-5부터 스테이지 시작 시 채집 건물 1개와 일꾼 1명을 기본 제공한다.
- 전투 내 자원은 `목재` 한 종류다.
- 목재와 모든 경제 강화는 판 종료 시 초기화한다.

### 10.2 나무와 일꾼

- 나무 수와 위치는 스테이지마다 다르게 데이터로 설정한다.
- 나무는 채집해도 고갈되지 않는다.
- 나무 한 그루에는 동시에 일꾼 한 명만 배정된다.
- 일꾼은 비어 있는 나무를 자동 탐색하고 채집 건물과 나무 사이를 왕복한다.
- 일꾼을 직접 선택하거나 목적지를 지정할 수 없다.
- 일꾼 동선은 고지대에 있어 공룡과 마주치지 않으며 공격·사망 대상이 아니다.
- 일꾼 최대 수는 해당 스테이지의 활성 나무 수와 같다.
- 최대 수에 도달하면 고용 버튼을 비활성화하고 `채집 가능한 나무가 없습니다`라고 표시한다.

### 10.3 채집 건물

- 플레이어는 일꾼이 아니라 채집 건물을 탭해 경제 화면을 연다.
- 목재를 사용해 일꾼 수와 채집 효율을 강화한다.
- 목재는 타워 이동, 일꾼 추가, 채집 효율 강화, 방벽 설치·강화·재건에 사용한다.
- 최대 일꾼 수, 운반량, 이동 속도, 채집시간, 강화 단계와 비용은 `economy-barricade-rules.md`를 따른다.

## 11. 방벽

- 방벽은 공룡 경로 위의 전용 방벽 슬롯에만 목재로 설치한다.
- 공룡은 방벽을 만나면 경로를 다시 찾지 않고 방벽을 공격한다.
- 방벽을 파괴한 공룡은 기존 경로를 따라 계속 이동한다.
- 방벽 체력과 강화 상태는 현재 판의 다음 웨이브에도 유지된다.
- 파괴된 방벽 슬롯에는 목재로 다시 건설할 수 있다.
- 방벽 설치와 재건은 정비 시간에만 허용하고, 방벽 전역 강화는 전투와 정비 시간 모두 허용한다.
- 방벽 비용, 체력, 전역 단계와 공룡별 방벽 피해는 `economy-barricade-rules.md`를 따른다.

## 12. 월드와 스테이지

### 12.1 명명 체계

- 앞 숫자는 월드, 뒤 숫자는 월드 안의 스테이지를 뜻한다.
- 봄 월드: `1-1~1-10`
- 여름 월드: `2-1~2-10`
- 겨울 월드: `3-1~3-10`
- 가을 월드: `4-1~4-10`이며, 1차 개발·검증 결과에 따라 제작 여부를 결정한다.

### 12.2 개발 범위

- 제품 비전은 사계절 4개 월드·40개 스테이지다.
- 1차 개발·검증 기준은 봄·여름·겨울 3개 월드·30개 스테이지다.
- 30개 스테이지의 완성도, D1 재방문율, 완료율과 제작 속도를 확인한 뒤 가을 월드 제작 여부를 결정한다.
- 개발 AI는 40개 스테이지 제품 비전과 30개 스테이지 1차 범위를 임의로 변경하거나 하나로 혼용하지 않는다.

### 12.3 봄 월드 학습 순서

| 스테이지 | 시작 시 해금·학습 |
| --- | --- |
| 1-1 | 건 타워, 초기 배치, 수동 웨이브, 일반 카드 세트 |
| 1-2 | 블레이드 타워, 군집 공룡, 알파 공룡과 건설 카드 |
| 1-3 | 캐논 타워, 밀집·장갑 공룡 |
| 1-4 | 파이어 타워, 타워 이동과 빈 슬롯 활용 |
| 1-5 | 채집 건물, 일꾼, 목재 채집과 타워 이동 비용 |
| 1-6 | 일꾼 추가와 채집 효율 강화 |
| 1-7 | 방벽 설치·강화·파괴·재건, 가시 방벽 |
| 1-8 | 레이저 타워, 첫 2경로 맵 |
| 1-9 | 독 보조 타워, 경제·방벽·재배치 응용 |
| 1-10 | 아이스 보조 타워, 봄 월드 보스 공룡과 종합 시험 |
| 2-1 | 일렉트릭 타워와 여름 환경 소개 |

- 각 타워는 표에 적힌 스테이지 시작 시 해금된다.
- 1-1은 건 타워 하나만으로 쉽게 클리어할 수 있어야 한다.
- 봄 월드는 기능 학습이 우선이며 높은 실패율을 의도하지 않는다.

## 14. 화면 구성과 피드백

### 14.1 전투 정보 화면

- 라이프
- 현재 웨이브 / 전체 웨이브
- 처치 경험치 게이지
- 보유 목재
- 활성 주력 타워 `현재/3종`
- 활성 보조 타워 `현재/1종`
- 카드 새로고침 잔여 횟수
- 다음 웨이브 시작
- 1배 / 2배
- 일시정지

### 14.2 선택과 상태 표시

- 타워, 빈 타워 슬롯, 채집 건물, 방벽 슬롯은 서로 다른 선택 외곽선과 강조색을 사용한다.
- 선택 불가능한 슬롯과 카드에는 불가능한 이유를 표시한다.
- 목재 부족, 주력 종류 제한, 보조 종류 확정, 일꾼 상한을 구체적인 문구로 알린다.
- 알파 공룡과 개척지 관문 누수 위험은 화면 밖에서도 식별 가능한 경고를 제공한다.
- 궁극 카드 등장은 맵 방향 알림에서 제외하고 카드 선택 화면의 전용 연출과 소리로 알린다.
- 화면 밖 알림에서 `중요 보상`으로 분류할 사건은 이 문서가 소유하며, 현재 정의된 중요 보상 사건은 없다.

## 15. 저장과 앱 생명주기

- 전투 정보 화면의 일시정지는 공룡, 타워, 일꾼, 투사체, 상태 효과와 웨이브 타이머를 모두 멈춘다.
- 앱이 백그라운드로 이동하면 자동으로 일시정지한다.
- 앱 프로세스가 유지되면 정지한 같은 순간부터 재개한다.
- 앱이 완전히 종료되면 현재 웨이브 시작 상태에서 복원한다.
- 카드 선택 중 앱이 종료되면 카드 선택 발생 전의 웨이브 체크포인트로 복원한다.
- 웨이브 체크포인트에 저장할 정확한 상태와 저장 시점은 저장 기능 명세에서 확정한다.

## 16. 아트 방향

- 시점: 탑다운 3/4뷰
- 스타일: 모험적 카툰
- 공룡: 실제 실루엣을 알아볼 수 있게 유지하고 역할에 맞게 특징을 과장
- 지형: 낮은 경로와 높은 건설 지형의 단차를 명확히 표현
- 계절: 팔레트, 식생, 지형, 날씨와 환경 장식으로 월드를 차별화
- 알파: 기존 공룡보다 큰 크기, 차별화된 색, 장식과 오라 사용
- 카드: 일반·고급·궁극의 프레임과 등장 연출을 명확히 구분

## 17. 사운드 방향

- 음악은 모험 오케스트라와 원시 타악을 기반으로 한다.
- 계절마다 악기와 리듬을 변주한다.
- 공룡 접근, 알파 등장, 카드 선택, 궁극 획득, 목재 운반 완료, 타워 이동, 방벽 피격·파괴, 라이프 손실에 구별되는 효과음을 사용한다.
- 화면 밖 중요 사건은 방향 표시와 함께 음향으로도 경고한다.

## 18. 분석 이벤트

최소한 다음 행동과 결과를 기록한다.

- 앱 최초 실행
- 스테이지 노출·선택·시작
- 웨이브 시작·종료
- 스테이지 승리·실패·중도 이탈
- 실패 후 재도전 또는 로비 복귀
- 카드 세트 노출·선택·새로고침
- 일반·고급·궁극 카드 획득
- 알파 처치와 건설 카드 선택
- 타워 건설·이동
- 일꾼 추가·채집 효율 강화
- 방벽 설치·강화·파괴·재건
- 백그라운드 전환과 웨이브 복원

이벤트에는 가능한 경우 스테이지, 웨이브, 타워, 카드, 전후 목재, 라이프, 실패 이유를 포함한다.

## 19. 검증 필요

- 카드 선택 10~16회가 전투를 지나치게 자주 끊지 않는지 확인한다.
- 카드 선택 10~16회, 누적 궁극 확률 보정과 새로고침 5회를 함께 적용한 정확 확률 계산은 완료됐다. 실제 카드 생성 결과가 `card-draw-rules.md`의 분포와 일치하는지 확인한다.
- 무제한 선형 카드 누적이 HTML5 모바일 성능과 전투 가독성에 미치는 영향을 측정한다.
- 맵 크기, 카메라 조작과 화면 밖 사건 인지에 관한 세부 검증은 `stage-map-rules.md`를 따른다.
- 정비 시간 채집 정지가 전략적 정비를 방해하지 않으면서 무한 대기를 막는지 확인한다.
- 나무 수, 일꾼 수, 목재 생산량과 소비 비용이 의미 있는 경제 선택을 만드는지 확인한다.
- 주력 3종·보조 1종 제한이 카드 풀과 타워 조합 다양성에 적합한지 확인한다.
- 봄 월드의 기능 도입 순서와 1-1 난이도가 신규 플레이어에게 적절한지 확인한다.
- 골드·실버 조건이 특정 타워 조합만 강요하지 않는지 확인한다.

## 20. 미정 사항

- HTML5 게임 프레임워크와 네이티브 래퍼
- 최소 Android OS, 화면비와 성능 기준 기기
- 여름 월드 2-1~2-10의 맵 기믹과 공룡 구성
- 겨울 월드 3-1~3-10의 맵 기믹과 공룡 구성
- 가을 월드 제작 판단에 사용할 30개 스테이지의 완성도·완료율·제작 속도 기준
- `Dino TD`의 Google Play·상표 중복 검증
- 목표 이용 연령

### 20.1 클라이언트 개발 담당 결정

- HTML5 게임 프레임워크와 네이티브 래퍼
- 최소 Android OS와 지원 화면비
- 대표 성능 기준 기기와 목표 초당 화면 표시 횟수(프레임)
- 비유혈 카툰 처치 표현을 기준으로 한 목표 이용 연령
- 결정 결과는 전투 가독성·무제한 카드 누적 성능 검증과 Google Play 출시 조건에 반영한다.

### 20.2 다음 콘텐츠 세션 인계

- 여름 월드는 2-1의 일렉트릭 타워 해금부터 2-10까지 맵 기믹, 공룡 구성, 웨이브, 경제 시작값과 예정 일반 카드 선택 횟수를 정한다.
- 겨울 월드는 3-1~3-10의 맵 기믹, 공룡 구성, 웨이브, 경제 시작값과 예정 일반 카드 선택 횟수를 정한다.
- 다음 콘텐츠 세션은 `combat-system-rules.md`, `card-draw-rules.md`, `economy-barricade-rules.md`, `stage-map-rules.md`의 공통 규칙과 수치를 변경하지 않고 콘텐츠 입력값만 작성한다.
- 봄 월드는 콘텐츠 명세가 완료됐지만 플레이테스트와 클라이언트 성능 검증은 완료되지 않았다. 여름·겨울 제작 시 봄 검증 결과로 공통 규칙을 바꿔야 한다면 먼저 사용자 승인을 받는다.

## 21. 개발 AI 적용 규칙

- 이 문서의 확정 규칙을 임의로 변경하지 않는다.
- 세부 일반·고급 등급 업그레이드 카드 효과는 `tower-upgrade-card-spec.md`를 우선한다.
- 궁극 카드 12종의 상세 효과는 `ultimate-card-spec.md`를 우선한다.
- 카드 생성, 확률, 새로고침, 궁극 확률 보정과 카드 대기열 규칙은 `card-draw-rules.md`를 우선한다.
- 공격 대상, 피해·장갑 공식, 타워별 기본 공격, 상태 효과, 방벽 전투와 동시 결과 우선순위는 `combat-system-rules.md`를 우선한다.
- 맵 배율, 카메라 이동 방향·경계, 공룡 경로, 배치 구획과 화면 밖 알림 규칙은 `stage-map-rules.md`를 우선한다.
- 목재 획득·소비, 일꾼, 채집 효율과 방벽 수치는 `economy-barricade-rules.md`를 우선한다.
- 봄 월드 스테이지별 콘텐츠는 `spring-stage-content.md`를 우선한다.
- 미정 값을 구현에 필요해 임시로 정할 경우 `가정`임을 표시하고 선택 이유를 기록한다.
- 밸런스와 성능 문제가 발견돼도 확정 규칙에 숨겨진 상한이나 예외를 추가하지 않는다.
- 변경 제안은 현재 규칙, 발견한 문제, 선택지, 추천안과 영향 범위를 함께 제시해 승인받는다.
- 40개 스테이지 제품 비전과 30개 스테이지 1차 개발·검증 범위를 구분한다.
