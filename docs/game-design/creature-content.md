## 2. 공통 콘텐츠 규칙

### 2.1 능력치와 공격

- 생물은 체력·공격력·운반능력만 개별 수치로 가진다.
- 각 종은 근접 또는 원거리 기본 공격 하나만 사용하며 별도 고유 능력·상태 이상·방어력은 없다.
- 공통 이동 속도와 근접·원거리 공격 간격·사거리·판정은
  [`exploration-combat.md`](exploration-combat.md#8-전투)를 따른다.
- 표의 `선호 결과`는 해당 역할을 맡았을 때 보정되는 능력치만 보여 준다. 다른 능력치는
  기본값을 유지한다.

### 2.2 태도와 무리

- 중립 생물은 먼저 공격하지 않는다. 한 마리를 공격하면 함께 다니는 같은 종 무리 전체가
  적대 상태로 바뀌어 반격한다.
- 적대 생물, 엘리트와 보스는 플레이어 측을 감지하면 먼저 공격한다.
- 일반·엘리트 무리의 추적 경계와 복귀 상태는
  [`exploration-combat.md`](exploration-combat.md#83-무리-반격과-추적-경계)를 따른다.
- 마지막 개체의 영입·재화 결과가 끝난 뒤 등급별 재등장 시간이 지나면 같은 종의 새 무리
  전체가 원래 무리 구역에 나타난다.

### 2.3 등급별 보상

각 종은 표의 보상 등급을 사용하며 개별 보상 변경은 없다. 뼈·소울 수량, 확률과 지급 경계는
[`creatures-and-recruitment.md`](creatures-and-recruitment.md#31-등급별-확률과-보상)의 단일 원본을 따른다.

## 6. 콘텐츠 진행과 상태 경계

1. 지역에 진입하면 거리 구간에 맞는 생물 무리를 발견한다.
2. 태도에 따라 먼저 공격받거나, 중립 무리를 공격할지 선택한다.
3. 전투는 종별 기본 공격 하나와 공통 전투 판정으로 진행한다.
4. 마지막 개체까지 쓰러뜨리고 각 결과를 처리하면 무리 재등장 시간이 시작된다.
5. 영입한 생물은 같은 기본 능력치와 선호 역할을 가진 동료가 된다.

일반·엘리트 무리의 체력·적대 유지와 초기화, 보스 체력 유지, 포탈 이동과 재등장은
[`exploration-combat.md`](exploration-combat.md)의 원본 규칙을 따른다. 영입·재화 결과와 수용량
실패는 [`creatures-and-recruitment.md`](creatures-and-recruitment.md)를 따른다.

## 7. UI·시각·사운드 표현

- 이름, 등급, 태도, 현재·최대 체력, 공격 방식과 선호 역할을 아이콘·윤곽·문구로 구분한다.
- 중립 생물은 먼저 공격하지 않는 느슨한 이동, 적대 생물은 몸 방향과 경고 소리로 태도를
  미리 알린다.
- 근접 공격은 몸을 당기는 동작과 짧은 충돌음, 원거리 공격은 1초 예고와 발사음을 사용한다.
- 일반·엘리트·보스는 몸집·윤곽 장식·이름표 모양과 소리를 함께 달리한다.
- 피·절단·상처 없이 빛·먼지·잎·수정 파편으로 공격과 피격을 표현한다.
- 쓰러진 생물은 숨을 고르며 남고 결과 선택 뒤 빛으로 사라진다.
- 보스 이름과 보금자리 경고는 위험 소리와 화면 방향 표시를 함께 사용한다.

## 9. 검증 필요

- 동굴·숲 각 5회 이상 탐험에서 근·중·원거리의 무리 수가 빈 이동과 과도한 연속 전투를
  만들지 않는지 확인한다.
- 일반·엘리트 각 3회, 보스 각 1회 이상 전투해 체력·공격력과 근접·원거리 공격 시간이
  플레이어 성장에 맞는지 확인한다.
- 외형을 3초 보여 준 뒤 이름·태도·근접 또는 원거리를 구분할 수 있는지 5명 이상에게 묻는다.
- 선호 역할 결과를 비교해 16종 모두 적어도 한 역할에서 영입 이유가 있는지 확인한다.
- 플레이어 운반능력 최대 45와 생물 운반능력을 함께 사용할 때 귀환·작업 선택이 사라지지 않는지
  확인한다.
- 보스 체력 800·900과 공격력 24가 동료 편성과 재도전을 요구하되 반복 대기만 만들지 않는지
  확인한다.

## 10. 결정 정리와 변경 기록
