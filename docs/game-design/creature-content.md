> 규칙 소유 범위: 동굴·숲 각 일반 5종, 엘리트 2종, 보스 1종의 콘텐츠 차별점과 종별 수치·보상

## 1. 문서 목적과 범위

이 문서는 출시 생물 16종을 플레이어가 서로 다른 행동과 역할 선택으로 느끼도록 정의하는
콘텐츠의 단일 원본이다. 동굴과 숲에 각각 일반 5종, 엘리트 2종, 보스 1종을 배치한다. 영입
확률·선택 제한·수용량·역할 보정은 [`creatures-and-recruitment.md`](creatures-and-recruitment.md)가
소유하고, 플레이어의 공통 피해·패배·카메라·재등장 규칙은 [`exploration-combat.md`](exploration-combat.md)가
소유한다.

### 포함

- 16종의 이름, 지역과 등급
- 실루엣·색·빛·소재 중심의 외형
- 중립·적대 태도와 지역별 행동
- 체력, 공격력, 공격 간격, 이동 속도, 운반력
- 탐험·작업·방어 적성 등급
- 고유 능력과 공격 전 텔레그래프
- 재화 선택 시 종별 뼈·소울 보상
- 정상·예외·실패 확인 사례와 콘텐츠 표현 수위

### 제외

- 코드, 자료형·데이터 컬럼·식별자
- 생물 스폰·전투·영입의 공통 알고리즘
- 별도 도감 보너스, 계정 성장, 유료 콘텐츠
- 생물의 종별 저장 구조와 분석 이벤트

## 2. 공통 수치와 설계 기준

### 2.1 능력치 단위

| 능력치 | 단위 | 의미 | 적용 원본 |

| 공격력 | 피해/회 | 기본 공격이 한 번에 주는 피해 | 공통 전투는 [`exploration-combat.md`](exploration-combat.md) |

| 운반력 | 자원 단위 | 탐험 동료가 공유 등짐에 더하거나 일꾼이 한 번에 옮기는 기본 수량 | 역할 보정은 [`creatures-and-recruitment.md`](creatures-and-recruitment.md) |

모든 능력치는 출시 시작값이며 `검증 필요`다. 체력·공격력·운반력은 정수로 표시하고, 이동
속도·공격 간격은 소수 둘째 자리까지 표시한다. 실제 피해는 공통 전투의 정수 피해 규칙을
따른다. 생물별 방어력은 사용하지 않는다.

### 2.2 공통 등급 보상

아래 표는 `재화`를 선택했을 때의 종별 기본 보상 원본이다. 소울을 얻을 확률과 영입 기회는
[`creatures-and-recruitment.md`](creatures-and-recruitment.md)의 등급 규칙을 함께 적용한다.

| 등급 | 재화 선택 시 뼈 | 재화 선택 시 소울 | 소울 추첨 확률 | 영입 선택 시 |
| --- | ---: | ---: | --- | --- |
| 일반 생물 | 2개 | 성공 시 1개 | [`creatures-and-recruitment.md`](creatures-and-recruitment.md) 참조 | 뼈·소울 없음 |
| 엘리트 생물 | 5개 | 성공 시 2개 | [`creatures-and-recruitment.md`](creatures-and-recruitment.md) 참조 | 뼈·소울 없음 |
| 보스 생물 | 12개 | 4개 | [`creatures-and-recruitment.md`](creatures-and-recruitment.md) 참조 | 뼈·소울 없음 |

영입 기회가 없을 때는 재화 선택을 자동 적용한다. 재화 보상은 등짐으로 받으며, 소울은
획득 즉시 안전 자원으로 보관한다. 방어·오프라인 결과에서는 뼈와 소울을 안전 자원으로
직접 보관하는 코어 규칙을 따른다.

### 2.3 콘텐츠 흐름과 상태 경계

1. 플레이어가 동굴·숲에 진입하면 해당 지역의 일반·엘리트 생물과 고정 보스 보금자리를
   발견한다. 생물의 태도와 등급은 외형·동작·표시명으로 구분한다.
2. 생물이 자동 목표가 되어 전투가 끝나면 생물 등급과 고유 능력의 결과를 확인한다.
3. 영입 기회가 있으면 `영입` 또는 `재화`를 선택하고, 없으면 재화 결과를 자동 적용한다.
4. 영입 시 기지 수용량·동행 수용량을 사용하고, 재화 시 종별 뼈와 등급별 소울 결과를 받는다.
5. 결과가 끝난 생물은 사라지고, 정해진 재등장 시간이 지난 뒤 같은 지역에 다시 나타난다.

콘텐츠 안의 선택 우선순위는 `적대 생물 → 중립 생물 → 자원`이라는 자동 목표 규칙을 따르며,
영입 기회가 있어도 수용량이 가득 차면 영입을 선택할 수 없다. 재화 보상의 뼈를 등짐에 넣지
못할 때의 현장 드롭·회수·패배 처리는 [`creatures-and-recruitment.md`](creatures-and-recruitment.md)가
소유한다. 플레이어 패배 시 콘텐츠 결과는 재화로 정리되고, 이미 안전 자원이 된 소울은
유지된다. 종별 생물은 이 문서의 외형·행동·능력치·적성·보상 원본을 벗어나지 않는다.

화면에는 생물 이름·등급·태도·체력·고유 능력의 예고를 표시하고, 쓰러진 뒤에는 영입 기회·수용량·
재화 보상을 표시한다. 색상만으로 등급·태도·영입 가능 여부를 구분하지 않으며, 세부 선택
피드백은 [`creatures-and-recruitment.md`](creatures-and-recruitment.md)의 UI 규칙을 따른다.

## 4. 콘텐츠 역할과 선택 차이

| 콘텐츠 묶음 | 플레이어가 느낄 차이 | 영입했을 때 강점 | 위험 또는 비용 |

생물의 강점은 한 역할을 영구 강제하지 않는다. 영입 후 역할을 기지에서 바꿀 수 있으므로
플레이어는 같은 생물을 탐험·생산·방어에 시험해 볼 수 있다. 보스 생물도 여러 마리 영입할 수
있지만, 보스 보금자리 재등장 시간과 영입 선택 기회를 함께 고려해야 한다.

## 5. 표현과 연출 기준

- 모든 생물은 피·절단·시체 대신 빛, 잎, 먼지, 수정 파편과 몸의 움직임으로 공격·피격·쓰러짐을
  전달한다.
- 중립 생물은 먼저 공격하지 않는 행동을 몸을 낮추거나 옆으로 비키는 동작으로 표현한다.
- 적대 생물은 눈빛·몸 방향·바닥 윤곽과 짧은 소리를 함께 사용해 먼저 공격한다는 것을 알린다.
- 엘리트는 일반 생물보다 외곽 빛과 발자국 소리를 분명하게 하고, 보스는 보금자리의 환경
  빛·울림·바닥 문양으로 지역의 중심이라는 느낌을 준다.
- 고유 능력은 실제 피해 영역과 같은 모양의 텔레그래프를 먼저 보여 준다. 텔레그래프는
  최소 0.8초 이상 유지하며 보스 능력은 1초로 한다.
- 보스의 체력 회복·피해 감소는 초록색 막대만으로 알리지 않고 `수정 장막`, `숲의 맥` 문구와
  빛의 변화로 함께 표시한다.

## 6. 수치 검증과 조정 기준

아래 값은 출시 기본값으로 구현 가능하지만, 사용자의 플레이 검증을 거치기 전까지 `검증 필요`다.
조정할 때 생물의 역할 정체성을 바꾸지 않고 다음 우선순위를 따른다.

1. 플레이어가 일반 생물의 태도와 공격 예고를 5초 안에 이해하는지 확인한다.
2. 일반 생물 처치 시간이 플레이어 혼자 20초 안에 들어오는지 확인한다.
3. 탐험 동료 1명과 함께 엘리트 생물을 상대할 때 공격 예고를 읽고 회피할 시간이 있는지 확인한다.
4. 보스는 혼자 무리하게 처치하는 대상이 아니라 동료 구성과 귀환 판단을 요구하는지 확인한다.
5. 운반력과 적성이 영입 선택의 이유가 되되, 높은 전투 수치 하나로 모든 역할을 대체하지 않는지
   확인한다.

플레이테스트는 동굴·숲 각 5회 이상 탐험, 일반·엘리트 각 3회 이상 전투, 보스 각 1회 이상
전투를 기준으로 한다. 관찰 질문은 `어떤 생물이 먼저 공격했는가`, `어떤 능력이 언제 발동했는가`,
`이 생물을 어느 역할로 쓰고 싶은가` 세 가지로 통일한다.

## 8. 결정 정리와 변경 기록

### 담당 범위에 반영한 확정

- 동굴·숲 각 일반 5종, 엘리트 2종, 보스 1종으로 총 16종을 구성한다.
- 모든 생물은 체력·공격력·이동 속도·운반력과 탐험·작업·방어 적성을 가진다.
- 일반·엘리트·보스의 보상·소울 확률과 보스의 고정 보금자리를 사용한다.
- 중립·적대 태도와 비고어 자연 판타지 표현을 사용한다.

### 사용자 승인으로 확정한 출시 기본값

- 16종의 출시 이름과 세부 외형·행동·능력·수치
- 등급별 뼈·소울 보상과 고유 능력의 시작 수치
- 모든 고유 공격의 최소 0.8초 텔레그래프와 보스 능력의 1초 예고

### 검증 필요

- 16종 수치의 전투 시간, 운반력·적성의 경제 영향, 보스 난이도와 재등장 체감
- 이름과 외형의 현지화 가능성, 최종 색상·모델·사운드 적합성
- 고유 능력의 이해 가능성, 범위 표시와 비고어 표현의 수용성

담당 출시 범위에는 `미정`을 남기지 않았다. 생물 이름은 사용자 승인으로 확정했으며 공식
용어집에 등록한다. 이름을 바꿀 필요가 생기면 이 문서와 관련 표시 문구·공식 용어집을 함께
갱신한다.
