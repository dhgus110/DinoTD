# Dino TD 전체 게임 리소스 제작 목록

> 문서 상태: 검토 중
>
> 목적: 현재 기획에서 확인되는 아트·화면·효과음·음악 리소스를 한곳에서 제작 순서대로 확인한다.
>
> 확정 범위: 공통 시스템, 봄 월드 제작 방향, 여름 월드 콘텐츠와 환경 방향
>
> 미정 범위: 여름 월드 실제 제작 명세, 겨울 월드 콘텐츠·제작 명세, 최종 화면 설계, 최종 아트 제작 규격
>
> 제품 범위 원본: `jurassic-tower-defense-gdd.md`
>
> 봄 제작 원본: `spring-world-production-spec.md`
>
> 공식 용어 기준: `terminology.md`

## 1. 문서의 역할과 원본 경계

이 문서는 여러 기획 문서에 흩어진 리소스 수요를 제작 체크리스트로 모은 파생 문서다. 게임 규칙,
수치, 카드 효과와 스테이지 배치는 각 원본 문서가 계속 소유한다. 원본 규칙이 바뀌면 이 목록의
수량·상태·우선순위도 함께 확인한다.

### 1.1 포함

- 월드·맵·공룡·타워·경제 시설·전투 효과의 시각 리소스
- 카드·전투 정보 화면·튜토리얼·결과 화면의 화면 리소스
- 음악·환경음·전투·경제·화면 효과음
- 생성 원본, 편집 원본, 내보내기 결과와 제작 기록
- 첫 플레이 가능한 버전부터 전체 제품까지의 제작 우선순위

### 1.2 제외

- 게임 규칙과 밸런스 수치의 재정의
- 실제 파일명, 폴더 구조, 아틀라스 형식과 엔진 좌표
- 이미지 생성 서비스의 내부 구현과 인증 방식
- 아직 기획하지 않은 겨울 월드의 구체적인 공룡·지형·음악 목록
- 여름 월드의 확정되지 않은 실제 경로·상대 배치·튜토리얼·화면 문구

프레임 수, 변형 재사용 방식과 음악 전환 방식이 정해진 뒤 확정한다.

## 3. 공통 아트 제작 기준

### 3.1 확정

- 시점은 탑다운 3/4뷰다.
- 스타일은 모험적 카툰이다.
- 공룡은 실제 종을 알아볼 수 있는 실루엣을 유지하고 전투 역할에 맞게 특징을 과장한다.
- 공룡 퇴장은 피와 절단 없이 쓰러진 뒤 빠르게 사라지는 비유혈 카툰 표현을 사용한다.
- 낮은 공룡 경로와 높은 고지대는 색뿐 아니라 높이·외곽선·절벽 측면으로 구분한다.
- 중요한 선택·위협 상태는 색만으로 구분하지 않고 형태·외곽선·무늬·움직임 차이를 함께 사용한다.
- 세로 화면의 18×18타일 전장 프로토타입에서 공룡, 타워, 슬롯과 공격 효과를 구분할 수 있어야 한다.
- 장식은 공룡 경로, 타워 슬롯, 방벽 슬롯, 나무, 공격 판정과 화면 밖 알림보다 낮은 시각적
  우선순위를 사용한다.

### 3.2 최종 제작 전에 결정할 항목

| 항목 | 현재 상태 | 결정이 필요한 이유 |
| --- | --- | --- |
| 픽셀아트 또는 고해상도 2D 일러스트 | 미정 | 타일·스프라이트 제작법, 축소 필터와 외곽선 규칙이 달라진다. |
| 기준 타일·캐릭터 작성 크기 | 미정 | 1타일의 실제 픽셀 크기와 공룡·타워의 화면 점유 크기를 고정해야 한다. |
| 공룡·일꾼 이동 방향 수 | 미정 | 4방향·8방향 또는 좌우 반전 사용에 따라 원화와 애니메이션 수가 달라진다. |
| 동작별 프레임 수와 초당 프레임 | 미정 | 이동·공격·피격·처치의 제작량과 모바일 성능에 영향을 준다. |
| 카드·화면 최종 화면 설계 | 미정 | 아이콘 안전 영역, 글자 영역, 9분할 패널과 버튼 규격을 확정해야 한다. |
| 한글 글꼴과 사용권 | 미정 | 튜토리얼·카드·결과 화면의 실제 제작과 배포에 필요하다. |
| 색각·명암 기준 | 검증 필요 | 상태를 색 외 요소로도 구분하는지 실제 기기에서 확인해야 한다. |

결정 전에는 콘셉트 탐색과 프로토타입용 임시 리소스까지만 제작한다. 최종 스프라이트 묶음과 전체
카드 일러스트 양산은 위 항목을 확정한 뒤 시작한다.

## 4. 월드·맵 리소스

### 4.1 공통 맵 구성

| 제작 대상 | 필요한 상태·변형 | 전달해야 할 정보 |
| --- | --- | --- |
| 낮은 공룡 경로 | 직선, 굽이, 대각선, 합류 전·후 연결부 | 공룡 이동 가능 영역과 진행 방향 |
| 고지대 | 평면, 가장자리, 절벽 측면, 서로 떨어진 구획 | 타워·채집 요소 배치 영역과 경로의 높이 차이 |
| 맵 밖 월드 배경 | 화면비별 연장 영역 | 맵 밖이 보일 때 자연스럽게 이어지되 상호작용 불가임을 전달 |
| 출현 지점 | 기본, 공룡 출현 강조 | 공룡이 처음 들어오는 방향 |
| 개척지 관문 | 기본, 누수 위험, 라이프 손실 | 반드시 지켜야 할 목표와 위험 상승 |
| 경로 방향 표지 | 오른쪽 진행 방향과 관문 방향 | 초기 화면에 관문이 없을 때 진행 방향 전달 |
| 타워 슬롯 | 활성, 선택, 잠김, 설치 불가, 건설 미리보기 | 건설 가능 여부와 현재 선택 대상 |
| 방벽 슬롯 | 빈 상태, 선택, 잠김, 설치 불가, 파괴 후 재건 가능 | 방벽 설치 가능 여부와 파괴 상태 |
| 카메라 경계 배경 | 좌우 끝, 확대 시 상하 끝 | 실제 맵 경계와 월드 배경의 구분 |

### 4.2 봄 월드: 초록 개척지

| 제작 묶음 | 필요한 요소 |
| --- | --- |
| 지형 재료 | 밝은 풀 고지대, 다져진 흙 경로, 경계 절벽, 봄 하늘·먼 배경 |
| 자연 장식 | 풀, 꽃, 바위, 봄 식생. 경로와 선택 영역을 가리지 않는 크기 변형 |
| 개척 장식 | 목재 구조물, 표지판, 관문 방향 표지, 새로 세운 개척 시설 분위기 |
| 스테이지 구성 | 1-1~1-10의 확정 경로·상대 배치를 표현하는 10개 고정 맵 |

봄 월드의 실제 경로와 배치는 `spring-world-production-spec.md`를 그대로 따른다.

### 4.3 여름 월드: 열대 해안

| 제작 묶음 | 현재 확인된 요소 | 상태 |
| --- | --- | --- |
| 지형 재료 | 모래, 얕은 물, 해안 경계, 따뜻한 햇빛 | 콘텐츠 방향 확정, 실제 제작 명세 미정 |
| 자연 장식 | 야자수, 조개, 해안 바위와 식생 | 전투·채집에 영향 없는 장식으로 확정 |
| 스테이지 구성 | 2-1~2-10의 10개 고정 맵 | 맵 크기·구조·수량만 확정, 실제 경로·상대 배치 미정 |
| 여름 전용 신호 | 빠른 물량과 두 경로 위협을 가리지 않는 배경·장식 대비 | 검증 필요 |

야자수와 해안 장식은 채집 가능한 나무처럼 보이지 않아야 하며 일꾼의 대상이나 장애물이 아니다.

### 4.4 겨울 월드

- 3-1~3-10의 환경 기믹, 신규 공룡, 실제 맵과 제작 명세가 아직 없다.
- 겨울 지형·장식·보스·음악은 후속 기획 확정 전까지 수량과 형태를 정하지 않는다.
- 공통 슬롯·관문·화면 요소는 재사용 가능성을 유지하되 겨울 전용 변형을 미리 확정하지 않는다.

## 5. 타워 리소스

### 5.1 타워 공통 상태

- 카드·건설 미리보기용 대표 이미지
- 빈 슬롯 위 건설 시작과 완료 연출
- 기본 대기, 공격 준비, 기본 공격, 선택, 이동 시작·이동 완료
- 공격 범위 표시와 선택 외곽선
- 잠김·비활성·설치 불가 상태
- 일반·고급 카드 효과가 실제 범위·수량·속도 변화를 보여주는 확장 표현
- 궁극 획득과 자동 발동을 구분하는 전용 표현

카드마다 별도의 타워 외형 변형이 필요하다고 확정된 것은 아니다. 우선 기본 외형과 실제 판정 변화를
읽게 하는 공격·효과 리소스를 제작하고, 외형 단계 변화는 후속 아트 결정으로 둔다.

### 5.2 타워별 공격·효과

| 타워 | 기본 공격 리소스 | 카드·궁극으로 필요한 추가 표현 |
| --- | --- | --- |
| 건 | 총구 섬광, 탄환, 적중 | 추가 탄환, 관통, 장갑 무시, 오버드라이브, 도탄 |
| 블레이드 | 회전 칼날, 칼날 적중 | 추가 칼날, 크기·반경 증가, 범위 둔화, 칼날 폭풍, 귀환 칼날 |
| 캐논 | 포탄, 직격, 폭발 | 폭발 범위, 연속 포격, 장갑 감소, 집속탄 소형 폭발, 공성탄 직격 |
| 파이어 | 부채꼴 화염, 화상 | 화염 범위, 불타는 지면, 화상 폭발, 화염 폭풍, 전염 화상 |

| 일렉트릭 | 최초 전격, 연쇄 전격 | 연쇄 거리·수, 감전 누적, 경직, 연쇄 폭풍, 과부하 폭발 |
| 아이스 | 얼음 기본 공격, 적중 | 감속 능력 해금 전·후, 감속 유지 |
| 독 | 독 기본 공격, 적중 | 중독 능력 해금 전·후, 중독 유지 |

## 6. 공룡 리소스

### 6.1 원종과 역할

### 6.2 공통 동작과 상태

- 대기 또는 출현 준비, 출현, 경로 이동
- 피격, 방벽 공격 준비, 방벽 공격, 경직
- 화상, 중독, 감속, 장갑 감소가 동시에 겹쳐도 구분되는 상태 표현
- 체력 막대, 보스 공룡 상시 체력 막대, 장갑 전달 표현
- 처치 판정 후 비유혈 쓰러짐과 빠른 사라짐
- 개척지 관문 도달과 라이프 손실 전달
- 화면 밖 알림용 실루엣·아이콘

### 6.3 알파 공룡 변형

- 콤프소그나투스, 벨로키랍토르, 트리케라톱스, 파키케팔로사우루스, 안킬로사우루스
- 갈리미무스, 딜로포사우루스, 카르노타우루스
- 각 알파는 원종 실루엣을 유지하면서 큰 크기, 차별화된 색, 장식과 오라를 모두 사용한다.
- 알파 출현·처치와 알파 카드 세트 발생을 전달하는 전용 효과·소리가 필요하다.

- 48×18타일 맵의 화면 밖 위험을 놓치지 않고 카메라 이동이 과도하지 않은지
- 일반 공격·일꾼·환경음이 알파·관문 위험·방벽 파괴 경고를 가리지 않는지
