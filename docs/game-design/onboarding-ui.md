## 1. 목적과 범위

처음 플레이하는 사람이 입력을 잠그는 긴 튜토리얼 없이 `동굴 기상 → 숲 벌목 → 숲 장터 가판대 건설 →
첫 판매 → 코인 귀환 → 대장간 곡괭이 제작 → 야영지 코어 활성화 → 영입 → 자동화 → 방어`의 관계를 직접 경험하게 한다. 화면은 안전한 것과 아직 잃을
수 있는 것, 정상 대기와 실제 막힘, 지금 해야 할 행동 하나를 세로 화면에서 즉시 구분하게 한다.

### 포함

- 동굴에서 깨어나 첫 나무를 자원 적재칸에서 등에 싣고 숲 장터에 가판대를 지어 판매하는 단일 목표 흐름
- 첫 판매 뒤 대장간·야영지 코어 성장, 첫 영입·자동화, 방어 시설과 첫 방어까지의 추천 순서
- 상단 안전 자원 HUD, 플레이어 운반물, 목표 목록과 월드 방향 표시
- 시설별 상태 아이콘, 부족 문구와 대상 기능 말풍선
- 약탈 배너, 지역별 방어 확인, 오프라인 요약
- 최소 터치 영역, UI 크기, 감각 접근성, 카메라·진동·흔들림 설정
- 기지 단계, 물류, 판매, 경보와 방어 결과의 시각·연출·사운드 방향

### 제외

- 기능 판정과 반복 수치는 각 세부 원본이 소유한다.
- 화면 픽셀 좌표, 최종 색상 팔레트와 생물·건축물의 구체 외형은 다루지 않는다.
- 코드, 데이터 형식, 저장 구조·시점, 구현 알고리즘, 런타임 오류 처리, 분석 이벤트와 개발·출시 절차는 다루지 않는다.
- 이미지 파일을 만들지 않는다.

### 결정 상태

- **확정**: 아래 온보딩, HUD, 접근성과 연출 규칙은 모두 사용자 승인 내용이다.
- **가정**: 없음.
- **미정**: 없음. 출시 필수 안내와 화면 상태에는 정상·예외·실패 피드백이 있다.
- **검증 필요**: 신규 사용자 목표 시간, 최소 세로 화면과 감각 설정은 11절과
  [`progression-balance.md`](progression-balance.md#12-검증-필요와-수치-조정-순서)로 확인한다.

## 2. 온보딩 원칙과 종료

- 첫 5분에는 다음 유효 행동 하나만 보여 준다. 첫 판매와 첫 영입을 동시에 제시하지 않는다.
- 정적 목표 문구를 먼저 사용하고, 멈춰 있을 때 월드 윤곽·화살표·맥동 순으로 안내를 강화한다.
- 가이드는 조이스틱 이동을 잠그지 않는다. 초반 순서가 깨지는 지역은 잠금 버튼 대신 환경과 위험 경고로 우회한다.
- 첫 처치의 영입 기회만 보장하고 이후에는
  [`creatures-and-recruitment.md`](creatures-and-recruitment.md#31-등급별-확률과-보상)의 일반 영입 확률을 사용한다.
- 플레이어가 추천 순서의 행동을 이미 충족했으면 즉시 완료로 인정하고 다음 미완료 목표 하나를 안내한다.
- 온보딩은 첫 방어 결과를 확인하고 벽 수리 또는 치료 안내를 본 시점에 종료한다.
- 완료 뒤 강제 안내는 반복하지 않는다. 도움말에서 이동, 입고, 영입, 판매, 자동화와 방어 설명을 다시 볼 수 있다.

## 3. 동굴 기상부터 첫 판매

### 3.1 시작 화면과 목표

- 플레이어는 꺼져 가는 모닥불 옆에서 허름한 옷을 입은 채 깨어난다. 조작권은 5초 안에 준다.
- 시작 카메라에는 동굴 내부와 빛이 드는 출입구가 보이되 숲 화면을 한 장의 배경처럼 함께 보여 주지 않는다.
- 모닥불·깔개·동굴 출입구만 있고 가판대·공방·장터 관리대·자동화·방어 시설은 아직 존재하지 않는다.
- 모닥불은 기상 위치를 보여 주는 장식이며 상호작용 윤곽·입고·강화 팝업을 표시하지 않는다.
- 첫 목표는 `빛이 드는 곳으로 가기` 하나다. 안전 자원 5종은 첫 자원 획득 전에는 접어 두고 체력과 목표만 표시한다.
- 낡은 손도끼는 시작 장비칸에 이미 지급한다. 획득 연출·줍기 목표는 사용하지 않고, 이동·대기 중에는
  빈손이다가 벌목 순간에만 손도끼가 나타난다.

### 3.2 첫 벌목·등짐·귀환

1. `조이스틱을 밀어 숲으로 나가세요`와 출입구의 월드 윤곽을 표시한다.
2. 숲 화면으로 전환되면 입구 앞 첫 벌목 군락의 가장 가까운 나무 하나만 강조한다.
3. 나무 가까이 가면 자동 벌목 대상 윤곽과 진행을 보여 주고, 완료된 목재가 옆의 네모난 자원 적재칸에
   하나씩 쌓이게 한다.
4. 필요한 양이 적재칸에 쌓이면 나무 강조를 잠시 낮추고 `쌓인 목재를 가져가세요`와 적재칸 윤곽을 표시한다.
5. 적재칸에 접근하면 목재가 하나씩 줄어 같은 순서로 등에 쌓인다.
6. 가판대 건설과 첫 판매에 필요한 양을 등에 실으면 `가판대를 지을 목재가 모였습니다`와 같은 숲 화면의 장터 자리 방향을 표시한다.
7. 운반 한도에 도달하면 추가 회수·채집만 멈추고 이동은 유지한다. 첫 가판대를 짓기 전에는 동굴 귀환을 다음 목표로 표시하지 않는다.

등짐이 가득 차면 채집만 멈추고 이동과 생물 대응은 가능하다는 문장을 표시한다. 안전 입고 전 물품과
상단 안전 자원을 같은 숫자나 같은 아이콘으로 합치지 않는다.

### 3.3 첫 가판대 건설과 진열

1. 숲의 동굴 출입구 가까운 안전 공터에 첫 가판대 건설 비콘을 다음 목표로 표시한다.
2. 완성 가판대의 반투명 미리보기 대신 네모난 건설 영역과 `목재 현재/5`를 표시한다. 범위에 들어가면 등에 쌓인 목재가 하나씩 줄고 진행 바와 골조가 `기초 → 기둥 → 천막` 순으로 조립된다.
3. 완성 뒤에도 첫 판매용 목재가 등에 남아야 하며, 빈 진열칸을 다음 목표로 표시한다.
4. 진열 범위에 접근하면 남은 목재 일부가 장작 묶음으로 가판대 위에 쌓인다.
5. 첫 재고가 생긴 순간 장터 바깥 숲길에서 첫 손님이 걸어 들어온다.

가판대가 완성되기 전에는 진열과 손님을 만들지 않는다. 건설 비용을 판매해 버리거나 손님이 동굴 안으로
들어오는 인과 오류를 허용하지 않는다.

### 3.4 첫 판매와 곡괭이 제작

1. 첫 손님의 장작 요청 말풍선과 가판대의 직접 응대 범위를 연결해 강조한다.
2. 플레이어가 범위에 서면 장작 묶음 하나를 배정하고 짧은 생존 물자 판매를 시작한다.
3. 판매가 끝나면 가판대 위 장작이 줄고 가판대 옆 네모난 코인 적재칸에 코인이 실제 수량만큼 생긴다.
4. 코인 적재칸에 접근하면 적재량이 0이 되고 같은 수량이 보유 코인에 더해진다. 회수 전에는 가판대 응대 위치가 아니라 코인 적재칸을 가리킨다.
5. 두 번째 손님까지 판매하면 동굴의 대장간 건설 영역을 공개하고 화면 안팎 방향표를 제공한다.
6. 미건설 시설은 완성 외형 대신 필요 재화·현재/필요 수량이 적힌 네모난 영역만 보인다. 접근하면 재화가 하나씩 줄고 진행 바와 기초·기둥이 차오른다.
7. 대장간 영역에 코인 10개를 모두 투입하면 완성 외형과 곡괭이 1단계가 나타나고 돌 군락의 필요 도구 표시가 해제된다.
8. 돌 1개를 채집하면 야영지 코어 건설 영역을, 완료 뒤에는 목재 3개가 필요한 동료 보관소 건설 영역을 순서대로 안내한다.
9. 완성된 대장간·야영지 코어·동료 보관소에 접근하면 각 전용 팝업을 자동으로 열고, 코인 강화 또는 동료 확인·역할 변경을 즉시 수행할 수 있게 한다.

첫 판매 목표는 시작 후 4분 이내, 첫 도구 변화는 6분 이내다. 정확한 건설 비용, 판매 시간·가격과 통과
기준은 [초반 퍼널 기본값](progression-balance.md#21-초반-퍼널-기본값)과
[첫 판매 검증](progression-balance.md#12-검증-필요와-수치-조정-순서)을 따른다.

## 4. 첫 자동화와 첫 방어

### 4.1 첫 판매 뒤 추천 목표

첫 판매가 끝나면 다음 순서를 추천하되 기능을 잠그지 않는다.

1. 두 번째 판매와 대장간 곡괭이 제작
2. 돌 군락 채집과 야영지 코어 활성화
3. 숲 외곽 첫 전투·영입, 동료 보관소 귀환과 탐험 역할 편성
4. 첫 동료와 한 단계 강한 생물을 사냥해 두 번째 영입 결과 확보
5. 두 번째 영입 동료의 작업 적성을 비교해 벌목 운반 또는 판매 보조 선택
6. 첫 자동화 자원·코인 회수, 동행 수용량 2 강화와 숨은 엘리트 동굴 탐색
7. 이후 공방·장터 관리대, 장터 벽·출입문과 방어 야영지 건설
8. 방어 동료 배치와 첫 방어

- 벌목 운반은 숲에서 동굴까지의 반복, 판매 보조는 가판대 응대를 줄인다는 차이를 나란히 설명한다.
- 영입한 동료가 현장에서 바로 따라오지 않고 동굴의 동료 보관소에서 기다린다는 결과를 보여 준다.
- 첫 영입 뒤에는 동료 보관소 방향을, 도착 뒤에는 탐험 역할을 추천하는 역할 선택 UI를 가리킨다.
- 영입 완료 뒤 추천 목표와 화면 가장자리 방향 화살표는 동료 보관소를 가리키며 `첫 동료를 탐험에 편성하세요`를
  함께 표시한다. 동료 명단을 열면 대기·탐험·작업·방어 상태와 두 활동 수용량을 보여 준다.
- 첫 동료와 상위 일반 생물을 쓰러뜨린 뒤 두 번째 영입에는 `일을 맡기면 다음 원정이 빨라집니다`를
  표시하고, 전투력과 작업 적성·작업력, 추천 시설의 배치 전후 예상값을 같은 카드에서 비교한다.
- 첫 작업 배치는 동료가 실제로 운반 또는 판매 한 번을 마치고 결과 자원·코인이 생길 때까지 완료로
  처리하지 않는다. 결과 회수 뒤 동행 수용량 2 강화 위치와 숨은 엘리트 동굴 방향을 차례로 안내한다.
- 첫 자동화 뒤 공방 물류와 가판대 판매 자동화·응대 속도 강화가 추가된다는 점을 미리 보여 준다.
- 단일 가판대의 다음 강화가 공개되면 같은 건물의 강화 비콘을 월드 윤곽과 방향 화살표로 보여 준다.
  강화하면 새 가판대를 짓지 않고 응대 시간이 짧아진다는 결과를 표시한다.
- 동료가 없으면 영입 목표를 계속 표시하고 배치 단계만 대기시킨다. 플레이어 직접 채집·판매는 계속 가능하다.
- 플레이어가 방어 시설보다 기지 성장이나 다른 자동화를 먼저 선택해도 막지 않는다.
- 공방·장터 관리대가 공개된 뒤 첫 가공 상품 판매가 끝나면 방어 시설 완성 여부와 관계없이 첫 경보까지 10분을 표시한다. 남은 시간과 아직
  완성되지 않은 벽·출입문 또는 방어 야영지를 함께 경고하되 다른 플레이를 잠그지 않는다.

### 4.2 첫 경보와 방어

- 첫 경보에서 상단 배너에 `손님 대피 → 가판대 덮개 → 방어 → 복귀`를 아이콘과 짧은 글로 보여 준다.
- 경보 시작과 함께 성장·건설·강화 비콘이 잠긴다는 점을 먼저 표시한다. 최초 건설의 확정 진행은 유지하고 성장·강화의 미완료 임시 투입분만 반환한다. 경보 중에는
  방어 동료 배치, 벽 수리와 상품·코인 입고가 가능하고 적 도착 뒤에는 배치·수리가 잠긴다는 점을 표시한다.
- 경보 중 출입문 배치를 마친 방어 동료는 적이 전투 범위에 들어오면 먼저 공격하고, 약탈자의 첫 공격은
  해당 생물의 공격 간격 뒤에 발생한다는 점을 첫 방어 도움말에 표시한다.
- 치료소가 아직 없으면 `이번 방어에서 쓰러진 방어 동료는 영구 이탈할 수 있습니다`를 전투 전에 경고한다.
- 플레이어가 약탈자를 한 번 이상 공격하면 직접 방어 결과 선택이 열린다는 점을 안내한다.
- 방어 뒤 성공 여부, 벽 손상, 회수하지 못한 상품·코인, 부상·이탈을 분리해 보여 준다.
- 벽이 손상됐으면 수리 비콘, 부상 동료가 있으면 치료소와 안전 코인 부족 여부를 다음 목표로 표시한다.
- 벽·출입문이나 방어 야영지가 없는 첫 방어에서는 약탈이 연기되지 않으며, 벽이 없으면 즉시 침입하고
  야영지가 없으면 플레이어만 싸운다는 결과를 전투 전에 보여 준다.

첫 방어에서 실패해도 저장을 되돌리거나 온보딩을 다시 시작하지 않는다. 결과와 회복 안내를 본 뒤 온보딩을 완료한다.

## 5. 목표 목록과 방향 안내

- 첫 장비 수리까지는 미완료 목표 하나만 보여 준다. 이후 목표 목록은 동시에 최대 3개를 보여 주되 추천 목표 하나를 맨 위에 둔다.
- 목표를 선택하면 가장 가까운 관련 시설·자원·동굴 출입구 방향을 화면 가장자리 화살표로 표시한다.
- 방향 화살표는 거리보다 다음 행동을 글로 함께 알려 준다. 예: `적재칸의 목재를 싣고 숲 장터로 가기`.
- 완료된 목표는 짧은 확인 표시 뒤 목록에서 사라진다. 다른 순서로 이미 충족한 목표는 즉시 완료 처리한다.
- 목표 목록을 접어도 시설 상태 아이콘과 약탈 배너는 유지한다.
- 현재 목표가 없어도 플레이를 막지 않으며 메인 기지, 주문과 수집 목표를 선택할 수 있다.

## 6. HUD와 시설 피드백

### 6.1 항상 보이는 정보

| 위치·정보 | 표시 내용 | 원칙 |
| --- | --- | --- |
| 상단 안전 자원 | 돌·나무·코인·뼈·소울 수량 | 다섯 종을 항상 표시하고 약탈 대상과 합치지 않음 |
| 플레이어 주변 운반물 | 등에 든 자원·상품·코인의 종류와 양 | 출발지와 안전 입고 전 상태를 구분 |
| 플레이어 상태 | 체력과 현재 자동 행동 대상 | 위험과 중단 이유를 색·모양·글로 표시 |
| 목표 목록 | 추천 목표와 선택한 방향 | 접기 가능, 입력 잠금 없음 |
| 기지 위험 | 약탈 배너, 벽 손상, 부상 수 | 평상시 최소화하고 위험 때 우선 노출 |

- 안전 자원 5종은 지역 이동, 카메라 확인과 약탈 중에도 상단에 남는다.
- 운반물은 안전 자원 수량에 더하지 않는다. 등에 든 물품이 없으면 주변 표시를 접는다.
- 동행·기지 수용량은 동료 명단에서 역할·배치 대상을 선택하거나 수용량을 강화할 때 표시하고 상단 5종
  자원 자리를 밀어내지 않는다.

### 6.2 시설 상태 아이콘

| 상태 | 아이콘 의미 | 선택했을 때 보여 줄 글 |
| --- | --- | --- |
| 담당자 없음 | 사람 윤곽 | 비어 있는 자리와 배치 가능한 동료 |
| 재료 부족 | 빈 상자 | 부족한 자원 종류와 정확한 수량 |
| 출력 가득 참 | 막힌 상자 | 가득 찬 위치와 현재량/상한 |
| 자원 적재칸 가득 참 | 나무·돌 더미 | 현재량/상한, 연결된 작업 정지와 회수 가능한 운반량 |
| 장터 관리대 코인 가득 참 | 코인 더미 | 반출할 코인과 필요한 운반 담당자 |
| 벽 파괴·손상 | 갈라진 방패 | 현재 내구도와 수리 비용 |
| 치료 코인 부족 | 동전이 빠진 치료 표식 | 대기 인원과 부족 코인 |

- 막힘은 해당 시설 머리 위 아이콘으로만 표시한다. 기지 전체에 일반 운영 경보를 만들지 않는다.
- 아이콘은 모양이 모두 달라야 하며 색만으로 구분하지 않는다.
- 정상 이동, 작업 대상 재생 대기와 다른 담당자의 적재·하역 대기는 막힘으로 표시하지 않는다.
- 아이콘을 선택하면 원인, 부족 수량과 가능한 다음 행동을 완성된 문장으로 보여 준다.
- 건물에 플레이어·동료·손님이 가려지면 대상 주변 지붕과 앞벽만 투명하게 하고 대상 윤곽을 유지한다.

### 6.3 대상 기능 말풍선

- 선택한 생물·시설·손님 옆에만 대상 기능 말풍선을 표시한다.
- 가장 중요한 기능 버튼을 최대 3개 보여 주고 나머지는 `더보기`에 넣는다.
- 기능 우선순위는 `위험 대응 → 현재 진행에 필요한 행동 → 관리·정보`다.
- 화면 가장자리에서는 말풍선을 대상 반대쪽으로 옮겨 잘리지 않게 한다.
- 여러 대상이 겹치면 선택한 대상과 말풍선을 가장 위에 표시하고 나머지는 흐리게 한다.
- 세로 화면 하단의 고정 기능 패널로 대체하지 않는다. 대상과 행동의 관계를 공간적으로 유지한다.

## 7. 약탈 배너와 지역별 확인

- 약탈 경보는 상단 배너, 전용 경보음과 진동을 함께 사용하며 게임을 멈추지 않는다.
- 숲 장터 안에서 배너를 누르면 장터 외곽 방어선을 카메라로 확인하고 원래 위치로 돌아갈 수 있다.
  확인 중 플레이어가 이동 입력을 하면 즉시 플레이어 카메라로 돌아온다.
- 숲의 다른 위치에 있을 때는 숲 장터 방향 화살표와 `숲 장터를 지키러 가세요`를 표시한다.
- 동굴에 있을 때는 다른 지역 카메라나 순간 이동을 제공하지 않는다. 동굴 출입구 방향 화살표와
  `출입구를 지나 숲 장터로 가세요`를 표시한다.
- 자동 카메라 이동을 꺼 둔 플레이어에게는 배너와 방향 표시만 사용한다.
- 경보음·진동을 꺼도 배너의 아이콘, 남은 시간과 상태 문구는 유지한다.

## 8. 오프라인 복귀 요약

오프라인 결과는 최대 24시간의 사건을 다음 순서로 보여 준다.

1. 적용한 경과 시간과 24시간 상한 여부
2. 자원 적재칸에 남은 돌·나무, 메인 기지에 입고된 돌·나무와 기타 안전 자원
3. 완성 상품, 판매 상품, 생성·입고된 안전 코인
4. 시간순 약탈별 경보, 방어, 회수와 최종 손실
5. 부상, 치료 완료·진행·안전 코인 부족
6. 첫 숲 장터 침입으로 추가 약탈이 중단됐는지
7. 현재 막힌 시설과 추천 행동 하나

- 수락 주문은 자동 납품하지 않으며, 수락 전 주문이 바뀌었다면 갱신 사실만 표시한다.
- 로그아웃 시 플레이어 운반물은 원래 출발 지점으로 돌아갔음을 종류별로 표시하고 안전 수입에 포함하지 않는다.
- 결과를 닫아도 이미 반영된 안전 자원과 운영 상태는 유지한다.
- 손실이 없으면 `안전 자원은 모두 지켜 냈습니다`, 손실이 있으면 대상·수량·원인과 회복 행동을 함께 표시한다.

## 9. 세로 화면 접근성

### 9.1 터치와 크기

- 모든 이동·기능·더보기·배너 선택 영역은 최소 `48dp`다.
- 이동 조이스틱은 왼쪽 아래 세이프 에어리어 안의 엄지 영역에서 동적으로 나타나며, 다른 고정 기능 버튼과 겹치지 않는다.
- 조이스틱 바탕은 필드를 가리지 않도록 반투명하게 표시하고 손을 떼면 사라지며, 손가락이 기준점에서 벗어나도 입력 손가락을 추적한다.
- 오른쪽 아래는 영입·재화 선택처럼 현재 상황에서 필요한 기능에 우선 배정하고 공격·채집 버튼을 상시 두지 않는다.
- UI 크기는 `100%`, `125%`, `150%` 중 선택할 수 있다.
- 화면을 확대·축소해도 터치 영역과 글자를 최소값 아래로 줄이지 않는다.
- 최소 검증 화면은 세로 `360×800dp`다. 긴 목록은 세로 스크롤하며 상단 자원과 닫기 기능을 가리지 않는다.
- 5단계 가판대 한 채, 앞줄 12명·뒷줄 11명으로 접힌 빛길 나그네 줄, 대상 기능 말풍선, 시설 아이콘과 약탈 배너가
  함께 있어도 기능 버튼이 화면 밖으로 잘리거나 서로 덮이지 않아야 한다.

### 9.2 감각 설정

- 진동, 화면 흔들림과 자동 카메라 이동은 각각 별도로 끌 수 있다.
- 모든 소리 피드백에는 아이콘, 숫자 변화, 배너 또는 문구 중 하나 이상의 시각 대체가 있다.
- 자원, 상품, 경보, 손상과 치료는 색뿐 아니라 서로 다른 모양·실루엣·문구를 함께 사용한다.
- 화면 흔들림을 끄면 피격·벽 파괴 위치 강조는 유지하고 화면 이동만 제거한다.
- 자동 카메라 이동을 끄면 확장·방어 구역을 가장자리 강조와 방향 화살표로 대신한다.

## 10. 시각·연출·사운드 방향

- 시작 캐릭터는 해진 옷·밧줄 허리띠·빈손으로 보이고, 손도끼를 줍거나 수리하고 의상·등 장비를 바꿀
  때 필드 캐릭터의 해당 파츠가 즉시 교체된다.
- 동굴과 숲에서 같은 캐릭터 조합을 사용한다. 장비 화면 전용 합성 이미지만 바꾸고 필드 외형을 그대로
  두는 방식은 허용하지 않는다.
- 목재·돌·상품·코인은 종류별 실루엣으로 등에 쌓이며, 건설·진열·입고할 때 실제 수량과 함께 하나씩 줄어든다.
- 자원 작업 구역의 네모난 자원 적재칸에는 돌 또는 나무 모델을 보관 상한까지 실제로 더한다. 플레이어나
  담당 동료가 회수할 때 적재칸 더미가 하나씩 줄고 같은 자원이 등에 하나씩 늘어나야 한다.
- 기지는 모닥불, 천, 목재, 식기와 작업 흔적으로 따뜻한 생활감을 만든다.
- 발광 버섯·식물·결정은 차가운 자연 발광을 은은하게 더하며 HUD와 시설 상태보다 밝게 번쩍이지 않는다.
- 발광에는 블룸을 사용하지 않는다. 밝은 부분색, 어두운 주변색, 윤곽과 작은 입자로 출입구 유도광·소울·식물·상품·
  빛길 나그네의 눈을 구분하며 게임 정보는 아이콘과 문구로도 전달한다.
- 단계 상승 때 건축 재질, 창고 정돈, 조명과 생활 소품이 늘어 이전 단계와 실루엣으로 구분된다.
- 평상시 환경음은 낮게 유지하고 물류 반복음이 오래 겹치지 않게 한다.
- 상품 판매, 공방 완성, 약탈 경보와 방어 결과는 서로 다른 짧은 대표음을 사용한다.
- 판매 완료는 밝은 코인음, 생산 완료는 공방 재질음, 경보는 낮은 북·경고음, 성공·침입·손실은 서로 다른 결과음으로 구분한다.
- 연출은 판정을 대신하지 않는다. 자원 더미 크기, 벽 균열과 발광은 실제 수량·내구도 문구를 함께 표시한다.
- 모닥불·텐트 단계의 북동쪽 다섯 자원 표시 구역은 종류별 모양으로 구분한다. 돌 거점부터 같은 자리에 닫힌
  부속 창고가 나타나면 더미를 숨기고 일꾼의 창고문 하역과 HUD 정확한 수량으로 입고를 보여 준다.
- 자유 장식을 들면 플레이어 앞 배치 미리보기, 놓기·네 방향 회전·보관을 표시한다. 보호 공간은 바닥
  윤곽과 문구로 구분하고 약탈 경보 자동 보관을 즉시 알린다.

## 11. 정상·예외·실패 확인과 검증

| 구분 | 확인 상황 | 기대 결과 |

### 플레이테스트 통과 기준

- 최소 `360×800dp`에서 UI 크기 100·125·150%를 각각 확인한다.
- 동료 24명, 빛길 나그네 23명, 5단계 가판대 한 채, 자원 20개가 쌓인 자원 적재칸, 자유 장식 24개와 최고 단계 시설을 둔 상태에서 약탈 경보를
  시작해 장식 자동 보관 전후를 함께 확인한다. 다음을 모두 만족해야 한다.
  - 중앙길과 안전 물류길, 모든 비콘·입출고점·동굴 출입구·방어선에 접근할 수 있다.
  - 작업 자리 양보와 대기로 물류가 영구 정지하지 않는다.
  - 상품 요청 말풍선, 가판대 덮개, 벽 손상과 약탈자를 동시에 구분할 수 있다.
  - 자유 장식이 보호 공간과 기능 대상을 막지 않는다.
  - 네 번의 확장 뒤에도 기존 시설과 물품이 이동하지 않는다.
- 진동, 화면 흔들림, 자동 카메라와 소리를 각각 끈 조합에서 같은 상태를 시각 정보만으로 끝까지 판단할 수 있어야 한다.
- 첫 숲 진입·가판대·판매·장비 변화·영입·자동화와 첫 방어 결과는
  [`progression-balance.md`](progression-balance.md#12-검증-필요와-수치-조정-순서)의 표본·통과 기준을 사용한다.

## 12. 유지·초기화

- 온보딩 목표 완료 상태와 접근성 설정은 접속 종료 뒤 유지한다.
- 안내 도중 앱을 닫아도 이미 완료한 기상, 채집, 가판대 건설, 진열, 입고, 영입, 판매,
  장비 변화, 시설 공개와 방어 결과를 되돌리지 않는다.
- 복귀하면 완료한 목표 다음의 가장 가까운 미완료 추천 목표를 표시한다.
- 첫 판매·방어 실패는 온보딩 초기화 조건이 아니다. 안전 자원과 시설 진행을 유지하고 회복 행동으로 연결한다.
- 새 게임에서만 온보딩 완료 상태와 기지 진행을 처음으로 되돌린다.
