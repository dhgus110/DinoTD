## 1. 문서 목적과 범위

이 문서는 쓰러뜨린 생물을 동료로 받아들이거나 재화로 처리하는 선택과, 영입한 동료를
탐험·일꾼·방어 역할로 운영하는 플레이 규칙의 단일 원본이다. 생물의 이름·외형·개별 능력치와
종별 보상은 [`creature-content.md`](creature-content.md)가 소유한다. 자동 전투와 플레이어
패배·등짐의 공통 판정은 [`exploration-combat.md`](exploration-combat.md)를 참조한다.

### 포함

- 영입 기회 발생, 영입·재화 선택, 선택 제한·취소·실패 처리
- 등급별 영입·소울 확률과 뼈·소울 지급 경계
- 동행 수용량·기지 수용량의 시작값, 확장, 제한과 비용
- 동료 역할 변경과 역할별 행동·우선순위
- 탐험 동료의 대형·운반·전투 기여, 일꾼 물류, 방어 동료 출동
- 동료 이탈·부상·치료와 역할 재배치의 플레이어 경험
- 영입·수용량·역할 UI, 접근성, 정상·예외·실패 확인 사례

### 제외

- 개별 생물의 이름·외형·행동·능력치·적성·종별 보상
- 생물 공격의 공통 피해 판정, 카메라와 지역 재등장
- 시설 생산·판매·약탈의 전체 규칙
- 코드, 데이터 컬럼·자료형, 저장 구조·분석 이벤트·기술 성능 기준

## 2. 결정 상태와 규칙 지도

### 확정

- 같은 종을 여러 마리 영입할 수 있으며 보스 생물도 예외가 아니다.
- 영입에는 동행 수용량과 기지 수용량의 빈자리가 모두 필요하다.
- 동료는 탐험 동료·일꾼·방어 동료 중 한 역할만 맡는다.
- 역할은 메인 기지가 있는 동굴에서 비용 없이 변경한다.
- 탐험 동료는 플레이어와 같은 목표를 공격·채집하고 운반력을 공유 등짐에 더한다.
- 플레이어가 직접 참여한 약탈 결과에서는 생물별 영입·재화 선택을 할 수 있으며, 자동·오프라인
  방어에서는 영입 없이 뼈와 소울을 안전 자원으로 자동 보관한다.
- 온라인 방어에서 치료소가 없을 때 체력 0인 방어 동료는 영구 이탈하고, 오프라인 방어의 부상
  동료는 치료소가 없어도 영구 이탈하지 않는다.

### 확정된 출시 기본값

- 새로 영입한 동료는 우선 탐험 동료로 편성된다. 영입 직후 두 수용량을 모두 확인하게 하는
  기존 규칙을 보존하고, 기지로 돌아와 역할을 바꾸면 동행 수용량 한 자리를 즉시 돌려준다.
- 동료 역할은 수치 선택이 아니라 화면에서 보이는 동선 선택이어야 한다. 같은 생물을 여러
  역할로 바꿔 보고 차이를 이해할 수 있게 한다.
- 영입 기회와 소울 획득은 서로 독립된 추첨이 아니라 등급별로 정한 한 번의 결과 흐름에서
  처리한다. 플레이어는 결과 버튼을 누르기 전까지 재화가 지급되지 않는다.

### 결정 순서

1. 쓰러진 생물의 등급과 재화 결과를 확인한다.
2. 영입 기회가 있는지와 두 수용량에 빈자리가 있는지 확인한다.
3. 플레이어가 영입 또는 재화를 선택한다.
4. 영입이면 기지 수용량과 동행 수용량을 소비하고 역할을 부여한다.
5. 재화이면 종별 뼈와 등급별 소울 추첨을 지급한다.
6. 기지에서 역할을 변경하고 동료의 다음 배치·동선을 확인한다.

## 3. 영입과 재화 선택

### 3.1 결과 흐름

1. 플레이어 또는 방어 동료가 생물을 쓰러뜨리면 생물 등급을 확인한다.
2. 등급별 영입 기회 추첨을 한다. 보스 생물은 항상 영입 기회를 가진다.
3. 영입 기회가 없으면 선택 화면 없이 종별 뼈를 지급하고 등급별 소울 추첨을 한다.
4. 영입 기회가 있으면 쓰러진 생물 아래에 `영입`과 `재화` 버튼을 15초 동안 표시한다.
5. `영입`은 두 수용량이 모두 비어 있을 때만 활성화한다. `재화`는 항상 활성화한다.
6. 영입을 선택하면 해당 생물을 동료로 만들고 뼈·소울을 지급하지 않는다.
7. 재화를 선택하면 [`creature-content.md`](creature-content.md)의 종별 보상을 지급하고,
   선택이 끝난 생물은 결과 상태에서 사라진다.

재화 선택으로 생긴 뼈를 등짐에 바로 넣을 자리가 없으면 `재화` 선택을 막지 않고, 뼈를 쓰러진
생물의 자리에 현장 자원 더미로 떨어뜨린다. 소울은 기존 규칙대로 즉시 안전 자원으로 보관한다.
플레이어가 등짐에 빈자리를 만든 뒤 더미에 접근하면 뼈를 자동 회수할 수 있다. 지역을 떠나거나
플레이어가 패배하면 회수하지 않은 현장 뼈는 사라진다. 뼈를 이미 등짐에 넣은 뒤의 패배는
탐험·전투 문서의 등짐 손실 규칙을 따른다.

### 3.2 확률과 보상 경계

아래 확률은 결과가 발생한 순간 한 번만 추첨한다. 화면 표시 확률과 실제 확률은 같다. 영입
기회 추첨과 소울 추첨은 같은 생물의 한 결과 흐름 안에서 각각 한 번씩만 실행하며, 재화를
선택했을 때만 소울 추첨 결과를 지급한다.

| 등급 | 영입 기회 확률 | 영입 기회가 없을 때 | 재화 선택 시 소울 확률 | 소울 지급 수량 |
| --- | ---: | --- | ---: | --- |
| 일반 생물 | 70% | 뼈 자동 지급, 소울 추첨 | 15% | [`creature-content.md`](creature-content.md)의 공통 등급 보상 참조 |
| 엘리트 생물 | 70% | 뼈 자동 지급, 소울 추첨 | 35% | [`creature-content.md`](creature-content.md)의 공통 등급 보상 참조 |
| 보스 생물 | 100% | 해당 없음 | 100% | [`creature-content.md`](creature-content.md)의 공통 등급 보상 참조 |

뼈 수량은 종별 보상 원본인 [`creature-content.md`](creature-content.md)의 `재화 선택 보상`
표를 따른다. 영입 버튼을 누른 경우에는 영입한 생물의 뼈·소울을 추가로 받지 않는다. 영입
기회가 없을 때는 플레이어의 선택을 기다리지 않고 재화 결과를 즉시 처리한다.

이 확률은 출시 시작값이며 `검증 필요`다. 등급별 30회 이상의 결과를 기록해 영입 선택이
너무 드물거나 생물 수집이 수용량 확장보다 빠르게 포화되지 않는지 확인한다. 검증 중에는
천장·연속 실패 보정·중복 방지 규칙을 사용하지 않는다.

### 3.3 선택 제한과 예외

- 선택 화면은 플레이어가 생물 결과를 확인한 뒤 15초 동안 유지한다. 카운트다운은 버튼 옆에
  초 단위 정수로 표시한다.
- 선택 중 플레이어는 다른 적대 생물의 공격을 받을 수 있다. 결과 화면이 세계를 멈추지 않기
  때문에 체력·방향 경고를 화면 위에 계속 표시한다.
- 플레이어가 3칸 이상 이동하거나 포탈을 사용하면 선택을 취소하고 `재화` 결과를 자동 처리한다.
- 플레이어가 패배하면 선택하지 않은 결과를 `재화`로 자동 처리한 뒤 등짐 손실 규칙을 적용한다.
- 15초가 지나면 `재화` 결과를 자동 처리한다. 수용량 부족으로 영입 버튼이 비활성화된 경우도
  같은 규칙을 사용한다.
- 영입 버튼이 활성화된 뒤 다른 동료가 먼저 영입되거나 역할 변경으로 수용량이 가득 차면
  영입 시점에 다시 확인한다. 조건이 사라지면 영입하지 않고, 재화 결과를 선택하게 한다.
- 이미 선택한 생물의 버튼을 다시 누를 수 없게 한다. 결과 목록의 `전부 영입`과 `전부 재화`도
  한 번 확정되면 되돌릴 수 없다.

## 4. 수용량과 확장

### 4.1 수용량 의미

- `기지 수용량`은 영입해 보유한 모든 동료의 수다. 탐험·일꾼·방어 중 어느 역할이어도 한
  자리를 사용한다.
- `동행 수용량`은 현재 탐험 동료로 편성할 수 있는 최대 인원이다. 일꾼·방어 동료로 역할을
  바꾸면 동행 수용량 한 자리를 사용하지 않는다.
- 영입 시점에는 새 동료를 탐험 동료로 받아들이므로 두 수용량에 빈자리가 모두 필요하다.
  이후 기지에서 일꾼·방어 동료로 변경할 수 있다.
- 현재 수용량과 최대 수용량은 영입 화면, 기지 동료 화면, 수용량 확장 비콘에 같은 형식으로
  표시한다.

### 4.2 시작·상한·비용

| 확장 대상 | 시작 수용량 | 출시 상한 | 확장 비용(소울) |
| --- | ---: | ---: | --- |
| 동행 수용량 | 1명 | 6명 | 1→2: 4, 2→3: 7, 3→4: 11, 4→5: 16, 5→6: 22 |
| 기지 수용량 | 1명 | 12명 | 1→2: 3, 2→3: 6, 3→4: 10, 4→5: 15, 5→6: 21, 6→7: 28, 7→8: 36, 8→9: 45, 9→10: 55, 10→11: 66, 11→12: 78 |

확장은 메인 기지의 수용량 비콘에 올라가 소울을 투입하는 코어 문서 9절의 공통 진행을
따른다. 비용 전부가 투입되면 즉시 최대치가 늘고, 부족하거나 비콘에서 나가면 임시 투입분을
반환한다. 확장 상한에 도달한 비콘은 `최대 수용량`을 표시하며 소울을 받지 않는다.

위 비용과 상한은 출시 시작값이며 `검증 필요`다. 첫 5회 세션에서 플레이어가 한 번은 동료를
영입하고, 두 번째 역할을 시도하기 전에 수용량 확장을 목표로 삼는지 확인한다. 소울 보유량이
일반 생물 영입보다 늦게 쌓여 확장 선택을 만들지 못하면 비용을 20% 단위로 조정한다.

### 4.3 조건 미충족

- 기지 수용량이 가득 차면 모든 생물의 `영입` 버튼을 비활성화하고 `기지 수용량 12/12`와
  `수용량 확장` 행동을 표시한다.
- 동행 수용량이 가득 차면 `동행 수용량 6/6`과 `기지에서 역할 변경` 또는 `수용량 확장`을
  표시한다.
- 두 수용량 중 하나라도 가득 차면 영입을 실행할 수 없고, 재화 선택은 계속할 수 있다.
- 영입을 위해 수용량을 일부러 비운 뒤 선택 화면으로 돌아오면 다른 선택하지 않은 결과에는
  같은 조건을 다시 적용한다. 이미 재화로 처리한 생물은 되돌아오지 않는다.

## 5. 동료 역할과 운영

### 5.1 역할 변경

- 역할 변경은 동굴 메인 기지의 동료 화면 또는 해당 동료를 탭한 상태에서만 가능하다.
- 변경 비용은 없다. 변경을 확정하면 이전 역할의 행동을 멈추고, 새 역할의 배치 지점으로
  이동한다.
- 탐험 중·숲·전투·영입 선택 중에는 역할 변경을 할 수 없다. `메인 기지에서 변경할 수
  있습니다`를 표시한다.
- 역할 변경 중 동료가 운반하던 자원·상품·코인은 손실하지 않고 기존 목적지에 내려놓은 뒤
  새 역할로 이동한다. 기지 밖에서 역할을 바꿔 위험을 우회하는 행동은 허용하지 않는다.
- 역할 변경 뒤 1초 동안 새 역할 아이콘을 표시하고, 이동이 완료되면 실제 동선을 보여 준다.

### 5.2 적성의 공통 의미

각 생물의 적성 등급은 [`creature-content.md`](creature-content.md)의 `탐험·작업·방어 적성`
표현을 따른다. 적성은 생물의 기본 체력·공격력·이동 속도를 바꾸지 않고 해당 역할의 효율만
바꾼다.

| 적성 등급 | 탐험 동료 공격력 보정 | 일꾼 운반력 보정 | 방어 동료 공격력 보정 |
| ---: | ---: | ---: | ---: |
| 1 | +0% | +0% | +0% |
| 2 | +5% | +15% | +10% |
| 3 | +10% | +30% | +20% |
| 4 | +15% | +45% | +30% |
| 5 | +20% | +60% | +40% |

보정은 해당 생물의 기본 능력치에 한 번만 적용하고, 같은 역할 안의 여러 적성 보정을 서로
곱하지 않는다. 탐험 동료의 운반력은 생물 기본 운반력에 작업 적성을 적용하지 않고 기본
운반력만 사용한다. 일꾼의 운반력은 작업 적성으로 계산되고, 방어 동료의 공격력은 방어
적성으로 계산된다.

### 5.3 탐험 동료

- 탐험 동료는 플레이어 주변의 고정 대형 위치를 따라가며, 플레이어가 현재 공격·채집하는
  목표를 함께 처리한다.
- 탐험 동료의 공격력은 기본 공격력에 탐험 적성 보정을 적용한다. 같은 목표에 기여하되,
  플레이어의 자동 목표 우선순위보다 먼저 다른 목표를 선택하지 않는다.
- 탐험 동료의 기본 운반력은 공유 등짐의 한도에 더한다. 동료가 이탈하면 해당 수치가 즉시
  빠진다.
- 동행 수용량이 비어 있는 만큼만 탐험 동료로 편성한다. 편성 순서는 플레이어가 기지 화면에서
  선택한 순서이며, 새 영입 동료는 마지막 위치에 들어간다.
- 좁은 길에서 대형이 모두 지나갈 수 없으면 동료는 플레이어 뒤의 가장 가까운 안전 지점에
  잠시 모였다가 길이 열리면 따라온다. 동료가 멈춰도 플레이어의 이동·전투는 막지 않는다.

### 5.4 일꾼

- 일꾼은 기지의 실제 동선으로 자원·상품·코인을 옮긴다. 기본 순서는
  `채석장·숲 벌목 파견 → 메인 기지 → 공방 → 판매대·계산대 → 메인 기지`다.
- 일꾼은 한 번에 자신의 기본 운반력에 작업 적성 보정을 적용한 수량만 옮긴다.
- 여러 일꾼이 동시에 비어 있으면 먼저 오래 기다린 운반 요청을 처리한다. 같은 시점의 요청은
  메인 기지에서 가까운 목적지부터 처리한다.
- 재료가 부족하거나 목적지가 가득 차면 일꾼은 해당 위치에서 대기하고, 플레이어에게 요청
  말풍선과 막힌 동선 아이콘을 보여 준다. 재료가 생기면 자동으로 다시 운반한다.
- 계산대 첫 강화 뒤 전용 코인 운반 자리 하나가 열리는 코어 규칙을 따른다. 담당 일꾼이
  사라지거나 다른 역할로 바뀌면 플레이어 직접 운반으로 돌아간다.

### 5.5 방어 동료

- 방어 동료는 방어 야영지에서 대기하다가 약탈 경보가 발생하면 남쪽 출입문으로 이동한다.
- 방어 동료의 공격력에는 방어 적성 보정을 적용한다. 방어 야영지에서 출입문까지의 이동 중
  약탈 무리와 마주치면 먼저 공격받은 대상을 방어한다.
- 모든 방어 동료가 쓰러지거나 치료 중이면 남은 약탈 무리가 벽·출입문을 공격한다. 약탈의
  손상·결과·자동 방어는 [`core-gameplay.md`](core-gameplay.md) 11~13절을 따른다.
- 온라인 방어에서 체력이 0이 된 동료는 치료소가 있으면 치료 대기열로, 없으면 영구 이탈한다.
  오프라인 방어에서 부상한 동료는 치료소가 없으면 부상 대기 상태로 남고, 치료소가 완성된
  뒤 치료를 시작한다.
- 치료를 마친 동료는 방어 동료 역할을 유지하고 다음 약탈에 자동 복귀한다. 역할을 바꾸려면
  플레이어가 메인 기지에서 직접 변경한다.

## 6. 유지·초기화와 선택 결과

| 상태 | 메인 기지·포탈 이동 | 플레이어 패배 | 앱을 닫았다가 복귀 |
| --- | --- | --- | --- |
| 영입한 동료 | 보유·역할·수용량 유지 | 살아 있으면 유지, 체력 0인 탐험 동료는 이탈 | 보유·역할·치료 상태를 유지 |
| 미선택 영입 결과 | 포탈 이동 시 재화로 자동 처리 | 재화로 자동 처리 | 재화로 자동 처리 후 안전 자원 보관 |
| 수용량 확장 | 완료된 확장은 유지, 미완료 임시 투입은 코어 규칙 적용 | 완료된 확장은 유지 | 완료된 확장은 유지 |
| 탐험 편성 | 살아 있으면 유지 | 생존 동료는 유지 | 마지막 역할과 편성으로 복귀 |
| 일꾼·방어 동선 | 기지 안에서 계속 진행 | 기지 운영은 계속 | 오프라인 규칙에 따라 계속 |

영입 선택은 같은 생물을 두 경로로 지급하지 않는다. `영입` 또는 `재화` 중 하나가 완료되면
그 생물은 결과 목록에서 사라진다. 자동·오프라인 방어는 보상 선택 화면을 만들지 않고, 생물별
뼈·소울을 안전 자원으로 한 번만 보관한다.

## 7. 영입·동료 UI와 접근성

| 화면 상태 | 필수 정보 | 선택·차단 피드백 |
| --- | --- | --- |
| 영입 기회 | 생물 이름·초상화·등급, 영입 가능 확률, 남은 시간, 동행·기지 수용량 | `영입`, `재화` 버튼과 각 결과의 보상 설명 |
| 영입 불가 | 부족한 수용량의 현재/최대, 확장 또는 역할 변경 방법 | `영입` 비활성화, `재화`는 활성화 |
| 재화 선택 | 뼈 수량, 소울 확률과 성공 시 수량 | `재화` 확정 뒤 뼈·소울 획득 연출 |
| 영입 완료 | 새 동료 이름·역할·적성, 수용량 변화 | 빛이 동료에게 모이고 동료가 플레이어를 따라감 |
| 역할 변경 | 세 역할, 현재 역할, 적성 등급과 예상 효율 | 역할 선택 전후 운반·전투·방어 아이콘 비교 |
| 수용량 확장 | 현재/최대 수용량, 소울 비용, 임시 투입량 | 부족한 소울 문구, 완료 빛, 최대치 표시 |
| 치료 대기 | 부상 동료 이름, 치료소 유무, 복귀 상태 | 치료 중·대기·복귀 아이콘을 색상과 문구로 표시 |
| 자동 방어 결과 | 잃은 상품·코인, 획득 뼈·소울, 부상·이탈 동료 | 영입 버튼을 표시하지 않고 안전 자원 자동 보관을 안내 |

영입 가능·불가는 색상만으로 구분하지 않는다. 버튼 모양, 자물쇠·수용량 아이콘, 현재/최대
숫자와 이유 문구를 함께 사용한다. 남은 시간은 초 단위 숫자와 진행 막대로 함께 표시한다.
화면을 닫아도 영입 선택이 완료되지 않았다면 타이머는 계속 흐르고, 닫힌 뒤 규칙에 따라
재화 결과가 처리된다.

| 보스 생물을 쓰러뜨림 | 항상 영입 버튼이 생기고 재화 선택 시 종별 공통 등급 보상의 소울 수량이 지급된다 |
| 동행 또는 기지 수용량이 가득 참 | 영입 버튼이 비활성화되고 부족한 수용량과 다음 행동이 표시된다 |
| 영입을 선택함 | 동료가 생기고 뼈·소울은 지급되지 않으며 결과가 다시 선택되지 않는다 |
| 재화를 선택함 | 종별 뼈와 등급별 소울 결과가 지급되고 생물이 결과 목록에서 사라진다 |
| 선택 중 3칸 이상 이동하거나 패배 | 영입이 되지 않고 재화 결과가 한 번만 자동 처리된다 |
| 새 동료를 일꾼으로 변경 | 메인 기지에서 비용 없이 역할이 바뀌고 실제 운반 동선이 시작된다 |
| 새 동료를 탐험 동료로 유지 | 플레이어와 같은 목표를 공격·채집하고 운반력이 등짐 한도에 더해진다 |
| 작업 적성 5 동료를 일꾼으로 배치 | 기본 운반력에 +60%가 적용되고 역할 아이콘에 적성이 표시된다 |
| 방어 동료가 온라인 약탈에서 쓰러짐 | 치료소가 있으면 치료 대기, 없으면 영구 이탈한다 |
| 방어 동료가 오프라인 약탈에서 부상 | 치료소가 없으면 대기하고, 치료소 완성 뒤 치료를 시작한다 |
| 동행 수용량을 확장함 | 소울 전량 투입 뒤 최대치가 즉시 +1 되고, 중도 이탈 시 임시 투입분이 돌아온다 |
| 기지 수용량이 12/12 | 확장 비콘이 최대치로 표시되고 더 이상 소울을 받지 않는다 |

## 9. 결정 정리와 변경 기록

### 담당 범위에 반영한 확정

- 코어 문서의 영입·수용량·역할·자동 방어·치료 경계
- 영입과 재화의 상호 배타적 결과, 역할 변경 무료·기지 한정, 탐험·일꾼·방어의 세 역할

### 사용자 승인으로 확정한 출시 기본값

- 일반·엘리트 영입 기회 70%, 소울 확률 15%·35%, 보스 영입·소울 100%
- 영입 선택 15초, 3칸 이탈 시 재화 자동 처리
- 동행 1~6명, 기지 1~12명과 소울 확장 비용
- 적성 등급 1~5와 역할별 보정

### 검증 필요

- 등급별 확률과 소울 수급 속도, 수용량 비용의 장기 균형
- 15초 선택 시간과 결과 선택 중 위험 노출의 이해 가능성
- 적성 보정이 역할 변경의 의미를 만들면서 특정 생물만 강제하지 않는지
- 대형 간격, 동료의 좁은 길 이동과 기지 물류 동선의 가독성

담당 출시 범위의 규칙에는 `미정`을 남기지 않았다. 검증 결과는 이 문서와 종별 콘텐츠 문서의
원본 수치를 함께 갱신한다.
