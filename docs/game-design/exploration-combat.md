## 1. 목적과 범위

이 문서는 플레이어가 동굴 메인 기지에서 출발해 동굴과 숲을 탐험하고, 이동만 직접 조작하면서
전투·채집 결과를 얻은 뒤 귀환하는 규칙의 단일 원본이다.

### 포함

- 상하좌우 이동, 자동 행동과 카메라
- 지역 크기·거리 구간·지도·고정 포탈
- 자원 노드, 회복 우물, 보스 보금자리와 재등장 시간
- 자동 목표, 공격·피해·체력·대상 변경
- 플레이어 능력치·강화·외형 변화
- 플레이어 패배, 동료 이탈, 회복과 재출발
- 탐험·전투·채집·비콘의 UI, 접근성, 시각·사운드 표현

### 제외

- 영입 확률·수용량·선호 역할: [`creatures-and-recruitment.md`](creatures-and-recruitment.md)
- 생물 16종의 개별 외형·수치·보상: [`creature-content.md`](creature-content.md)
- 기지 생산·판매·약탈의 상세 규칙: [`core-gameplay.md`](core-gameplay.md)
- 코드, 데이터 컬럼·자료형, 저장 구조·시점, 구현 알고리즘, 런타임 오류 처리, 분석 이벤트와 개발·출시 절차

## 2. 전체 규칙 지도와 진행 순서

| 항목 | 확정 규칙 |
| --- | --- |
| 시작 조건 | 플레이어는 최대 체력으로 동굴 메인 기지에서 시작한다 |
| 진행 순서 | 지역 선택 → 이동·탐색 → 자동 전투·채집 → 결과 확인 → 귀환 또는 계속 탐험 |
| 플레이어 선택 | 이동 방향, 카메라 둘러보기·확대, 포탈 이동 확인, 귀환 시점과 강화 경로 |
| 비용·보상 | 자원 노드는 자원 1개, 생물은 영입 또는 재화 결과를 주며 강화는 코인을 쓴다 |
| 제한 | 체력, 등짐, 사거리, 지역 경계와 재등장 시간이 탐험을 제한한다 |
| 우선순위 | 적대 생물 → 중립 생물 → 자원, 같은 종류는 거리와 마지막 이동 방향 순 |
| 종료·실패 | 귀환·포탈 이동·게임 종료로 현장 행동이 끝나며 패배하면 등짐을 잃고 재출발한다 |
| 유지·초기화 | 안전 자원과 완료 강화는 유지하고, 대상별 전투 상태는 10절을 따른다 |
| UI 피드백 | 체력·등짐·대상·지역·작은 지도를 항상 표시하고 자동 행동의 원인과 결과를 알린다 |

## 3. 조작과 카메라

### 3.1 플레이어 조작

- 플레이어가 직접 조작하는 현장 행동은 상·하·좌·우 이동뿐이다.
- 터치 방향 패드를 기본으로 사용하며, 키보드에서는 방향키와 WASD가 같은 4방향 이동을 한다.
- 공격, 채집, 비콘 재화 투입과 목표 선택은 조건을 만족하면 자동으로 진행한다.
- 공격·채집 버튼, 수동 조준과 대상을 직접 고르는 목표 변경은 사용하지 않는다.
- 이동을 시작해 행동 범위를 벗어나면 아직 판정되지 않은 자동 행동은 해당 행동의 규칙에 따라
  중단된다.

플레이어 능력치와 모든 생물의 이동 속도는 초당 3칸으로 같다. 이동 속도 차이나 이동 속도
강화는 출시 범위에 없다.

### 3.2 카메라

- 카메라는 플레이어를 따라가며 마지막 이동 방향 앞쪽을 3칸 더 보여 준다.
- 화면을 끌어 플레이어 위치에서 최대 8칸까지 둘러볼 수 있다. 손을 떼면 플레이어 추적으로
  돌아온다.
- 확대 범위는 85%~120%이며 플레이어가 정한 확대값은 지역 이동과 패배 뒤에도 유지한다.
- 지역 이동 직후에는 새 지역의 플레이어 위치를 화면 안에 맞추고 앞쪽 3칸 보기로 돌아간다.
- 둘러보기 중에도 이동을 입력하면 즉시 플레이어 추적으로 돌아간다.

## 4. 지역과 지도

### 4.1 지역 구조

- 동굴과 숲은 각각 320×480칸의 개방형 지역이며 번호가 붙은 스테이지로 나누지 않는다.
- 메인 기지 또는 지역 진입점을 기준으로 이동 거리 0~30%는 근거리, 30~65%는 중거리,
  65~100%는 원거리로 구분한다.
- 동굴은 돌·수정·이끼, 숲은 나무·달빛·발광 식물과 서로 다른 생물 구성으로 구분한다.
- 보스 보금자리, 회복 우물, 자원과 생물의 배치는 통행을 막지 않는 열린 공간을 사용한다.

### 4.2 지도 공개

- 플레이어 주변 12칸을 지도에 밝힌다.
- 메인 기지와 고정 포탈은 처음부터 지도에 표시한다.
- 회복 우물과 보스 보금자리는 한 번 발견하면 계속 표시한다.
- 작은 지도는 탐험 HUD에 항상 표시하고, 전체 지도에서는 발견한 범위와 영구 표식만 보여 준다.
- 발견하지 않은 자원·생물과 재등장 위치는 지도에 미리 표시하지 않는다.

### 4.3 고정 포탈

1. 플레이어가 고정 포탈에 닿으면 이동할 지역을 보여 주는 확인창을 연다.
2. 확인창이 열려 있는 동안 세계를 정지한다.
3. 취소하면 원래 위치와 모든 현장 상태를 유지한다.
4. 확인하면 플레이어, 생존 동료와 등짐을 새 지역으로 즉시 옮긴다.
5. 적과 투사체는 포탈을 넘어오지 않으며, 자동 목표와 카메라 둘러보기는 초기화한다.

포탈 이동 때 선택하지 않은 생물 결과는 보상 없이 사라지는
[`영입·재화 선택`](creatures-and-recruitment.md) 규칙을 따른다. 포탈 이동은 쓰러지지 않은 보스의
체력을 완전히 회복시키는 유일한 조건이다.

## 5. 자원과 재등장

### 5.1 자원 노드

| 지역 | 자원 | 노드 내구도 | 채집 완료 보상 | 고정 위치 | 위치 변경 | 합계 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 동굴 | 돌 | 20 | 돌 1개 | 50개 | 70개 | 120개 |
| 숲 | 나무 | 20 | 나무 1개 | 50개 | 70개 | 120개 |

- 각 지역의 근거리·중거리·원거리에 자원 노드 40개씩을 유지한다.
- 고정 위치 노드는 근거리 17개·중거리 17개·원거리 16개다.
- 위치 변경 노드는 근거리 23개·중거리 23개·원거리 24개다.
- 고정 위치가 다른 대상에 막혀 있으면 원래 자리에서 가장 가까운 빈자리에 나타난다.
- 위치 변경 노드는 같은 거리 구간의 이전과 다른 빈자리에 나타나며 메인 기지·고정 포탈·회복
  우물·보스 보금자리 바로 옆에는 나타나지 않는다.
- 등짐이 가득 차면 채집만 멈추고 이동과 전투는 계속한다.

### 5.2 재등장 시간

`재등장 시간`은 채집 또는 생물 결과 처리가 끝난 뒤 대상이 다시 나타날 때까지 흐르는 실제
시간이다. 다른 지역에 있거나 게임을 닫아도 흐른다.

| 대상 | 재등장 시간 | 시작 시점 |
| --- | ---: | --- |
| 돌 노드 | 30초 | 돌 1개 채집 완료 |
| 나무 노드 | 45초 | 나무 1개 채집 완료 |
| 일반 생물 무리 | 60초 | 마지막 개체의 영입·재화 결과 처리 또는 미선택 소멸 |
| 엘리트 생물 무리 | 180초 | 마지막 개체의 영입·재화 결과 처리 또는 미선택 소멸 |
| 보스 생물 | 900초 | 보스의 영입·재화 결과 처리 또는 미선택 소멸 |

재등장 시 플레이어가 같은 화면에 있어도 즉시 나타난다. 생물 무리는 마지막 개체의 결과가
끝난 뒤 등급별 시간이 지나면 원래 무리 구역에 종별 허용 수만큼 새 무리 전체가 나타난다.

## 6. 회복 우물과 보스 보금자리

### 6.1 회복 우물

- 지역마다 고정 회복 우물 4개를 근거리 1개·중거리 1개·원거리 2개 배치한다.
- 보스 보금자리 안에는 회복 우물을 두지 않는다.
- 플레이어와 체력이 1 이상인 탐험 동료는 우물 중심 반경 1.5칸 안에서 초당 최대 체력의
  10%를 회복한다.
- 공격하거나 피해를 받으면 회복을 멈춘다. 마지막 공격·피격 뒤 2초가 지나고 범위 안에 있으면
  회복을 재개한다.
- 체력 0인 동료는 회복 우물로 되살릴 수 없다.

### 6.2 보스 보금자리

- 각 지역의 원거리에 열린 보스 보금자리 하나를 고정 배치한다.
- 처음 들어가면 보스 이름과 위험 경고를 표시하며, 범위 안에서 보스와 자동 교전한다.
- 플레이어가 보금자리를 벗어나면 보스는 중심으로 돌아가지만 현재 체력을 유지한다.
- 플레이어 패배와 게임 종료에도 쓰러지지 않은 보스의 현재 체력을 유지한다.
- 고정 포탈로 지역을 이동할 때만 쓰러지지 않은 보스가 최대 체력으로 완전히 회복한다.
- 보스를 쓰러뜨린 뒤에는 영입·재화 결과가 끝나야 900초 재등장 시간이 시작된다.

## 7. 자동 목표

1. 공격·채집 범위 안의 대상을 `적대 생물 → 중립 생물 → 자원` 순으로 찾는다.
2. 같은 종류의 후보가 여럿이면 가장 가까운 대상을 고른다.
3. 거리까지 같으면 플레이어의 마지막 이동 방향과 가장 가까운 대상을 고른다.
4. 현재 목표는 쓰러짐·채집 완료·범위 이탈 전까지 유지한다.
5. 더 높은 우선순위 대상이 나타나면 현재 공격 또는 채집 1회를 끝낸 뒤 전환한다.
6. 현재 행동이 판정 전에 취소되면 결과를 지급하지 않고 다음 목표를 찾는다.

플레이어와 탐험 동료는 같은 자동 목표를 사용한다. 수동 목표 선택이나 같은 우선순위 안의
강제 대상 고정은 제공하지 않는다.

## 8. 전투

### 8.1 공통 능력치와 피해

- 전투와 운반에 사용하는 능력치는 `체력`, `공격력`, `운반능력`뿐이다.
- 피해 한 번은 공격자의 공격력과 같은 수치를 대상의 현재 체력에서 직접 뺀다.
- 방어력, 치명타, 회피와 무작위 피해는 사용하지 않는다.
- 서로의 마지막 공격 판정이 같은 순간에 도달해 양쪽 체력이 0이 되면 양쪽 모두 쓰러진다.
- 플레이어와 생물이 동시에 쓰러지면 생물의 아직 선택하지 않은 영입·재화 결과는 플레이어
  패배로 인해 보상 없이 사라진다.

### 8.2 공격 판정

| 공격자 | 방식 | 공격 간격 | 사거리 | 판정 |
| --- | --- | ---: | ---: | --- |
| 플레이어 | 근접 | 0.5초 | 1.2칸 | 판정 순간 대상이 범위 밖이면 빗나간다 |
| 근접 생물 | 근접 | 0.8초 | 1.2칸 | 판정 순간 대상이 범위 밖이면 빗나간다 |
| 원거리 생물 | 투사체 | 1.0초 | 4칸 | 발사 전 범위를 벗어나면 취소되고, 발사된 투사체는 반드시 맞는다 |

- 생물은 종별로 정한 근접 또는 원거리 기본 공격 하나만 사용한다.
- 공격 간격이 공격 예고와 다음 공격 가능 시점을 함께 정하며 별도 재사용 대기시간은 없다.
- 접촉 자체는 피해를 주지 않는다.
- 발사된 투사체는 빠르게 직선으로 표현하지만 목표를 따라 휘지 않는다. 판정은 반드시 맞는
  규칙을 따른다.
- 근접과 원거리 공격의 예고 동작·소리를 구분해 피할 수 있는 공격과 이미 확정된 공격을 알린다.

### 8.3 무리 반격과 추적 경계

- 중립 생물 한 마리를 공격하면 함께 다니는 같은 종 무리 전체가 적대 상태로 바뀌어 반격한다.
- 일반·엘리트 생물은 시작 위치에서 6칸 밖으로 나가면 돌아간다. 돌아가는 동안 현재 체력과
  적대 상태를 유지한다.
- 포탈 이동, 플레이어 패배 또는 게임 종료 시 쓰러지지 않은 일반·엘리트 생물은 최대 체력과
  기본 태도로 돌아간다.
- 보스는 6.2절의 별도 유지·회복 규칙을 따른다.

## 9. 플레이어 성장

### 9.1 능력치와 비용

| 능력치 | 시작값 | 단계별 증가 | 5회 강화 후 |
| --- | ---: | ---: | ---: |
| 체력 | 100 | +25 | 225 |
| 공격력 | 10 | +2 | 20 |
| 운반능력 | 20 | +5 | 45 |

세 경로는 서로 독립적으로 5회 강화한다. 각 경로의 단계별 비용은
`100 → 250 → 500 → 1,000 → 2,000코인`이다.

### 9.2 강화 흐름과 외형

1. 동굴 메인 기지의 플레이어 강화 비콘에 접근한다.
2. `체력`, `무기`, `운반능력` 버튼 중 강화할 경로 하나를 고른다.
3. 현재 단계에 필요한 코인이 자동 투입되며 공통 비콘의 부족·이탈·완료 규칙을 따른다.
4. 전량 투입되면 선택한 능력치가 즉시 증가하고 다음 비용을 표시한다.
5. 5회 강화한 경로는 최대치로 표시하고 더 이상 코인을 받지 않는다.

무기 외형은 시작 상태를 포함해 다음 여섯 단계로 바뀐다.

`나무자루 돌도끼 → 단단한 돌도끼 → 뼈날 도끼 → 수정날 도끼 → 소울빛 도끼 → 태고의 도끼`

등짐은 `작은 가죽 주머니 → 나무틀 추가 → 뼈장식 추가 → 수정장식 추가 → 소울빛 추가 →
태고풍 등짐` 순으로 바뀐다. 운반능력 화면에는 현재 한도, 다음 한도, `+5`, 비용과 다음 등짐
외형을 함께 표시한다.

탐험 동료의 기본 운반능력은 플레이어의 운반능력에 합산한다. 동료의 `선호 역할` 보정은
[`creatures-and-recruitment.md`](creatures-and-recruitment.md)를 따른다.

## 10. 패배·회복·유지와 초기화

### 10.1 플레이어 패배

1. 플레이어 체력이 0이 되면 현재 행동과 미선택 영입·재화 선택을 끝낸다.
2. 등짐의 돌·나무·뼈와 현장에 남은 초과 자원을 잃고, 안전 자원과 소울은 유지한다.
3. 3초 뒤 동굴 메인 기지에서 최대 체력으로 돌아온다.
4. 별도 비용이나 무적 시간 없이 다시 이동할 수 있다.

생존한 탐험 동료는 현재 체력과 함께 기지로 돌아온다. 플레이어와 생존 동료가 기지에 5초
머물면 모두 최대 체력으로 완전히 회복한다. 체력 0이 된 탐험 동료는 영구 이탈한다.

### 10.2 동료 이탈과 등짐

- 탐험 동료가 이탈하면 그 동료의 기본 운반능력이 공유 등짐 한도에서 즉시 빠진다.
- 현재 화물이 새 한도를 넘으면 초과분을 현장에 내려놓는다.
- 플레이어가 살아 있고 공간을 만들면 현장 자원에 접근해 다시 자동으로 싣는다.
- 플레이어가 패배하면 등짐과 현장 초과분을 모두 잃는다.

### 10.3 상태 경계

## 11. UI·접근성·표현

### 11.1 항상 표시

- 플레이어와 탐험 동료의 현재·최대 체력
- 등짐의 현재 화물과 합산 운반 한도
- 자동 목표의 이름, 체력 또는 자원 내구도와 현재 행동
- 현재 지역 이름과 작은 지도

### 11.2 상태별 피드백

| 상황 | 필수 피드백 |
| --- | --- |
| 자동 전투·채집 | 대상 윤곽, 행동 아이콘, 판정 소리와 피해·회복 숫자 |
| 비콘 | 선택한 강화 경로, 요구량·현재 투입량·부족량과 완료 연출 |
| 포탈 | 이동 지역, 유지되는 동료·화물, 확인·취소 버튼과 세계 정지 표시 |
| 회복 우물 | 회복 범위, 회복 숫자, 전투로 멈춘 이유와 2초 뒤 재개 상태 |
| 보스 보금자리 | 보스 이름·체력, 위험 경고, 보금자리 경계와 재등장 시간 |
| 패배·동료 이탈 | 잃은 것·유지된 것, 줄어든 운반 한도와 다음 행동 |
| 강화 | 현재값·다음값·증가량·비용·최대치와 무기 또는 등짐 외형 변화 |

- 피해·회복 숫자는 기본 표시하고 설정에서 각각 끌 수 있다.
- UI 크기는 100%·125%·150%를 제공한다.
- 색만으로 상태를 구분하지 않고 아이콘·윤곽·문구를 함께 쓴다.
- 진동과 화면 흔들림은 각각 끌 수 있다. 화면 흔들림은 보스와 패배처럼 의미 있는 순간에만
  낮은 강도로 사용한다.
- 적대 감지와 보스 위험 소리는 화면 가장자리 방향 아이콘과 짧은 경고 문구로도 표시한다.
- 근접·원거리 예고, 피격, 적대 전환, 회복 우물, 영입·재화 결과와 보스 진입은 서로 다른
  짧은 소리를 사용한다.

### 11.3 표현 수위

- 피, 절단과 시체 훼손은 사용하지 않는다.
- 공격과 피격은 빛·먼지·잎·수정 파편으로 표현한다.
- 쓰러진 생물은 숨을 고르며 남고, 영입·재화 결과가 정해지면 빛으로 사라진다.
- 플레이어 패배와 동료 이탈은 비명이나 고통 묘사 대신 빛이 약해지는 연출과 결과 문구를 쓴다.

## 13. 검증 필요

- 카메라 앞쪽 3칸, 둘러보기 8칸, 확대 85%~120%가 세로 화면에서 목표와 위험을 읽기에
  적절한지 5개 이상 화면 비율로 확인한다.
- 320×480칸에서 자원 120개와 생물 무리 밀도가 10~15분 탐험에 빈 이동 시간을 만들지 않는지
  동굴·숲 각 5회 이상 탐험으로 확인한다.
- 돌 30초·나무 45초와 생물 60초·180초·900초 재등장이 기다림을 강요하지 않는지 확인한다.
- 플레이어 체력·공격력·운반능력과 강화 비용이 초반과 장기 목표를 함께 만드는지 확인한다.
- 최종 운반능력 45에서 귀환 빈도가 지나치게 낮아지지 않는지, 작업 선호 동료의 가치가
  사라지지 않는지 플레이어 단독·동료 편성·기지 작업을 비교한다.
- 회복 우물이 위험을 완전히 제거하지 않는지, 보스 체력 유지가 재도전 동기를 만드는지 확인한다.
- 근접·원거리 판정과 동시에 쓰러짐 결과를 플레이어가 공정하게 이해하는지 확인한다.
