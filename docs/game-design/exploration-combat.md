## 1. 목적과 범위

이 문서는 플레이어가 동굴에서 깨어나 출입구로 숲과 동굴을 오가며 탐험하고, 이동만 직접 조작하면서
전투·채집 결과를 얻은 뒤 귀환하는 규칙의 단일 원본이다.

### 포함

- 아날로그 연속 이동, 자동 행동과 카메라
- 지역 크기·거리 구간·지도·동굴 출입구
- 자원 노드, 자원 적재칸, 회복 우물, 보스 보금자리와 재등장 시간
- 자동 목표, 공격·피해·체력·대상 변경
- 플레이어 능력치·강화·외형 변화
- 플레이어 패배, 동료 이탈, 회복과 재출발
- 탐험·전투·채집·비콘의 UI, 접근성, 시각·사운드 표현

### 제외

- 영입 확률·수용량·선호 역할: [`creatures-and-recruitment.md`](creatures-and-recruitment.md)
- 생물 16종의 개별 외형·수치·보상: [`creature-content.md`](creature-content.md)
- 기지 생산·물류의 상세 규칙: [`base-automation.md`](base-automation.md)
- 판매·약탈·치료의 상세 규칙: [`sales-defense.md`](sales-defense.md)
- 코드, 데이터 컬럼·자료형, 저장 구조·시점, 구현 알고리즘, 런타임 오류 처리, 분석 이벤트와 개발·출시 절차

## 2. 전체 규칙 지도와 진행 순서

| 항목           | 확정 규칙                                                                                         |
| -------------- | ------------------------------------------------------------------------------------------------- |
| 시작 조건      | 플레이어는 최대 체력·허름한 옷·낡은 손도끼를 소지한 채 동굴 모닥불 옆에서 깨어난다                |
| 진행 순서      | 동굴 출입구 → 이동·탐색 → 자동 전투·채집 → 결과 확인 → 귀환 또는 계속 탐험                        |
| 플레이어 선택  | 이동 방향, 카메라 둘러보기·확대, 귀환 시점과 강화 경로                                            |
| 비용·보상      | 자원 노드는 자원 적재칸에 자원 1개를 만들고, 생물은 영입 또는 재화 결과를 주며 강화는 코인을 쓴다 |
| 제한           | 체력, 등짐, 사거리, 지역 경계와 재등장 시간이 탐험을 제한한다                                     |

| 우선순위       | 적대 생물 → 중립 생물 → 자원, 같은 종류는 거리와 마지막 이동 방향 순                              |
| 종료·실패      | 귀환·지역 전환·게임 종료로 현장 행동이 끝나며 패배하면 등짐을 잃고 재출발한다                     |
| 유지·초기화    | 안전 자원과 완료 강화는 유지하고, 대상별 전투 상태는 10절을 따른다                                |
| UI 피드백      | 체력·등짐·대상·지역·작은 지도를 항상 표시하고 자동 행동의 원인과 결과를 알린다                    |

## 3. 조작과 카메라

### 3.1 플레이어 조작

- 플레이어가 직접 조작하는 현장 행동은 이동뿐이다.
- 모바일에서는 왼쪽 아래 엄지 영역에서 터치를 시작한 위치에 나타나는 동적 아날로그 조이스틱을 기본으로 사용한다.
- 조이스틱은 누른 방향으로 360도 연속 이동하며, 중심에서 민 거리에 따라 0~100% 이동 속도를 적용한다.
- 손을 떼면 이동 입력과 조이스틱 표시를 즉시 해제한다. 키보드의 방향키와 WASD는 개발·접근성 입력으로 같은 이동 벡터를 만든다.
- 공격, 채집, 비콘 재화 투입과 목표 선택은 조건을 만족하면 자동으로 진행한다.
- 공격·채집 버튼, 수동 조준과 대상을 직접 고르는 목표 변경은 사용하지 않는다.
- 이동을 시작해 행동 범위를 벗어나면 아직 판정되지 않은 자동 행동은 해당 행동의 규칙에 따라
  중단된다.

조이스틱을 끝까지 민 플레이어의 이동 속도는 초당 3칸이다. 대각선 입력은 정규화해 직선보다 빨라지지
않는다. 야생 생물의 생활 이동과 추적 속도는 5.3절을 따르며 플레이어 이동 속도 강화는 출시 범위에 없다.

### 3.2 카메라

- 카메라는 플레이어를 화면 중앙보다 조금 아래에 두고 부드럽게 따라가며 마지막 이동 방향 앞쪽을 3칸 더 보여 준다.
- 세로 화면의 배경은 가장자리까지 필드로 채우고 이동용 격자선이나 개발용 좌표·대상 이름을 상시 표시하지 않는다.
- 플레이어, 동행 생물과 가까운 자동 목표가 한 화면에서 무리의 움직임으로 읽히는 크기를 기본 배율로 삼는다.
- 화면을 끌어 플레이어 위치에서 최대 8칸까지 둘러볼 수 있다. 손을 떼면 플레이어 추적으로
  돌아온다.
- 확대 범위는 85%~120%이며 플레이어가 정한 확대값은 지역 이동과 패배 뒤에도 유지한다.
- 지역 이동 직후에는 새 지역의 플레이어 위치를 화면 안에 맞추고 앞쪽 3칸 보기로 돌아간다.
- 둘러보기 중에도 이동을 입력하면 즉시 플레이어 추적으로 돌아간다.

## 4. 지역과 지도

### 4.1 지역 구조

- 동굴은 성장 시설과 채굴장이 한 지역으로 읽히는 64×64칸 허브이며, 첫 숲은 1024×1536칸의
  개방형 지역이다. 번호가 붙은 스테이지로 나누지 않는다.
- 메인 기지 또는 지역 진입점을 기준으로 이동 거리 0~~30%는 근거리, 30~~65%는 중거리,
  65~100%는 원거리로 구분한다.
- 동굴은 거친 암반과 돌·철·금·다이아 광물 군락, 숲은 층이 겹친 나무·풀·잎과 서로 다른 생물 구성으로 구분한다.
- 동굴에는 상호작용하지 않는 버섯·수정 장식을 두지 않는다. 빛나는 광맥은 실제 채광 대상이어야 한다.
- 숲의 동굴 출입구 가까이에는 `숲 장터` 안전 공터를 고정 배치한다. 이 공터에는 야생 생물·자원 노드가
  나타나지 않으며 장터의 가판대, 판매대, 장터 관리대와 방어 시설 자리만 사용한다.
- 보스 보금자리, 회복 우물, 자원과 생물의 배치는 통행을 막지 않는 열린 공간을 사용한다.

첫 숲은 하나의 긴 복도가 아니라 아래 세 위험 지대가 자연스럽게 이어지는 광활한 필드다. 경계는 로딩 화면으로
나누지 않고 지면 색, 수목 밀도, 생물 구성과 미니맵의 지역명으로 읽게 한다.

| 숲 지대 | 거리 기준 | 위험 | 탐험 약속 | 권장 군단 전투력 |
| --- | ---: | ---: | --- | ---: |
| 초록 들머리 | 0~30% | I | 시야가 트인 개활지, 작은 무리, 첫 영입과 첫 일꾼 | 제한 없음 |
| 이끼숲 벌판 | 30~65% | II | 희귀 일반 생물, 빠른 적대 무리, 갈라지는 샛길 | 24 |
| 고대 수관 심부 | 65~100% | III | 영웅 엘리트, 전설 보스, 가장 좋은 작업 적성 | 52 |

- 나무는 벽처럼 화면을 채우지 않는다. 160×160칸 표본 통행 가능 비율 88% 이상을 1차 목표로 두고,
  큰 수목 군집 사이에 여러 화면 길이의 개활지와 시야축을 만든다.
- 더 깊은 지대에 들어가기 전에 미니맵의 위험 색, 희귀 생물 표식과 현장 이름표로 다음 목표를 먼저 보여 준다.

### 4.2 지도 공개

- 플레이어 주변 12칸을 발견 처리하며, 로컬 미니맵은 플레이어 중심 반경 48칸을 보여 준다.
- 메인 기지와 발견한 동굴 출입구는 지도에 표시한다. 새 게임의 숲 쪽 출입구는 첫 진입과 동시에 발견 처리한다.
- 회복 우물과 보스 보금자리는 한 번 발견하면 계속 표시한다.
- 북쪽 고정 작은 지도는 탐험 HUD에 항상 표시한다. 단색 레이더가 아니라 주변 지면·길·통행 불가 수목을
  축약한 지형형 지도로 그리고, 플레이어 방향, 발견한 입구·시설·자원과 반경 안의 야생 생물을 표시한다.
  엘리트는 보라색 맥동 표식, 보스는 금색 맥동 표식으로 일반 생물과 구분한다. 반경 밖 영구 표식은 지도
  테두리에 방향만 표시하며 전체 지도는 후속 범위다.
- 발견하지 않은 자원·생물과 재등장 위치는 지도에 미리 표시하지 않는다.

### 4.2.1 대형 숲 스트리밍과 개활지

- 첫 숲은 1024×1536 논리 셀을 한꺼번에 생성하지 않는다. 32×32칸 청크를 플레이어 주변에서 지연
  생성하고 최근 사용 청크는 최대 12개만 메모리에 둔다.
- 지면·길·수목·수풀·바위의 화면 인스턴스도 고정 크기 풀에서 빌려 쓰고 화면 밖으로 나가면 재사용한다.
- 주 동선은 최소 폭 13칸의 완만한 세로 길이며, 세 개의 가로 샛길과 불규칙 개활지를 연결한다.
  임의 160×160칸 표본의 통행 가능 비율은 88% 이상을 시작값으로 삼는다.
- 맵 크기를 더 늘릴 때 메모리 상한은 청크 캐시와 화면 오브젝트 풀 크기로만 결정하고 전체 논리 셀 수에
  비례해 증가시키지 않는다.

### 4.2.2 숲의 숨은 엘리트 동굴

- 숲의 긴 이동 구간 사이에는 근·중·원거리마다 하나씩, 총 3개의 숨은 동굴 입구를 둔다. 입구는 장식이
  아니라 접근하면 별도 동굴 내부 구역으로 전환되는 실제 탐험 장소다.
- 동료 보관소를 완성한 뒤 입장할 수 있으며, 미니맵에는 플레이어가 반경 48칸 안으로 접근해 발견했을 때만
  보라색 엘리트 동굴 표식이 나타난다.

| 거리대 | 동굴 | 엘리트 | 전투력 | 탐험 목적 |
| --- | --- | --- | ---: | --- |
| 근거리 | 이끼숨굴 | 동굴 가시깃 멧돼지 | 40 | 첫 엘리트와 영웅 희귀도 소개 |
| 중거리 | 바람틈 동굴 | 폭풍 수관큰부리새 | 44 | 원거리 엘리트 대응과 운반 적성 확보 |
| 원거리 | 고대뿌리 굴 | 고대 가시깃 우두머리 | 55 | 보스 전 마지막 군단 점검과 벌목 5단계 후보 확보 |

- 내부는 출구→짧은 접근로→넓은 전투 공터→엘리트 한 마리의 2~3분 포켓 구역이다. 일반 무리와 자원은
  넣지 않아 발견한 엘리트에 집중하게 한다.
- 엘리트를 쓰러뜨리면 일반 필드와 같은 `영입/재화` 선택을 적용한다. 선택 전에 출구로 나가면 결과는
  사라지고, 처치 전 후퇴하면 줄어든 체력을 유지한 채 다음 진입에서 이어 싸운다.
- 플레이어가 패배하면 등짐 손실과 함께 동굴 기지에서 회복한다. 탐험 동료는 일반 탐험 규칙대로 함께
  입장하고 전투한다.

### 4.3 동굴 출입구와 지역 전환

1. 동굴과 숲은 각각 별도 화면이며 자연스러운 동굴 입구로 연결한다.
2. 플레이어가 출입구 안쪽 전환선까지 이동하면 확인창 없이 화면을 전환한다.
3. 플레이어, 생존 동료와 등짐은 반대편 출입구의 대응 위치로 함께 이동한다.
4. 적과 투사체는 출입구를 넘어오지 않으며, 자동 목표와 카메라 둘러보기는 초기화한다.
5. 전환 직후 되돌아가는 입력으로 화면이 반복 전환되지 않도록 대응 위치를 전환선에서 충분히 떨어뜨린다.

지역 전환 때 선택하지 않은 생물 결과는 보상 없이 사라지는
[`영입·재화 선택`](creatures-and-recruitment.md) 규칙을 따른다. 지역 전환은 쓰러지지 않은 보스의
체력을 완전히 회복시키는 유일한 조건이다.

## 5. 자원과 재등장

### 5.1 자원 노드

| 지역 | 자원 구성                  | 도구 단계          | 채집 완료 결과                | 수치 상태                |
| ---- | -------------------------- | ------------------ | ----------------------------- | ------------------------ |
| 동굴 | 돌·철·금·다이아 군락       | 곡괭이 1·2·3·4단계 | 해당 광물 1개를 적재칸에 생성 | 내구도·배치 수 검증 필요 |
| 숲   | 시작 나무·단단한 나무 군락 | 도끼 1·2단계       | 해당 목재 1개를 적재칸에 생성 | 내구도·배치 수 검증 필요 |

- 자원은 종류와 등급별 군락으로 묶고, 상위 등급 군락일수록 출입구에서 더 멀거나 별도 채광 구역에 둔다.
- 전체 노드 수와 거리별 비율은 넓은 맵의 빈 이동 시간과 모바일 가독성을 확인한 뒤 확정한다.
- 고정 위치가 다른 대상에 막혀 있으면 원래 자리에서 가장 가까운 빈자리에 나타난다.
- 위치 변경 노드는 같은 거리 구간의 이전과 다른 빈자리에 나타나며 메인 기지·동굴 출입구·회복
  우물·보스 보금자리·숲 장터 안에는 나타나지 않는다.
- 서로 가까운 같은 자원 노드 묶음에는 네모난 자원 적재칸 하나를 둔다. 적재칸은 통행을 막지 않으며
  연결된 노드가 위치를 바꿔도 같은 거리 구간의 가장 가까운 적재칸을 사용한다.
- 노드 하나의 채집이 끝나면 돌 또는 나무 1개가 등에 즉시 들어가지 않고 연결된 자원 적재칸에 실물로
  하나씩 쌓인다. 적재칸 상한은 [채집·운반 기본값](progression-balance.md#61-채석장과-벌목장)을 따른다.
- 적재칸이 상한에 도달하면 연결된 노드를 새 자동 목표로 잡지 않고 `자원 적재칸이 가득 찼습니다`와
  현재량·상한을 표시한다. 하나 이상 회수되면 채집을 다시 허용한다.
- 플레이어가 자원 적재칸에 접근하면 공유 등짐의 빈 운반 한도만큼 자동으로 싣는다. 자원은 적재칸에서
  하나씩 줄고 같은 순서로 등에 쌓인다. 등짐이 가득 차면 회수만 멈추고 이동과 전투는 계속한다.
- 나무는 도끼, 돌·광석은 곡괭이의 요구 단계를 만족할 때만 채집한다. 요구 단계, 작업 시간과 상황별
  도구 장착은 [`tool-and-core-progression.md`](tool-and-core-progression.md)가 소유한다.

### 5.2 재등장 시간

`재등장 시간`은 채집 또는 생물 결과 처리가 끝난 뒤 대상이 다시 나타날 때까지 흐르는 실제
시간이다. 다른 지역에 있거나 게임을 닫아도 흐른다.

| 대상             |      재등장 시간 | 시작 시점                                          |
| ---------------- | ---------------: | -------------------------------------------------- |
| 광물 노드        | 등급별 검증 필요 | 광물 1개 채집 완료                                 |
| 나무 노드        | 등급별 검증 필요 | 목재 1개 채집 완료                                 |
| 일반 생물 무리   |             60초 | 마지막 개체의 영입·재화 결과 처리 또는 미선택 소멸 |
| 엘리트 생물 무리 |            180초 | 마지막 개체의 영입·재화 결과 처리 또는 미선택 소멸 |
| 보스 생물        |            900초 | 보스의 영입·재화 결과 처리 또는 미선택 소멸        |

재등장 시 플레이어가 같은 화면에 있어도 즉시 나타난다. 생물 무리는 마지막 개체의 결과가
끝난 뒤 등급별 시간이 지나면 원래 무리 구역에 종별 허용 수만큼 새 무리 전체가 나타난다.

### 5.3 야생 생물의 생활 이동

- 숲의 야생 생물은 전투 대기 오브젝트처럼 제자리에 서 있지 않는다. 각 개체는 자기 서식지의 시작점에서
  반경 1.5~~2.4칸 안의 결정론적 경유점을 골라 초당 0.5~~0.82칸으로 계속 배회한다.
- 경유점 도착 뒤 멈추는 시간은 0.12~0.48초뿐이며, 상하로 흔들기만 하는 대기 연출을 배회로 간주하지 않는다.
- 전투가 열리기 전에도 야생 생물은 보여야 하고 움직여야 한다. 적대 생물은 전투가 열린 뒤 플레이어가
  5.5칸 안으로 들어오면 추적하고, 공격 중·쓰러짐·영입 결과 선택 중에는 제자리에서 행동한다.
- 같은 종은 서식지 무리로 읽히되 완전히 같은 방향과 타이밍으로 움직이지 않는다. 토끼·벌·원숭이·여우·
  거북·멧돼지·큰부리새·사슴은 리소스 제작 전 프로토타입에서도 서로 다른 실루엣이어야 한다.
- 영입한 탐험 동료는 야생 배회 상태를 끝내고 플레이어 뒤의 군단 대형을 따른다.

## 6. 회복 우물과 보스 보금자리

### 6.1 회복 우물

- 지역마다 고정 회복 우물 4개를 근거리 1개·중거리 1개·원거리 2개 배치한다.
- 보스 보금자리 안에는 회복 우물을 두지 않는다.
- 플레이어와 체력이 1 이상인 탐험 동료는 우물 중심 반경 1.5칸 안에서 초당 최대 체력의
  10%를 회복한다.
- 공격하거나 피해를 받으면 회복을 멈춘다. 마지막 공격·피격 뒤 2초가 지나고 범위 안에 있으면
  회복을 재개한다.
- 체력 0인 동료는 회복 우물로 되살릴 수 없다.

### 6.2 보스 보금자리

- 각 지역의 원거리에 열린 보스 보금자리 하나를 고정 배치한다.
- 처음 들어가면 보스 이름과 위험 경고를 표시하며, 범위 안에서 보스와 자동 교전한다.
- 플레이어가 보금자리를 벗어나면 보스는 중심으로 돌아가지만 현재 체력을 유지한다.
- 플레이어 패배와 게임 종료에도 쓰러지지 않은 보스의 현재 체력을 유지한다.
- 동굴 출입구로 지역을 전환할 때만 쓰러지지 않은 보스가 최대 체력으로 완전히 회복한다.
- 보스를 쓰러뜨린 뒤에는 영입·재화 결과가 끝나야 900초 재등장 시간이 시작된다.

## 7. 자동 목표

1. 공격·채집·회수 범위 안의 대상을 `적대 생물 → 중립 생물 → 회수 가능한 자원 적재칸 → 자원` 순으로 찾는다.
2. 같은 종류의 후보가 여럿이면 가장 가까운 대상을 고른다.
3. 거리까지 같으면 플레이어의 마지막 이동 방향과 가장 가까운 대상을 고른다.
4. 현재 목표는 쓰러짐·채집 완료·범위 이탈 전까지 유지한다.
5. 더 높은 우선순위 대상이 나타나면 현재 공격 또는 채집 1회를 끝낸 뒤 전환한다.
6. 현재 행동이 판정 전에 취소되면 결과를 지급하지 않고 다음 목표를 찾는다.

플레이어와 탐험 동료는 같은 자동 목표를 사용한다. 수동 목표 선택이나 같은 우선순위 안의
강제 대상 고정은 제공하지 않는다.

## 8. 전투

### 8.1 공통 능력치와 피해

- 전투와 운반에 사용하는 능력치는 `체력`, `공격력`, `운반능력`뿐이다.
- 피해 한 번은 공격자의 공격력과 같은 수치를 대상의 현재 체력에서 직접 뺀다.
- 방어력, 치명타, 회피와 무작위 피해는 사용하지 않는다.
- 서로의 마지막 공격 판정이 같은 순간에 도달해 양쪽 체력이 0이 되면 양쪽 모두 쓰러진다.
- 플레이어와 생물이 동시에 쓰러지면 생물의 아직 선택하지 않은 영입·재화 결과는 플레이어
  패배로 인해 보상 없이 사라진다.

### 8.2 공격 판정

| 공격자      | 방식   | 공격 간격 | 사거리 | 판정                                                            |
| ----------- | ------ | --------: | -----: | --------------------------------------------------------------- |
| 플레이어    | 근접   |     0.5초 |  1.2칸 | 판정 순간 대상이 범위 밖이면 빗나간다                           |
| 근접 생물   | 근접   |     0.8초 |  1.2칸 | 판정 순간 대상이 범위 밖이면 빗나간다                           |
| 원거리 생물 | 투사체 |     1.0초 |    4칸 | 발사 전 범위를 벗어나면 취소되고, 발사된 투사체는 반드시 맞는다 |

- 생물은 종별로 정한 근접 또는 원거리 기본 공격 하나만 사용한다.
- 공격 간격이 공격 예고와 다음 공격 가능 시점을 함께 정하며 별도 재사용 대기시간은 없다.
- 접촉 자체는 피해를 주지 않는다.
- 발사된 투사체는 빠르게 직선으로 표현하지만 목표를 따라 휘지 않는다. 판정은 반드시 맞는
  규칙을 따른다.
- 근접과 원거리 공격의 예고 동작·소리를 구분해 피할 수 있는 공격과 이미 확정된 공격을 알린다.

### 8.3 무리 반격과 추적 경계

- 중립 생물 한 마리를 공격하면 함께 다니는 같은 종 무리 전체가 적대 상태로 바뀌어 반격한다.
- 일반·엘리트 생물은 시작 위치에서 6칸 밖으로 나가면 돌아간다. 돌아가는 동안 현재 체력과
  적대 상태를 유지한다.
- 지역 전환, 플레이어 패배 또는 게임 종료 시 쓰러지지 않은 일반·엘리트 생물은 최대 체력과
  기본 태도로 돌아간다.
- 보스는 6.2절의 별도 유지·회복 규칙을 따른다.

## 9. 플레이어 성장

### 9.1 능력치와 비용

| 능력치   | 시작값 | 단계별 증가 | 5회 강화 후 |
| -------- | -----: | ----------: | ----------: |
| 체력     |    100 |         +25 |         225 |
| 운반능력 |     20 |          +5 |          45 |

체력과 운반능력은 야영지 코어에서 서로 독립적으로 5회 강화한다. 각 경로의 단계별 비용은
`100 → 250 → 500 → 1,000 → 2,000코인`이다.

### 9.2 강화 흐름과 외형

1. 동굴 야영지 코어의 강화 비콘에 접근한다.
2. `체력`, `운반능력` 또는 동료 수용량 경로 하나를 고른다.
3. 현재 단계에 필요한 코인이 자동 투입되며 공통 비콘의 부족·이탈·완료 규칙을 따른다.
4. 전량 투입되면 선택한 능력치가 즉시 증가하고 다음 비용을 표시한다.
5. 5회 강화한 경로는 최대치로 표시하고 더 이상 코인을 받지 않는다.

도끼·곡괭이·무기의 제작, 강화와 외형 변화는 동굴 대장간에서 진행한다. 자원별 요구 단계와 상황별
도구 장착은 [`tool-and-core-progression.md`](tool-and-core-progression.md)를 따른다.

등짐은 `작은 가죽 주머니 → 나무틀 추가 → 뼈장식 추가 → 수정장식 추가 → 소울빛 추가 →
태고풍 등짐` 순으로 바뀐다. 운반능력 화면에는 현재 한도, 다음 한도, `+5`, 비용과 다음 등짐
외형을 함께 표시한다.

탐험 동료의 기본 운반능력은 플레이어의 운반능력에 합산한다. 동료의 `선호 역할` 보정은
[`creatures-and-recruitment.md`](creatures-and-recruitment.md)를 따른다.

## 10. 패배·회복·유지와 초기화

### 10.1 플레이어 패배

1. 플레이어 체력이 0이 되면 현재 행동과 미선택 영입·재화 선택을 끝낸다.
2. 등짐의 돌·나무·뼈와 현장에 남은 초과 자원을 잃고, 안전 자원과 소울은 유지한다.
3. 3초 뒤 동굴 모닥불 근처의 안전한 귀환 위치에서 최대 체력으로 돌아온다.
4. 별도 비용이나 무적 시간 없이 다시 이동할 수 있다.

생존한 탐험 동료는 현재 체력과 함께 기지로 돌아온다. 플레이어와 생존 동료가 기지에 5초
머물면 모두 최대 체력으로 완전히 회복한다. 체력 0이 된 탐험 동료는 영구 이탈한다.

### 10.2 동료 이탈과 등짐

- 탐험 동료가 이탈하면 그 동료의 기본 운반능력이 공유 등짐 한도에서 즉시 빠진다.
- 현재 화물이 새 한도를 넘으면 초과분을 현장에 내려놓는다.
- 플레이어가 살아 있고 공간을 만들면 현장 자원에 접근해 다시 자동으로 싣는다.
- 플레이어가 패배하면 등짐과 현장 초과분을 모두 잃는다.

## 11. UI·접근성·표현

### 11.1 항상 표시

- 플레이어와 탐험 동료의 현재·최대 체력
- 등짐의 현재 화물과 합산 운반 한도
- 자동 목표의 이름, 체력 또는 자원 내구도와 현재 행동
- 가까운 자원 적재칸의 자원 종류와 현재량·상한
- 현재 지역 이름과 작은 지도

### 11.2 상태별 피드백

| 상황           | 필수 피드백                                                    |
| -------------- | -------------------------------------------------------------- |
| 자동 전투·채집 | 대상 윤곽, 행동 아이콘, 판정 소리와 피해·회복 숫자             |
| 자원 적재칸    | 네모난 바닥 윤곽, 실물 자원 더미, 현재량/상한과 등짐 부족 공간 |
| 비콘           | 선택한 강화 경로, 요구량·현재 투입량·부족량과 완료 연출        |
| 동굴 출입구    | 전환할 지역, 함께 이동하는 동료·화물과 입구 윤곽               |
| 회복 우물      | 회복 범위, 회복 숫자, 전투로 멈춘 이유와 2초 뒤 재개 상태      |
| 보스 보금자리  | 보스 이름·체력, 위험 경고, 보금자리 경계와 재등장 시간         |
| 패배·동료 이탈 | 잃은 것·유지된 것, 줄어든 운반 한도와 다음 행동                |
| 강화           | 현재값·다음값·증가량·비용·최대치와 무기 또는 등짐 외형 변화    |

- 피해·회복 숫자는 기본 표시하고 설정에서 각각 끌 수 있다.
- 공통 UI 크기와 최소 터치 영역은 [`onboarding-ui.md`](onboarding-ui.md#9-세로-화면-접근성)를 따른다.
- 색만으로 상태를 구분하지 않고 아이콘·윤곽·문구를 함께 쓴다.
- 진동과 화면 흔들림은 각각 끌 수 있다. 화면 흔들림은 보스와 패배처럼 의미 있는 순간에만
  낮은 강도로 사용한다.
- 적대 감지와 보스 위험 소리는 화면 가장자리 방향 아이콘과 짧은 경고 문구로도 표시한다.
- 근접·원거리 예고, 피격, 적대 전환, 회복 우물, 영입·재화 결과와 보스 진입은 서로 다른
  짧은 소리를 사용한다.

### 11.3 표현 수위

- 피, 절단과 시체 훼손은 사용하지 않는다.
- 공격과 피격은 빛·먼지·잎·수정 파편으로 표현한다.
- 빛 표현에는 블룸을 사용하지 않는다. 밝은 부분색, 어두운 주변색, 윤곽과 작은 입자로 효과를 구분한다.
- 쓰러진 생물은 숨을 고르며 남고, 영입·재화 결과가 정해지면 빛으로 사라진다.
- 플레이어 패배와 동료 이탈은 비명이나 고통 묘사 대신 빛이 약해지는 연출과 결과 문구를 쓴다.

## 13. 검증 필요

- 카메라 앞쪽 3칸, 둘러보기 8칸, 확대 85%~120%가 세로 화면에서 목표와 위험을 읽기에
  적절한지 5개 이상 화면 비율로 확인한다.
- 1024×1536칸에서 자원 군락과 생물 무리 밀도가 10~15분 탐험에 빈 이동 시간을 만들지 않는지
  동굴·숲 각 5회 이상 탐험으로 확인한다.
- 돌 30초·나무 45초와 생물 60초·180초·900초 재등장이 기다림을 강요하지 않는지 확인한다.
- 자원 적재칸에 1~20개가 쌓일 때 더미 증가와 접근 회수, 가득 참으로 멈춘 노드의 원인을 세로 화면에서
  설명 없이 구분할 수 있는지 확인한다.
- 플레이어 체력·공격력·운반능력과 강화 비용이 초반과 장기 목표를 함께 만드는지 확인한다.
- 최종 운반능력 45에서 귀환 빈도가 지나치게 낮아지지 않는지, 작업 선호 동료의 가치가
  사라지지 않는지 플레이어 단독·동료 편성·기지 작업을 비교한다.
- 회복 우물이 위험을 완전히 제거하지 않는지, 보스 체력 유지가 재도전 동기를 만드는지 확인한다.
- 근접·원거리 판정과 동시에 쓰러짐 결과를 플레이어가 공정하게 이해하는지 확인한다.
