## 1. 플레이어 경험 목표

동굴과 숲은 같은 배경 위의 작은 구역이 아니라 출입구로 왕복하는 서로 다른 넓은 플레이 공간이다.
동굴에서는 광물 등급과 곡괭이 성장이, 숲에서는 나무 등급과 도끼 성장이 눈에 보이는 다음 목표가 된다.
플레이어는 아직 캘 수 없는 자원을 먼저 발견하고, 판매로 번 코인을 대장간에 투자해 도구를 강화한 뒤
그 자원에 다시 도전한다.

## 2. 공간 역할

| 공간 | 확정 역할 | 두지 않는 것 |
| --- | --- | --- |
| 동굴 | 기상·귀환, 광물 채광, 대장간·야영지 코어·동료 보관소 이용 | 손님, 가판대, 장식용 버섯·수정, 모닥불 상호작용 |
| 숲 | 넓은 탐험, 나무 벌목, 생물 전투·영입, 숲 장터 판매 | 한 장 배경처럼 보이는 축소 필드, 동굴 내부 성장 건물 |
| 숲 장터 | 출입구 가까운 안전 공터의 단일 가판대·판매·코인 회수 | 여러 가판대 증설, 동굴 안 손님 동선 |

- 동굴과 숲은 각각 플레이어 추적 카메라로 이동하는 넓은 쿼터뷰 맵이다.
- 양쪽 출입구는 자연 지형으로 보이며 전환선을 통과하면 반대편 대응 위치로 이동한다.
- 자원은 종류와 등급별 군락으로 묶어, 멀리서도 어떤 작업 구역인지 읽히게 한다.
- 통행을 막지 않는 바위·벽·바닥 균열·광맥 표시는 사용할 수 있다. 버섯이나 수정처럼 상호작용할 수
  있을 것처럼 보이는 오브젝트를 순수 장식으로 두지 않는다.
- 실제 채광 대상인 금·다이아 광맥은 장식이 아니라 요구 곡괭이 단계, 내구도와 보상을 가진 자원 노드다.

## 3. 동굴 모닥불과 성장 건물

### 3.1 모닥불

- 플레이어는 낡은 깔개와 작은 모닥불 옆에서 깨어난다.
- 모닥불은 기상 위치, 귀환 방향과 생활감만 전달하는 비상호작용 장식이다.
- 모닥불에는 자원 입고, 스탯 강화, 동료 관리, 건설, 업그레이드와 팝업을 연결하지 않는다.
- 모닥불이 텐트나 12단계 중심 건물로 자동 성장하는 이전 규칙은 현재 구현 기준에서 제외한다.

### 3.2 성장 건물

- 동굴에서 상호작용하는 고정 건물은 `대장간`, `야영지 코어`, `동료 보관소`다.
- 세 건물은 숲으로 나가는 출입구를 중심으로 서로 충분히 떨어뜨려, 건설 영역·라벨·팝업 진입 범위가
  겹치지 않게 한다.
- 정확한 칸 간격은 모바일 세로 화면에서 출입구와 두 시설이 한 덩어리로 겹쳐 보이지 않는지 검증한 뒤 확정한다.
- 미건설 시설은 해금 전에는 보이지 않는다. 해금 뒤에는 완성 건물의 반투명 미리보기 대신 네모난 건설
  영역, 필요 재화, 현재/필요 수량과 진행 골조만 표시한다.
- 완성 뒤 접근하면 대장간은 도구·무기, 야영지 코어는 캐릭터·활동 수용량, 동료 보관소는 보유 동료·역할·
  보관 수용량 팝업을 연다.

## 4. 자원 등급과 도구 게이트

### 4.1 공통 규칙

1. 자원 노드는 자신에게 필요한 도구 종류와 최소 단계를 가진다.
2. 보유 도구 단계가 요구 단계보다 낮으면 내구도와 진행도를 바꾸지 않는다.
3. 차단 시 `필요: 도구 N단계`와 대장간 방향을 함께 표시한다.
4. 보유 단계와 요구 단계가 같으면 해당 자원의 기준 작업 시간을 사용한다.
5. 보유 단계가 더 높으면 낮은 등급 자원의 작업 시간이 줄어든다.
6. 채집 완료 결과는 등짐에 즉시 들어가지 않고 가까운 네모난 자원 적재칸에 한 개씩 쌓인다.
7. 적재칸에는 최대 20개가 실물로 쌓이며, 플레이어나 담당 동료가 접근하면 운반 한도 안에서 하나씩 싣는다.

### 4.2 동굴 광물 순서

| 순서 | 자원 군락 | 요구 도구 | 진행 역할 | 상태 |
| ---: | --- | --- | --- | --- |
| 1 | 돌 | 곡괭이 1단계 | 첫 곡괭이 직후 채광과 야영지 코어 건설 | 확정 |
| 2 | 철 광석 | 곡괭이 2단계 | 첫 곡괭이 강화 목표 | 확정 |
| 3 | 금 광석 | 곡괭이 3단계 | 중간 동굴 성장 목표 | 확정 |
| 4 | 다이아 광석 | 곡괭이 4단계 | 현재 동굴의 최상위 채광 목표 | 확정 |

- 낮은 등급의 곡괭이로 상위 광석을 오래 쳐서 캘 수 없게 한다.
- 네 등급 군락은 동굴 안에서 서로 다른 작업 구역으로 보이며, 상위 광맥을 초반부터 발견할 수 있다.
- 등급별 내구도, 기준 작업 시간, 보상 수량과 강화 비용은 플레이테스트 전까지 `검증 필요`다.

### 4.3 숲 나무 순서

| 순서 | 자원 군락 | 요구 도구 | 진행 역할 | 상태 |
| ---: | --- | --- | --- | --- |
| 1 | 시작 나무 군락 | 도끼 1단계 | 첫 벌목·가판대·첫 판매 | 확정 |
| 2 | 단단한 나무 군락 | 도끼 2단계 | 첫 도끼 강화 뒤 진입 | 확정 |
| 3 이상 | 상위 나무 군락 | 미정 | 더 깊은 숲의 후속 성장 | 후속 범위 |

- 벌목 대상은 서 있는 나무다. 이미 잘린 통나무 더미에 도끼질하는 표현은 사용하지 않는다.
- 나무가 쓰러지거나 사라진 뒤 목재 한 개가 적재칸에 생긴다.
- 3단계 이상 나무의 이름·수·요구 단계는 임의로 만들지 않고 후속 숲 콘텐츠 기획에서 정한다.

## 5. 성장 인과

1. 시작 나무를 베어 가판대를 짓고 장작을 판다.
2. 가판대 옆 코인 적재칸에서 코인을 회수한다.
3. 동굴 대장간에서 곡괭이 또는 도끼를 강화한다.
4. 새 도구 단계로 이전에 막혔던 광물·나무 군락을 연다.
5. 상위 자원을 새 건설·장비·자동화 성장에 사용한다.
6. 동료에게 이미 직접 경험한 채집·회수·운반을 맡기고 더 깊은 숲으로 간다.

초반에는 가판대 판매와 첫 곡괭이가 한 줄로 이어지는 수직 성장 경로를 보장한다. 첫 자동화 이후에는
도끼, 곡괭이, 캐릭터 스탯과 동료 수용량 중 다음 투자 목표를 선택하게 한다.

## 6. 안전 입고 경계

- 자원 적재칸과 등에 실은 자원은 아직 안전 자원이 아니다.
- 모닥불 접근은 안전 입고를 발생시키지 않는다.
- 장기 자동화에 필요한 최종 안전 입고 건물·지점은 현재 `미정`이다. 별도 창고가 확정되기 전에는
  모닥불이나 야영지 코어에 자동 입고 기능을 임의로 붙이지 않는다.
- 안전 입고 목적지가 확정되기 전까지 장기 공방 물류·오프라인 생산·약탈 수치는 구현 확정 기준으로 사용하지 않는다.

## 7. 확인 사례

| 구분 | 확인 상황 | 기대 결과 |
| --- | --- | --- |
| 정상 | 곡괭이 1단계로 돌 군락에 접근 | 곡괭이가 손에 나타나 채광하고 돌 한 개가 적재칸에 쌓인다 |
| 정상 | 곡괭이 4단계로 철 광석에 접근 | 채광 가능하며 곡괭이 2단계보다 작업 시간이 짧다 |
| 정상 | 도끼 1단계로 시작 나무를 벌목 | 서 있는 나무를 베고 목재가 한 개씩 적재칸에 쌓인다 |
| 경계 | 적재칸이 20/20개 | 연결된 채집만 멈추고 하나 이상 회수하면 다시 시작한다 |
| 실패 | 곡괭이 1단계로 철 광석에 접근 | 진행 없이 곡괭이 2단계 요구와 대장간 방향을 표시한다 |
| 실패 | 도끼 1단계로 단단한 나무에 접근 | 진행 없이 도끼 2단계 요구와 대장간 방향을 표시한다 |
| 실패 | 모닥불에 자원을 들고 접근 | 자원·스탯·팝업에 변화가 없다 |

## 8. 열린 결정과 검증

- 안전 자원을 확정 입고할 별도 건물·지점과 첫 공개 시점
- 광물·나무 등급별 내구도, 작업 시간, 보상과 도구 강화 비용
- 동굴 출입구와 세 성장 건물 사이의 출시 배치 간격
- 숲 3단계 이상 나무 종류와 깊은 숲의 지역 구성
- 5명 이상이 상위 자원을 보고 `대장간에서 도구를 강화해 돌아온다`는 목표를 설명할 수 있는지 검증한다.
- 최소 세로 화면에서 광물 네 군락, 출입구와 성장 건물이 장식이 아니라 서로 다른 기능으로 읽히는지 검증한다.
