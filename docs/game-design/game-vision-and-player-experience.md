## 1. 문서 목적과 범위

이 문서는 플레이어가 이 게임을 어떤 게임으로 이해하고 어떤 감정을 반복해서 경험해야 하는지의
단일 원본이다. 탐험·전투의 상세 판정은 [`exploration-combat.md`](exploration-combat.md), 동료의
영입·역할은 [`creatures-and-recruitment.md`](creatures-and-recruitment.md), 16종 생물의 개별
콘텐츠는 [`creature-content.md`](creature-content.md)가 소유한다.

### 포함

- 신비로운 자연 판타지의 핵심 판타지와 플레이어 약속
- 대상 플레이어, 사용 환경과 세션 길이의 기본값
- 디자인 기둥과 새 기능을 판단하는 질문
- 순간·세션·메타·장기 루프의 경험 목적
- 초반 학습 순서와 성장에 따른 페이싱
- 의도적으로 만들지 않을 경험
- 시각·청각·문구·접근성의 공통 표현 원칙
- 출시 필수 경험과 검증 방법

### 제외

- 자동 공격, 채집, 영입, 약탈과 비콘의 세부 판정
- 시설·생물별 수치와 재화 보상
- 코드, 데이터 컬럼·자료형, 저장 구조, 분석 이벤트와 기술 성능 기준
- 프로젝트 이름과 출시 절차

## 2. 결정 상태

### 확정

- 모바일 웹 환경에서 플레이하고 플레이스토어 출시를 목표로 한다.
- 2D 아이소메트릭 세로 화면을 사용한다.
- 테이밍과 기지 자동화·타이쿤을 핵심 경험으로 삼되, 게임 안에서 생물을 동료로 만드는 행동은
  `영입`으로 표현한다.
- 플레이어의 주 조작은 상하좌우 이동이며, 공격·채집·비콘 재화 투입은 거리 조건을 만족하면
  자동으로 진행한다.
- 동굴과 숲을 오가며 생물을 영입하고, 동료의 탐험·생산·판매·방어 활동으로 동굴 기지를
  계속 성장시킨다.
- 번호가 붙은 전투 구간 없이 탐험과 기지 운영이 계속 이어진다.
- 완전 무료이며 유료 상품, 광고와 인앱 결제를 사용하지 않는다.
- 별도 계정 성장과 능력치형 도감 보너스를 사용하지 않는다.
- 발광 생명체와 식물, 소울의 빛, 부드러운 안개와 자연 소재를 중심으로 한 `신비로운 자연
  판타지` 분위기를 사용한다.

### 가정

- 주요 대상은 짧은 시간에도 조작과 성장을 확인하고 싶은 모바일 캐주얼·라이트 코어
  플레이어다. 숙련된 액션 조작보다 탐험 경로와 동료 선택을 더 오래 고민하는 플레이어를
  포함한다.
- 1회 접속의 기본 목표 시간은 8~15분, 하루에 1~3회 접속하는 흐름을 기준으로 한다. 이 값은
  플레이 세션을 강제하는 제한이 아니라 콘텐츠와 보상의 체감 속도를 정하기 위한 시작값이다.
- 터치 조작을 기본으로 하고, 같은 화면에서 키보드 방향키 또는 WASD 이동도 허용한다. 모바일
  세로 화면에서 한 손으로 이동할 수 있고, 두 손을 쓰면 목표 지정과 상태 확인을 편하게 할 수
  있도록 한다.
- 첫 10분 안에 플레이어가 `이동 → 자동 전투 → 영입 또는 재화 선택 → 메인 기지 입고`를
  한 번 경험하고, 첫 20분 안에 첫 동료를 일꾼으로 배치해 자동화의 결과를 확인한다.
- 생물과 약탈 무리는 공포나 고어보다 빛·먼지·잎·소리의 변화로 위험을 전달한다.

### 검증 필요

- 8~15분 세션이 첫 상품 판매와 탐험 재출발을 모두 경험하기에 적절한지 초반 플레이테스트로
  확인한다. 5명 이상의 신규 플레이어가 첫 접속에서 핵심 흐름을 완료하는 시간과 다음 행동을
  스스로 설명하는지를 기록해 판단한다.
- 세로 아이소메트릭 화면에서 플레이어, 자동 목표, 자원 더미, 동료 이동과 손님 요청을 동시에
  읽을 수 있는지 확인한다. 화면 녹화 없이 관찰자가 세 가지 상태를 정확히 말하는지와 목표를
  잘못 선택한 횟수를 기준으로 조정한다.
- 첫 실패가 동료 영구 이탈을 학습 가능한 위험으로 느끼게 하는지 확인한다. 실패 뒤 30초 안에
  플레이어가 잃은 것과 보존된 것을 설명하고 재출발하는지를 확인한다.

## 3. 한 줄 방향과 핵심 판타지

### 한 줄 방향

짧은 세션을 선호하는 플레이어가 빛나는 동굴과 숲을 탐험해 생물을 동료로 영입하고, 귀환해
자원·상품·방어가 실제로 움직이는 기지를 키워 가는 2D 아이소메트릭 세로 화면 게임이다.

### 핵심 판타지

플레이어는 미지의 자연을 두려워하기보다 직접 길을 열고, 만난 생물의 성향과 능력을 읽어
동료로 받아들이며, 작은 모닥불 주변이 생물과 일꾼이 살아 움직이는 거점으로 바뀌는 모습을
만든다.

- **플레이어 역할**: 위험한 지역에 직접 들어가 목표를 고르고 귀환을 결정하는 탐험가이자,
  동료의 역할을 배치해 기지를 운영하는 조율자
- **반복 선택**: 지금 더 싣고 돌아갈지, 새 생물을 영입할지, 자원을 더 얻을지, 동료를 어느
  역할로 보낼지 선택한다.
- **힘이 커지는 방식**: 플레이어의 공격과 체력이 커지고, 동행 수용량과 기지 수용량이 늘며,
  더 다양한 생물과 시설이 함께 일한다.
- **차별화된 감정**: 숫자만 증가하는 성장이 아니라, 내가 위험을 감수해 데려온 생물이 실제
  동선으로 자원을 옮기고 판매·방어를 이어 주는 것을 본다.

새 기능은 위 네 기둥 중 하나 이상에 기여해야 한다. 기여하는 기둥이 없거나 기존 루프의
선택을 줄이는 기능은 출시 범위에 넣지 않는다.

## 5. 플레이어 경험 루프

세부 규칙과 비용은 [`core-gameplay.md`](core-gameplay.md)를 원본으로 사용한다. 아래는 각 루프가
플레이어에게 어떤 의미를 줘야 하는지의 경험 기준이다.

### 순간 루프: 몇 초 단위

1. 상하좌우로 탐색한다.
2. 적대 생물, 중립 생물, 자원 순으로 자동 목표가 잡히고 공격·채집 피드백을 본다.
3. 체력·등짐·주변 위험을 확인한다.
4. 계속 이동해 더 얻거나, 고정 포탈·메인 기지로 돌아갈지 고른다.

### 세션 루프: 한 번 접속한 동안

1. 메인 기지에서 동료 역할과 기지의 진행 중 작업을 확인한다.
2. 동굴 또는 숲으로 나가 생물과 자원을 탐색한다.
3. 생물을 영입할지 재화로 받을지, 등짐을 언제 입고할지 결정한다.
4. 메인 기지에서 자원 더미·공방·판매대·계산대·방어 상태의 변화를 확인한다.
5. 다음 탐험 목표 또는 비콘 강화 목표를 정하고 세션을 끝내거나 다시 출발한다.

### 메타 루프: 여러 세션에 걸쳐

1. 코인·뼈·소울을 안전 자원으로 모은다.
2. 플레이어 능력, 동행 수용량, 기지 수용량과 기지 시설을 강화한다.
3. 새로운 공간과 역할 운영을 열어 탐험과 자동화의 선택지를 늘린다.
4. 다른 적성의 동료를 영입해 같은 지역을 다른 구성으로 공략한다.

### 장기 루프: 출시 범위

- 16종 생물을 발견하고 원하는 역할 조합으로 기지를 운영한다.
- 메인 기지를 12단계까지 성장시켜 동굴의 모든 출시 공간과 시설 상한을 연다.
- 탐험과 자동화가 끊기지 않는 상태를 만들면서도, 약탈과 탐험 실패의 위험을 관리한다.
- 출시 후 확장 시 지역·생물·상품을 추가할 수 있지만, 기존 16종의 역할과 보상 규칙을
  무효화하는 계정 성장이나 유료 강화는 도입하지 않는다.

### 경험 규칙 지도

비전 문서는 세부 수치를 복제하지 않고, 플레이어가 한 세션에서 겪어야 할 조건과 결과 및
세부 원본의 소유 위치를 연결한다.

| 화면 피드백 | 현재 목표·체력·등짐·지역·동료 동선·상품·방어 상태를 상태 변화와 함께 보여 준다 | 각 상세 문서의 `UI`·`피드백` 절 |

| --- | --- | --- |
| 주요 대상 | 모바일에서 짧게 플레이하며 수집·성장·자동화를 함께 즐기는 플레이어 | 가정. 5명 이상 신규 플레이어의 첫 15분 관찰로 확인 |
| 보조 대상 | 생물 수집과 기지 꾸미기보다 역할 배치와 동선 최적화를 좋아하는 라이트 코어 플레이어 | 가정. 역할 변경 후 목표 행동을 선택하는지 확인 |
| 숙련도 | 게임 장르 경험이 적어도 이동과 자동 목표만으로 첫 전투를 완료할 수 있음 | 확정 방향. 온보딩 완료율로 검증 |
| 기본 입력 | 터치 방향 패드, 대상 탭, 비콘 위 머무르기 | 가정. 세로 화면에서 한 손 사용성 검증 |
| 보조 입력 | 키보드 방향키 또는 WASD 이동, 마우스·트랙패드 대상 탭 | 가정. 모바일 웹 데스크톱 브라우저에서 회귀 확인 |
| 세션 길이 | 8~15분 기본, 더 긴 연속 플레이도 제한하지 않음 | 검증 필요. 첫 판매·첫 귀환 시점을 관찰 |
| 하루 접속 | 1~3회 기준 | 검증 필요. 접속 강제 없이 오프라인 진행 요약이 다음 목표를 제공하는지 확인 |
| 온라인 요구 | 현장 탐험은 접속 중 진행하고, 기지 자동화·생산·판매·약탈·치료는 접속하지 않아도 진행 | 확정. 상세 규칙은 [`core-gameplay.md`](core-gameplay.md) 13절 참조 |

## 7. 초반 경험과 페이싱

| 순서 | 플레이어가 이해할 것 | 보여 줄 결과 | 강제 정도 | 완료 기준 |
| --- | --- | --- | --- | --- |
| 첫 이동 | 화면 방향과 자동 목표 | 플레이어가 움직이면 가까운 대상에 목표 표시가 붙는다 | 필수 안내 | 상하좌우 한 번씩 입력하고 동굴을 이동한다 |
| 첫 전투 | 공격 버튼 없이 거리로 전투가 시작됨 | 공격 동작, 피해 숫자와 생물 체력 변화 | 필수 안내 | 생물 하나를 쓰러뜨린다 |
| 첫 결과 | 영입 또는 재화 선택 | `영입`·`재화` 선택과 결과 연출 | 필수 안내 | 한 가지 결과를 선택한다 |
| 첫 귀환 | 등짐과 안전 자원의 차이 | 메인 기지 입고와 자원 더미 변화 | 필수 안내 | 돌·나무·뼈 중 하나를 입고한다 |
| 첫 역할 | 생물은 역할을 맡아 움직임 | 첫 동료를 일꾼으로 바꾸고 공방 물류를 본다 | 필수 안내 | 공방에 재료가 도착한다 |
| 첫 판매 | 기지가 스스로 돈을 만듦 | 상품 요청 말풍선, 판매와 계산대 코인 | 선택 안내 | 첫 판매 코인이 생긴다 |
| 첫 위험 | 확장과 약탈에는 준비가 필요함 | 방어 시설 비콘과 방어 동료의 필요성 | 선택 안내 | 방어 시설과 동료 역할을 확인한다 |

초반에는 생물 종류를 한꺼번에 보여 주지 않는다. 첫 생물의 결과와 첫 상품 판매를 먼저
이해시킨 뒤, 숲·엘리트·보스·약탈 순서로 선택지를 추가한다. 수치 난이도보다 정보량과
위험의 거리를 단계적으로 늘리는 것을 기본 페이싱으로 삼는다.

## 8. 의도적으로 만들지 않을 경험

- 정확한 타이밍의 회피·콤보·조준을 계속 요구하는 고난도 액션 게임 경험
- 번호가 붙은 전투 구간, 무한 웨이브, 전투만 반복하는 스테이지 진행
- 플레이어 간 경쟁, 순위, 협동 매칭이나 대전으로 인한 사회적 압박
- 광고 시청, 유료 상품, 인앱 결제 또는 결제 없이는 늦어지는 진행
- 생물을 소모품처럼 즉시 교체하는 대신, 영입한 동료를 잃을 수 있는 선택의 무게를 없애는
  경험
- 도감 수치나 계정 등급을 올려야만 강해지는 별도 성장 압박
- 피·절단·시체를 중심으로 한 고어, 현실적인 동물 학대나 잔혹한 처치 표현
- 화면을 가득 채우는 장식과 정보로 자원·위험·동료 동선을 읽기 어렵게 하는 경험

## 9. 공통 표현과 접근성 원칙

### 시각

- 동굴은 차가운 수정빛과 어두운 바위, 숲은 따뜻한 달빛과 발광 식물로 구분한다. 정확한
  색상값은 이 문서에서 고정하지 않고 색약·저시력 검증 뒤 조정한다.
- 위험한 대상은 색만 바꾸지 않고 짧은 경고 동작, 윤곽, 바닥 표시와 소리를 함께 사용한다.
- 자동 목표에는 대상 윤곽과 현재 행동 아이콘을 함께 표시한다.
- 메인 기지의 자원 더미, 일꾼 동선, 손님 요청, 벽 손상은 같은 화면에서 서로 겹치지 않게
  명도·윤곽·동작으로 구분한다.

### 청각과 촉각

- 자동 공격 시작, 자원 채집 완료, 영입 선택, 비콘 투입, 플레이어 패배와 약탈 경보는
  서로 다른 짧은 효과음으로 구분한다.
- 약탈·보스 공격·플레이어 패배에는 저음과 짧은 간격의 경고를 사용하되, 공포감을 과도하게
  높이지 않는다.
- 진동은 지원 기기에서 선택적으로 제공하며, 플레이어 패배·영입 완료·비콘 완료처럼 한 번의
  결과를 전달할 때만 사용한다. 진동이 꺼져도 시각·청각 피드백으로 같은 정보를 전달한다.

### 문구와 화면 읽기

- 버튼은 `영입`, `재화`, `역할 변경`, `출발`, `돌아가기`처럼 짧은 행동형으로 쓴다.
- 실패 문구는 원인과 다음 행동을 함께 쓴다. 예: `동행 수용량이 가득 찼습니다. 기지에서
  다른 동료를 역할 변경하거나 수용량을 확장하세요.`
- 색상만으로 체력·등짐·영입 가능 여부를 전달하지 않는다. 아이콘, 숫자, 상태 문구를 함께
  제공한다.
- 터치 대상은 손가락으로 누르기 쉬운 크기로 제공하고, 작은 생물의 실제 몸체가 아니라 그
  주변의 넓은 상호작용 영역을 사용한다.
- 화면 확대, 높은 대비, 진동 끄기, 효과음·배경음 분리 조절은 출시 접근성 범위로 포함한다.

## 11. 확인 사례와 검증 기준

| 확인 상황 | 기대 결과 |
| --- | --- |
| 처음 이동하는 플레이어가 방향 입력을 유지 | 별도 공격 버튼 없이 가까운 대상에 자동 목표가 잡히고 공격이 시작된다 |
| 플레이어가 전투 후 더 이동할지 돌아갈지 고민 | 체력·등짐·포탈·메인 기지 위치를 한 화면에서 확인할 수 있다 |
| 첫 생물을 영입한 플레이어가 기지로 돌아옴 | 동료가 역할을 바꾸어 실제로 탐험·운반·방어 중 하나를 수행한다 |
| 플레이어가 잠시 게임을 닫았다가 복귀 | 생산·판매·약탈·치료 결과의 요약을 보고 다음 행동을 선택할 수 있다 |
| 색약 모드 또는 색상 구분이 어려운 플레이어가 보스 경고를 봄 | 색상 외 윤곽·동작·소리·문구 중 두 가지 이상으로 위험을 알아본다 |
| 플레이어가 패배함 | 고어 없이 귀환·등짐 손실·안전 자원 유지가 명확히 전달되고 즉시 재출발할 수 있다 |

## 12. 결정 정리

### 담당 범위에 반영한 확정

- 게임 방향, 플랫폼, 화면 형식, 무료 정책, 핵심 경험과 기존 코어 순환
- 단순 이동 중심 조작, 위험을 감수하는 귀환, 동료가 움직이는 기지, 신비로운 자연 판타지

### 담당 범위에 사용한 가정

- 주요 대상 플레이어, 8~15분 세션, 터치·키보드 보조 입력, 초반 20분 학습 순서
- 생물 처치의 비고어 표현과 접근성 기능의 출시 포함

### 검증 필요

- 세션 길이, 첫 재미 도달 시간, 정보 가독성, 실패 후 재출발 의향과 표현 수위
- 정확한 색상, 최종 생물·건축물 외형, 사운드 톤과 진동 강도

담당 출시 범위에 `미정`은 남기지 않는다. 프로젝트 이름은 게임 규칙에 영향을 주지 않는 제품
결정으로 이 문서의 출시 필수 범위에서 제외한다.
