## 2. 확정된 게임 방향

### 한 줄 방향

짧은 시간에도 쉬운 이동으로 신비로운 숲을 탐험하고, 영입한 생물 군단으로 더 강한 생물을 사냥해
다시 군단과 기지를 성장시키는 캐주얼 우선 테이밍·타이쿤 게임이다.

### 핵심 판타지

플레이어는 영입한 생물 군단을 이끌고 더 깊은 숲의 강한 생물을 사냥한다. 좋은 생물을 새 전투원으로
편성할지, 기존 전투원을 작업에 내려 자동화를 늘릴지, 재화로 바꿔 장비와 동행 수용량을 키울지가
핵심 선택이다. 기지는 사냥을 대신하는 목적지가 아니라 다음 군단 원정을 준비하는 성장 거점이다.

### 대상 플레이어와 권장 시간

| 항목 | 확정 기준 |
| --- | --- |
| 주요 대상 | 쉬운 조작으로 수집·성장·자동화를 함께 즐기려는 모바일 캐주얼 플레이어 |
| 보조 대상 | 탐험 위험과 동료 역할 조합을 고민하고 싶은 라이트 코어 플레이어 |
| 권장 접속 | 10~20분, 하루 2~3회. 더 긴 연속 플레이를 막는 제한은 두지 않는다 |
| 탐험 1회 | 정확한 시간과 검증 기준은 [`exploration-combat.md`](exploration-combat.md#2-전체-규칙-지도와-진행-순서)를 따른다 |
| 첫 핵심 순환 | 숲 진입·벌목·숲 장터 가판대·첫 판매를 시작 후 4분 이내에 경험한다 |
| 첫 도구 성장 | 대장간에서 곡괭이를 제작해 돌 채집이 열리는 경험을 시작 후 6분 이내에 제공한다 |
| 첫 전투 동료 | 첫 영입 생물을 탐험 동료로 편성해 함께 싸우는 경험을 시작 후 9분 이내에 제공한다 |
| 첫 상위 사냥 | 첫 전투 동료와 한 단계 강한 일반 생물을 쓰러뜨리는 경험을 시작 후 12분 이내에 제공한다 |
| 첫 역할 분기 | 두 번째 결과 뒤 군단 유지·교체 또는 작업 자동화 선택을 시작 후 15분 이내에 보여 준다 |

권장 시간은 강제 종료 시간이 아니다. 플레이어가 짧게 접속해도 탐험 결과를 안전 자원과 다음
성장 목표로 바꿀 수 있게 콘텐츠 간격을 판단하는 기준이다.

## 3. 디자인 기둥

| 디자인 기둥 | 쉬운 의미 | 프로젝트의 구체적 예시 | 채택 판단 |
| --- | --- | --- | --- |
| 쉬운 조작, 의미 있는 선택 | 직접 조작은 단순하지만 선택의 결과는 분명하다 | 이동만 직접 하고 공격·채집은 자동으로 진행하되 귀환과 영입은 플레이어가 결정한다 | 반복 입력을 늘리지 않으면서 서로 다른 결과를 만드는가 |
| 군단 사냥이 더 좋은 영입으로 이어진다 | 현재 동료로 강한 생물을 잡아 더 좋은 동료를 얻는다 | 근거리 일반 생물에서 시작해 중거리 적대 생물·원거리 엘리트로 사냥 목표가 올라간다 | 새 영입이 다음 사냥의 전력이나 편성 선택을 실제로 바꾸는가 |
| 탐험과 기지가 서로 성장시킨다 | 밖에서 얻은 것이 기지를 바꾸고, 기지 성장이 다음 탐험을 넓힌다 | 생물과 자원을 가져와 동료·장비·수용량 강화에 쓰고 더 먼 지역을 탐험한다 | 기지 성장이 군단 사냥으로 되돌아가는가 |
| 위험이 귀환 판단을 만든다 | 더 멀리 갈수록 보상과 손실 위험이 함께 커진다 | 등짐과 동료 상태를 보고 계속 탐험할지 동굴 출입구·기지로 돌아갈지 정한다 | 위험의 원인과 잃는 것·남는 것이 미리 읽히는가 |
| 동료가 살아 있는 세계를 만든다 | 생물은 목록 속 보너스가 아니라 화면에서 일하는 존재다 | 탐험 대형, 자원 적재칸의 채집·운반, 출입문 방어에서 동료의 역할이 동선으로 보인다 | 역할 변화가 실제 행동과 피드백으로 드러나는가 |
| 성장한 모습이 몸에 남는다 | 장비 성장은 숫자뿐 아니라 캐릭터의 인상도 바꾼다 | 해진 옷에서 작업복·등짐틀로 외형이 바뀌고 도끼·곡괭이·무기는 관련 행동 순간에 강화된 파츠로 나타난다 | 장착 결과를 필드에서 즉시 알아볼 수 있는가 |
| 성장한 기지를 내 공간으로 느낀다 | 기능 성장을 가리지 않는 범위에서 기지를 꾸민다 | 탐험 자원으로 자유 장식을 만들고 보호된 물류 동선을 피해 직접 배치한다 | 장식이 기능 접근을 막지 않으면서 귀환할 이유를 더하는가 |

새 기능은 하나 이상의 디자인 기둥에 기여해야 한다. 기여하지 않거나 탐험↔기지 순환을
끊는 기능은 출시 필수 범위에 넣지 않는다.

## 4. 플레이어 경험 순환

### 순간 순환

1. 아날로그 조이스틱을 밀어 원하는 방향과 속도로 이동한다.
2. `자동 목표`에 따라 전투·채집이 시작되고 자원 적재칸에 결과가 쌓이는 것을 본다.
3. 적재칸에서 자원을 회수하고 체력, 동료, 등짐과 주변 위험을 확인한다.
4. 더 나아가거나 안전한 곳으로 돌아갈 방향을 정한다.

### 세션 순환

1. 보관소에서 현재 군단과 다음에 영입할 생물을 정한다.
2. 군단과 숲을 탐험해 목표 생물 무리를 사냥한다.
3. 영입 또는 재화를 선택하고 위험이 커지기 전에 귀환한다.
4. 새 동료를 군단·작업·방어에 편성하고 장비·동행 수용량을 강화한다.
5. 이전보다 강한 생물이 있는 거리대를 목표로 다시 출발하거나 세션을 끝낸다.

### 여러 세션의 성장

- 판매 코인과 생물 결과의 소울을 모아 플레이어와 동행·기지 수용량을 강화한다.
- 16종 생물을 영입해 탐험·작업·방어 구성을 바꾼다.
- 기지의 실제 생산·판매·방어 동선을 완성한다.
- 번호가 붙은 전투 구간이나 전체 성장 초기화 없이 같은 세계를 계속 넓힌다.

## 6. 의도적으로 만들지 않을 경험

- 수동 조준, 공격 버튼 연타, 회피 타이밍과 복잡한 기술 조합을 중심으로 한 고난도 액션
- 공격·채집·비콘 투입·목표 선택을 플레이어가 계속 직접 눌러야 하는 조작
- 번호가 붙은 전투 구간, 무한 웨이브와 전투만 반복하는 진행
- 전체 성장 초기화, 별도 계정 성장 또는 능력치형 도감 보너스로 기존 성과를 무효화하는 진행
- 경쟁 순위, 플레이어 간 대전과 매칭 중심 경험
- 광고·유료 상품·인앱 결제로 성장 속도를 바꾸는 경험
- 피·절단·시체와 현실적인 고통을 중심으로 한 잔혹한 표현
- 동료를 화면 밖 수치 보너스로만 취급하거나, 탐험과 기지가 서로 영향을 주지 않는 구조

## 7. 공통 표현과 접근성

- 동굴은 거친 바위·바닥 균열·실제 채광 광맥, 숲은 층이 겹친 나무·잎·풀로 구분하는 카툰톤 자연 판타지를 사용한다.
- 동굴에는 상호작용할 수 있을 것처럼 보이는 장식용 버섯·수정을 두지 않는다. 금·다이아처럼 빛나는 대상은 실제 채광 자원으로 사용한다.
- 블룸은 사용하지 않는다. 밝은 부분색과 어두운 주변색, 윤곽, 작은 입자와 매우 약한 명암 변화로
  출입구 유도광·소울·식물·상품과 생물의 빛을 표현한다.
- 공격·피격·쓰러짐은 피와 절단 없이 빛·먼지·잎·수정 파편으로 표현한다.
- 위험과 선택 가능 여부는 색만으로 전달하지 않고 아이콘·윤곽·문구·소리를 함께 사용한다.
- 피해·회복 숫자는 기본 표시하되 설정에서 끌 수 있다.
- 공통 UI 크기와 최소 터치 영역은 [`onboarding-ui.md`](onboarding-ui.md#9-세로-화면-접근성)를 따른다.
- 진동과 화면 흔들림은 각각 끌 수 있고, 위험 소리는 방향 아이콘과 짧은 문구로도 표시한다.
- 실패 문구는 원인과 다음 행동을 함께 안내한다.
- 세로 전체 필드 쿼터뷰에서 플레이어를 화면 중앙보다 조금 아래에 두어 전진 방향과 동료 무리를 넓게 보여 준다.
- 동굴은 손님이 들어오지 않는 개인 야영지로, 숲 장터는 단일 가판대의 응대 속도와 손님 흐름이 성장하는 외부 생활 공간으로 구분한다.
- 상시 HUD는 화면 가장자리의 작은 정보로 제한하고 이동 조이스틱과 상황별 기능만 하단 엄지 영역에 둔다.
- 캐릭터의 의상·무기·등짐은 동일한 몸·방향·발 기준선을 공유하는 교체형 2D 파츠로 만들고, 장착 직후
  동굴·숲·전투의 필드 외형에 함께 반영한다.

세부 화면과 사운드의 상태별 피드백은 각 시스템 문서가 소유한다.

## 8. 정상·예외·실패 확인 사례

| 구분 | 확인 상황 | 기대 결과 |
| --- | --- | --- |
| 정상 | 처음 시작한 플레이어가 이동한다 | 60초 안에 숲에 나가 첫 나무를 채집하고 4분 안에 첫 판매를 완료한다 |
| 정상 | 첫 코인을 번 플레이어가 대장간을 방문한다 | 6분 안에 곡괭이를 제작하고 돌 채집 자격이 열린다 |
| 정상 | 첫 생물을 영입해 동료 보관소로 돌아온다 | 9분 안에 탐험 역할로 편성하고 12분 안에 더 강한 일반 생물을 함께 쓰러뜨린다 |
| 예외 | 15분을 넘겨 계속 플레이한다 | 접속을 강제로 끝내지 않고 체력·등짐·군단 전력과 다음 사냥 목표를 계속 제공한다 |
| 예외 | 색상 차이를 구분하기 어렵다 | 아이콘·윤곽·문구·소리로 목표, 위험과 결과를 구분한다 |
| 실패 | 플레이어가 패배한다 | 고어 없이 손실·유지 자원을 알리고 짧은 회복 뒤 같은 성장 상태로 재출발한다 |
| 실패 | 동료가 영구 이탈한다 | 이탈 이유와 운반 한도 변화를 즉시 알리고 남은 동료·기지 성장은 유지한다 |

## 9. 검증 필요

- 신규 플레이어 10명 이상이 60초 안에 숲 진입, 4분 안에 첫 판매, 6분 안에 첫 곡괭이 제작, 9분 안에
  첫 탐험 동료 편성, 12분 안에 첫 상위 일반 생물 처치를 완료하는지 관찰한다.
- 10~20분 접속 안에 `탐험 결과 확인 → 기지 변화 확인 → 다음 목표 선택`이 모두 가능한지 확인한다.
- 탐험 1회 시간은 [`exploration-combat.md`](exploration-combat.md#13-검증-필요)의 기준으로 확인한다.
- 세로 화면에서 플레이어·자동 목표·동료·등짐·작은 지도를 동시에 구분하는지 확인한다.
- 실패 뒤 30초 안에 플레이어가 잃은 것과 유지된 것을 설명하고 재출발하는지 확인한다.
- 비고어 쓰러짐 장면을 보고도 위험, 생존 여부와 영입·재화 선택을 혼동하지 않는지 확인한다.

검증은 승인 철회가 아니라 확정된 방향을 유지하며 수치를 조정하는 절차다. 값을 바꾸면 이
기획 원본을 먼저 갱신한다.
