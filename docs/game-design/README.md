## 1. 한 줄 방향

플레이어가 생물 군단을 이끌고 광활한 숲의 더 강한 생물을 영입하며, 영입한 생물로 동굴 거점을
자동화해 다음 원정을 더 빠르고 강하게 준비하는 2D 쿼터뷰 세로 화면 모바일 네이티브 게임이다.

## 2. 확정된 제품 방향

- MineHero 프레임워크와 동일한 모바일 네이티브 앱 패키징·배포 경로를 사용하고 플레이스토어 출시를 목표로 한다.
- 화면 대부분을 필드로 쓰는 2D 쿼터뷰 세로 화면을 사용하고 카메라가 플레이어와 동료 무리를 추적한다.
- 군단 탐험·사냥·영입을 주 코어로, 기지 자동화·판매를 다음 원정을 지원하는 성장축으로 삼는다.
- 기능 우선순위는 탐험 65%, 거점 35%를 검증 가설로 사용한다. 이는 강제 체류 시간이 아니라 제작·플레이테스트 판단 기준이다.
- 모든 영입 생물은 전투 정체성과 작업 정체성을 함께 가지며, 전투원 또는 일꾼 배치가 실제 군단 전력이나 시설 처리량을 바꾼다.
- 플레이어 조작은 왼쪽 아래의 동적 아날로그 조이스틱을 이용한 연속 이동을 중심으로 단순하게 유지한다.
- 공격, 채집과 재화 투입은 플레이어가 대상이나 `비콘`에 가까이 가면 자동으로 진행한다.
- 번호가 붙은 전투 구간 없이 탐험과 기지 운영이 계속 이어진다.
- 완전 무료이며 유료 상품, 광고와 인앱 결제를 사용하지 않는다.
- 별도 계정 성장과 능력치형 도감 보너스를 사용하지 않는다.
- 굵은 형태와 단순한 명암의 카툰톤 자연 소재, 발광 생명체와 소울의 빛을 중심으로 한 `신비로운 자연 판타지` 분위기를 사용한다.
- 블룸 없이 밝은 부분색, 어두운 주변색, 윤곽과 작은 입자로 자연 발광을 표현한다.
- 공식 게임 이름은 `Wild Survival`이다.

정확한 색상과 생물·건축물의 최종 외형은 후속 시각 기획에서 정한다. 현재 분위기 방향은 특정 상용
게임의 캐릭터, 사용자 인터페이스 또는 화풍을 모방하는 기준으로 사용하지 않는다.

## 3. 1차 기획 범위

### 포함

- 플레이어 이동, 자동 공격과 자동 채집
- 별도 화면인 동굴·숲 탐험과 자연스러운 동굴 출입구 전환
- 생물 등급, 전투 결과, 영입과 동료 역할
- 플레이어와 생물의 체력·공격력·이동 속도·운반능력 등 게임 규칙상 능력치
- 허름한 시작 외형에서 의상·무기·등 장비가 실제로 교체되는 플레이어 성장
- 대장간의 도끼·곡괭이·무기 성장과 야영지 코어의 캐릭터·동료 운영 성장
- 이동 중 빈손이고 상호작용 순간에만 필요한 도구가 나타나는 상황별 도구 장착
- 등짐, 안전 자원, 패배와 동료 이탈
- 돌·나무가 실물로 쌓이고 접근해 회수하는 자원 적재칸
- 비상호작용 장식인 동굴 모닥불과 별도 성장 건물인 대장간·야영지 코어·동료 보관소
- 동굴의 돌→철→금→다이아 광물 군락과 곡괭이 단계, 숲 나무 군락과 도끼 단계의 성장 게이트
- 숲의 동굴 출입구 가까이에 조성하고 단일 가판대의 응대 속도를 강화하는 숲 장터
- 영입 동료가 즉시 들어가고 보관 수용량을 강화할 수 있는 동굴의 동료 보관소
- 출입구를 중심으로 넓게 분리한 고정 성장 시설 배치
- 공방 생산, 숲 장터 손님 판매, 장터 코인 운반
- 비콘을 이용한 건설·강화·수리
- 약탈 무리, 방어 동료, 치료소와 오프라인 진행
- 플레이어에게 보여 줄 상태, 선택 버튼과 결과 피드백

### 제외

- 코드 자료형, 데이터 컬럼과 객체 구조
- 계산 알고리즘과 저장 구조
- 런타임 오류 처리
- 개발 도구, 기술 스택, 배포와 출시 절차
- 광고, 인앱 결제와 유료 상품

생물의 능력치는 플레이 규칙과 밸런스이므로 기획 범위에 포함한다. 그 능력치를 코드에 어떤
형식으로 저장할지는 개발 구현이므로 제외한다.

## 4. 코어 순환

1. 현재 군단으로 이길 수 있는 숲의 생물 무리, 숨은 엘리트 동굴과 보스를 발견한다.
2. 목표를 쓰러뜨리고 생물을 영입할지 뼈·소울 재화로 바꿀지 선택한다.
3. 영입 생물을 동료 보관소에서 탐험 전투원 또는 채집·운반·판매·제작 일꾼으로 배치한다.
4. 탐험 동료는 다음 사냥의 전력이 되고, 일꾼은 플레이어가 직접 해 본 반복을 실제 동선으로 자동화한다.
5. 자동 생산 자원과 숲 장터 판매 코인으로 무기·도구·동행·기지 수용량을 강화한다.
6. 강해진 군단과 짧아진 준비 시간으로 더 깊은 숲의 희귀 생물과 엘리트에 도전한다.

초반의 벌목·가판대·첫 판매는 이 순환을 여는 인과 학습이다. 판매 자체가 최종 목표가 되지 않으며,
첫 30분 안에 전투 동료·작업 동료·다음 엘리트 목표가 모두 보여야 한다.

공통 경계와 세부 규칙의 소유 문서는 [`core-gameplay.md`](core-gameplay.md)의 문서 지도를 따른다.

## 6. 결정 상태

### 확정

- 이 문서의 제품 방향과 1차 기획 범위
- 위 문서 지도에서 `확정`으로 표시한 출시 규칙과 영입 문서의 명시된 확정 범위
- 최종 프로젝트·게임 표시 이름 `Wild Survival`

### 가정

- 없음

### 미정

- 동행·기지 수용량의 단계별 코인 비용
- 동료 보관소의 출시 수용량·강화 비용 확정값
- 모닥불과 분리된 안전 자원 최종 입고 건물·지점
- 기존 12단계 메인 기지·장기 공방 물류·오프라인 성장안의 대체 구조
- 정확한 제작용 색상·외형 자료는 게임 규칙 밖의 후속 시각 제작 범위다.

### 검증 필요

- 첫 30분 안에 전투 동료 1명 이상, 작업 동료 1명 이상과 다음 엘리트 목표를 이해하는지
- 생물의 전투력·작업 적성 차이가 영입과 역할 배치 선택을 실제로 바꾸는지
- 자동화가 거점 체류를 늘리는 대신 다음 원정 준비 시간을 줄이는지
- 영입·생산·판매·방어가 하나의 끊기지 않는 순환으로 느껴지는지
- 동굴은 개인 야영지, 숲 장터는 손님이 찾아오는 외부 공간으로 서로 다르게 느껴지는지
- 가판대가 1→5단계로 강화될 때 응대 속도와 장터 외형의 성장을 즉시 이해하는지
- 단일 가판대·판매대·장터 관리대와 손님 줄, 물류길·방어 접근이 겹치지 않는지
- 동굴 기상부터 첫 가판대·첫 코인·대장간 곡괭이 제작까지 다음 행동을 설명 없이 이해하는지
- 채집 결과가 자원 적재칸에 쌓이고 접근 회수되며 상한에서 작업이 멈추는 이유를 설명 없이 이해하는지
- 자원 20개를 실제로 쌓아도 플레이어·동료·작업 대상과 자원 적재칸의 현재량을 세로 화면에서 구분할 수 있는지
- 의상·무기·등짐 교체가 모든 이동 방향과 행동에서 즉시 읽히고 기준점이 흔들리지 않는지
- 세로 전체 필드 쿼터뷰에서 플레이어·동료 무리, 이동 대상, 요청 말풍선과 운반 동선을 함께 읽기 쉬운지
- 최소 화면에서 조이스틱이 시야와 대상 기능 말풍선을 가리지 않으면서 한 손 이동이 편한지
- 최소 360×800dp에서 최대 동료·손님·가판대·장식·시설과 약탈 경보를 함께 표시해도 접근과 가독성을 유지하는지
- 확정된 확률, 비용, 생산 시간, 운반능력과 치료 시간이 장기 플레이에 맞는지
