# 새 게임 기획 재출발

> 문서 상태: 초안
>
> 재출발 결정일: 2026-08-17
>
> 구현 기준 사용: 금지
>
> 공식 용어 기준: `terminology.md`

## 1. 재출발 결정

기존 `Dino TD`의 공룡 타워디펜스 기획은 새 게임의 방향으로 사용하지 않는다. 기존 전투, 웨이브,
타워, 카드, 공룡, 월드, 경제와 콘텐츠 수치는 모두 폐기한다. 과거 내용은 현재 파일로 유지하지
않으며 필요할 때만 Git 이력에서 확인한다.

## 2. 현재 확정된 방향

- 모바일용 2D 게임으로 만든다.
- 테이밍 장르와 타이쿤 장르를 결합한다.
- 공룡에 한정하지 않고 독창적인 판타지 생물을 사용한다.
- 플레이어가 직접 조작하고 화면에서 계속 만나는 귀여운 남자 주인공을 둔다.
- 생물과 관계를 맺는 경험과 생물들이 참여하는 거점 운영을 핵심 후보로 삼는다.

위 항목을 제외한 세계관, 생물의 공식 명칭, 테이밍 방식, 전투 포함 여부, 거점 구조, 성장,
경제, 세션 길이와 출시 범위는 아직 확정하지 않았다.

## 3. 전체 규칙 지도

세부 기획서를 쓰기 전에 아래 순서로 규칙을 합의한다.

1. 제품 정체성: 핵심 판타지, 대상 플레이어, 분위기와 만들지 않을 경험
2. 플레이어 역할과 세계: 주인공의 목표, 거점과 탐험 지역의 관계
3. 핵심 루프: 거점 준비, 탐험, 테이밍, 귀환, 배치와 성장의 반복
4. 테이밍: 시작 조건, 플레이어 행동, 성공·실패·중단과 재도전
5. 생물: 종별 역할, 성격, 작업 적성, 동행과 보유 제한
6. 타이쿤: 시설 건설, 작업 배치, 생산 흐름, 정체와 자동화
7. 탐험과 위험: 조작, 지역 목표, 충돌 해결 방식과 귀환 조건
8. 성장과 경제: 획득 자원, 소비처, 해금, 생물·주인공·거점 성장
9. 실패와 유지: 탐험 실패, 거점 문제, 잃는 것과 다음 시도에 남는 것
10. 모바일 화면: 세로·가로 방향, 한 손·양손 조작과 정보 우선순위
11. 시각·사운드: 주인공과 생물의 2D 조형, 애니메이션 범위와 분위기
12. 첫 제작 범위: 재미 검증용 프로토타입과 출시 범위

의존 관계는 `제품 정체성 → 핵심 루프 → 테이밍·타이쿤·탐험 → 성장·경제 → 콘텐츠·표현 → 첫 제작
범위` 순서다. 앞선 항목이 확정되기 전에는 뒤 항목을 구현 기준으로 만들지 않는다.

## 4. 결정 상태

### 확정

- 2D 모바일 게임
- 테이밍과 타이쿤의 결합
- 공룡에 한정하지 않은 판타지 생물
- 귀여운 남자 주인공
- 기존 Dino TD 기획 폐기

### 가정

- 없음

### 미정

- 전체 규칙 지도의 세부 항목 전부
- 새 게임 이름과 저장소 이름 변경 여부

### 검증 필요

- 테이밍과 거점 운영이 서로 독립된 두 게임처럼 끊기지 않고 하나의 보상 순환으로 이어지는지
- 모바일 화면에서 주인공 직접 조작과 다수 생물의 작업 상태를 함께 읽을 수 있는지
- 첫 프로토타입에 필요한 최소 생물·시설·탐험 콘텐츠 수

## 5. 다음 결정

가장 먼저 플레이어가 되고 싶은 역할과 게임의 정서적 중심을 확정한다. 이 결정 전에는 특정
세계관, 전투 방식이나 자원 수치를 기준 문서에 추가하지 않는다.
