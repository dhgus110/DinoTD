# 새 게임 기획 개요

> 문서 상태: 확정
>
> 기준일: 2026-08-18
>
> 구현 기준: 이 문서의 `확정` 항목과 `core-gameplay.md`의 확정 규칙
>
> 공식 용어 기준: [`terminology.md`](terminology.md)

## 1. 한 줄 방향

플레이어가 동굴과 숲을 오가며 생물을 동료로 영입하고, 동료의 탐험·생산·판매·방어 활동으로
동굴 기지를 계속 성장시키는 2D 아이소메트릭 세로 화면 게임이다.

## 2. 확정된 제품 방향

- 모바일 웹 환경에서 플레이하고 플레이스토어 출시를 목표로 한다.
- 2D 아이소메트릭 세로 화면을 사용한다.
- 테이밍과 기지 자동화·타이쿤을 핵심 경험으로 삼는다.
- 플레이어 조작은 상하좌우 이동을 중심으로 단순하게 유지한다.
- 공격, 채집과 재화 투입은 플레이어가 대상이나 `비콘`에 가까이 가면 자동으로 진행한다.
- 번호가 붙은 전투 구간 없이 탐험과 기지 운영이 계속 이어진다.
- 완전 무료이며 유료 상품, 광고와 인앱 결제를 사용하지 않는다.
- 별도 계정 성장과 능력치형 도감 보너스를 사용하지 않는다.
- 발광 생명체와 식물, 소울의 빛, 부드러운 안개와 자연 소재를 중심으로 한 `신비로운 자연 판타지` 분위기를 사용한다.
- 프로젝트 이름은 출시 기획과 별도의 브랜딩 작업에서 정한다. 이 저장소에서는 `새 게임`을 작업명으로 사용한다.

정확한 색상과 생물·건축물의 최종 외형은 후속 시각 기획에서 정한다. 현재 분위기 방향은 특정 상용
게임의 캐릭터, 사용자 인터페이스 또는 화풍을 모방하는 기준으로 사용하지 않는다.

## 3. 1차 기획 범위

### 포함

- 플레이어 이동, 자동 공격과 자동 채집
- 동굴·숲 탐험과 고정 포탈 이동
- 생물 등급, 전투 결과, 영입과 동료 역할
- 플레이어와 생물의 체력·공격력·이동 속도·운반능력 등 게임 규칙상 능력치
- 등짐, 안전 자원, 패배와 동료 이탈
- 메인 기지 12단계 성장과 동굴 확장
- 공방 생산, 손님 판매, 계산대 코인 운반
- 비콘을 이용한 건설·강화·수리
- 약탈 무리, 방어 동료, 치료소와 오프라인 진행
- 플레이어에게 보여 줄 상태, 선택 버튼과 결과 피드백

### 제외

- 코드 자료형, 데이터 컬럼과 객체 구조
- 계산 알고리즘과 저장 구조
- 런타임 오류 처리
- 개발 도구, 기술 스택, 배포와 출시 절차
- 광고, 인앱 결제와 유료 상품

생물의 능력치는 플레이 규칙과 밸런스이므로 기획 범위에 포함한다. 그 능력치를 코드에 어떤
형식으로 저장할지는 개발 구현이므로 제외한다.

## 4. 코어 순환

1. 플레이어가 동굴 또는 숲을 탐험하며 생물과 자원을 발견한다.
2. 플레이어와 탐험 동료가 가까운 대상을 자동으로 공격하거나 채집한다.
3. 쓰러뜨린 생물을 영입하거나 뼈·소울을 얻고, 돌·나무를 등짐에 싣는다.
4. 메인 기지에 접근해 등짐을 안전 자원으로 입고한다.
5. 동료가 자원 운반, 상품 생산, 판매와 방어를 자동으로 수행한다.
6. 코인·뼈·소울을 비콘에 투입해 기지와 시설, 수용량을 성장시킨다.
7. 커진 기지와 동료 구성을 바탕으로 탐험과 운영을 계속한다.

공통 경계와 세부 규칙의 소유 문서는 [`core-gameplay.md`](core-gameplay.md)의 문서 지도를 따른다.

## 6. 결정 상태

### 확정

- 이 문서의 제품 방향과 1차 기획 범위
- 위 문서 지도에서 `확정`으로 표시한 출시 규칙

### 가정

- 없음

### 미정

- 출시 필수 게임 규칙에는 없음
- 프로젝트의 최종 이름과 정확한 제작용 색상·외형 자료는 게임 규칙 밖의 후속 브랜딩·시각 제작 범위다.

### 검증 필요

- 영입·생산·판매·방어가 하나의 끊기지 않는 순환으로 느껴지는지
- 세로 아이소메트릭 화면에서 이동 대상, 요청 말풍선과 운반 동선을 함께 읽기 쉬운지
- 확정된 확률, 비용, 생산 시간, 운반능력과 치료 시간이 장기 플레이에 맞는지
