## 1. 목적과 범위

플레이어가 직접 탐험해 자원과 생물을 발견하고, 안전하게 입고한 자원으로 기지를 키우며, 동료에게 반복
작업을 맡겨 상품 판매와 방어를 이어 가는 전체 관계를 정의한다. 직접 행동은 새 지역과 선택을 열고,
자동화는 이미 경험한 반복을 대신하며, 방어는 쌓아 둔 판매 가치에 긴장과 회복 목표를 더한다.

### 포함

- 새 게임 시작부터 탐험·입고·영입·생산·판매·방어로 이어지는 핵심 순환
- 현장 물품, 등짐, 안전 자원과 기지 안의 약탈 가능 물품을 구분하는 공통 경계
- 자동 목표, 역할 배치, 실제 운반과 비콘에 공통으로 적용되는 원칙
- 실패 뒤 유지되는 성장과 캠페인 완료 뒤 반복 목표의 관계
- 세부 규칙 원본의 소유권과 서로 넘겨주는 시점

### 제외

- 탐험 판정, 생물 능력치·보상·영입 확률과 종별 콘텐츠의 상세값
- 기지 단계별 공개, 시설 비용·시간·수용량, 생산·판매·방어의 상세값
- HUD의 정확한 크기·배치와 접근성 수치
- 코드, 데이터 형식, 저장 구조·시점, 구현 알고리즘, 런타임 오류 처리, 분석 이벤트와 개발·출시 절차

### 결정 상태

- **확정**: 아래 핵심 순환, 공통 경계와 문서 소유권은 사용자 승인 내용이다.
- **가정**: 없음.
- **미정**: 없음. 출시 필수 세부 규칙은 각 원본 문서에서 확정돼 있다.
- **검증 필요**: 재미와 속도에 영향을 주는 수치는
  [`progression-balance.md`](progression-balance.md#12-검증-필요와-수치-조정-순서)의 통과 기준으로 확인한다.

## 3. 게임 형식과 핵심 순환

- 게임은 세로 화면의 2D 아이소메트릭 생활형 타워 디펜스다.
- 플레이어는 방향 패드로 이동하고, 가까운 유효 대상에 채집·공격·적재·하역을 자동 수행한다.
- 직접 조작하는 플레이어 한 명과 영입한 생물 동료가 같은 세계에서 움직인다.
- 동굴은 메인 기지와 판매·방어 시설이 있는 중심 지역이고, 숲은 고정 포탈로 오가는 탐험 지역이다.
- 장기 진행은 메인 기지 12단계에서 캠페인을 완료한다. 환생, 진행 초기화와 무한 능력치 성장은 없다.
- 완료 뒤에는 16종 수집과 주문 운영을 선택형 반복 목표로 계속한다.

핵심 순환은 다음 순서를 반복한다.

1. 동굴과 숲을 탐험해 자원을 채집하고 생물과 싸운다.
2. 얻은 물품을 등에 싣고 메인 기지에 입고해 안전 자원으로 바꾼다.
3. 영입 기회가 생긴 생물을 동료로 받거나 재화 결과를 선택한다.
4. 안전 자원을 플레이어 강화, 수용량, 메인 기지와 시설에 투자한다.
5. 직접 해 본 채집·운반·생산·판매를 역할별 동료에게 맡긴다.
6. 상품을 판매해 코인을 벌고, 쌓인 위험에 맞춰 기지를 방어하고 피해를 회복한다.
7. 새 단계와 지역에서 더 강한 생물, 시설과 반복 목표를 연다.

한 순환의 실패는 저장 초기화가 아니다. 잃지 않은 안전 자원과 완성한 성장은 다음 시도의 기반으로 남는다.

## 4. 시작 조건과 첫 순환

- 새 게임은 동굴의 메인 기지 입고 범위에서 시작한다.
- 시작 시 플레이어는 직접 이동·채집·입고할 수 있고, 공방·공용 판매대·계산대와 고정 포탈을 확인할 수 있다.
- 첫 영입과 첫 판매는 동시에 추천하며 어느 한쪽을 다른 쪽의 잠금 조건으로 삼지 않는다.
- 첫 판매에서는 메인 기지 재료 꺼내기부터 공방 반입, 완성 상품 진열, 창구 판매와 코인 입고까지 플레이어가 직접 수행한다.
- 첫 판매 뒤 채집 자동화 하나, 공방 물류 또는 판매 자동화 하나, 방어 시설과 첫 방어를 순서대로 추천하되 기능을 강제로 잠그지 않는다.
- 정확한 안내 순서와 종료 조건은 [`onboarding-ui.md`](onboarding-ui.md#2-온보딩-원칙과-종료)를 따른다.

## 5. 현장 물품, 등짐과 안전 자원

- 채집한 원자재와 생물에게서 얻은 뼈는 먼저 플레이어와 탐험 동료가 공유하는 등짐에 들어간다.
- 등짐 한도는 플레이어와 현재 동행 중인 탐험 동료의 운반능력으로 정한다.
- 소울은 획득 즉시 안전 자원이 되며 등짐을 사용하지 않는다.
- 등짐의 물품은 메인 기지 입고 범위에서 안전 자원으로 바뀐다. 입고 전에는 탐험 패배로 잃을 수 있다.
- 메인 기지에 입고된 돌·나무·코인·뼈·소울은 안전 자원이며 약탈로 잃지 않는다.
- 공방 완성품, 판매대 상품, 계산대와 운반 중 코인은 기지 안에 있지만 안전 입고 전이므로 약탈 대상이 될 수 있다.
- 지역 이동이나 접속 종료가 안전 입고를 대신하지 않는다. 탐험 중 채집한 등짐은 접속 종료 뒤 유지하지만,
  기지 안에서 보관 지점으로부터 꺼내 수동 운반 중인 물품은 원래 출발 지점으로 돌아간다.

## 6. 자동 행동과 역할

### 6.1 탐험 자동 행동

- 플레이어와 탐험 동료는 현재 행동을 끝낸 뒤 자동 목표 우선순위를 다시 평가한다.
- 적대 생물 대응, 자원 채집, 중립 생물 대응과 같은 정확한 순서·거리 판정은
  [`exploration-combat.md`](exploration-combat.md#7-자동-목표)가 소유한다.
- 등짐이 가득 차면 추가 채집만 멈추며 이동과 생물 대응은 계속한다.
- 플레이어 패배와 탐험 동료 이탈 때의 물품 손실·유지 규칙은 탐험 원본을 따른다.

### 6.2 동료 역할과 전담 작업

- 영입한 생물은 탐험 동료, 일꾼, 방어 동료 중 한 역할을 맡는다.
- 선호 역할 보정은 현재 맡은 역할이 종의 선호 역할과 같을 때만 적용한다.
- 일꾼은 배치된 전담 시설의 요청만 처리하며 자동으로 다른 시설 인력을 대신하지 않는다.
- 전담 시설 안의 공통 요청 순서는
  [`creatures-and-recruitment.md`](creatures-and-recruitment.md#62-일꾼)를 따른다.
- 물류 관리소는 전담 배치와 막힘을 확인·교체하는 곳이며 자동 인력 분배나 순간 이동을 제공하지 않는다.
- 작업 선호와 시설 보정이 함께 적용되는 계산 순서는
  [`progression-balance.md`](progression-balance.md#62-운반)의 단일 원본을 따른다.

## 7. 비용, 비콘과 성장 선택

- 안전 자원은 플레이어 능력치, 동행·기지 수용량, 메인 기지, 시설 건설·강화와 수리·치료에 사용한다.
- 건설·강화·수리는 대상 비콘 가까이에서 요구 재화를 자동 투입해 진행한다.
- 투입 전에 선택이 필요한 성장 경로는 대상 기능 말풍선에서 고른다. 선택 버튼 자체는 비콘이 아니다.
- 요구 재화를 전부 투입하면 해당 작업을 완료한다. 재화가 부족하거나 완료 전에 범위를 벗어나면 임시
  투입분을 모두 안전 자원으로 반환하고 완료하지 않는다.
- 한 작업을 완료해도 다음 단계나 다른 작업을 자동 시작하지 않는다.
- 비용, 투입 시간, 강화 효과와 상한은 [`progression-balance.md`](progression-balance.md)가 소유한다.

플레이어는 직접 전투·채집 능력, 더 많은 동료, 자동화 처리량과 방어 안정성 사이에서 투자 순서를 선택한다.
어떤 선택도 진행을 초기화하지 않으며, 부족한 재화의 종류와 수량을 해당 대상에서 확인할 수 있어야 한다.

## 8. 기지 운영, 판매와 방어 연결

- 메인 기지 단계 상승은 새 시설과 강화 상한, 동굴 공간과 외형 변화를 공개한다.
- 기지의 고정 시설·물류 보호 공간은 처음부터 최대 자리를 예약하며, 자유 장식은 기능 접근과 운반 동선을 막지 않는 바닥에만 둔다.
- 채석장과 벌목장은 실제 시설이며 배치된 동료가 현장에서 직접 채집하고 메인 기지까지 운반한다.
- 공방은 메인 기지 자원을 상품으로 바꾸고, 공방 물류 동료가 재료 반입과 완성품 반출을 맡는다.
- 판매대 상품은 공용 한 줄의 선두 손님부터 계산 창구에서 처리한다. 선두 요청이 품절이면 뒤 손님을 먼저 판매하지 않는다.
- 계산대 코인은 플레이어 또는 전담 동료가 메인 기지에 실제로 운반해야 안전 코인이 된다.
- 상품 생산으로 약탈 위험이 쌓이고, 경보 뒤 방어 동료와 플레이어가 약탈자를 막는다.
- 약탈자는 가까운 플레이어 측 전투 대상을 먼저 공격하고, 대상이 없을 때 벽·출입문을 공격한다.
- 벽이 뚫리면 안전 입고 전 상품과 코인을 훔칠 수 있다. 탈출 전에 약탈자를 쓰러뜨리면 물품을 회수할 수 있다.
- 방어 피해는 벽 수리와 동료 치료로 회복하며 안전 자원과 기지 진행을 되돌리지 않는다.

시설 공개·물류·생산은 [`base-automation.md`](base-automation.md), 판매·약탈·방어·치료는
[`sales-defense.md`](sales-defense.md), 모든 반복 수치는 [`progression-balance.md`](progression-balance.md)를 따른다.

## 9. 우선순위, 종료와 실패 처리

| 상황 | 우선 처리 | 종료·실패 결과 |
| --- | --- | --- |
| 탐험 중 적대 생물 접근 | 현재 행동 뒤 자동 목표 규칙으로 대응 | 플레이어 패배 시 등짐을 잃고 기지에서 재개 |
| 영입 기회 발생 | 영입 또는 재화 중 플레이어가 선택 | 수용량 부족 시 영입만 막고 재화 선택은 유지 |
| 일꾼 요청 중복 | 일꾼 원본의 공통 요청 순서 적용 | 입력·출력 막힘이면 해당 시설에서 대기 |
| 판매 재고 부족 | 공용 줄 선두 요청 유지 | 손님이 떠나지 않으며 재고 도착 뒤 같은 순서 재개 |
| 약탈 경보 | 성장 비콘 잠금·미완료 반환, 판매 중단 준비, 손님 대피, 방어 배치·수리 | 적 도착 뒤 배치·수리를 잠그고 정시에 전투 시작 |
| 방어 동료 체력 0 | 치료소 유무와 접속 상태 확인 | 온라인 치료소 없음은 영구 이탈, 그 밖은 치료 규칙 적용 |
| 벽 침입 | 도난·추격·회수 처리 | 경계 밖으로 나간 물품만 최종 손실 |
| 캠페인 완료 | 12단계 완료 상태 유지 | 수집·주문 반복 목표로 계속하며 초기화하지 않음 |

## 10. 접속 종료와 오프라인 진행

- 안전 자원, 영입 동료, 역할·시설 배치, 기지·시설 단계, 주문과 방어 피해는 접속 종료 뒤 유지한다.
- 오프라인에는 배치가 끝난 자동화 구간만 온라인과 같은 규칙·속도로 진행한다.
- 오프라인 진행 시간 상한, 약탈 중단, 치료비와 로그아웃 운반물 처리는
  [`sales-defense.md`](sales-defense.md#10-오프라인-판매방어)와
  [`progression-balance.md`](progression-balance.md#9-오프라인-진행-수치와-종료)를 따른다.
- 복귀 시 입고, 생산·판매, 약탈·손실, 치료와 막힘을 시간 순서대로 요약한다.
- 새 게임에서만 전체 진행을 시작 상태로 되돌린다. 캠페인 완료 뒤 별도 초기화 기능은 없다.

## 11. 공통 화면 피드백

- 안전 자원과 등에 든 운반물은 서로 다른 위치와 표현으로 구분한다.
- 자동 행동 대상, 진행 중 작업, 부족 재화, 시설 막힘과 손실 원인을 글과 아이콘으로 함께 보여 준다.
- 선택 대상의 행동은 대상 기능 말풍선에 표시하고, 약탈은 다른 운영 알림보다 높은 우선순위로 알린다.
- 소리·진동·카메라 연출을 꺼도 같은 상태와 다음 행동을 시각 정보로 판단할 수 있어야 한다.
- 정확한 HUD, 터치 영역, UI 크기와 접근성 기준은 [`onboarding-ui.md`](onboarding-ui.md)가 소유한다.

## 12. 정상·예외·실패 확인 사례

| 구분 | 확인 상황 | 기대 결과 |
| --- | --- | --- |
| 정상 | 탐험 물품을 메인 기지에 입고 | 등짐에서 빠지고 안전 자원에 더해져 이후 패배·약탈로 잃지 않음 |
| 정상 | 영입 동료를 시설에 배치 | 해당 전담 시설 요청만 실제 이동으로 처리 |
| 정상 | 상품을 판매하고 코인을 입고 | 판매대 상품은 코인 더미로, 입고한 코인은 안전 자원으로 전환 |
| 예외 | 첫 영입보다 첫 판매를 먼저 완료 | 판매·기지 성장을 계속하고 영입 목표만 유지 |
| 예외 | 선두 손님의 상품이 품절 | 뒤 손님을 건너뛰지 않고 같은 요청·순서로 무기한 대기 |
| 실패 | 탐험 중 플레이어 패배 | 안전 자원과 기지 성장은 유지하고 현장 손실만 적용한 뒤 기지에서 재개 |
| 실패 | 온라인에서 치료소 없이 방어 동료 패배 | 해당 동료가 영구 이탈하되 기지·판매·안전 자원은 초기화하지 않음 |
| 실패 | 약탈자가 물품을 들고 경계를 벗어남 | 경계를 넘은 상품·코인만 최종 손실로 확정하고 회복 운영 계속 |
| 종료 | 메인 기지 12단계 완료 | 완료 상태를 유지하고 16종 수집·주문을 선택해 반복 |
