## 1. 목적과 범위

플레이어가 직접 탐험해 자원과 생물을 발견하고, 안전하게 입고한 자원으로 기지를 키우며, 동료에게 반복
작업을 맡겨 상품 판매와 방어를 이어 가는 전체 관계를 정의한다. 직접 행동은 새 지역과 선택을 열고,
자동화는 이미 경험한 반복을 대신하며, 방어는 쌓아 둔 판매 가치에 긴장과 회복 목표를 더한다.

### 포함

- 새 게임 시작부터 탐험·입고·영입·생산·판매·방어로 이어지는 핵심 순환
- 현장 물품, 등짐, 안전 자원과 메인 기지 입고 전 약탈 가능 물품을 구분하는 공통 경계
- 자동 목표, 역할 배치, 실제 운반과 비콘에 공통으로 적용되는 원칙
- 실패 뒤 유지되는 성장과 캠페인 완료 뒤 반복 목표의 관계
- 세부 규칙 원본의 소유권과 서로 넘겨주는 시점

### 제외

- 탐험 판정, 생물 능력치·보상·영입 확률과 종별 콘텐츠의 상세값
- 기지 단계별 공개, 시설 비용·시간·수용량, 생산·판매·방어의 상세값
- HUD의 정확한 크기·배치와 접근성 수치
- 코드, 데이터 형식, 저장 구조·시점, 구현 알고리즘, 런타임 오류 처리, 분석 이벤트와 개발·출시 절차

### 결정 상태

- **확정**: 아래 핵심 순환, 공통 경계와 문서 소유권은 사용자 승인 내용이다.
- **가정**: 없음.
- **미정**: 모닥불과 분리된 안전 자원 최종 입고 건물·지점, 이를 전제로 한 장기 물류 구조.
- **검증 필요**: 재미와 속도에 영향을 주는 수치는
  [`progression-balance.md`](progression-balance.md#12-검증-필요와-수치-조정-순서)의 통과 기준으로 확인한다.

## 3. 게임 형식과 핵심 순환

- 게임은 화면 대부분을 필드로 쓰는 세로 화면의 2D 쿼터뷰 테이밍·생존 타이쿤 게임이다.
- 플레이어는 동적 아날로그 조이스틱으로 연속 이동하고, 가까운 유효 대상에 채집·공격·적재·하역을 자동 수행한다.
- 직접 조작하는 플레이어 한 명과 영입한 생물 동료가 같은 세계에서 움직인다.
- 동굴은 채광과 세 성장 건물이 있는 개인 공간이고, 숲은 탐험 지역이자 동굴 출입구 가까운
  안전 공터에 단일 가판대를 강화해 가는 `숲 장터`가 있는 외부 지역이다.
- 모닥불은 기상·귀환 위치만 보여 주는 장식이며 입고·강화·동료 관리 기능이 없다.
- 기존 메인 기지 12단계 완료 조건은 최신 동굴 구조와 안전 입고 목적지가 정해질 때까지 구현 기준에서 제외한다.

핵심 순환은 다음 순서를 반복한다.

1. 동굴의 등급별 광물과 숲의 등급별 나무를 도구 단계에 맞춰 채집하고, 자원 적재칸에 실물로 쌓인 결과를 등에 실어 운반한다.
2. 숲 장터에 가판대 한 채를 짓고 응대 속도를 강화하며 원자재·가공 상품을 숲길로 찾아오는 손님에게 판매한다.
3. 번 코인으로 대장간의 도구·무기, 야영지 코어의 캐릭터·동료 운영 능력치와 자동화 시설을 강화한다.
4. 강해진 장비로 더 깊은 숲에서 생물과 싸우고 영입 또는 재화 결과를 선택한다.
5. 직접 해 본 채집·운반·생산·판매를 역할별 동료에게 맡긴다.
6. 자동화로 번 코인을 다음 탐험과 기지 방어에 투자한다.
7. 새 단계와 지역에서 더 강한 생물, 장비, 시설과 반복 목표를 연다.

한 순환의 실패는 저장 초기화가 아니다. 잃지 않은 안전 자원과 완성한 성장은 다음 시도의 기반으로 남는다.

## 4. 시작 조건과 첫 순환

- 새 게임은 완성된 기지가 아니라 동굴 안쪽의 꺼져 가는 모닥불 옆에서 시작한다.
- 모닥불은 상호작용하지 않으며 대장간·야영지 코어·동료 보관소와 별개의 장식이다.
- 플레이어는 허름한 옷과 빈손으로 깨어나 출구 옆 부러진 손도끼를 줍고 숲으로 나간다.
- 첫 자원은 나무다. 첫 벌목 군락에서 목재가 자원 적재칸에 하나씩 쌓이고, 그 칸에 접근해 등에 싣는 모습과
  운반 한도를 배운 뒤 같은 숲 화면의 동굴 출입구 가까운 장터 자리로 이동한다.
- 첫 목재로 숲 장터에 허름한 가판대를 직접 짓고, 남은 목재를 장작 묶음으로 진열해 숲길에서 온 첫 손님에게 판매한다.
- 첫 코인은 가판대 옆 네모난 적재칸에 쌓이고 접근해 회수한 뒤 대장간에서 곡괭이를 제작하는 데 사용하며,
  판매 수익이 새 자원 채집 자격으로 되돌아오는 왕복을 보여 준다.
- 첫 곡괭이로 돌을 채집해 야영지 코어를 활성화한 뒤 캐릭터·동료 운영 성장과 약한 생물의 첫 영입·자동화를 소개한다.
- 첫 영입과 첫 판매를 동시에 추천하던 이전 규칙은 사용하지 않는다. 정확한 단계, 목표 시간과 캐릭터
  파츠 규칙은 [`early-funnel-and-character-parts.md`](early-funnel-and-character-parts.md)를 따른다.
- 안내의 표현과 온보딩 종료 조건은 [`onboarding-ui.md`](onboarding-ui.md#2-온보딩-원칙과-종료)를 따른다.

## 5. 현장 물품, 등짐과 안전 자원

- 채집한 돌·나무는 먼저 해당 작업 구역의 자원 적재칸에 쌓이고, 플레이어나 담당 일꾼이 접근해 실은 뒤
  등짐 또는 운반물로 바뀐다. 생물에게서 얻은 뼈는 기존 결과 규칙에 따라 등짐에 들어간다.
- 자원 적재칸에는 돌 또는 나무가 [보관 상한](progression-balance.md#61-채석장과-벌목장)까지 하나씩
  실물로 쌓인다. 상한에 도달하면 연결된 채집만 멈추고, 하나 이상 반출되면 자동으로 재개한다.
- 플레이어가 자원 적재칸에 접근하면 빈 운반 한도만큼 하나씩 등에 싣는다. 한도가 가득 차면 남은 자원은
  적재칸에 그대로 남는다.
- 등짐 한도는 플레이어와 현재 동행 중인 탐험 동료의 운반능력으로 정한다.
- 소울은 획득 즉시 안전 자원이 되며 등짐을 사용하지 않는다.
- 등짐의 물품은 아직 확정하지 않은 별도 안전 입고 지점에 도착하기 전에는 탐험 패배로 잃을 수 있다.
- 모닥불과 야영지 코어 접근은 안전 입고를 발생시키지 않는다.
- 공방 완성품, 숲 장터 판매대 상품, 장터 관리대와 운반 중 코인은 메인 기지 안전 입고 전이므로 약탈 대상이 될 수 있다.
- 지역 이동이나 접속 종료가 안전 입고를 대신하지 않는다. 탐험 중 채집한 등짐은 접속 종료 뒤 유지하지만,
  동굴·숲 장터에서 보관 지점으로부터 꺼내 수동 운반 중인 물품은 원래 출발 지점으로 돌아간다.

## 6. 자동 행동과 역할

### 6.1 탐험 자동 행동

- 플레이어와 탐험 동료는 현재 행동을 끝낸 뒤 자동 목표 우선순위를 다시 평가한다.
- 적대 생물 대응, 자원 채집, 중립 생물 대응과 같은 정확한 순서·거리 판정은
  [`exploration-combat.md`](exploration-combat.md#7-자동-목표)가 소유한다.
- 등짐이 가득 차면 추가 채집만 멈추며 이동과 생물 대응은 계속한다.
- 플레이어 패배와 탐험 동료 이탈 때의 물품 손실·유지 규칙은 탐험 원본을 따른다.

### 6.2 동료 역할과 전담 작업

- 영입한 생물은 현장에서 바로 따라오지 않고 동굴의 동료 보관소에 대기 상태로 등록된다.
- 플레이어는 동료 보관소에서 동료를 탐험 동료로 편성하거나 일꾼·방어 동료로 기지에 배치한다.
- 보관 수용량은 전체 소유 수를 제한하고 동료 보관소에서 강화한다. 동행·기지 수용량은 활동 인원만 제한하며 야영지 코어에서 강화한다.
- 탐험 동료는 동행 수용량을, 일꾼과 방어 동료는 기지 수용량을 사용하며 대기 동료는 어느 활동
  수용량도 사용하지 않는다.
- 선호 역할 보정은 현재 맡은 역할이 종의 선호 역할과 같을 때만 적용한다.
- 일꾼은 배치된 전담 시설의 요청만 처리하며 자동으로 다른 시설 인력을 대신하지 않는다.
- 전담 시설 안의 공통 요청 순서는
  [`creatures-and-recruitment.md`](creatures-and-recruitment.md#62-일꾼)를 따른다.
- 물류 관리소는 전담 배치와 막힘을 확인·교체하는 곳이며 자동 인력 분배나 순간 이동을 제공하지 않는다.
- 작업 선호와 시설 보정이 함께 적용되는 계산 순서는
  [`progression-balance.md`](progression-balance.md#62-운반)의 단일 원본을 따른다.

## 7. 비용, 비콘과 성장 선택

- 안전 자원은 플레이어 능력치, 동행·기지 수용량, 메인 기지, 시설 건설·강화와 수리·치료에 사용한다.
- 판매로 번 코인과 생물 재화 결과의 소울은 동행·기지 수용량 확장에 함께 사용한다. 단계별 정확한
  코인 비용은 [`creatures-and-recruitment.md`](creatures-and-recruitment.md)의 미정 항목을 따른다.
- 미건설 시설은 해금 전에는 건물·건설 영역을 모두 숨긴다. 해금 순간 고정 위치에 필요 재화와 네모난 건설 영역만 표시한다.
- 플레이어가 건설 영역 안에 머무르면 요구 재화를 한 개씩 확정 투입하고, 바닥 진행도·기초·기둥·외형이 순서대로 차오른다.
- 건설 영역에서 나가거나 재화가 부족해도 이미 확정 투입한 수량과 진행도는 유지한다. 다시 접근하면 남은 수량부터 이어서 투입한다.
- 완성 전에는 완성 건물 기능과 외형을 사용하지 않으며, 마지막 재화가 들어가면 건설 영역을 완성 건물로 교체한다.
- 강화·수리는 대상 비콘 가까이에서 요구 재화를 자동 투입해 진행한다.
- 투입 전에 선택이 필요한 성장 경로는 대상 기능 말풍선에서 고른다. 선택 버튼 자체는 비콘이 아니다.
- 강화·수리에서 요구 재화를 전부 투입하면 해당 작업을 완료한다. 재화가 부족하거나 완료 전에 범위를 벗어나면 임시
  투입분을 모두 안전 자원으로 반환하고 완료하지 않는다. 건설의 확정 투입은 반환하지 않는다.
- 한 작업을 완료해도 다음 단계나 다른 작업을 자동 시작하지 않는다.
- 비용, 투입 시간, 강화 효과와 상한은 [`progression-balance.md`](progression-balance.md)가 소유한다.

플레이어는 직접 전투·채집 능력, 더 많은 동료, 자동화 처리량과 방어 안정성 사이에서 투자 순서를 선택한다.
어떤 선택도 진행을 초기화하지 않으며, 부족한 재화의 종류와 수량을 해당 대상에서 확인할 수 있어야 한다.

## 8. 기지 운영, 판매와 방어 연결

- 메인 기지 단계 상승은 새 시설과 강화 상한, 동굴 공간·외형과 숲 장터 가판대의 다음 강화 상한을 공개한다.
- 기지의 고정 시설·물류 보호 공간은 처음부터 최대 자리를 예약하며, 자유 장식은 기능 접근과 운반 동선을 막지 않는 바닥에만 둔다.
- 채석장과 벌목장은 실제 시설이며 배치된 동료가 현장에서 직접 채집해 자원 적재칸에 쌓고, 그 칸에서
  다시 등에 실어 메인 기지까지 운반한다.
- 공방은 메인 기지 자원을 상품으로 바꾸고, 공방 물류 동료가 재료 반입과 완성품 반출을 맡는다.
- 숲 장터의 가판대는 공용 한 줄의 선두 손님부터 처리한다. 선두 요청이 품절이면 뒤 손님을 먼저 판매하지 않는다.
- 장터 관리대의 코인은 플레이어 또는 전담 동료가 동굴 출입구를 지나 메인 기지에 실제로 운반해야 안전 코인이 된다.
- 상품 생산으로 약탈 위험이 쌓이고, 경보 뒤 방어 동료와 플레이어가 약탈자를 막는다.
- 약탈자는 가까운 플레이어 측 전투 대상을 먼저 공격하고, 대상이 없을 때 벽·출입문을 공격한다.
- 벽이 뚫리면 안전 입고 전 상품과 코인을 훔칠 수 있다. 탈출 전에 약탈자를 쓰러뜨리면 물품을 회수할 수 있다.
- 방어 피해는 벽 수리와 동료 치료로 회복하며 안전 자원과 기지 진행을 되돌리지 않는다.

시설 공개·물류·생산은 [`base-automation.md`](base-automation.md), 판매·약탈·방어·치료는
[`sales-defense.md`](sales-defense.md), 모든 반복 수치는 [`progression-balance.md`](progression-balance.md)를 따른다.

## 9. 우선순위, 종료와 실패 처리

| 상황 | 우선 처리 | 종료·실패 결과 |
| --- | --- | --- |
| 탐험 중 적대 생물 접근 | 현재 행동 뒤 자동 목표 규칙으로 대응 | 플레이어 패배 시 등짐을 잃고 기지에서 재개 |
| 영입 기회 발생 | 영입 또는 재화 중 플레이어가 선택 | 영입하면 동료 보관소에 대기 등록하고, 재화를 고르면 뼈·소울 결과를 적용 |
| 일꾼 요청 중복 | 일꾼 원본의 공통 요청 순서 적용 | 입력·출력 막힘이면 해당 시설에서 대기 |
| 판매 재고 부족 | 공용 줄 선두 요청 유지 | 손님이 떠나지 않으며 재고 도착 뒤 같은 순서 재개 |

| 방어 동료 체력 0 | 치료소 유무와 접속 상태 확인 | 온라인 치료소 없음은 영구 이탈, 그 밖은 치료 규칙 적용 |
| 벽 침입 | 도난·추격·회수 처리 | 경계 밖으로 나간 물품만 최종 손실 |
| 장기 완료 | 완료 조건 재설계 중 | 현재 성장·동료·수집 상태를 초기화하지 않음 |

## 10. 접속 종료와 오프라인 진행

- 안전 자원, 영입 동료, 역할·시설 배치, 기지·시설 단계, 주문과 방어 피해는 접속 종료 뒤 유지한다.
- 오프라인에는 배치가 끝난 자동화 구간만 온라인과 같은 규칙·속도로 진행한다.
- 오프라인 진행 시간 상한, 약탈 중단, 치료비와 로그아웃 운반물 처리는
  [`sales-defense.md`](sales-defense.md#10-오프라인-판매방어)와
  [`progression-balance.md`](progression-balance.md#9-오프라인-진행-수치와-종료)를 따른다.
- 복귀 시 입고, 생산·판매, 약탈·손실, 치료와 막힘을 시간 순서대로 요약한다.
- 새 게임에서만 전체 진행을 시작 상태로 되돌린다. 캠페인 완료 뒤 별도 초기화 기능은 없다.

## 11. 공통 화면 피드백

- 안전 자원과 등에 든 운반물은 서로 다른 위치와 표현으로 구분한다.
- 자동 행동 대상, 진행 중 작업, 부족 재화, 시설 막힘과 손실 원인을 글과 아이콘으로 함께 보여 준다.
- 자원 적재칸은 바닥 윤곽, 실물 더미와 현재량·상한을 함께 보여 주고, 가득 차면 연결된 채집이 멈춘 이유를 표시한다.
- 선택 대상의 행동은 대상 기능 말풍선에 표시하고, 약탈은 다른 운영 알림보다 높은 우선순위로 알린다.
- 소리·진동·카메라 연출을 꺼도 같은 상태와 다음 행동을 시각 정보로 판단할 수 있어야 한다.
- 정확한 HUD, 터치 영역, UI 크기와 접근성 기준은 [`onboarding-ui.md`](onboarding-ui.md)가 소유한다.
