# 1차 코어 게임플레이 규칙

> 문서 상태: 검토 중
>
> 적용 범위: 탐험, 생물 영입, 기지 성장, 자동화, 판매, 약탈과 오프라인 진행
>
> 구현 기준: 이 문서에서 `확정`으로 표시한 규칙
>
> 공식 용어 기준: [`terminology.md`](terminology.md)

## 1. 문서 목적과 제외 범위

이 문서는 첫 동료 영입부터 자원 입고, 상품 생산·판매와 첫 약탈 방어까지 이어지는 1차 코어
게임플레이의 단일 규칙 원본이다.

생물의 체력·공격력·이동 속도·운반력, 영입 확률과 생산 시간처럼 플레이 결과를 바꾸는 값은
게임 규칙과 밸런스이므로 기획 범위에 포함한다. 단, 구체적인 값은 후속 콘텐츠·밸런스 문서에서
정한다.

코드 자료형, 데이터 컬럼, 객체 구조, 계산 알고리즘, 저장 구조, 런타임 오류 처리, 개발 도구와
출시 절차는 이 문서에서 다루지 않는다.

### 1.1 결정 상태

- 이 문서의 규칙 문장은 사용자가 승인한 `확정` 사항이다.
- 문장 안에서 후속 기획·밸런스·검증으로 남긴 항목과 16절의 항목은 아직 구현 수치로 확정하지 않는다.
- 논의를 진행하기 위해 임의로 추가한 `가정`은 없다.

## 2. 게임 형식과 코어 순환

### 2.1 확정 형식

- 2D 아이소메트릭 세로 화면을 사용한다.
- 플레이어의 주 조작은 상하좌우 이동이다.
- 공격, 채집과 비콘 재화 투입은 거리 조건을 만족하면 자동으로 진행한다.
- 번호가 붙은 전투 구간 없이 탐험과 기지 운영을 연속해서 플레이한다.
- 별도 계정 성장과 능력치형 도감 보너스를 사용하지 않는다.

### 2.2 코어 순환

1. 동굴이나 숲을 탐험해 자원과 생물을 찾는다.
2. 자원을 채집하고 생물을 쓰러뜨려 영입 또는 재화 결과를 얻는다.
3. 메인 기지에 접근해 등짐의 돌·나무·뼈를 안전 자원으로 입고한다.
4. 동료를 탐험·일꾼·방어 역할에 배치한다.
5. 일꾼이 자원을 공방으로 옮겨 상품을 만들고 계산대 판매까지 연결한다.
6. 판매 코인을 메인 기지에 입고한다.
7. 코인·뼈·소울로 기지, 시설과 동료 수용량을 성장시킨다.
8. 약탈 무리를 방어하면서 더 오래 탐험하고 자동화 흐름을 확장한다.

## 3. 지역과 이동

### 3.1 동굴 기지

- 플레이어는 동굴의 메인 기지에서 시작한다.
- 메인 기지 주변은 안전한 운영 공간이며, 동굴의 바깥 탐험 공간에는 돌과 생물이 존재한다.
- 기지 남쪽 출입구는 플레이어와 약탈 무리가 함께 사용한다.
- 손님은 계산대 정면의 남쪽 대기 구역에 머문다. 이 구역은 벽 건설 뒤에도 벽 바깥쪽에 남는다.
- 남쪽에는 계산대, 벽·출입문과 방어 야영지가 놓이고, 계산대의 안쪽은 기지 물류 공간과 연결된다.
- 동굴의 동쪽·서쪽·북쪽 공간은 메인 기지 성장에 따라 확장된다.

### 3.2 숲과 포탈

- 동굴 기지와 숲은 게임 시작부터 작동하는 고정 포탈로 연결한다.
- 플레이어가 포탈에 접근하면 숲으로 이동하며, 숲에서 같은 방식으로 동굴로 돌아온다.
- 숲에는 나무와 숲 생물이 존재한다.
- 지역은 일회성 스테이지가 아니며 자원과 생물이 시간이 지나면 다시 나타난다.
- 보스 생물은 일반 자원·생물보다 긴 재등장 시간을 사용한다.

## 4. 탐험 행동과 자동 목표

### 4.1 플레이어

- 플레이어는 상하좌우 이동만으로 탐험 대상을 찾아 접근한다.
- 공격 가능한 거리 안에 대상이 들어오면 자동으로 공격한다.
- 채집 가능한 거리 안에 자원이 들어오면 자동으로 채집한다.
- 여러 종류의 대상이 동시에 범위에 들어오면 다음 우선순위를 사용한다.

`적대 생물 → 중립 생물 → 자원`

- 더 높은 우선순위 대상이 나타나면 낮은 우선순위 행동을 멈추고 대응한다.
- 같은 우선순위 안에서 어떤 대상을 먼저 고르는지는 후속 조작감 검증에서 정한다.

### 4.2 탐험 동료

- 탐험 동료는 플레이어를 중심으로 대형을 이루어 함께 이동한다.
- 플레이어가 공격하거나 채집하는 목표를 함께 공격·채집한다.
- 각 탐험 동료의 운반력이 공유 등짐의 운반 한도에 더해진다.
- 대형 간격, 충돌과 좁은 길 통과 방식은 후속 조작감 검증에서 정한다.

## 5. 등짐, 입고와 탐험 실패

### 5.1 공유 등짐

- 돌·나무·뼈는 공유 등짐에 쌓인다.
- 소울은 희귀 재화이므로 획득 즉시 안전하게 보관하며 등짐 한도를 사용하지 않는다.
- 운반 한도는 플레이어의 기본 운반력과 동행 중인 탐험 동료별 운반력의 합이다.
- 등짐이 가득 차면 자원 채집만 중단한다.
- 등짐이 가득 차도 이동, 생물 사냥과 영입은 계속할 수 있다.
- 등짐에 빈자리가 생기면 별도의 버튼 없이 채집을 다시 시작한다.

### 5.2 메인 기지 입고

- 플레이어가 메인 기지의 입고 범위에 접근하면 등짐의 돌·나무·뼈를 전부 입고한다.
- 기지 출입구를 통과한 것만으로는 입고되지 않는다.
- 입고가 끝난 자원은 안전 자원이 되며 탐험 패배와 약탈로 잃지 않는다.

### 5.3 플레이어 패배

- 플레이어 체력이 0이 되면 전투를 종료하고 동굴 기지로 자동 귀환한다.
- 패배 시 등짐에 남은 돌·나무·뼈를 전부 잃는다.
- 이미 입고된 안전 자원과 즉시 보관된 소울은 유지한다.
- 패배 뒤 체력 회복 방식과 재출발 대기 시간은 후속 밸런스에서 정한다.

### 5.4 탐험 동료 이탈

- 탐험 동료의 체력이 0이 되면 영구 이탈한다.
- 이탈한 동료의 운반력이 빠져 현재 등짐이 새 운반 한도를 넘으면 초과분이 현장에 떨어진다.
- 플레이어가 떨어진 자원에 접근하고 등짐에 여유가 있으면 다시 자동으로 회수한다.
- 이후 플레이어까지 패배하면 남아 있는 등짐은 현장에 떨어지지 않고 전부 사라진다.

## 6. 생물 구성, 결과와 영입

### 6.1 지역별 구성

| 지역 | 일반 생물 | 엘리트 생물 | 보스 생물 | 합계 |
| --- | ---: | ---: | ---: | ---: |
| 동굴 | 5종 | 2종 | 1종 | 8종 |
| 숲 | 5종 | 2종 | 1종 | 8종 |
| 전체 | 10종 | 4종 | 2종 | 16종 |

- 16종의 이름, 외형, 설명과 세부 능력치는 후속 콘텐츠·밸런스 문서에서 정한다.
- 같은 종을 여러 마리 영입할 수 있으며 보스 생물도 예외가 아니다.
- 보스 생물은 지역마다 정해진 보금자리에 나타난다.

### 6.2 쓰러뜨린 생물의 결과

| 생물 등급 | 영입 선택 기회 | 재화 선택 시 뼈 | 재화 선택 시 소울 |
| --- | --- | --- | --- |
| 일반 생물 | 엘리트와 같은 높은 확률 | 재화 선택 또는 영입 기회 실패 시 확정 | 낮은 확률 |
| 엘리트 생물 | 일반과 같은 높은 확률 | 재화 선택 또는 영입 기회 실패 시 확정 | 일반보다 높은 확률 |
| 보스 생물 | 항상 발생 | 확정 | 확정 |

- 정확한 영입 확률과 소울 확률은 후속 밸런스에서 정한다.
- 영입 기회가 발생하면 쓰러진 생물 아래에 `영입`과 `재화` 버튼을 표시한다.
- 플레이어가 `영입`을 선택하면 해당 생물을 동료로 만든다.
- 플레이어가 `재화`를 선택하면 해당 등급의 뼈와 소울 결과를 받는다.
- 영입 기회가 발생하지 않으면 선택 버튼을 띄우지 않고 재화 결과를 자동 획득한다.
- 영입한 경우에는 그 생물의 재화 결과를 함께 받지 않는다.
- 선택 중 다른 위험에 노출되는지, 선택이 자동 종료되는 시간은 후속 플레이 검증에서 정한다.

### 6.3 수용량과 역할

- 동행 수용량과 기지 수용량은 서로 별개다.
- 영입에는 새 동료를 받아들이는 데 필요한 두 수용량의 빈자리가 있어야 한다.
- 수용량이 부족하면 `영입` 버튼을 비활성화하고 부족한 수용량을 표시한다.
- 동행 수용량과 기지 수용량은 각각 소울로 확장한다.
- 동료는 탐험 동료, 일꾼, 방어 동료 중 한 역할만 맡는다.
- 역할은 기지에서만 변경할 수 있으며 변경 비용은 없다.
- 역할을 바꾸면 이전 역할의 행동을 멈추고 새 역할의 배치 지점으로 이동한다.

### 6.4 생물 능력치 범위

각 생물은 다음 게임 규칙상 능력치와 역할 적성을 가진다.

- 체력
- 공격력
- 이동 속도
- 운반력
- 탐험 적성
- 작업 적성
- 방어 적성

종별 수치, 역할별 효율과 등급에 따른 범위는 후속 콘텐츠·밸런스 문서에서 정한다.

## 7. 시작 상태와 메인 기지 성장

### 7.1 시작 상태

- 메인 기지는 모닥불 1단계에서 시작한다.
- 돌만 소비해 상품을 만드는 공방 하나가 처음부터 있다.
- 손님이 상품을 구매하는 수동 계산대가 처음부터 있다.
- 계산대는 처음에는 독립 시설이지만 미래 남쪽 벽 접합선에 고정하며, 최대 다섯 계산 창구와 양옆 벽 연결부가 들어갈 공간을 처음부터 비워 둔다.
- 시작 시 실제로 운영하는 계산 창구는 하나다.
- 초기 수용량과 비용은 첫 생물 한 마리를 영입해 일꾼으로 배치하고 첫 상품을 판매할 수 있도록 정한다.
- 첫 판매부터 방어 시설 하나를 건설하기까지 반복 판매 외의 별도 성장 조건을 요구하지 않는다.
- 벽·출입문, 방어 야영지와 약탈 시스템은 아직 해금되지 않는다.

### 7.2 메인 기지 12단계

| 전체 단계 | 큰 단계 | 세부 단계 |
| ---: | --- | --- |
| 1 | 모닥불 | 모닥불 |
| 2 | 텐트 | 싸구려 텐트 |
| 3 | 텐트 | 고급 텐트 |
| 4 | 돌 거점 | 기본 |
| 5 | 돌 거점 | 고급 |
| 6 | 돌 거점 | 완성 |
| 7 | 돌·나무 거점 | 기본 |
| 8 | 돌·나무 거점 | 고급 |
| 9 | 돌·나무 거점 | 완성 |
| 10 | 판타지 완성 거점 | 기본 |
| 11 | 판타지 완성 거점 | 고급 |
| 12 | 판타지 완성 거점 | 최종 완성 |

- 모든 세부 단계에서 메인 기지 외형이 달라진다.
- 모든 세부 단계가 오를 때 현재 해금된 모든 기능 시설의 강화 상한이 1단계씩 오른다.
- 메인 기지는 안전 보관소이며 기지 확장과 시설 강화 상한의 기준이다.
- 1차 코어에서는 안전 보관 용량에 상한을 두지 않는다.

### 7.3 동굴 공간 확장

- 모닥불, 텐트, 돌 거점과 돌·나무 거점의 마지막 단계가 완료될 때마다 동굴 공간을 한 번 확장한다.
- 확장 연출 중에는 플레이어 조작을 잠시 멈춘다.
- 카메라가 확장 방향으로 이동하고 동굴 벽이 무너진다.
- 새 공간과 그 공간에 놓일 기능 시설의 전용 자리를 공개한다.
- 카메라가 메인 기지로 돌아온 뒤 플레이어 조작을 다시 허용한다.
- 첫 확장 공간에는 치료소 전용 자리를 배치한다.
- 기능 시설은 지정된 고정 공간에 배치한다.
- 순수 장식의 자유 배치는 1차 코어 범위에서 제외한다.

## 8. 안전 자원의 시각 표현

- 돌·나무·코인·뼈·소울을 메인 기지 주변에서 서로 구분해 보여 준다.
- 돌·나무·코인·뼈는 물리적인 더미로 표현한다.
- 소울은 빛나는 전용 보관 용기에 담긴 모습으로 표현한다.
- 실제 수량 전체를 개별 오브젝트로 만들지 않고 보유량 구간에 따라 더미 크기와 풍성함을 바꾼다.
- 모닥불과 텐트 단계에서는 자원 더미가 야외에 노출된다.
- 돌 거점부터 일꾼이 건물 내부 보관 공간에 자원을 내려놓는다.
- 돌·나무 거점과 판타지 완성 거점으로 성장할수록 내부 창고가 정돈되고 확장된다.
- 아이소메트릭 화면에서 적재 상태와 일꾼의 이동을 볼 수 있도록 내부를 열린 단면처럼 보여 준다.
- 시각 더미의 크기는 보유량을 이해시키는 표현이며 실제 소비 단위를 대신하지 않는다.

## 9. 비콘과 비용 규칙

### 9.1 공통 진행

- 건설, 강화와 수리는 플레이어가 올라가는 비콘을 공통으로 사용한다.
- 비콘은 필요한 재화 종류와 수량을 보여 준다.
- 플레이어가 비콘 위에 머무르면 안전 자원이 정해진 투입 속도에 맞춰 현장에 쌓인다.
- 요구량 전부가 투입되면 재화를 소비하고 건설·강화·수리를 즉시 완료한다.
- 보유 재화가 부족하면 가진 수량까지만 임시로 쌓이고 완료되지 않는다.
- 완료 전에 비콘에서 나가면 임시 투입분을 전부 안전 자원으로 반환한다.
- 완료되지 않은 일부 투입량은 다음 접근까지 유지하지 않는다.
- 한 단계가 완료되면 같은 비콘 위에 계속 서 있어도 다음 단계를 시작하지 않는다.
- 플레이어가 비콘을 완전히 나갔다 다시 들어와야 다음 단계 투입을 시작한다.

### 9.2 재화 용도

| 작업 | 사용하는 재화 |
| --- | --- |
| 새 시설 건설 | 코인 |
| 낮은 단계 시설 강화 | 코인 |
| 높은 단계 시설 강화 | 코인 + 뼈 |
| 벽·출입문 수리 | 코인 |
| 플레이어 체력·공격력 강화 | 코인 |
| 동행 수용량 확장 | 소울 |
| 기지 수용량 확장 | 소울 |

- 높은 단계 강화가 시작되는 정확한 단계와 비용은 후속 밸런스에서 정한다.
- 플레이어 이동 속도 강화는 1차 코어에 포함하지 않는다.

## 10. 자동화와 상품 판매

### 10.1 전체 물류

동료가 다음 순서의 자원과 상품을 화면 안에서 실제로 운반한다.

`채석장·숲 벌목 파견 → 메인 기지 → 공방 → 판매대·계산대 → 메인 기지`

- 채석장과 숲 벌목 파견은 자동 돌·나무 공급원으로만 먼저 정의한다.
- 파견 위치, 동료 행동, 생산 주기, 강화 효과와 수치는 후속 기획으로 남긴다.
- 일꾼의 운반력과 이동 속도가 한 번에 옮기는 양과 왕복 효율에 영향을 준다.
- 메인 기지에 도착한 모든 자원은 약탈로부터 안전하다.

### 10.2 공방

- 공방은 하나만 사용한다.
- 초기 공방은 돌만 소비해 첫 판매 상품을 만든다.
- 강화한 공방은 돌과 나무를 함께 소비하는 더 높은 가치의 상품을 만든다.
- 필요한 재료 중 하나라도 부족하면 해당 상품 생산을 시작하지 않는다.
- 일꾼이 메인 기지에서 재료를 가져오고 완성 상품을 판매대로 옮긴다.
- 상품 종류, 생산 시간, 재료 비용과 판매 가치는 후속 밸런스에서 정한다.

### 10.3 손님과 상품 요청 말풍선

- 1차 코어에서 손님 외형과 행동 유형은 한 종류만 사용한다.
- 손님은 기지 남쪽의 계산대 정면 대기 구역에 한 줄로 선다. 벽·출입문이 완성된 뒤 이 구역은 남쪽 벽 바깥에 위치한다.
- 손님이 줄에 들어올 때 판매대의 현재 판매 목록에서 재고가 있는 상품 하나를 원하는 상품으로 정한다.
- 줄에 선 손님의 머리 위에 말풍선 형태의 상품 요청 말풍선을 표시한다.
- 상품 요청 말풍선 안에는 그 손님이 원하는 상품 아이콘을 표시한다.
- 비어 있는 계산 창구가 생기면 줄의 선두 손님부터 해당 창구로 이동한다.
- 손님이 상품을 구매하거나 줄에서 떠나면 상품 요청 말풍선을 제거한다.
- 현재 판매 가능한 상품이 하나도 없으면 새로운 손님은 줄에 들어오지 않는다.
- 대기 중인 손님의 원하는 상품 재고가 먼저 소진되면 그 손님은 말풍선을 유지한 채 재입고를 기다린다.
- 재입고되면 줄 순서를 유지한 상태에서 구매를 진행한다.
- 최대 대기 시간을 넘기면 손님이 줄을 떠나지만 정확한 시간은 후속 밸런스에서 정한다.
- 첫 코어에서는 판매 상품이 한 종류이므로 모든 손님이 같은 상품 아이콘을 표시한다.
- 공방 확장 뒤 여러 상품을 추가해도 손님별 원하는 상품 선택과 말풍선 규칙을 그대로 사용한다.

### 10.4 계산대와 계산 창구

- 계산대는 하나의 통합 시설이며 계산 창구는 그 안에서 손님 한 명씩을 응대하는 자리다.
- 모든 계산 창구는 판매대의 상품 재고와 계산대 코인을 함께 사용한다.
- 한 계산 창구에는 한 번에 손님 한 명만 들어가며, 여러 창구가 비어 있으면 줄의 앞쪽 손님부터 순서대로 배정한다.
- 메인 기지의 큰 단계에 따라 동시에 운영하는 계산 창구 수가 다음과 같이 증가한다.

| 메인 기지 큰 단계 | 운영 계산 창구 수 |
| --- | ---: |
| 모닥불 | 1개 |
| 텐트 | 2개 |
| 돌 거점 | 3개 |
| 돌·나무 거점 | 4개 |
| 판타지 완성 거점 | 5개 |

- 새 큰 단계에 도달하면 해당 단계의 계산 창구 수를 즉시 운영한다.
- 다섯 창구의 자리와 벽 연결부는 게임 시작부터 같은 위치에 예약하며, 창구가 늘어나도 계산대를 옮기지 않는다.
- 첫 판매 뒤 벽·출입문을 건설하면 기존 계산대를 이동시키지 않고 벽이 계산대 양옆에 맞물린다.
- 손님이 이용하는 계산대 정면은 벽 바깥을, 상품과 코인을 운반하는 계산대 안쪽은 기지 내부를 향한다.

### 10.5 계산대 코인

- 판매가 완료되면 코인이 계산대에 쌓인다.
- 초기 계산대에서는 플레이어가 접근해 코인을 직접 들고 메인 기지까지 운반한다.
- 계산대 첫 강화가 끝나면 계산대 전용 일꾼 자리 하나를 해금한다.
- 담당 일꾼은 자신의 운반력만큼 코인을 싣고 메인 기지까지 실제로 이동한다.
- 담당 일꾼을 다른 역할로 바꾸면 계산대는 다시 플레이어 직접 운반 상태가 된다.
- 계산대와 운반 중인 코인은 아직 안전하지 않으며 약탈 대상이다.
- 메인 기지에 도착한 코인은 안전 자원이 된다.

## 11. 약탈과 기지 방어

### 11.1 해금

- 첫 상품 판매가 완료되면 벽·출입문과 방어 야영지의 건설 비콘을 공개한다.
- 벽·출입문을 건설하면 처음부터 고정된 계산대를 옮기지 않고 계산대 양옆에 벽을 연결한다.
- 벽·출입문과 방어 야영지가 모두 완성되기 전에는 약탈 무리가 나타나지 않는다.
- 두 시설이 모두 완성되면 약탈 시스템을 영구 해금한다.
- 벽과 출입문은 하나의 방어 시설로 취급하며 체력과 손상 상태를 함께 사용한다.

### 11.2 약탈 경보와 창구 셔터

1. 약탈 경보가 발생하면 새로운 손님의 줄 합류와 모든 계산 창구의 판매를 즉시 중단한다.
2. 줄과 계산 창구에 있던 손님은 화면 밖으로 대피한다. 각 손님의 기존 줄 순서와 원하는 상품은 유지하고, 대피 중에는 상품 요청 말풍선을 숨긴다.
3. 계산대 정면에서 손님이 모두 빠져나가면 모든 계산 창구의 목재·금속 창구 셔터가 자동으로 내려온다.
4. 모든 창구 셔터는 항상 함께 닫히고 열리며, 별도 건설·강화·수리 비용, 체력과 손상 상태를 갖지 않는다.
5. 창구 셔터는 손님이 이용하는 계산대 정면 접근만 차단하며 벽·출입문을 대신하는 방어 시설이 아니다.
6. 창구 셔터가 닫힌 동안에도 공방 생산과 기지 내부의 상품·코인 운반은 계속한다.
7. 약탈 무리가 퇴각하면 벽·출입문의 파괴 여부와 관계없이 모든 창구 셔터를 열고 계산대를 정상 작동시킨다.
8. 대피한 손님은 기존 순서와 원하는 상품을 유지한 채 돌아오고 상품 요청 말풍선을 다시 표시한다. 원하는 상품이 약탈됐다면 재입고될 때까지 기다린다.
9. 오프라인 약탈에서도 손님 대피, 창구 셔터 폐쇄, 약탈 종료 뒤 계산대 재개와 손님 복귀를 같은 순서로 자동 적용한다.

### 11.3 약탈 발생과 진행

- 판매대의 상품과 계산대의 안전하지 않은 코인 가치가 쌓일수록 약탈 무리가 찾아온다.
- 약탈은 번호가 붙은 전투 구간이 아니라 기지 운영 중 간헐적으로 발생하는 사건이다.
- 약탈 무리는 남쪽 출입구로 와서 벽·출입문을 공격한다.
- 약탈이 시작되면 방어 야영지의 방어 동료가 출입문까지 이동해 약탈 무리와 싸운다.
- 방어 동료가 모두 쓰러지거나 치료 중이면 남은 약탈자가 벽·출입문을 계속 공격한다.
- 벽·출입문 체력이 0이 되면 약탈 무리가 기지 안으로 들어온다.
- 창구 셔터가 닫혀 있어도 기지 안으로 들어온 약탈 무리의 이동과 약탈을 막지 못한다.
- 약탈 무리는 판매대의 상품과 메인 기지에 도착하지 않은 계산대 코인만 훔친다.
- 벽·출입문이 파괴되지 않은 채 방어에 성공하면 판매대 상품과 계산대 코인을 잃지 않는다.
- 가져갈 상품과 코인이 없으면 벽 손상과 동료 부상만 남기고 빈손으로 퇴각한다.
- 메인 기지의 안전 자원은 약탈 대상이 아니다.
- 약탈이 끝나도 벽 손상은 유지되며 코인 수리 비콘으로 복구한다.
- 벽·출입문의 손상과 파괴는 계산대와 창구 셔터를 손상시키거나 판매 재개를 막지 않는다.

### 11.4 방어 동료 패배와 치료

- 플레이어가 접속해 있는 동안 방어 동료의 체력이 0이 되면 치료소 유무를 확인한다.
- 치료소가 있으면 해당 동료는 치료 대기열로 이동한다.
- 치료소가 없으면 온라인 방어에서 쓰러진 동료는 영구 이탈한다.
- 오프라인 방어에서 쓰러진 동료는 치료소 유무와 관계없이 영구 이탈하지 않는다.
- 오프라인 부상 동료는 인원 제한 없는 치료 대기열에 들어간다.
- 치료소가 없으면 부상 상태로 대기하고, 치료소가 완성된 뒤 치료를 시작한다.
- 치료소는 오프라인에도 치료를 진행한다.
- 치료를 마친 방어 동료는 후속 약탈 방어에 자동 복귀한다.
- 동시 치료 수, 치료 시간과 비용은 후속 밸런스에서 정한다.

## 12. 약탈 무리 결과 선택

### 12.1 플레이어가 직접 참여한 방어

- 방어가 끝나면 약탈 무리 생물을 공식 이름순으로 정렬한 결과 목록을 표시한다.
- 각 행에는 이름, 초상화, 영입 가능 여부, `영입`과 `재화` 버튼을 표시한다.
- 일반·엘리트·보스 생물의 영입 기회와 뼈·소울 결과는 탐험에서 쓰러뜨린 생물과 같은 규칙을 사용한다.
- 영입 기회가 없는 행은 `영입` 버튼을 비활성화하고 재화 결과로 처리할 수 있게 한다.
- 목록이 한 화면을 넘으면 세로 스크롤을 제공한다.
- `전부 영입`은 아직 선택하지 않은 모든 생물이 영입 가능하고 필요한 동행·기지 수용량이 충분할 때만 활성화한다.
- 조건이 부족하면 `전부 영입`을 비활성화하고 필요한 수용량을 표시한다.
- `전부 재화`는 아직 선택하지 않은 모든 생물을 재화 결과로 한 번에 처리한다.

### 12.2 자동 방어

- 플레이어가 다른 지역에 있어 방어에 직접 참여하지 않으면 결과 선택 화면을 표시하지 않는다.
- 이때 약탈 무리 생물은 영입할 수 없으며 뼈와 등급별 소울 결과를 자동 획득한다.
- 자동 획득한 뼈와 소울은 등짐을 거치지 않고 안전 자원으로 보관한다.

## 13. 오프라인 진행

- 채집·운반·생산·판매·약탈과 치료는 플레이어가 접속하지 않아도 진행한다.
- 오프라인 채집은 파견된 일꾼의 채석장·숲 벌목 활동을 뜻하며 플레이어의 현장 탐험은 진행하지 않는다.
- 오프라인 진행은 마지막 접속 이후 최대 24시간까지만 누적한다.
- 오프라인 약탈에서는 생물을 영입할 수 없으며 뼈와 등급별 소울 결과만 자동 획득한다.
- 오프라인 약탈의 손님 대피와 복귀, 창구 셔터 작동은 11.2절의 순서를 따른다.
- 오프라인 방어 실패 시 로그아웃 뒤 생산된 상품과 계산대에 아직 남아 있는 판매 코인만 잃을 수 있다.
- 로그아웃 전에 메인 기지에 입고된 자원은 잃지 않는다.
- 오프라인 중 일꾼이 메인 기지까지 운반을 마친 코인도 안전 자원이 된다.
- 오프라인 결과 화면의 상세 항목과 시간 순서 표현은 후속 UI 기획에서 정한다.

| 계산대 정면에서 손님 대피 완료 | 모든 계산 창구의 창구 셔터가 함께 닫힌다 |

| 파괴된 벽을 수리하기 전에 약탈 종료 | 모든 창구 셔터가 열리고 계산대 판매가 재개된다 |

| 온라인 직접 방어 | 방어 결과와 이름순 생물 선택 목록을 표시한다 |
| 플레이어가 다른 지역에서 자동 방어 | 영입 없이 재화 결과를 안전하게 자동 보관한다 |
| 오프라인 중 약탈 발생 | 손님 대피·셔터 폐쇄·약탈 처리·셔터 개방·손님 복귀가 같은 순서로 자동 적용된다 |
| 24시간을 넘겨 복귀 | 오프라인 진행은 앞의 24시간까지만 반영한다 |

## 16. 후순위와 검증 필요

### 후순위

- 채석장과 숲 벌목 파견의 위치, 동료 행동, 생산 주기, 강화 효과와 수치
- 16종 생물의 이름, 외형, 설명, 체력, 공격력, 이동 속도, 운반력과 역할 적성
- 큰 단계별로 열리는 치료소 이외의 시설 배치
- 능력치 보너스가 없는 생물 도감과 부가 수집 목표
- 여러 판매 상품의 구체적인 구성

### 검증 필요

- 일반·엘리트 영입 확률, 등급별 소울 확률과 보스 재등장 시간
- 비용, 생산 속도, 상품 가치, 운반력과 치료 시간
- 높은 단계 강화가 코인과 뼈를 함께 요구하기 시작하는 단계
- 손님의 최대 대기 시간과 여러 상품이 생긴 뒤 상품별 선택 비율
- 탐험 동료의 대형, 같은 우선순위 목표 선택과 좁은 길 이동의 조작감
- 생물 결과 선택 중 위험 처리와 선택 제한 시간
- 등짐이 가득 찬 상태에서 사냥으로 얻은 뼈의 현장 처리 방식
- 플레이어 패배 뒤 체력 회복과 재출발 흐름
- 생물 처치 표현 수위
- 신비로운 자연 판타지 안에서 사용할 정확한 색상과 생물·건축물의 최종 외형
- 세로 화면에서 자원 더미, 열린 단면, 손님 말풍선과 전투를 함께 읽기 쉬운지
