# Dino TD 카드 생성 규칙

> 문서 상태: 확정
>
> 적용 범위: 카드 세트 발생, 후보 구성, 확률 추첨, 새로고침, 궁극 확률 보정과 카드 대기열
>
> 작업명: Dino TD
>
> 작성 기준: `../guidelines/game-design-authoring-rules.md`
>
> 공식 용어 기준: `terminology.md`

## 1. 목적과 원본 범위

이 문서는 한 판 안에서 카드 선택 화면을 언제 열고 어떤 후보를 어떤 확률로 제시할지 정의하는 단일 원본이다. 일반·고급 카드의 기능과 반복 획득 효과는 `tower-upgrade-card-spec.md`, 타워별 궁극의 기능은 `ultimate-card-spec.md`를 따른다.

## 2. 용어와 카드 분류

- `카드 세트`는 한 번의 선택을 위해 동시에 제시하는 카드 묶음이다.
- `예정 일반 카드 선택`은 스테이지 데이터에 포함된 처치 경험치 기반 일반 카드 선택을 뜻한다. 알파 카드 세트가 전환된 추가 일반 카드 선택은 포함하지 않는다.
- 건설 카드는 등급이 없는 별도 분류다.
- 업그레이드 카드는 `일반`, `고급`, `궁극` 등급으로 나눈다.
- 주력 타워는 건·블레이드·캐논·파이어·레이저·일렉트릭이며 한 판에 최대 3종을 활성화한다.
- 보조 타워는 아이스·독이며 한 판에 둘 중 1종만 활성화한다.
- 하나의 카드 세트에는 같은 카드 ID를 중복해서 표시하지 않는다.

## 3. 공통 후보 규칙

- 잠긴 타워의 모든 카드는 후보에서 제외한다.
- 빈 타워 슬롯이 없으면 모든 건설 카드를 후보에서 제외한다.
- 주력 타워 3종이 활성화된 뒤에는 아직 활성화하지 않은 주력 타워의 건설 카드를 제외한다. 이미 활성화된 주력 타워는 같은 종류를 추가 건설할 수 있다.
- 아이스나 독을 처음 건설하면 해당 보조 종류가 확정된다. 이후 확정된 종류는 추가 건설할 수 있지만 반대 종류의 건설·능력 카드는 제외한다.
- 현재 전투 상태에 적용할 수 없는 카드는 후보에서 제외한다.
- 획득 후 제거하도록 지정된 카드는 같은 판의 이후 후보에서 제외한다.
- 슬롯을 채우는 도중 이미 같은 카드 ID가 선택됐다면 남은 슬롯 후보에서 해당 ID를 제외한다.
- 건설 카드는 현재 유효하고 아직 같은 화면에 배치되지 않은 건설 카드 ID 중 하나를 균등 확률로 선택한다.

## 4. 카드 세트 비교

| 카드 세트 | 발생 조건 | 제시 규칙 | 새로고침 |
| --- | --- | --- | --- |
| 초기 배치 카드 세트 | 스테이지 시작 | 주력 3종 제한 안에서 해금된 기본 타워를 표시하고 초기 건설권 수만큼 순차 선택·설치 | 불가 |
| 일반 카드 세트 | 처치 경험치 기준 충족 | 건설·업그레이드 혼합 4장, 주력 업그레이드 1장 보장 | 화면당 1회 가능 |
| 알파 카드 세트 | 알파 공룡 처치 | 현재 건설 가능한 서로 다른 건설 카드 최대 4장 | 불가 |

## 5. 초기 배치 카드 세트

1. 스테이지 시작 시 스테이지 데이터의 초기 건설권 수를 확인한다.
2. 활성 주력 타워가 3종 미만이면 해금된 기본 타워인 건·블레이드·캐논·파이어 건설 카드를 모두 표시한다.
3. 활성 주력 타워가 3종에 도달했다면 이미 활성화된 기본 타워의 건설 카드만 표시하고 새로운 네 번째 종류는 제외한다.
4. 플레이어가 카드 한 장을 선택하면 빈 타워 슬롯에 해당 타워를 설치한다.
5. 남은 초기 건설권이 있으면 같은 절차를 반복한다. 매번 현재 활성 주력 종류를 반영해 후보를 다시 표시하므로 같은 타워를 여러 번 선택할 수 있다.
6. 초기 건설권을 모두 사용하면 초기 배치를 종료한다.

- 초기 배치에는 카드 등급, 확률 추첨과 새로고침을 적용하지 않는다.
- 1-1에서 건 타워만 해금되고 초기 건설권이 2개라면 건 타워 한 장짜리 세트를 두 번 제시한다.
- 기본 타워 4종이 모두 해금되고 초기 건설권이 3개라면 매 선택마다 4종을 다시 표시한다.

## 6. 일반 카드 세트

### 6.1 기본 생성 순서

1. 첫 슬롯에 현재 활성화된 주력 타워의 적용 가능한 업그레이드 카드 1장을 보장한다.
2. 첫 슬롯의 등급은 일반 80%, 고급 20%로 정한다.
3. 나머지 3개 슬롯은 각각 건설 20%, 업그레이드 80%로 독립 추첨한다.
4. 업그레이드 슬롯의 등급은 일반 80%, 고급 20%로 정한다.
5. 업그레이드 카드는 `등급 → 해당 등급 후보가 있는 타워 균등 선택 → 해당 타워의 카드 균등 선택` 순서로 뽑는다.
6. 추첨한 등급에 유효하고 중복되지 않는 업그레이드 카드가 없으면 반대 등급으로 전환하고 5단계를 적용한다.
7. 건설로 결정된 슬롯에 유효하고 중복되지 않는 건설 후보가 없으면 해당 슬롯을 업그레이드로 전환하고 4~6단계를 적용한다.
8. 카드 ID 중복을 제거한 유효 카드 4장이 완성되면 화면을 연다.

- 첫 슬롯의 보장 대상은 주력 타워만 사용한다. 보조 타워의 능력 해금 카드는 이 보장을 대신하지 않는다.
- 보조 능력 해금 카드는 조건을 충족한 경우 나머지 고급 등급 업그레이드 카드 후보에 포함한다.
- 첫 슬롯이 궁극 카드로 교체되어도 주력 업그레이드 보장을 충족한 것으로 처리한다.
- 타워 건설 카드는 목재를 소비하지 않고 선택 후 빈 슬롯에 설치한다.
- 반대 등급으로 전환한 뒤에도 적용 가능한 주력 일반 등급 업그레이드 카드가 하나도 없는 상태는 정상 게임에서 발생하지 않아야 한다. 발생하면 임의의 카드를 표시하지 말고 카드 생성 오류로 기록한다.

### 6.2 등급 전환 예시

- 현재 활성 주력 타워가 블레이드뿐이고 `칼날 크기 증가`를 이미 획득한 상태에서 고급 슬롯 2개가 발생했다고 가정한다.
- 먼저 처리한 고급 등급 슬롯에는 유일하게 남은 고급 등급 업그레이드 카드인 `범위 둔화`를 배치한다.
- 다음 고급 등급 슬롯에는 중복되지 않는 고급 등급 업그레이드 카드가 없으므로 일반 등급으로 전환한다.
- 블레이드의 일반 등급 업그레이드 카드 중 아직 같은 화면에 배치되지 않은 카드 하나를 균등 확률로 선택한다.

### 6.3 보조 타워 능력

- 아이스 건설 카드는 감속을, 독 건설 카드는 중독을 자동으로 부여하지 않는다.
- 아이스를 건설하면 `감속 능력 해금`, 독을 건설하면 `중독 능력 해금`이 일반 카드 세트의 고급 등급 업그레이드 카드 확률 후보에 들어간다.
- 능력 카드를 선택할 때까지 해당 보조 타워는 상태 효과가 없는 기본 공격만 수행한다.
- 능력 카드는 판당 1회만 획득하며 선택하면 카드 풀에서 제거한다.
- 남은 일반 카드 세트가 없을 때 보조 타워를 건설해도 능력을 자동 지급하지 않는다.

## 7. 알파 카드 세트

- 알파 공룡을 처치하면 현재 건설 가능한 서로 다른 건설 카드만 최대 4장 제시한다.
- 유효한 건설 후보가 4종보다 적으면 존재하는 후보만 표시한다.
- 유효한 후보가 4종을 초과하면 모든 후보를 같은 확률로 취급하고 중복 없이 최대 4종을 선택한다.
- 업그레이드 카드·능력 해금 카드·궁극 카드는 등장하지 않는다.
- 빈 타워 슬롯이 없어 건설 후보가 없으면 알파 카드 세트를 추가 일반 카드 세트로 전환한다.
- 전환된 추가 일반 카드 세트는 `6. 일반 카드 세트`의 기본 생성 규칙을 따르고 새로고침을 사용할 수 있다.

## 8. 새로고침

- 한 판에 총 5회 제공하고 다음 판으로 이월하지 않는다.
- 한 카드 선택 화면에서 최대 1회만 사용할 수 있다.
- 일반 카드 세트와 알파에서 전환된 추가 일반 카드 세트에만 사용할 수 있다.
- 새로고침을 선택하면 현재 4장을 모두 폐기하고 아래 규칙으로 새 4장을 만든다.

### 8.1 새로고침 생성 순서

1. 첫 슬롯에 활성 주력 타워의 고급 등급 업그레이드 카드 1장을 보장한다.
2. 나머지 3개 슬롯은 각각 건설 20%, 업그레이드 80%로 독립 추첨한다.
3. 업그레이드 슬롯의 등급은 일반 75%, 고급 25%로 정한다.
4. 후보 선택 순서는 일반 카드 세트와 동일하게 적용한다.
5. 건설 후보가 없거나 카드 ID가 중복되면 해당 슬롯을 업그레이드로 전환한다.
6. 후보가 충분하면 새 카드 세트 중 카드 ID 기준 최소 2장이 이전 세트와 달라야 한다. 불가능하면 변경 가능한 최대 수만큼 바꾼다.

## 9. 궁극 카드와 궁극 확률 보정

### 9.1 등장 자격과 교체 확률

- 활성화된 주력 타워는 별도 선행 강화 없이 즉시 궁극 후보가 된다.
- 보조 타워는 궁극 후보가 되지 않는다.
- 방벽 시스템이 해금되는 1-7부터 전술 궁극 `가시 방벽`이 궁극 후보가 된다. 현재 설치된 방벽이 없어도 후보에 포함한다.
- 기본 일반 카드 세트에서는 첫 보장 업그레이드 슬롯만 기본 10% 확률로 궁극 카드로 교체한다.
- 새로고침에서는 첫 보장 고급 슬롯을 25%, 나머지 업그레이드 슬롯을 각각 5% 확률로 궁극 카드로 교체한다.
- 각 확률에는 9.3의 현재 확률 보정 보너스를 더하고 최종 확률을 최대 80%로 제한한다.
- 건설 카드 슬롯은 궁극 카드로 교체하지 않는다.

### 9.2 궁극 후보 선택

1. 궁극 교체 판정이 성공하면 `아직 궁극을 선택하지 않은 활성 주력 타워 종류`와 `아직 선택하지 않은 가시 방벽`을 각각 하나의 후보 단위로 구성한다.
2. 후보 단위 중 하나를 균등 확률로 고른다.
3. 주력 타워를 골랐다면 해당 타워의 두 궁극 중 하나를 균등 확률로 고른다. 가시 방벽을 골랐다면 가시 방벽 카드로 교체한다.
4. 한 화면의 궁극은 가시 방벽을 포함해 최대 2장이다. 같은 주력 타워의 궁극 또는 가시 방벽을 한 화면에 중복 표시하지 않는다.
5. 주력 궁극을 선택하면 그 타워의 다른 궁극도 같은 판의 후보에서 제거한다.
6. 가시 방벽을 선택하면 같은 판의 궁극 후보에서 제거하고, 현재 및 이후 건설되는 모든 방벽에 효과를 적용한다.
7. 궁극이 화면에 나왔지만 선택되지 않았다면 해당 주력 타워의 두 궁극 또는 가시 방벽은 이후 후보에 남는다.
8. 주력 궁극을 선택한 뒤에도 해당 타워의 일반·고급 등급 업그레이드 카드는 기존 규칙대로 후보에 남는다.

- 새로고침에서 궁극 판정이 3개 이상 성공하면 첫 보장 업그레이드 슬롯의 성공을 우선 유지한다. 남은 성공 슬롯 중 필요한 수를 무작위로 골라 최대 2장만 궁극으로 교체한다.
- 첫 보장 업그레이드 슬롯이 성공하지 않았다면 성공한 슬롯 중 최대 2개를 무작위로 고른다.
- 궁극 대상이 부족하거나 최대 표시 수를 넘은 판정은 원래 추첨된 업그레이드 카드로 유지한다.
- 가시 방벽은 판당 주력 궁극 평균 약 2장 집계에서 제외한다.

### 9.3 누적 궁극 확률 보정

`궁극 확률 보정`은 예정 일반 카드 선택을 일정 비율 이상 진행했는데 주력 궁극을 선택하지 못했을 때 이후 궁극 등장 확률을 높이는 규칙이다.

1. 확률 보정 구간을 시작할 때 해당 구간에 남은 예정 일반 카드 선택 횟수를 `N`, 구간에서 이미 완료한 예정 일반 카드 선택 횟수를 `K`로 둔다.
2. 기준점은 각각 `ceil(N × 0.30)`, `ceil(N × 0.50)`, `ceil(N × 0.70)`이다.
3. `K`가 기준점에 도달한 뒤 다음에 표시하는 카드 세트부터 `+10%p`, `+20%p`, `+30%p`를 누적 적용한다.
4. 여러 기준점이 같은 횟수로 계산되면 해당 보너스를 모두 누적한다.
5. 주력 궁극을 실제로 선택했을 때만 궁극 확률 보정을 초기화한다. 그 시점에 남은 예정 일반 카드 선택 횟수를 새 `N`으로 두고 `K`를 0으로 되돌린다.
6. 주력 궁극이 등장했지만 선택되지 않으면 궁극 확률 보정을 초기화하지 않는다.
7. 가시 방벽은 등장하거나 선택돼도 주력 궁극 확률 보정을 초기화하지 않는다.

- 알파에서 전환된 추가 일반 카드 세트는 `K`를 증가시키지 않지만 현재 확률 보정 보너스를 적용한다.
- 추가 일반 카드 세트에서 주력 궁극을 선택하면 궁극 확률 보정을 초기화한다. 가시 방벽을 선택하면 현재 확률 보정을 유지한다.

## 10. 경험치와 카드 대기열

- 각 스테이지는 예정 일반 카드 선택 횟수를 10~16회로 설정한다.
- 경험치는 처치한 공룡에게서만 얻고 관문에 도달해 누수된 공룡에게서는 얻지 않는다.
- 모든 공룡을 처치하면 예정 횟수를 정확히 달성하도록 경험치 기준을 설정한다.
- 마지막 경험치 기준은 최종 웨이브 시작 전에 달성할 수 있어야 한다.
- 예정 횟수를 모두 발생시킨 뒤 얻는 경험치는 추가 일반 카드 세트를 만들지 않는다.
- 경험치가 한 번에 여러 기준을 넘으면 초과 경험치를 유지하고 해당 수만큼 일반 카드 세트를 대기열에 넣는다.
- 알파 처치와 경험치 기준 충족이 동시에 발생하면 알파 카드 세트를 먼저 대기열에 넣는다.
- 같은 처리 시점에 여러 알파를 처치했다면 각 알파 카드 세트를 처치 처리 순서대로 넣은 뒤 경험치 기반 일반 카드 세트를 넣는다.
- 카드 후보는 대기열에 들어갈 때가 아니라 선택 화면이 실제로 열릴 때 생성한다. 따라서 앞선 카드 선택으로 바뀐 타워·카드 풀 상태를 반영한다.
- 대기열이 남아 있는 동안 공룡, 타워, 일꾼과 모든 게임 시간을 정지한다.
- 카드 선택은 즉시 확정하며 취소할 수 없다. 건설 카드는 빈 슬롯 설치까지 완료해야 다음 세트를 열거나 전투를 재개한다.
- 마지막 웨이브가 끝나 승리가 확정되면 아직 화면에 표시하지 않은 대기 카드 세트는 생략하고 승리 화면으로 이동한다.
- 라이프가 0이 되는 패배 판정은 알파 처치와 경험치 기준 충족에 따른 카드 세트 발생보다 우선한다.
- 같은 전투 처리에서 패배와 카드 발생 조건이 함께 성립하면 새 카드 세트를 생성하거나 표시하지 않는다.
- 패배가 확정되면 아직 표시하지 않은 카드 대기열을 모두 폐기하고 즉시 게임오버 화면으로 이동한다.
- 정상 진행에서는 카드 화면이 열려 있는 동안 전투가 완전히 정지하므로 카드 선택 중 라이프가 감소하지 않는다.
- 복원 오류 등으로 카드 화면과 라이프 0 상태가 함께 존재하면 카드 화면을 닫고 패배를 우선 처리한다.

## 11. 구현용 상태와 스테이지 데이터

카드 생성기는 최소한 다음 상태를 입력으로 사용해야 한다.

- 스테이지 데이터: 초기 건설권 수, 예정 일반 카드 선택 횟수, 경험치 기준 목록, 타워 해금 상태
- 판 상태: 빈 타워 슬롯 수, 활성 주력 종류, 확정된 보조 종류, 획득해 제거된 카드 ID
- 선택 상태: 새로고침 잔여 횟수, 현재 화면 새로고침 사용 여부, 직전 제시 카드 ID
- 궁극 상태: 타워별 궁극 선택 여부, 가시 방벽 선택 여부, 현재 확률 보정 구간의 `N`과 `K`, 누적 확률 보너스
- 카드 대기열 상태: 발생 순서와 카드 세트 종류, 알파 전환 추가 일반 카드 세트 여부

난수 시드 저장과 재접속 시 난수 복원 형식은 저장·복구 설계에서 별도로 확정한다.

## 13. 확률 계산 결과와 검증 필요

### 13.1 현재 계산 결과

- 목표 합격 범위는 판당 주력 궁극 평균 `1.8~2.4장`이다.
- 주력 타워 3종 활성화, 주력 궁극이 제시되면 항상 선택, 주력 궁극이 없는 화면에만 새로고침을 최대 5회 사용하는 조건으로 계산했다.
- 예정 일반 카드 선택 10~16회를 각각 100,000판 모의 계산한 결과, 가시 방벽이 후보에 없을 때 평균 `2.653~2.850장`, 후보에 있을 때 평균 `2.375~2.675장`이었다.
- 현재 확률은 목표에 도달하지만 일부 조건에서 상한 2.4장을 초과한다.
- 사용자 결정에 따라 9절의 현재 확률, 누적 보정과 주력 궁극 획득 가능 수를 변경하지 않는다.

### 13.2 클라이언트 검증 필요

- 실제 카드 생성 결과로 예정 일반 카드 선택 10~16회와 가시 방벽 후보 유무를 각각 확인한다.
- 주력 궁극은 항상 선택하고, 주력 궁극이 없는 화면에만 새로고침을 최대 5회 사용하는 동일 조건을 사용한다.
- 실제 결과가 목표 범위를 벗어나도 임의로 확률이나 획득 상한을 변경하지 않고 결과와 변경 선택지를 사용자에게 보고한다.
- 봄 월드의 예정 일반 카드 세트 간격은 판 전체 평균 25초 이상, 최소 12초 이상인지 플레이테스트한다.
- 서로 다른 후보가 부족할 때 새로고침 결과가 반복적으로 같아지는 빈도를 기록한다.
