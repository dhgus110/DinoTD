## 1. 목적과 플레이어 가치

목재는 현재 판에서 타워 이동, 일꾼 고용, 채집 효율 강화와 방벽 관리가 경쟁하도록 만드는 현장
자원이다. 플레이어는 미래의 목재 생산에 투자할지, 현재 전선의 재배치와 방벽에 사용할지 선택한다.
나무와 채집 건물의 거리가 실제 생산 주기에 반영되므로 맵을 읽는 판단도 경제 선택에 포함된다.

## 2. 결정 상태와 원본 경계

### 2.1 확정

- 이 문서의 목재 흐름, 비용, 단계, 실패 처리와 확인 사례는 사용자와 합의된 기준이다.
- 목재, 추가 일꾼, 채집 효율과 방벽 상태는 현재 판에서만 유지한다.
- 봄 월드의 스테이지별 시작 목재와 배치 수량은 `spring-stage-content.md`, 여름 월드는 `summer-stage-content.md`가 소유한다.

### 2.2 검증 필요

- 나무 거리, 일꾼 수와 채집 효율 투자가 타워 이동·방벽과 의미 있게 경쟁하는지
- 방벽이 공격 타워를 대체하지 않으면서 공룡을 묶어 두는 전술 가치를 갖는지
- 전투 중 방벽 전역 강화와 최대 체력 회복이 긴급 방어 수단으로 지나치게 강하지 않은지

### 2.3 제외

- 코드 구조, 데이터 형식, 저장 구조와 분석 이벤트
- 공룡의 방벽 공격 판정과 같은 순간 결과 우선순위
- 스테이지별 맵 배치와 웨이브 콘텐츠
- 궁극 카드의 상세 효과

## 3. 한 판의 시작과 종료

- 채집 경제가 해금된 스테이지는 채집 건물 1개와 기본 일꾼 1명으로 시작한다.
- 시작 목재는 스테이지별 고정값이며 봄 월드는 `spring-stage-content.md`, 여름 월드는 `summer-stage-content.md`에서 정한다.
- 기본 일꾼은 고용 횟수와 무관하며 고용 비용 증가 계산에 포함하지 않는다.
- 목재 잔액, 추가 일꾼 수, 채집 효율 단계, 방벽 전역 단계와 각 방벽 상태는 한 판 시작 시
  해당 스테이지의 기본 상태로 초기화한다.
- 승리, 실패, 재시작 또는 로비 이동으로 현재 판을 끝내면 목재와 모든 경제·방벽 진행을 다음 판에
  넘기지 않는다.

## 4. 목재 획득 흐름

1. 활성 웨이브가 시작되면 작업이 없는 일꾼이 예약되지 않은 나무를 탐색한다.
2. 일꾼은 채집 건물을 기준으로 왕복 이동 거리가 가장 짧은 나무를 선택하고 즉시 예약한다.
3. 왕복 이동 거리가 같으면 화면에서 더 위쪽인 나무를 우선하고, 위쪽 위치도 같으면 더 왼쪽인
   나무를 우선한다.
4. 일꾼은 초당 `2타일` 속도로 예약한 나무까지 이동한다.
5. 나무에 도착하면 게임 시간 `3초` 동안 채집한다.
6. 채집을 마치면 현재 채집 효율 단계의 운반량을 가지고 채집 건물로 돌아온다.
7. 일꾼이 채집 건물에 도착한 순간 운반량 전부를 보유 목재에 더한다.
8. 지급을 마친 일꾼은 모든 예약되지 않은 나무를 다시 탐색한다.

- 나무는 채집해도 고갈되지 않으며 한 판 동안 계속 사용할 수 있다.
- 나무 한 그루는 선택 즉시 일꾼 한 명에게 예약되며, 해당 일꾼이 목재를 지급할 때까지 다른
  일꾼이 선택할 수 없다.
- 카드 선택과 정비 시간에는 일꾼 이동과 채집시간이 멈춘다. 다음 활성 웨이브에서 중단된 위치와
  채집 진행도부터 이어간다.
- 일꾼은 직접 선택하거나 나무를 지정할 수 없으며 공격·사망 대상이 아니다.

## 5. 일꾼 고용과 채집 효율

### 5.1 일꾼 고용

- 일꾼 최대 수는 현재 스테이지의 활성 나무 수와 같다.
- 이번 판에 추가로 고용하려는 일꾼의 순번을 `n`이라 할 때 비용은 다음과 같다.

```text
일꾼 고용 비용 = 30 + 20 × (n - 1) 목재
```

- 첫 추가 고용은 `30목재`, 두 번째는 `50목재`, 세 번째는 `70목재`다.
- 고용을 확정하면 비용을 차감하고 일꾼을 채집 건물에서 즉시 추가한다.
- 일꾼 수가 활성 나무 수와 같으면 고용을 허용하지 않고 `채집 가능한 나무가 없습니다`라고
  표시한다.

### 5.2 채집 효율

| 채집 효율 단계 | 일꾼 1명의 운반량 | 다음 단계 비용 |
| --- | --- | --- |
| 1단계 | 10목재 | 40목재 |
| 2단계 | 15목재 | 80목재 |
| 3단계 | 20목재 | 최대 단계 |

- 채집 효율은 모든 현재 및 이후 일꾼의 운반량에 적용한다.
- 강화 시 이미 목재를 들고 돌아오는 일꾼의 운반량은 바꾸지 않는다. 다음 나무에서 채집을
  완료할 때부터 새 운반량을 적용한다.
- 3단계에서는 강화 버튼을 비활성화하고 `채집 효율이 최대 단계입니다`라고 표시한다.
- 채집 효율은 이동 속도와 채집시간을 바꾸지 않는다.

## 6. 목재 소비와 공통 실패 처리

| 소비 행동 | 비용 | 허용 시점 |
| --- | --- | --- |
| 타워 이동 | 20목재 | 활성 웨이브, 정비 시간 |
| 일꾼 고용 | `30 + 20 × (n - 1)`목재 | 활성 웨이브, 정비 시간 |
| 채집 효율 2단계 | 40목재 | 활성 웨이브, 정비 시간 |
| 채집 효율 3단계 | 80목재 | 활성 웨이브, 정비 시간 |
| 방벽 설치·재건 | 30목재 | 정비 시간 |
| 방벽 전역 2단계 | 100목재 | 활성 웨이브, 정비 시간 |
| 방벽 전역 3단계 | 200목재 | 활성 웨이브, 정비 시간 |

- 모든 비용은 플레이어가 최종 확인한 순간 한 번 차감하고 해당 행동을 즉시 적용한다.
- 비용 확인을 취소하면 목재와 상태를 바꾸지 않는다.
- 확정 시 보유 목재가 부족하면 행동을 적용하지 않고 목재도 차감하지 않는다. 화면에는 보유량,
  필요량과 부족량을 함께 표시한다.
- 같은 행동을 연속 입력하더라도 앞선 행동이 확정된 뒤의 목재와 단계로 다음 행동의 가능 여부를
  다시 판단한다.
- 타워 이동 비용은 타워 종류, 이동 거리와 이번 판의 이동 횟수에 관계없이 항상 `20목재`다.

## 7. 방벽

### 7.1 전역 단계

| 방벽 전역 단계 | 방벽 최대 체력 | 다음 단계 비용 |
| --- | --- | --- |
| 1단계 | 300 | 100목재 |
| 2단계 | 500 | 200목재 |
| 3단계 | 800 | 최대 단계 |

- 방벽 시스템은 한 판을 1단계로 시작한다.
- 방벽 강화는 개별 방벽이 아니라 현재 및 이후 모든 방벽에 적용하는 전역 강화다.
- 강화를 확정하면 설치된 모든 방벽의 최대 체력을 새 단계 값으로 바꾸고 현재 체력도 새 최대
  체력까지 회복한다.
- 파괴된 슬롯은 회복 대상이 아니다.
- 3단계에서는 강화 버튼을 비활성화하고 `방벽이 최대 단계입니다`라고 표시한다.

### 7.2 설치와 재건

- 빈 방벽 슬롯에 방벽을 설치하거나 파괴된 방벽을 재건하는 비용은 모두 `30목재`다.
- 설치와 재건은 정비 시간에만 허용한다. 활성 웨이브에서 슬롯을 선택하면 비용을 차감하지 않고
  `정비 시간에 설치할 수 있습니다`라고 안내한다.
- 설치·재건된 방벽은 현재 방벽 전역 단계의 최대 체력으로 생성한다.
- 공룡과 방벽 슬롯 영역이 겹치면 정비 시간이어도 설치·재건할 수 없다. 목재를 차감하지 않고
  `공룡이 지나간 뒤 설치할 수 있습니다`라고 안내한다.
- 방벽이 파괴돼도 전역 단계는 유지된다. 이미 슬롯을 통과한 공룡은 재건된 방벽으로 돌아오지 않는다.
- 방벽의 공격받는 규칙과 파괴 순간의 전투 처리는 `combat-system-rules.md`를 따른다.

### 7.3 공룡별 방벽 공격

공룡은 방벽에 도착해 자신의 공격 준비를 마칠 때마다 아래 피해를 준다. 여러 공룡이 같은 방벽을
공격하면 각 공룡의 피해와 공격 간격을 독립적으로 적용한다.

| 공룡 | 1회 피해 | 공격 간격 |
| --- | ---: | ---: |
| 콤프소그나투스 | 10 | 게임 시간 1초 |
| 벨로키랍토르 | 20 | 게임 시간 1초 |
| 트리케라톱스 | 35 | 게임 시간 1.5초 |
| 파키케팔로사우루스 | 75 | 게임 시간 1.5초 |
| 안킬로사우루스 | 45 | 게임 시간 2초 |
| 티라노사우루스 | 80 | 게임 시간 1.5초 |

- 알파 공룡의 방벽 1회 피해와 공격 간격은 원종과 같다. 알파 배율은 체력과 처치 경험치
  가중치에만 적용한다.
- 파키케팔로사우루스는 같은 수의 다른 일반 공룡보다 방벽을 빠르게 파괴하는 돌진형 역할을 맡는다.
- 아래 시간은 공룡 한 마리가 다른 방해 없이 최대 체력의 방벽을 계속 공격하고 첫 피해를 공격 간격
  경과 후 주는 경우의 예시다. 실제 전투에서는 경직, 처치와 여러 공룡의 동시 공격에 따라 달라진다.

## 8. 화면 피드백

- 전투 정보 화면에는 현재 보유 목재를 항상 표시한다.
- 채집 건물 화면에는 현재 일꾼 수와 상한, 다음 일꾼 고용 비용, 채집 효율 단계, 현재 운반량과
  다음 강화 비용을 표시한다.
- 방벽 관리 화면에는 전역 단계, 단계별 최대 체력, 다음 강화 비용과 설치·재건 비용을 표시한다.
- 일꾼이 채집 건물에 도착해 목재를 지급하면 운반량 표시와 목재 운반 완료 효과음을 한 번 낸다.
- 선택할 수 없는 행동은 비활성 상태와 구체적인 이유를 함께 표시한다.

## 9. 상황별 확인 사례

| 사전 상태 | 행동 또는 상황 | 기대 결과 |
| --- | --- | --- |
| 예약되지 않은 나무가 여러 그루 있다. | 일꾼이 새 작업을 찾는다. | 채집 건물 기준 왕복 거리가 가장 짧은 나무를 즉시 예약한다. |
| 왕복 거리가 같은 나무가 여러 그루 있다. | 일꾼이 새 작업을 찾는다. | 더 위쪽, 다시 같으면 더 왼쪽 나무를 선택한다. |
| 1단계 일꾼이 채집을 마쳤다. | 채집 건물로 돌아오는 중이다. | 목재는 아직 늘지 않고 건물 도착 순간 10목재가 늘어난다. |
| 일꾼이 목재를 운반 중이다. | 채집 효율을 2단계로 강화한다. | 운반 중인 양은 유지하고 다음 채집 완료부터 15목재를 운반한다. |
| 활성 나무 5그루에 일꾼 5명이 있다. | 일꾼 고용을 선택한다. | 고용 버튼이 비활성화되고 목재와 일꾼 수가 바뀌지 않는다. |
| 필요 비용보다 목재가 적다. | 타워 이동이나 강화를 확정한다. | 행동을 적용하지 않고 보유량·필요량·부족량을 표시한다. |
| 방벽 전역 단계가 3단계다. | 방벽 강화를 선택한다. | 버튼이 비활성화되고 목재와 방벽 상태가 바뀌지 않는다. |
| 피해를 입은 방벽 여러 개가 있다. | 전역 단계를 강화한다. | 모든 설치된 방벽이 새 최대 체력으로 회복되고 파괴 슬롯은 그대로 남는다. |
| 활성 웨이브가 진행 중이다. | 빈 슬롯에 방벽 설치를 선택한다. | 설치를 차단하고 정비 시간 안내를 표시하며 목재를 차감하지 않는다. |
| 정비 시간이고 슬롯에 공룡이 겹쳐 있지 않다. | 파괴된 방벽을 재건한다. | 30목재를 차감하고 현재 전역 단계의 최대 체력으로 재건한다. |
| 1단계 방벽을 파키케팔로사우루스 한 마리가 공격한다. | 다른 방해 없이 공격을 계속한다. | 1.5초마다 75 피해를 주고 네 번째 공격인 6초 시점에 방벽을 파괴한다. |
| 알파 공룡이 방벽을 공격한다. | 원종과 공격 결과를 비교한다. | 원종과 같은 1회 피해와 공격 간격을 사용한다. |
| 카드 선택이나 정비 시간이 시작된다. | 일꾼이 이동 또는 채집 중이다. | 진행이 멈추고 다음 활성 웨이브에 같은 상태부터 이어간다. |
| 현재 판이 승리·실패·포기로 끝난다. | 같은 스테이지에서 새 한 판을 시작한다. | 목재와 경제·방벽 진행이 스테이지 기본 상태로 초기화된다. |
