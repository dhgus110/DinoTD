> 적용 범위: 전장 맵 구조, 공룡 경로, 배치 구획, 카메라와 스테이지별 맵 콘텐츠 기획
>
> 상위 기획서: `jurassic-tower-defense-gdd.md`

## 1. 목적과 플레이어 가치

이 문서는 플레이어가 공룡 경로와 방어 지점을 한눈에 읽고, 제한된 타워 슬롯과 채집 공간을 활용해
재배치 전략을 세울 수 있도록 맵의 공통 제작 규칙을 정의한다. 스테이지마다 고정된 전용 맵을 제공해
플레이어가 실패 후에도 지형을 학습하고 다음 한 판에서 더 나은 배치와 대응을 선택하게 하는 것이
목적이다.

이 기능은 게임 기획서(Game Design Document, GDD)의 `배치보다 중요한 재배치`, `현장 경제의 선택`,
`한눈에 읽히는 지형과 위협`이라는 디자인 기둥에 기여한다.

## 2. 결정 상태

### 2.1 확정

- 이 문서의 공통 규칙과 확인 사례는 사용자와 합의된 기준이다.
- 스테이지마다 고정된 전용 격자 맵을 사용한다.
- 맵·공룡 경로·배치 요소·카메라의 공통 제작 수치는 이 문서가 소유한다.

### 2.2 검증 필요

- 현재 확정된 봄·여름 월드 기준 타워 슬롯 최대 `14개`의 모바일 가독성
- 현재 확정된 봄·여름 월드 기준 나무 최대 `8그루`의 전투·채집 가독성
- `48×18타일` 맵의 전투 가독성과 카메라 이동 빈도
- 세로 `9:19.5` 화면에서 전장 `18×18타일`을 표시하는 프로토타입 기준의 조작·전투 가독성
- 화면 밖 위험과 보상을 플레이어가 제때 인지하는 비율

### 2.3 미정

- 현재 추가로 결정해야 할 맵 공통 규칙은 없다.

## 3. 범위와 원본 경계

### 3.1 포함

- 고정 전용 맵과 격자 크기
- 공룡 경로, 출현 지점과 개척지 관문
- 고지대, 타워 슬롯과 방벽 슬롯
- 나무, 채집 건물과 일꾼이 이동할 공간의 배치
- 카메라 이동·확대와 화면 밖 알림
- 스테이지별 맵 콘텐츠를 기획할 때 기록할 항목

### 3.2 제외

- 스테이지 진행, 다음 스테이지 개방과 타워·건물·전술의 해금 순서
- 월드·스테이지 수와 개발·출시 범위
- 웨이브 구성, 공룡 수치와 출현 순서
- 타워·방벽·채집 경제의 비용, 효과와 전투 수치
- 좌표 형식, 필드 타입, 파일 구조와 내부 식별자 규칙
- 경로 탐색 알고리즘과 내부 계산 방식
- 저장·복원 구조와 런타임 오류 처리
- 자동 맵 유효성 검사와 별도 제작 점검표

진행·해금 범위는 `jurassic-tower-defense-gdd.md`를 따른다. 봄 월드의 콘텐츠 수량과 학습 목표는
`spring-stage-content.md`, 실제 경로·상대 배치·초기 카메라는 `spring-world-production-spec.md`,
여름 월드의 맵 구조·수량·전략적 의도와 검증 항목은 `summer-stage-content.md`를 원본으로 사용한다.
여름 월드의 실제 경로 형태·상대 배치와 초기 카메라는 아직 제작 명세가 없으며
`remaining-design-work.md`의 후속 작업에서 정한다.
카드와 초기 건설권의 세부 규칙은 `card-draw-rules.md`를 따른다. 이 문서는 해당 내용을 복제하거나
변경하지 않는다.

## 4. 맵의 공통 구조

- **고정 전용 맵:** 각 스테이지는 매번 같은 전용 맵을 사용한다. 맵을 무작위로 생성하거나
  서로 다른 스테이지가 같은 맵을 공유하지 않는다. 같은 월드의 지형 그림과 장식 재료는 재사용할 수
  있다.
- **제품 화면:** 세로 화면을 사용하고, 화면 안의 전장은 왼쪽에서 오른쪽으로 이어지는 가로형
  맵으로 구성한다.
- **전장 표시 기준:** `1.0배`의 프로토타입 기준 화면에는 `18×18타일`을 표시한다. 이 값은
  세로 `9:19.5` 화면에서 위·아래 사용자 인터페이스 영역을 제외한 전장의 가독성을 검증한 뒤
  확정하거나 조정한다.
- **맵 크기:** 맵의 세로 크기는 `18타일`로 고정하고, 가로 크기는 `32~48타일` 범위의
  정수로 정한다.
- **화면 안전 영역:** 필수 맵 요소와 초기 배치 가독성은 세로 `9:19.5` 제품 화면의 전장 영역에서
  `18×18타일`이 보이는 프로토타입 기준으로 구성한다.
- **맵 방향:** 공룡은 맵의 왼쪽에서 출현해 오른쪽의 개척지 관문으로 이동한다.
- **출현 지점:** 출현 지점은 맵의 왼쪽 가장자리에 `1~2개` 배치하며, 한 출현 지점은
  `1×1타일`을 차지한다.
- **개척지 관문:** 개척지 관문은 맵의 오른쪽 가장자리에 정확히 `1개` 배치하며,
  `2×2타일`을 차지한다.
- **고정 배치:** 공룡 경로, 출현 지점, 개척지 관문, 고지대, 타워 슬롯, 방벽 슬롯, 나무와
  채집 건물의 위치는 같은 스테이지를 재도전해도 바뀌지 않는다.

## 5. 공룡 경로와 고지대

- **공룡 경로 폭:** 공룡 경로는 전체 구간에서 `1~2타일` 폭으로 제작한다. 회전 구간과
  두 경로가 합쳐지는 구간도 이 범위를 넘지 않는다.
- **공룡 경로 방향:** 공룡 경로는 가로·세로·대각선 방향으로 이어질 수 있다. 공룡이
  개척지 관문 반대쪽인 왼쪽으로 되돌아가야 하는 구간은 만들지 않는다.
- **이동 선택:** 공룡은 자신이 출현한 지점과 연결된 공룡 경로 안에서 개척지 관문까지
  이동할 수 있는 가장 짧은 길을 이용한다.
- **경로 수:** 한 맵에는 공룡 경로를 `1개` 또는 `2개` 둔다.
- **합류와 분기:** 두 공룡 경로는 하나로 합쳐질 수 있지만, 하나의 공룡 경로가 둘 이상으로
  갈라지는 구조는 허용하지 않는다. 합쳐진 공룡 경로는 개척지 관문까지 다시 갈라지지 않는다.
- **경로 길이:** 각 출현 지점에서 개척지 관문까지 이용할 수 있는 가장 짧은 공룡 경로의
  길이는 맵 가로 크기 이상, 맵 가로 크기의 `2배` 이하로 제작한다. 기획상 경로 길이를 셀 때는
  가로·세로·대각선 방향으로 인접한 타일에 한 번 이동하는 구간을 모두 `1타일`로 센다.
- **두 경로의 균형:** 두 공룡 경로의 길이 차이는 짧은 공룡 경로 길이의 `25% 이내`로
  제한한다.
- **합류 위치:** 두 공룡 경로가 합쳐지는 지점은 각 출현 지점에서 개척지 관문까지 이어지는
  진행 구간의 `25~75%` 사이에 둔다.
- **고지대 역할:** 고지대는 타워와 채집 관련 요소가 놓이는 배치 구획이며, 고지대 자체는
  타워의 피해나 공격 범위를 높이지 않는다.
- **고지대 구성:** 한 맵에 서로 떨어진 여러 고지대 영역을 둘 수 있다. 공룡 경로와 고지대는
  높이, 색, 외곽선과 절벽 측면으로 즉시 구분할 수 있어야 한다.

## 6. 타워 슬롯과 방벽 슬롯

- **타워 슬롯 크기:** 타워 슬롯 하나는 `2×2타일`을 차지한다. 타워 슬롯끼리 맞닿을 수는
  있지만 서로 겹칠 수 없다.
- **초기 배치 시야:** 새로 스테이지에 진입했을 때 보이는 화면에는 해당 스테이지의 초기
  건설권 수 이상의 타워 슬롯이 완전히 보이고, 공룡 경로 일부도 함께 보여야 한다.
- **방벽 슬롯 범위:** 방벽 슬롯 하나는 해당 위치의 공룡 경로 폭 전체인 `1~2타일`을
  가로막을 수 있게 배치한다. 공룡이 방벽을 옆으로 피해 지나갈 수 있는 슬롯은 만들지 않는다.
- **방벽 슬롯 위치:** 방벽 슬롯은 출현 지점, 공룡 경로의 회전·합류 지점과 개척지 관문에서
  공룡 경로를 따라 각각 `2타일 이상` 떨어뜨린다.
- **방벽 슬롯 간격:** 같은 공룡 경로에 놓인 방벽 슬롯끼리는 공룡 경로를 따라
  `4타일 이상` 떨어뜨린다.
- **방벽의 경로별 영향:** 합류 전 방벽 슬롯은 해당 공룡 경로의 공룡만 막고, 합류 후 방벽
  슬롯은 모든 출현 지점에서 온 공룡을 막는다.

방벽의 설치 비용, 전역 단계, 체력과 재건은 `economy-barricade-rules.md`, 공격받는 규칙과 파괴
순간의 전투 처리는 `combat-system-rules.md`를 따른다.

## 7. 채집 관련 배치

- **채집 요소 수:** 채집 기능이 해금된 맵에는 채집 건물 정확히 `1개`와
  나무 최소 `5그루`를 배치한다. 채집 건물은 `2×2타일`, 나무 한 그루는 `1×1타일`을 차지한다.
- **채집 요소 위치:** 채집 건물과 나무는 고지대에 배치한다. 나무끼리는 맞닿을 수 있다.
  채집 가능한 나무마다 상하좌우와 네 대각선을 포함한 주변 `8타일` 중 최소 `1타일`은 일꾼이
  채집할 수 있는 고지대 공간이어야 하며, 일꾼이 채집 건물에서 그 공간까지 도달할 수 있어야 한다.
- **일꾼 이동 공간:** 일꾼은 고지대에서 채집 건물과 나무 사이를 이동한다. 공룡 경로,
  나무와 채집 건물이 차지한 공간은 통과하지 않는다.
- **타워 앞 이동:** 일꾼은 이동할 수 있는 가장 짧은 길에 타워가 있으면 타워 앞을 지나갈 수
  있다. 이때 일꾼과 타워가 서로 이동이나 공격을 막지 않는다.

일꾼의 채집 대상 선택, 목재 운반과 경제 수치는 `economy-barricade-rules.md`를 따른다.

## 8. 해금 전 맵 요소

- **사전 배치:** GDD에서 아직 해금되지 않은 채집 건물, 나무와 방벽 슬롯을 맵에 미리
  배치할 수 있다. 미리 배치된 요소도 처음부터 해당 공간을 차지하며 다른 요소와 겹칠 수 없다.
- **잠금 표시:** 아직 해금되지 않은 채집 건물, 나무와 방벽 슬롯은 흐리게 표시하고
  상호작용할 수 없게 한다.
- **잠금 안내:** 플레이어가 잠긴 요소를 선택하면 사용할 수 없는 이유와 해금 조건을
  안내한다. 해금 조건의 원본은 GDD이며 이 문서에 스테이지 번호나 순서를 복제하지 않는다.

## 9. 카메라와 화면 밖 알림

- **초기 카메라:** 플레이어가 새로 스테이지에 진입하면 맵별로 정한 초기 위치와 `1.0배`
  배율에서 시작한다. 초기 위치는 진입 시점의 시작 기준이며, 별도의 초기 위치 복귀 버튼은 제공하지
  않는다.
- **이동 조작:** 플레이어는 전장 위를 한 손가락으로 드래그해 카메라를 이동한다.
- **확대·축소 조작:** 플레이어는 전장 위에 댄 두 손가락의 간격을 벌려 확대하고 모아 축소한다.
  조작 중 두 손가락 사이의 기준 지점 아래에 있던 맵 위치가 화면에서 갑자기 벗어나지 않아야 한다.
  별도의 확대·축소 버튼은 제공하지 않는다.
- **확대 범위:** 카메라 확대·축소 범위는 `1.0~1.5배`다.
- **이동 방향:** `1.0배`에서는 좌우로만 이동하며, `1.0배`보다 확대하면 상하좌우로 이동할
  수 있다.
- **맵 경계:** 카메라는 실제 맵 경계를 벗어나지 않는다.
- **화면비 대응:** 지원 화면비에서 실제 맵 바깥이 보이면 상호작용할 수 없는 월드
  배경으로 채운다.
- **조작 허용 상태:** 카메라 이동과 확대·축소는 전투, 정비 시간, 초기 배치와 건설 카드로
  타워를 배치하는 동안 허용한다. 수동 일시정지 중에는 카메라를 포함한 모든 전투 화면 조작을 차단한다.
- **카드 선택 중 조작:** 카드 세트에서 카드를 선택하는 동안에는 카메라 입력을 받지 않는다.
- **화면 밖 알림 우선순위:** 화면 밖 알림은
  `개척지 관문 누수 위험 → 알파 공룡 → 중요 보상` 순으로 대표 아이콘을 정하고, 같은 방향에 함께
  발생한 알림 수를 표시한다. 중요 보상에 해당하는 사건은 GDD를 원본으로 사용한다. 궁극 카드 등장은
  맵상의 위치가 없으므로 화면 밖 알림 대상에서 제외한다.
- **화면 밖 알림 선택:** 플레이어가 화면 밖 알림을 선택하면 해당 위치로 부드럽게 이동한다.
  이동 중 플레이어가 직접 드래그하면 자동 이동을 즉시 취소한다.

## 11. 수용 조건

수용 조건은 플레이어가 보거나 맵 콘텐츠에서 확인할 수 있는 결과만 다루며 구현 방법은 지정하지 않는다.

| 사전 상태 | 행동 또는 상황 | 기대 결과 |
| --- | --- | --- |
| 같은 스테이지를 한 번 완료했다. | 같은 스테이지에서 두 번째 한 판을 시작한다. | 공룡 경로와 모든 배치 요소가 첫 번째 한 판과 같은 위치에 있다. |
| 가로 크기가 32타일과 48타일인 맵을 각각 연다. | 세로 9:19.5 화면과 1.0배로 확인한다. | 두 맵 모두 세로 18타일이며 전장 영역에는 18×18타일이 보이고 좌우로 나머지 영역을 확인할 수 있다. |
| 출현 지점이 하나인 맵에서 공룡이 출현한다. | 공룡이 이동한다. | 공룡은 공룡 경로를 벗어나지 않고 오른쪽 개척지 관문에 도달한다. |
| 출현 지점이 두 개인 맵을 연다. | 두 지점에서 공룡이 이동한다. | 두 공룡 경로는 정해진 구간에서 하나로 합쳐지고 이후 다시 갈라지지 않는다. |
| 새 스테이지에 처음 진입한다. | 초기 배치를 시작한다. | 초기 건설권 수 이상의 타워 슬롯 전체와 공룡 경로 일부가 화면에 보인다. |
| 폭 2타일인 공룡 경로의 방벽 슬롯에 방벽을 설치한다. | 공룡이 방벽에 도달한다. | 공룡은 방벽 옆으로 지나가지 않고 방벽 앞에서 멈춘다. |
| 합류 전과 합류 후에 각각 방벽이 있다. | 두 출현 지점에서 공룡이 이동한다. | 합류 전 방벽은 해당 경로만, 합류 후 방벽은 양쪽 공룡을 모두 막는다. |
| 채집 기능을 사용할 수 있는 맵을 연다. | 채집 공간을 확인한다. | 고지대에 채집 건물 1개와 나무 5그루 이상이 배치되어 있고, 모든 채집 가능한 나무의 주변 8타일 중 최소 1타일에 일꾼이 채집 건물에서 도달할 수 있다. |
| 일꾼의 이동 길에 타워가 있다. | 일꾼이 나무와 채집 건물 사이를 이동한다. | 일꾼은 타워 앞을 지나가며 공룡 경로, 나무와 채집 건물을 통과하지 않는다. |
| 아직 해금되지 않은 맵 요소가 배치되어 있다. | 플레이어가 해당 요소를 선택한다. | 요소는 흐리게 보이고 작동하지 않으며 사용할 수 없는 이유와 해금 조건을 안내한다. |
| 플레이어가 새로 스테이지에 진입한다. | 카메라를 조작하지 않는다. | 맵별 초기 위치와 1.0배에서 시작하며 별도의 초기 위치 복귀 버튼은 보이지 않는다. |
| 카메라가 1.0배 또는 확대 상태다. | 플레이어가 전장을 한 손가락으로 드래그한다. | 1.0배에서는 좌우로만, 확대 상태에서는 상하좌우로 이동하며 맵 경계를 넘지 않는다. |
| 카메라가 1.0~1.5배 범위 안에 있다. | 플레이어가 전장 위의 두 손가락을 벌리거나 모은다. | 두 손가락 사이의 기준 지점 아래 맵 위치를 유지하면서 1.0~1.5배 범위 안에서 확대·축소되고, 별도의 확대·축소 버튼은 보이지 않는다. |
| 같은 화면 밖 방향에 여러 사건이 발생한다. | 플레이어가 대표 알림을 선택한다. | 우선순위가 가장 높은 아이콘과 발생 수가 보이고 카메라가 해당 위치로 이동한다. 직접 드래그하면 이동이 취소된다. |
| 카드 선택 화면에 궁극 카드가 등장한다. | 맵 화면의 가장자리를 확인한다. | 궁극 카드로 인한 화면 밖 알림은 생성되지 않고 카드 선택 화면의 전용 연출과 소리만 나온다. |
| 카드 세트에서 카드를 선택하는 화면이 열려 있다. | 플레이어가 배경의 맵을 한 손가락으로 드래그하거나 두 손가락을 벌리고 모은다. | 카메라 위치와 배율이 바뀌지 않는다. |
| 지원 화면비에서 실제 맵 바깥 영역이 보인다. | 플레이어가 바깥 영역을 보거나 선택한다. | 월드 배경이 이어져 보이지만 해당 영역에는 상호작용할 수 없다. |
| 수동 일시정지 메뉴가 열려 있다. | 플레이어가 전장을 한 손가락으로 드래그하거나 두 손가락을 벌리고 모은다. | 카메라 위치와 배율이 바뀌지 않고 일시정지 메뉴만 조작할 수 있다. |
