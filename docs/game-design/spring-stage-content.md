> 문서 상태: 부분 확정
>
> 적용 범위: 봄 월드 1-1~1-10의 학습 목표, 맵 구조, 배치 수량, 웨이브 수와 알파 공룡 배치 골격
>
> 맵 공통 규칙: `stage-map-rules.md`
>
> 경제·방벽 규칙: `economy-barricade-rules.md`

## 1. 목적과 원본 경계

봄 월드는 타워, 카드, 재배치, 목재 경제, 방벽과 2경로 대응을 한 요소씩 누적해 가르친다. 이 문서는
각 스테이지의 콘텐츠 역할과 제작 수량을 소유한다. 공통 맵 제작 규칙, 경제 행동의 비용과 효과,
전투 판정과 카드 생성 규칙은 관련 상세 원본을 따른다.

## 2. 결정 상태

### 2.1 확정

- 1-1~1-10의 맵 크기, 경로 수, 초기 건설권, 타워·방벽 슬롯, 채집 건물, 나무, 시작 목재,
  웨이브 수, 알파 횟수와 알파 출현 웨이브
- 스테이지별 학습 목표, 공룡 역할 공개 순서와 맵의 전술적 역할
- 1-10의 마지막 웨이브는 티라노사우루스 중심의 보스 웨이브로 사용

### 2.2 적용 대기

- 1-4의 타워 이동 학습은 목재 경제가 1-5에 해금되는 현재 GDD와 충돌한다. 1-4에 한정된 이동용
  목재를 제공할지, 타워 이동 학습을 1-5로 옮길지는 병합 담당 세션에서 사용자와 다시 합의한다.
- 세션 1의 전투 수치를 참조한 웨이브별 공룡 종별 마릿수, 출현 간격과 조합 비율
- 공룡별 체력, 이동 속도, 장갑, 경험치와 방벽 피해
- 위 수치 적용 뒤 목표 플레이 시간 `8~12분`과 예정 일반 카드 선택 `10~16회`에 맞춘 최종 웨이브 조정

### 2.3 검증 필요

- 타워 슬롯 최대 14개와 나무 최대 8그루를 작은 모바일 화면에서 구분하고 정확히 선택할 수 있는지
- 48×18타일 맵에서 주요 전투 지점과 화면 밖 사건을 놓치지 않는지
- 카드 선택 10~16회와 알파 카드 세트가 전투 흐름을 지나치게 자주 끊지 않는지
- 플레이테스트에는 정량 합격선을 두지 않고 불편, 오선택과 전투 흐름 중단 사례를 기록한 뒤 변경을 합의한다.

### 2.4 제외

- 실제 좌표, 데이터 형식과 내부 식별자
- 공룡과 타워의 전투 수치
- 여름·겨울·가을 월드 콘텐츠

## 3. 봄 월드 공통 전개

- 1-1~1-7은 출현 지점 1개와 단일 공룡 경로를 사용한다.
- 1-8~1-10은 출현 지점 2개와 합류하는 2개 공룡 경로를 사용한다.
- 공룡 역할은 벨로키랍토르, 콤프소그나투스, 트리케라톱스, 파키케팔로사우루스,
  안킬로사우루스, 티라노사우루스 순으로 누적 공개한다.
- 앞 스테이지에서 공개한 일반 공룡은 이후 스테이지에서도 사용할 수 있다.
- 알파 공룡은 해당 스테이지까지 공개된 일반 공룡 중에서 선정한다. 구체적인 종과 수치는 적용 대기다.
- 마지막 웨이브에는 알파 공룡을 새로 배치하지 않아 알파 카드 세트에서 얻은 타워를 활용할 시간을 남긴다.

## 6. 웨이브 역할 초안

- 각 스테이지의 첫 웨이브는 해당 스테이지에서 새로 공개한 조작 또는 공룡 역할을 다른 신규 요소와
  겹치지 않게 관찰하는 구간으로 둔다.
- 중반 웨이브는 기존 역할과 신규 역할을 섞고, 알파 공룡 처치로 얻은 건설 카드를 다음 웨이브부터
  활용할 수 있게 한다.
- 마지막 웨이브는 해당 스테이지에서 배운 요소를 조합해 확인하며 알파 공룡을 새로 배치하지 않는다.
- 1-10의 10웨이브는 티라노사우루스를 중심으로 구성한다. 함께 출현할 일반 공룡과 출현 순서는
  세션 1 전투 수치 적용 뒤 확정한다.
- 웨이브별 공룡 종별 마릿수와 출현 간격은 임의로 채우지 않는다.

## 7. 플레이테스트 관찰 조건

### 7.1 공통 조건

- 예정 일반 카드 선택 횟수를 최소 10회, 최대 16회로 각각 설정한 판을 비교한다.
- 같은 스테이지를 처음 보는 판과 한 번 실패한 뒤 재도전하는 판을 구분해 관찰한다.
- 1.0배와 2배, 타워 이동을 적게 사용한 판과 자주 사용한 판을 각각 확인한다.

### 7.2 기록할 내용

- 카드 선택이 연속되거나 전투 판단을 시작하기 전에 다시 중단되는 구간
- 알파 카드 세트와 일반 카드 세트가 연이어 열려 피로하거나 앞선 선택을 잊는 상황
- 48×18타일에서 카메라를 반복 이동하느라 관문 위험이나 알파 공룡을 놓치는 상황
- 타워 슬롯 14개에서 빈 슬롯·설치된 타워·선택한 슬롯을 혼동하는 상황
- 나무 8그루와 일꾼 이동이 공룡 경로, 방벽과 타워 공격을 가리는 상황
- 한 판에서 실제 사용한 타워 이동, 일꾼 고용, 채집 효율 강화와 방벽 행동 및 사용하지 않은 이유

정량 합격선은 두지 않는다. 관찰 결과는 규칙 유지 또는 변경의 근거로 기록하고, 변경은 사용자와
다시 합의한다.

| 1-7의 첫 정비 시간이다. | 방벽 슬롯을 선택한다. | 슬롯 2개 중 하나에 30목재로 방벽을 설치할 수 있다. |

| 1-10의 9웨이브 알파를 처치한다. | 건설 카드를 선택하고 10웨이브를 시작한다. | 얻은 타워를 배치한 뒤 마지막 티라노사우루스 웨이브에서 사용할 수 있다. |
| 세션 1 전투 수치가 아직 반영되지 않았다. | 웨이브 콘텐츠를 확인한다. | 공룡 역할과 알파 위치만 사용하며 종별 마릿수·출현 간격을 확정값으로 취급하지 않는다. |
