# Dino TD 봄 월드 스테이지 콘텐츠

> 문서 상태: 확정
>
> 적용 범위: 봄 월드 1-1~1-10의 학습 목표, 맵 구조, 배치 수량, 웨이브 수와 알파 공룡 배치 골격
>
> 맵 공통 규칙: `stage-map-rules.md`
>
> 경제·방벽 규칙: `economy-barricade-rules.md`
>
> 전투 규칙: `combat-system-rules.md`
>

## 1. 목적과 원본 경계

봄 월드는 타워, 카드, 재배치, 목재 경제, 방벽과 2경로 대응을 한 요소씩 누적해 가르친다. 이 문서는
각 스테이지의 콘텐츠 역할과 제작 수량을 소유한다. 공통 맵 제작 규칙, 경제 행동의 비용과 효과,
전투 판정과 카드 생성 규칙은 관련 상세 원본을 따른다.

## 2. 결정 상태

### 2.1 확정

- 1-1~1-10의 맵 크기, 경로 수, 초기 건설권, 타워·방벽 슬롯, 채집 건물, 나무, 시작 목재,
  웨이브 수, 예정 일반 카드 선택 횟수, 공룡 구성, 출현 간격, 알파 원종과 알파 출현 웨이브
- 스테이지별 학습 목표, 공룡 역할 공개 순서와 맵의 전술적 역할
- 1-10의 마지막 웨이브는 티라노사우루스 중심의 보스 웨이브로 사용

### 2.2 검증 필요

- 타워 슬롯 최대 14개와 나무 최대 8그루를 작은 모바일 화면에서 구분하고 정확히 선택할 수 있는지
- 48×18타일 맵에서 주요 전투 지점과 화면 밖 사건을 놓치지 않는지
- 예정 일반 카드 선택의 경험치 기준 최초 도달 시점 사이 게임 시간 간격이 판 전체 평균 `25초 이상`이고 어느 두 최초 도달 시점도 `12초 미만`으로 이어지지 않는지. 같은 공격의 초과 경험치로 대기열에 함께 들어온 카드 세트 사이의 표시 간격은 제외한다.
- 1-1~1-4는 마지막 공룡 처치 시 전체 경로 이동시간의 `25% 이상`, 1-5~1-9는 `15% 이상`,
  1-10 보스는 `10% 이상`이 남는지
- 목표 플레이 시간 `8~12분` 안에서 카드 선택과 알파 카드 세트가 전투 흐름을 지나치게 자주 끊지 않는지
- 위 정량 전투 기준과 별개로 가독성의 불편, 오선택과 전투 흐름 중단 사례를 함께 기록한다.

### 2.3 제외

- 실제 좌표, 데이터 형식과 내부 식별자
- 공룡과 타워의 전투 수치
- 여름·겨울·가을 월드 콘텐츠

## 3. 봄 월드 공통 전개

- 1-1~1-7은 출현 지점 1개와 단일 공룡 경로를 사용한다.
- 1-8~1-10은 출현 지점 2개와 합류하는 2개 공룡 경로를 사용한다.
- 공룡 역할은 벨로키랍토르, 콤프소그나투스, 트리케라톱스, 파키케팔로사우루스,
  안킬로사우루스, 티라노사우루스 순으로 누적 공개한다.
- 앞 스테이지에서 공개한 일반 공룡은 이후 스테이지에서도 사용할 수 있다.
- 알파 공룡은 해당 스테이지에서 새로 공개한 공룡 역할을 우선하며, 새 공룡이 없으면 해당
  스테이지의 주된 압박 역할을 사용한다.
- 알파 공룡 한 마리는 같은 웨이브의 원종 일반 공룡 한 마리를 대체하며 웨이브 총 마릿수를 늘리지 않는다.
- 마지막 웨이브에는 알파 공룡을 새로 배치하지 않아 알파 카드 세트에서 얻은 타워를 활용할 시간을 남긴다.

## 6. 웨이브 구성

### 6.1 표기와 출현 간격

- 웨이브 표는 공식 종명인 콤프소그나투스, 벨로키랍토르, 트리케라톱스,
  파키케팔로사우루스와 안킬로사우루스를 먼저 기준으로 삼는다. 표 안에서만 각각 `콤프소`,
  `벨로키`, `트리케라`, `파키`, `안킬로`로 줄여 쓸 수 있다.
- `알파`가 붙은 공룡은 같은 원종 일반 공룡 한 마리를 대체한 알파 공룡이다.
- 단일 역할 웨이브의 기본 출현 간격은 군집형 `0.6초`, 빠른 이동형 `1초`, 돌진형 `1.3초`,
  장갑형 `1.8초`, 중장갑형 `2.2초`다. 두 종류 이상을 섞은 웨이브는 `1.2초`다.
- 2경로 맵은 A와 B에서 동시에 출현을 시작하고 각 경로가 같은 기본 출현 간격을 사용한다.
- 1-8~1-10의 단일 역할 웨이브는 홀수 웨이브에서 A, 짝수 웨이브에서 B에 더 많은 공룡을 둔다.
  혼합 웨이브는 두 경로의 처치 경험치 가중치 합계 차이를 가능한 작게 유지한다.

### 6.5 처치 경험치 기준

- 세션 1의 처치 경험치 가중치는 콤프소그나투스 1, 벨로키랍토르 2, 트리케라톱스 5,
  파키케팔로사우루스 4, 안킬로사우루스 8, 티라노사우루스 40이다. 알파 공룡은 원종의 2배다.
- 최종 웨이브를 제외한 모든 공룡의 처치 경험치 가중치 합계를 `W`, 해당 스테이지의 예정 일반
  카드 선택 횟수를 `M`으로 둔다.
- `k`번째 누적 기준은 `ceil(W × k ÷ M)`으로 계산하며 `k`는 1부터 `M`까지다.
- 최종 웨이브에서 얻는 처치 경험치는 예정 일반 카드 선택을 추가로 만들지 않는다.
- 한 번의 처치로 여러 기준을 넘으면 초과 경험치와 카드 대기열 처리는 `card-draw-rules.md`를 따른다.
- 이 정의로 모든 공룡을 처치하면 예정 일반 카드 선택이 정확히 `M`회 발생하고 마지막 기준은
  최종 웨이브 시작 전에 달성된다.

## 7. 플레이테스트 관찰 조건

### 7.1 공통 조건

- 예정 일반 카드 선택 횟수를 최소 10회, 최대 16회로 각각 설정한 판을 비교한다.
- 같은 스테이지를 처음 보는 판과 한 번 실패한 뒤 재도전하는 판을 구분해 관찰한다.
- 1.0배와 2배, 타워 이동을 적게 사용한 판과 자주 사용한 판을 각각 확인한다.

### 7.2 기록할 내용

- 카드 선택이 연속되거나 전투 판단을 시작하기 전에 다시 중단되는 구간
- 알파 카드 세트와 일반 카드 세트가 연이어 열려 피로하거나 앞선 선택을 잊는 상황
- 48×18타일에서 카메라를 반복 이동하느라 관문 위험이나 알파 공룡을 놓치는 상황
- 타워 슬롯 14개에서 빈 슬롯·설치된 타워·선택한 슬롯을 혼동하는 상황
- 나무 8그루와 일꾼 이동이 공룡 경로, 방벽과 타워 공격을 가리는 상황
- 한 판에서 실제 사용한 타워 이동, 일꾼 고용, 채집 효율 강화와 방벽 행동 및 사용하지 않은 이유

위 정성 관찰 항목에는 별도의 정량 합격선을 두지 않는다. 관찰 결과는 규칙 유지 또는 변경의 근거로 기록하고, 변경은 사용자와
다시 합의한다.
