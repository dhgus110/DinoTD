## 1. 목적과 범위

탐험에서 확보한 자원이 메인 기지, 공방, 판매대를 실제로 오가며 기지가 살아 움직이는 모습을 만든다.
플레이어는 처음에는 모든 단계를 직접 수행하고, 동료와 시설을 확보하면서 원하는 구간부터 자동화한다.

### 포함

- 메인 기지 단계별 외형, 시설 공개, 시설 강화 상한과 기지 확장
- 채석장·벌목장의 건설, 배치, 채집, 복귀, 입고와 재출발
- 메인 기지, 공방, 판매대 사이의 플레이어·동료 실제 운반
- 공방의 상품 선택, 동시 생산, 완성품 보관과 공방 물류 동료
- 모든 전담 배치와 막힘을 확인·교체하는 물류 관리소
- 건설·강화 비콘, 시설 상태, 유지·초기화와 오프라인 연결

### 제외

- 비용·시간·거리·수용량은 [`progression-balance.md`](progression-balance.md)에만 둔다.
- 손님, 판매, 코인, 약탈, 방어와 치료 판정은 [`sales-defense.md`](sales-defense.md)가 소유한다.
- 첫 목표 안내, HUD, 말풍선과 접근성은 [`onboarding-ui.md`](onboarding-ui.md)가 소유한다.
- 생물 능력치와 현장 자원 규칙은 세션 1 원본을 따른다.
- 코드, 데이터 형식, 저장 구조·시점, 구현 알고리즘, 런타임 오류 처리, 분석 이벤트와 개발·출시 절차는 다루지 않는다.

### 결정 상태

- **확정**: 아래 규칙은 모두 사용자 승인 내용이다.
- **가정**: 없음.
- **미정**: 없음. 출시 필수 기지·자동화 흐름에는 시작, 성공, 막힘, 실패와 재개가 정의돼 있다.
- **검증 필요**: 실제 이동이 세로 화면에서 읽히는지와 60분 자동화 막힘 비율은
  [`progression-balance.md`](progression-balance.md#12-검증-필요와-수치-조정-순서)로 확인한다.

## 2. 전체 진행 순서

1. 플레이어가 현장에서 자원을 채집해 메인 기지에 안전 입고한다.
2. 첫 판매는 메인 기지에서 재료를 꺼내는 단계부터 상품·코인을 다시 입고할 때까지 직접 수행한다.
3. 첫 판매 뒤 채석장, 공방 물류, 판매 자동화와 방어 시설을 원하는 순서로 건설한다.
4. 메인 기지를 성장시켜 벌목장, 추가 채집 시설, 물류 관리소와 주문 게시판을 공개한다.
5. 시설별 담당 동료를 배치하고, 막힌 구간을 확인해 시설 강화 또는 역할 교체를 선택한다.
6. 메인 기지 12단계에서 캠페인을 완료한 뒤에도 시설 배치와 주문 운영을 반복한다.

자동화는 시설을 공개하는 것만으로 작동하지 않는다. 건설, 필요한 자리 활성화와 담당 동료 배치가 모두
완료된 연결만 작동하며, 담당자가 없는 구간은 플레이어가 직접 처리하거나 멈춘다.

## 3. 메인 기지 12단계와 공개

| 단계 | 큰 단계·세부 외형 | 새 기능과 운영 변화 | 확장 |
| ---: | --- | --- | --- |
| 1 | 모닥불 | 공방, 공용 판매대, 계산대 1창구로 시작 | - |
| 첫 판매 뒤 | 모닥불 유지 | 채석장 1호, 공방 물류 자리, 판매 동료 1번 자리, 벽·출입문, 방어 야영지 공개 | - |
| 2 | 텐트·싸구려 텐트 | 치료소 자리, 계산대 2창구 공개 | 1차 |
| 3 | 텐트·고급 텐트 | 해금 시설 강화 상한 상승 | - |
| 4 | 돌 거점·기본 | 벌목장 1호, 혼합 상품, 감시탑, 계산대 3창구 공개 | 2차 |
| 5 | 돌 거점·고급 | 해금 시설 강화 상한 상승 | - |
| 6 | 돌 거점·완성 | 해금 시설 강화 상한 상승 | - |
| 7 | 돌·나무 거점·기본 | 채석장 2호, 벌목장 2호, 물류 관리소, 계산대 4창구 공개 | 3차 |
| 8 | 돌·나무 거점·고급 | 해금 시설 강화 상한 상승 | - |
| 9 | 돌·나무 거점·완성 | 해금 시설 강화 상한 상승 | - |
| 10 | 판타지 완성 거점·기본 | 채석장 3호, 벌목장 3호, 주문 게시판, 계산대 5창구 공개 | 4차 |
| 11 | 판타지 완성 거점·고급 | 해금 시설 강화 상한 상승 | - |
| 12 | 판타지 완성 거점·최종 완성 | 메인 캠페인 완료 | - |

- 1차·2차·3차·4차 확장은 각각 1→2, 3→4, 6→7, 9→10 상승 완료 때 발생한다.
- 모든 단계에서 메인 기지 외형이 달라진다. 단계 상승은 현재 해금된 시설 종류의 강화 상한을 1 올리되,
  각 시설의 최종 상한에서 멈춘다. 최종 상한은 [시설 단계·비용·효과](progression-balance.md#5-시설-단계비용효과)를 따른다.
- 나중에 지은 2·3호 채집 시설도 현재 해당 시설 종류의 상한까지 단계별 비용을 내고 따라잡을 수 있다.
- 새 공간은 고정 시설 자리를 제공한다. 기능 시설과 완료 보상 외형은 자유 배치하지 않는다.
- 12단계 이후 환생이나 기지 초기화는 없으며 16종 수집과 주문 운영으로 이어진다.

### 기지 확장 연출

1. 단계 상승 완료 뒤 조작을 잠시 멈추고 카메라가 확장 방향을 비춘다.
2. 동굴 벽이 무너지고 새 공간과 고정 시설 자리의 윤곽을 보여 준다.
3. 기존 공방·계산대·시설·운반물은 이동하거나 초기화하지 않는다.
4. 카메라가 메인 기지로 돌아오면 조작을 재개하고 새 기능을 표시한다.

카메라 자동 이동을 꺼 둔 경우 화면은 이동하지 않고 가장자리 강조와 문구로 같은 정보를 전달한다.

## 4. 첫 판매의 완전 수동 흐름

첫 판매는 자동화 시설이 없어도 반드시 완료할 수 있다.

1. 플레이어가 동굴 현장에서 돌을 채집한다.
2. 메인 기지 입고 범위에 접근해 돌을 안전 자원으로 만든다.
3. 플레이어가 메인 기지의 돌을 등에 싣고 공방에 접근해 내려놓는다.
4. 공방이 돌 상품을 자동 생산한다.
5. 플레이어가 공방 완성품을 등에 싣고 공용 판매대에 내려놓는다.
6. 플레이어가 빈 계산 창구 하나를 직접 맡아 손님의 판매를 완료한다.
7. 플레이어가 계산대의 물리 코인을 등에 싣고 메인 기지에 내려놓아 안전 코인으로 만든다.

- 적재·하역은 대상 가까이에 있는 동안 진행하며, 범위에서 벗어나면 즉시 멈춘다.
- 첫 판매 중에는 공방 물류 동료, 판매 동료와 코인 운반 동료가 필요하지 않다.
- 첫 판매의 목표 시간과 통과 범위는 [플레이테스트 표](progression-balance.md#12-검증-필요와-수치-조정-순서)를 따른다.
- 플레이어가 중간에 다른 행동을 해도 이미 안전 입고한 재료와 완료 상품은 유지된다. 등에 든 물품의
  로그아웃 처리는 10절을 따른다.

## 5. 채석장과 벌목장

### 5.1 건설과 배치

- 채석장과 벌목장은 화면에 존재하는 실제 시설이다. 건설 비콘을 완료한 뒤 별도의 배치 비콘에서 채집 동료 한 명을 선택한다.
- 채석장은 첫 판매 뒤 1호, 기지 7단계에 2호, 10단계에 3호를 공개한다.
- 벌목장은 기지 4단계에 1호, 7단계에 2호, 10단계에 3호를 공개한다.
- 추가 시설은 기존 같은 시설 옆에 생기며 모든 시설에서 메인 기지까지 같은 편도 경로를 사용한다.
- 벌목장 채집 동료는 고정 포탈을 자동 통과한다. 플레이어 확인이나 지역 이동 입력을 요구하지 않는다.
- 시설마다 동료 한 명만 배치한다. 담당자가 없으면 시설은 대기하며 자원을 만들거나 운반하지 않는다.

### 5.2 채집과 입고

1. 배치된 동료가 시설의 가장 가까운 작업 대상으로 이동한다.
2. 자신의 공격력과 공격 간격을 사용해 직접 채집한다.
3. 완료 보상을 등에 싣고 다음 대상을 이어서 채집한다.
4. 운반 한도가 차거나 모든 대상이 고갈되면 현재 적재량으로 메인 기지에 돌아온다.
5. 메인 기지에 전부 입고한 뒤 작업 대상이 하나 이상 있으면 다시 출발한다.

- 작업 대상은 플레이어 현장 자원과 별개지만 내구도와 완료 보상 기본값은 세션 1 현장 자원과 같게
  사용한다. 시설 대상을 채집해도 플레이어 탐험 지역의 자원이 사라지지 않는다.
- 대상 하나의 상태, 재생, 시설 단계별 수량과 운반 단위는
  [채집·운반·생산 기본값](progression-balance.md#6-채집운반생산-기본값)을 따른다.
- 모든 대상이 고갈됐고 적재량이 0이면 메인 기지에서 기다린다. 대상 하나가 재생되면 자동 출발한다.
- 입고 전 자원은 안전 자원이 아니다. 다만 일반 약탈자는 판매대 상품과 미입고 코인만 훔치므로 채집 동료의 원자재를 훔치지 않는다.

### 5.3 배치 변경

- 플레이어는 기지에서 비용 없이 동료의 전담 배치를 바꿀 수 있다.
- 변경을 선택한 동료는 현재 운반물을 기존 목적지에 먼저 입고하고 나서 새 배치로 이동한다.
- 채집 중이지만 아직 보상을 얻지 못한 작업은 중단한다. 작업 대상의 남은 내구도는 유지되고 다음 담당자가 이어서 작업할 수 있다.
- 새 시설 자리가 가득 찼으면 변경을 시작하지 않고 `배치 자리 없음`과 필요한 시설을 표시한다.

## 6. 공방과 실제 물류

### 6.1 공방 생산

- 공방은 하나이며 단계에 따라 동시 생산 자리와 완성품 보관 상한이 증가한다.
- 플레이어는 돌 상품 또는 공개된 혼합 상품을 버튼으로 선택한다. 모든 생산 자리는 같은 선택 상품을 반복 생산한다.
- 상품 변경을 눌러도 진행 중인 상품은 끝까지 완성한다. 변경은 다음 생산부터 적용한다.
- 생산을 시작할 재료가 부족하면 어떤 재료도 먼저 소비하지 않는다. 부족 종류와 수량을 표시하고 입고 뒤 자동 재개한다.
- 완성품 상한에 도달하면 새 생산을 시작하지 않는다. 상품이 반출돼 빈자리가 생기면 자동 재개한다.
- 레시피, 생산 시간, 동시 자리와 보관 상한은
  [공방과 상품](progression-balance.md#63-공방과-상품)을 따른다.

### 6.2 공방 물류 동료

- 첫 판매 뒤 공방 물류 자리를 활성화할 수 있다. 동료 한 명이 메인 기지→공방 재료 반입과 공방→공용 판매대 상품 반출을 모두 맡는다.
- 완성 상품과 투입 재료가 동시에 기다리면 완성 상품 반출을 먼저 한다. 그다음 재료를 가져온다.
- 담당자가 없으면 두 이동 모두 멈추지만 플레이어가 같은 물품을 직접 운반할 수 있다.
- 판매대가 상품 종류별 상한에 도달하면 해당 상품 반출을 멈추고, 반출 가능한 다른 상품이나 재료 반입을 처리한다.
- 역할 변경을 선택하면 들고 있던 물품을 기존 목적지에 내려놓은 뒤 새 배치로 이동한다.

### 6.3 물류 우선순위

`완성 상품 반출 → 현재 생산에 필요한 재료 반입 → 다음 생산에 필요한 재료 반입`

- 한 번에 옮기는 양은 담당 동료의 운반력을 넘지 않는다.
- 적재·하역 중 상한에 도달하면 들어갈 수 있는 양까지만 내려놓고 남은 물품을 출발지로 되돌린다.
- 약탈 경보 중에도 기지 내부의 재료 반입, 상품 반출과 코인 운반은 계속한다.
- 판매대에 도착한 상품만 손님 재고이자 약탈 대상으로 취급한다.

## 7. 물류 관리소

- 기지 7단계에서 고정 자리가 공개되며, 건설 뒤 모든 전담 배치와 막힘을 한곳에서 확인하고 교체할 수 있다.
- 채석장, 벌목장, 공방 물류, 판매 창구, 코인 운반, 방어 야영지의 담당자와 현재 목적지를 보여 준다.
- `담당자 없음`, `재료 부족`, `출력 가득 참`, `경로 이동 중`, `정상 작동`을 구분한다.
- 플레이어가 교체를 선택하면 각 시설의 배치 비콘에서 선택한 것과 같은 배치 변경 규칙을 사용한다.
- 자동 인력 분배, 자동 최적화, 물품 순간 이동과 시설 원격 건설은 하지 않는다.
- 물류 관리소를 짓지 않아도 각 시설의 배치 비콘에서 모든 자동화 기능을 계속 사용할 수 있다.

## 8. 비콘과 시설 상태

### 8.1 건설·강화

- 시설이 공개되면 고정 자리에 건설 비콘을 표시한다. 이미 있는 시설은 현재 강화 상한 안에서 강화 비콘을 표시한다.
- 플레이어가 비콘 위에 머무르면 안전 자원을 투입하며, 정확한 비용과 투입 시간은
  [`progression-balance.md`](progression-balance.md#5-시설-단계비용효과)를 따른다.
- 여러 재화를 요구하면 동시에 투입한다. 하나라도 부족하거나 완료 전에 나가면 임시 투입분 전부를 반환한다.
- 완료 시 건설·강화를 즉시 적용한다. 계속 서 있어도 다음 강화는 시작하지 않으며 완전히 나갔다가 재진입해야 한다.

### 8.2 시설 상태

| 상태 | 조건 | 결과와 피드백 |
| --- | --- | --- |
| 정상 | 담당자·재료·출력 공간이 준비됨 | 현재 작업과 목적지를 표시하고 계속 작동 |
| 담당자 없음 | 전담 자리가 비어 있음 | 시설 정지, 사람 모양 상태 아이콘과 배치 안내 |
| 재료 부족 | 다음 생산 재료가 모자람 | 생산 시작 안 함, 부족 종류·수량 표시 |
| 출력 가득 참 | 공방 또는 판매대 상한 도달 | 앞 구간 정지, 필요한 반출 위치 표시 |
| 작업 대상 대기 | 모든 시설 대상이 재생 중 | 고장으로 표시하지 않고 정상 대기와 다음 재생 표시 |
| 강화 잠김 | 메인 기지 또는 시설 상한 미충족 | 비용 차감 없음, 필요한 기지 단계 표시 |
| 비용 부족 | 비콘 요구량 미충족 | 완료 안 함, 임시 투입 반환과 부족 수량 표시 |

시설 막힘은 해당 시설 위 아이콘으로만 알리고 전역 경보를 만들지 않는다. 화면 표현 세부는
[`onboarding-ui.md`](onboarding-ui.md#6-hud와-시설-피드백)를 따른다.

## 9. 선택·실패·종료 우선순위

1. 동료가 운반 중이면 기존 목적지 입고를 완료한다.
2. 출력 상한과 목적지 수용 가능 여부를 확인한다.
3. 완성 상품 반출을 재료 반입보다 먼저 처리한다.
4. 재료와 생산 자리가 모두 준비된 생산만 시작한다.
5. 시설 막힘이 해소되면 별도 확인 없이 자동 재개한다.

- 담당 동료가 부상·이탈하면 해당 전담 구간만 멈춘다. 다른 시설과 플레이어 직접 운반은 계속한다.
- 상한 때문에 실을 수 없거나 내릴 수 없는 물품은 사라지지 않는다.
- 기지 확장, 시설 강화와 역할 변경은 진행 중 생산을 취소하지 않는다. 강화 효과는 다음 생산·운반부터 적용한다.
- 메인 기지 12단계 완료는 캠페인 종료지만 기지 운영을 끝내지 않는다.

## 10. 유지·초기화와 오프라인

- 메인 기지·시설 단계, 공개 상태, 건설 완료와 동료 배치는 접속 종료 뒤 유지한다.
- 배치된 채집, 운반과 생산 구간만 최대 24시간 오프라인 진행한다. 담당자 없는 구간과 플레이어 직접 행동은 진행하지 않는다.
- 로그아웃 때 플레이어가 든 안전 자원은 메인 기지 출발 지점, 완성 상품은 공방 완성품 자리, 코인은
  계산대의 안전하지 않은 코인 자리로 반환한다. 어디에도 자동 입고하지 않는다.
- 동료가 운반 중인 물품은 같은 목적지를 향해 계속 이동한다.
- 새 게임에서만 기지와 시설을 시작 상태로 초기화한다. 캠페인 완료 뒤 선택 초기화는 없다.

## 11. 시각·연출·사운드

- 기지는 불빛, 천, 목재와 작업 흔적으로 따뜻한 생활감을 주고, 발광 버섯·식물·결정의 차가운 빛을 은은하게 섞는다.
- 모닥불·텐트 단계는 야외 더미와 짧은 동선, 돌 거점 이후는 열린 단면 창고와 정돈된 물류로 변화한다.
- 각 단계는 구조물·지붕·창고·발광 장식 중 하나 이상이 추가돼 직전 단계와 실루엣으로 구분된다.
- 평상시 환경음과 반복 작업음은 낮게 유지한다. 입고, 상품 완성, 시설 완료만 짧고 구별되는 소리를 사용한다.
- 자원과 시설 상태는 색뿐 아니라 재질, 모양, 아이콘과 문구로 함께 구분한다.
- 이미지 파일은 이 기획 작업에서 만들지 않는다.

## 12. 상황별 확인 사례

| 구분 | 상황 | 기대 결과 |
| --- | --- | --- |

| 정상 | 채집 동료의 운반 한도가 참 | 작업을 멈추고 실제 경로로 메인 기지에 입고한 뒤 돌아간다 |
| 예외 | 모든 작업 대상이 고갈됐지만 부분 적재 | 부분 적재량을 입고하고 대상 재생 전까지 기지에서 기다린다 |
| 예외 | 공방 상품 변경 중 생산이 진행 중 | 현재 상품을 완료하고 다음 생산부터 새 상품을 만든다 |
| 예외 | 역할 변경 중 물품을 들고 있음 | 기존 목적지에 전부 입고한 뒤 새 배치로 이동한다 |

| 실패 | 비콘 비용 일부 투입 뒤 이탈 | 임시 투입분 전부를 안전 자원으로 반환하고 완료하지 않는다 |

| 종료 | 기지 12단계 완료 | 캠페인 완료 외형을 표시하고 수집·주문·운영을 계속한다 |
