# 기지·자동화 기획서

> 문서 상태: 검토 중
>
> 담당 범위: 메인 기지의 12단계 외형·시설 공개, 네 차례 기지 확장, 채석장·숲 벌목 파견,
> 실제 물류, 공방 생산, 비콘을 통한 건설·강화·수리와 기지 운영 연출
>
> 규칙 원본: 이 문서는 기지 공간과 자동화 흐름의 단일 원본이다.
>
> 상위 규칙: [`core-gameplay.md`](core-gameplay.md)의 입고·비콘·기지·자동화 확정 규칙을 따른다.
>
> 수치 원본: 반복 비용·시간·확률·수용량은 [`progression-balance.md`](progression-balance.md)에서 관리한다.

## 1. 목적과 범위

### 1.1 플레이어 가치

플레이어가 동굴과 숲에서 가져온 자원이 메인 기지 안에서 실제로 이동하고, 공방과 판매로 이어지는
모습을 보며 “탐험한 결과가 기지를 움직인다”는 감각을 얻는 것이 목적이다. 메인 기지의 단계가 오를수록
새 공간과 시설 자리가 공개되고, 이미 해금한 시설도 강화 상한이 올라가 운영 선택이 넓어진다.

### 1.2 포함 범위

- 메인 기지 1~12단계의 공개 순서, 큰 단계, 외형 변화와 네 차례 기지 확장
- 채석장·숲 벌목 파견의 진입, 일꾼 배치, 생산 더미와 실제 운반
- 메인 기지 입고, 내부 보관, 공방·판매대·계산대 사이의 실제 물류
- 공방 1개, 생산 조건, 재료 부족, 완성 상품 인계와 생산 중단
- 비콘의 건설·강화·수리 흐름과 중도 이탈·완료·다음 단계 차단
- 기지 시설의 대기·작동·부족·손상·완료 상태 피드백
- 기지·자원 더미·일꾼 동선의 시각, 연출과 사운드

### 1.3 제외 범위

- 메인 기지 비용, 시설 비용, 생산 시간과 상품 판매가는
  [`progression-balance.md`](progression-balance.md)의 수치 원본에 중복 작성하지 않는다.
- 손님·계산 창구·약탈 무리·방어 결과·치료의 세부 규칙은
  [`sales-defense.md`](sales-defense.md)를 따른다.
- 온보딩 순서, HUD 배치, 접근성 기준은 [`onboarding-ui.md`](onboarding-ui.md)를 따른다.
- 코드, 데이터 컬럼·자료형, 저장 구조, 처리 알고리즘, 분석 이벤트와 기술 성능 기준은 다루지 않는다.

## 2. 상태와 결정 순서

### 2.1 결정 상태

- **확정**: [`core-gameplay.md`](core-gameplay.md#7-시작-상태와-메인-기지-성장)의 시작 구조,
  12단계 이름, 네 차례 확장, 실제 물류를 화면에 보여 준다는 원칙이다.
- **가정**: 파견 경로, 시설 공개 단계, 기지 외형의 세부 연출과 공방 생산의 플레이어 표시 방식은
  출시 플레이가 끊기지 않도록 이 문서에서 기본 흐름을 채택했다.
- **검증 필요**: 세로 화면에서 열린 단면, 자원 더미, 일꾼의 이동을 동시에 읽을 수 있는지 확인한다.
- **미정 없음**: 출시 범위의 기지·자동화 흐름은 시작·성공·부족·중단·실패 결과를 모두 정의한다.

### 2.2 의존 순서

1. 메인 기지 단계와 공간 공개 상태를 확인한다.
2. 현재 해금된 공급원과 빈 일꾼 역할을 확인한다.
3. 공급원에서 자원을 만들고 일꾼이 실제 경로로 운반한다.
4. 메인 기지에 도착한 자원만 안전 자원으로 전환한다.
5. 공방이 재료를 받아 생산하고 완성 상품을 판매대에 넘긴다.
6. 계산대와 방어 시설의 후속 흐름은 각 원본 문서로 넘긴다.

## 3. 메인 기지 진입과 공간 규칙

- 새 게임은 모닥불 1단계의 메인 기지에서 시작한다. 공방, 판매대와 독립 계산대가 이미 보인다.
- 고정 포탈은 시작부터 작동하며 메인 기지와 숲을 왕복한다. 포탈 이동 자체가 기지 단계 조건은 아니다.
- 메인 기지의 입고 범위에 접근하면 등짐의 돌·나무·뼈를 전부 입고한다. 출입구를 통과하는 것만으로는
  입고되지 않는다.
- 메인 기지 내부에 도착한 자원은 시각적으로 보이는 보관 더미에 합쳐지고, 이후 탐험 패배와 약탈의
  손실 대상이 아니다.
- 기능 시설은 지정된 고정 자리에만 놓인다. 순수 장식의 자유 배치는 출시 범위에 포함하지 않는다.
- 계산대는 시작부터 남쪽 벽 접합선을 향한 자리를 예약한다. 계산 창구가 늘어나도 계산대를 옮기지
  않으며, 첫 판매 뒤 벽·출입문을 지어도 양옆에 벽을 연결할 뿐이다.

## 4. 메인 기지 12단계와 네 차례 확장

아래 표는 이 문서가 소유하는 공개·외형 원본이다. 비용과 강화 수치는
[`progression-balance.md`](progression-balance.md#5-메인-기지-성장-비용과-공개-순서)를 참조한다.

| 단계 | 큰 단계·세부 표시 | 새로 공개하거나 강화하는 시설·흐름 | 외형·공간 변화 | 확장 |
| ---: | --- | --- | --- | --- |
| 1 | 모닥불·모닥불 | 공방, 판매대, 계산대, 채석장 파견, 고정 포탈 | 모닥불과 야외 자원 더미, 열린 바닥 | - |
| 2 | 텐트·싸구려 텐트 | 1차 기지 확장 공간, 치료소 전용 자리와 텐트 큰 단계의 계산 창구 공개 | 거친 천막, 노출된 치료소 자리, 자원 더미 유지 | 1차 |
| 3 | 텐트·고급 텐트 | 현재 해금된 시설의 강화 상한 갱신 | 보강된 천막과 정돈된 모닥불 주변 | - |
| 4 | 돌 거점·기본 | 숲 벌목 파견 경로, 돌·나무 상품 생산 흐름 | 기초 돌벽, 내부 보관 단면 시작 | - |
| 5 | 돌 거점·고급 | 공방·계산대·방어·치료의 해금된 강화 선택 확장 | 다듬은 돌기둥과 더 넓은 내부 동선 | - |
| 6 | 돌 거점·완성 | 두 번째 기지 확장 공간과 고정 시설 자리 | 완성된 돌 거점, 내부 창고 구획 | 2차 |
| 7 | 돌·나무 거점·기본 | 채석장·숲 벌목 파견 자리 각 1개 추가 | 목재 지붕과 돌·나무 혼합 보관 공간 | - |
| 8 | 돌·나무 거점·고급 | 두 공급원에서 늘어난 운반 흐름을 수용하는 내부 동선 | 보강 목재, 열린 단면 확장 | - |
| 9 | 돌·나무 거점·완성 | 세 번째 기지 확장 공간과 고정 시설 자리 | 정돈된 창고, 자원 더미의 구획화 | 3차 |
| 10 | 판타지 완성 거점·기본 | 최종 구간의 시설 강화 상한과 계산대 다섯 창구 운영 | 발광 식물과 자연 소재가 건축에 결합 | - |
| 11 | 판타지 완성 거점·고급 | 해금된 모든 시설의 마지막 강화 선택지 | 더 선명한 발광 요소와 확장된 내부 보관 공간 | - |
| 12 | 판타지 완성 거점·최종 완성 | 네 번째 기지 확장과 출시 성장 목표 완료 | 완성된 신비로운 자연 판타지 거점 | 4차 |

- 메인 기지의 모든 세부 단계 상승은 외형을 바꾸고, 현재 해금된 시설의 강화 상한을 한 단계 올린다.
  실제 상한과 비용은 [시설 강화 비용 표](progression-balance.md#52-시설-건설과-강화-비용)를 따른다.
- 큰 단계가 바뀌는 즉시 해당 단계의 계산 창구 수를 운영한다. 계산 창구 수의 숫자 원본은
  [`progression-balance.md`](progression-balance.md#51-메인-기지-단계-비용)에 있다.
- 기지 확장 중에는 플레이어 조작을 잠시 막고, 카메라가 확장 방향으로 이동한 뒤 동굴 벽이 무너지는
  모습을 보여 준다. 새 공간과 고정 시설 자리가 보인 뒤 카메라가 메인 기지로 돌아오면 조작을 재개한다.
- 확장 전에 이미 배치된 시설과 물류 상태는 유지한다. 확장은 기존 계산대나 공방을 옮기지 않는다.

## 5. 비콘: 건설·강화·수리 흐름

### 5.1 시작 조건과 선택

- 건설 비콘은 시설이 공개된 뒤 해당 고정 자리에 나타난다. 비콘에는 작업 이름, 필요한 재화 종류와
  필요량, 현재 투입량을 함께 표시한다.
- 플레이어가 비콘 위에 서면 안전 자원이 종류별 투입 속도로 현장에 쌓인다. 투입 속도와 작업 비용은
  [`progression-balance.md`](progression-balance.md#5-메인-기지-성장-비용과-공개-순서)를 참조한다.
- 플레이어가 비콘에서 완전히 나가면 완료되지 않은 임시 투입분을 전부 안전 자원으로 돌려준다.
  임시 투입분은 다음 접근까지 유지하지 않는다.
- 요구량이 모두 쌓이면 해당 비용을 소비하고 건설·강화·수리를 즉시 완료한다.
- 같은 비콘 위에 계속 서 있어도 완료된 다음 단계를 자동으로 시작하지 않는다. 다음 단계는 플레이어가
  비콘에서 나갔다가 다시 들어온 뒤에만 시작한다.

### 5.2 우선순위와 예외

1. 현재 메인 기지 단계가 허용하는 시설 강화 상한을 확인한다.
2. 해금되지 않은 시설이면 비콘을 보여 주지 않거나 잠금 이유만 보여 준다.
3. 재화가 부족하면 가진 수량까지만 임시로 쌓고 완료하지 않는다.
4. 플레이어가 중도 이탈하면 임시 투입분을 반환하고, 안전 자원 잔액을 복원한다.
5. 벽·출입문 수리는 건설·강화와 같은 비콘 흐름을 사용하되, 손상된 내구도만큼 코인을 요구한다.

건설과 강화 비용은 한 번의 작업에서 전부 충족되어야 완료한다. 비용이 부족한 상태에서 다른 시설로
이동해도 임시 투입분이 사라지지 않고 반환되므로, 플레이어는 재화를 잃지 않고 목표를 바꿀 수 있다.

## 6. 시설 상태와 강화

| 시설 | 시작·공개 조건 | 작동 상태 | 부족·중단 상태 | 실패·재개 |
| --- | --- | --- | --- | --- |
| 공방 | 메인 기지 1단계부터 1개 | 재료가 있고 생산 대기 공간이 있으면 생산 | 재료 부족 또는 대기 공간 가득 참 | 재료가 보충되면 자동 재개, 생산 중단분은 소비하지 않음 |
| 판매대 | 공방 완성 상품이 도착하면 활성 | 상품 재고를 손님에게 제공 | 재고 0이면 새 손님을 받지 않음 | 대기 손님은 요청을 유지하고 재입고를 기다림 |
| 계산대 | 메인 기지 1단계부터 독립 시설 | 계산 창구 수만큼 손님 응대 | 약탈 경보 중 판매 정지·셔터 폐쇄 | 약탈 종료 뒤 셔터 개방·손님 복귀 |
| 방어 야영지 | 첫 상품 판매 완료 뒤 건설 비콘 공개 | 배치한 방어 동료가 출입문으로 출동 | 방어 동료가 모두 부상·치료 중이면 출동 불가 | 치료 완료 동료가 후속 방어에 자동 복귀 |
| 벽·출입문 | 첫 상품 판매 완료 뒤 건설 비콘 공개 | 약탈 무리의 남쪽 진입을 막음 | 손상될수록 수리 필요, 체력 0이면 기지 안쪽 진입 허용 | 수리 비콘에 코인을 전부 투입하면 최대 체력으로 회복 |
| 치료소 | 1차 기지 확장 때 자리 공개 | 부상 동료를 순서대로 치료 | 치료 비용·치료 자리 조건을 만족하지 못하면 대기 | 비용을 충족하면 치료를 재개하고 완료 후 방어 복귀 |

- 약탈의 손님 대피, 창구 셔터와 결과는 [`sales-defense.md`](sales-defense.md#6-약탈-경보방어-결과)를
  따른다.
- 시설이 대기 중이라는 이유로 이미 메인 기지에 입고된 자원을 다시 등짐으로 되돌리지 않는다.
- 강화 후 생산·운반 흐름은 새 시설 단계의 효과를 즉시 사용하지만, 현재 작업 중인 손님·운반·생산은
  완료 뒤 다음 작업부터 새 효과를 사용한다.

## 7. 파견과 실제 물류

### 7.1 파견 진입

- 메인 기지 1단계에서 채석장 파견을 노출한다. 첫 일꾼은 채석장에 배치할 수 있다.
- 메인 기지 4단계와 공방 2단계의 조건이 충족되면 숲 벌목 파견과 돌·나무 상품 흐름을 노출한다.
- 파견 화면에서 일꾼 한 명을 선택하고 `채석장` 또는 `숲 벌목 파견`을 선택하면 배치한다.
- 역할 변경에는 비용이 없다. 이미 다른 시설에서 작업 중인 일꾼을 파견으로 바꾸면 현재 운반을 끝낸
  뒤 새 경로로 이동한다. 진행 중인 상품 생산은 재료가 공방에 도착한 분량까지 완료한다.
- 파견 자리가 가득 차면 배치 선택을 비활성화하고 `파견 자리 없음`과 다음 메인 기지 단계를 표시한다.

### 7.2 물류의 실제 이동

물류는 다음 화면 흐름을 가진다.

`채석장·숲 벌목 파견 → 메인 기지 입고 → 공방 → 판매대 → 계산대 → 메인 기지 입고`

- 공급원 더미가 생산되면 일꾼이 더미까지 걸어가 운반 가능한 양을 싣는다.
- 일꾼은 포탈·벽·시설을 건너뛰지 않고, 정해진 통로로 메인 기지까지 돌아온다.
- 메인 기지 입고 범위에 들어오면 일꾼이 자원을 내려놓고 보관 더미가 갱신된다. 이 순간 돌·나무는
  안전 자원이 된다.
- 공방 생산에 필요한 자원이 준비되면 일꾼이 메인 기지 보관 더미에서 공방으로 옮긴다.
- 생산이 끝나면 일꾼이 완성 상품을 공방에서 판매대로 옮긴다. 판매대에 도착하기 전 상품은 손님이
  구매할 수 있는 재고가 아니다.
- 계산대 코인은 [`sales-defense.md`](sales-defense.md#5-계산대-코인-운반)의 규칙으로 플레이어 또는
  전용 일꾼이 메인 기지까지 운반한다.

### 7.3 운반 실패와 재개

- 일꾼의 운반량을 초과한 자원은 공급원 더미에 남고, 일꾼이 한 번 더 왕복한다.
- 공급원 더미가 가득 차면 추가 생산을 멈춘다. 더미에 빈자리가 생긴 뒤 다음 공급 주기를 시작한다.
- 일꾼이 역할을 바꾸면 손에 든 자원을 먼저 메인 기지에 내려놓고 새 역할로 이동한다.
- 약탈 경보가 발생해도 메인 기지 내부의 자원·상품 운반은 계속한다. 벽·출입문이 파괴되어 약탈이
  기지 안으로 들어온 경우에는 판매대 상품과 계산대 코인만 약탈 결과의 대상이 된다.
- 오프라인에서도 같은 실제 이동 흐름을 적용하되, 플레이어 현장 채집은 생성하지 않는다.

## 8. 공방 생산 흐름

- 공방은 하나만 존재하며, 현재 해금된 상품 종류 중 플레이어가 선택한 생산을 기다린다.
- 재료가 하나라도 부족하면 생산을 시작하지 않고 부족한 재료와 필요한 수량을 표시한다.
- 생산 시작 시 재료를 공방으로 운반하는 흐름을 먼저 보여 준다. 재료가 공방에 모두 도착한 뒤 생산
  시간이 흐른다.
- 생산 중에는 공방 머리 위에 상품 아이콘과 남은 시간을 표시한다. 재료가 추가로 부족해져도 이미
  시작한 생산은 취소하지 않는다.
- 완성품은 공방에 잠시 쌓인 뒤 일꾼이 판매대로 옮긴다. 판매대에 도착하면 재고가 증가하고 손님이
  들어올 수 있다.
- 생산 시간, 재료, 판매가는 [`progression-balance.md`](progression-balance.md#43-공방과-판매)만 참조한다.
- 공방 강화로 생산 효율이 바뀌면 다음 생산부터 적용한다. 진행 중 생산을 되돌리거나 재료를 다시
  차감하지 않는다.

## 9. 유지·초기화와 종료

- 메인 기지 단계, 시설 강화, 해금한 공급원·시설, 안전 자원과 기지 수용량은 세션 종료 뒤 유지한다.
- 파견 중인 일꾼, 현재 공급원 더미, 공방 생산, 판매대 재고와 메인 기지로 운반 중인 자원은 운영
  상태로 유지하며, 오프라인 진행이 같은 규칙으로 이어 간다.
- 플레이어가 탐험에서 패배해도 메인 기지에 이미 도착한 자원과 진행 중인 시설 강화는 유지한다.
- 비콘에서 미완료로 떠난 경우만 임시 투입분을 반환하고, 완료한 건설·강화·수리는 되돌리지 않는다.
- 기지 확장 연출 중 앱을 닫거나 플레이어가 이동을 시도해도 확장 완료 뒤 메인 기지와 새 공간을
  보여 주고 조작을 허용한다. 플레이어가 볼 수 있는 확장 결과는 사라지지 않는다.

## 10. 시각·연출·사운드 방향

### 10.1 시각 원칙

- 전체 분위기는 `신비로운 자연 판타지`를 사용하며, 발광 생명체·식물·소울의 빛·부드러운 안개와
  자연 소재를 공통 요소로 삼는다.
- 모닥불·텐트 단계에서는 돌·나무·코인·뼈를 야외 더미로 보이고, 돌 거점부터 일꾼이 열린 단면의
  내부 보관 공간에 자원을 내리는 모습을 보인다.
- 자원 종류는 색만으로 구분하지 않는다. 더미의 재질·실루엣·아이콘을 함께 사용하며, 소울은 빛나는
  전용 용기로 분리한다.
- 단계가 오를수록 동굴 벽, 기둥, 지붕, 창고 단면과 발광 장식이 한 번에 하나씩 추가되어 변화 원인을
  읽을 수 있게 한다. 최종 색상과 생물·건축물의 상세 외형은 후속 시각 기획의 범위다.

### 10.2 기지 확장 연출

1. 메인 기지 단계 완료 직후 화면의 움직임을 잠시 멈춘다.
2. 카메라가 새로 열리는 동쪽·서쪽·북쪽 방향으로 이동한다.
3. 동굴 벽이 무너지고 안개·먼지·발광 입자가 퍼진다.
4. 고정 시설 자리와 첫 확장의 치료소 자리를 밝은 윤곽으로 보여 준다.
5. 카메라가 메인 기지로 돌아오고, 시설 상태와 새 선택을 HUD에 표시한 뒤 조작을 재개한다.

### 10.3 사운드 규칙

- 파견 시작은 가벼운 발걸음과 도구 소리, 자원 적재는 재질별 짧은 적재 소리로 구분한다.
- 메인 기지 입고에는 낮은 울림과 자원별 짧은 음을 겹쳐 안전해졌음을 알린다.
- 공방 생산 중에는 불·돌·나무의 작은 반복 소리를 사용하고, 완성품이 판매대로 옮겨질 때 밝은
  한 음으로 생산 완료를 알린다.
- 비콘 투입 중에는 재화가 쌓일 때마다 낮은 음을, 완료 때에는 상승하는 두 음을 사용한다. 부족이나
  중도 반환은 짧고 낮은 음으로 알려 주되 실패처럼 과도하게 연출하지 않는다.
- 기지 확장은 벽 붕괴의 저음, 바람 소리, 발광음 순으로 재생해 변화의 원인과 완료를 구분한다.

## 13. 검증 필요와 완료 조건

- 세로 화면에서 파견 장소·메인 기지·공방·판매대·계산대의 실제 이동이 가려지지 않는지 확인한다.
- 단계별 외형 변화가 1단계씩 상승할 때도 알아볼 수 있는지, 확장 연출 중 현재 목표를 잊지 않는지
  플레이테스트한다.
- 첫 일꾼의 채석장 왕복과 첫 공방 생산이 온보딩의 첫 판매 목표 시간 안에 들어오는지 확인한다.
- 재료 부족과 파견 자리 부족이 시설 고장처럼 보이지 않고, 수량과 다음 행동을 알려 주는지 확인한다.
- 오프라인 복귀 뒤 파견·운반·생산 상태와 안전 자원 더미가 서로 어긋나지 않는지 확인한다.
