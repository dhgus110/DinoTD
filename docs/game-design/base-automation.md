## 1. 목적과 범위

탐험에서 확보한 자원이 동굴의 메인 기지·공방과 숲 장터의 판매대를 실제로 오가며 두 공간이 함께 살아 움직이는 모습을 만든다.
플레이어는 처음에는 모든 단계를 직접 수행하고, 동료와 시설을 확보하면서 원하는 구간부터 자동화한다.

### 포함

- 메인 기지 단계별 외형, 시설 공개, 시설 강화 상한과 기지 확장
- 동굴 시작 공간·확장방·동료 보관소, 숲 장터의 단일 가판대 자리, 시설 최대 자리, 안전 물류길과 입출고점
- 초기 자원 더미와 부속 창고, 자유 장식의 배치·운반·회수
- 채석장·벌목장의 건설, 배치, 채집, 자원 적재칸 회수, 복귀, 입고와 재출발
- 동굴 메인 기지·공방과 숲 장터 판매대·장터 관리대 사이의 플레이어·동료 실제 운반
- 공방 생산 자리별 상품·교대 생산 선택, 동시 생산, 완성품 보관과 공방 물류 동료
- 모든 전담 배치와 막힘을 확인·교체하는 물류 관리소
- 건설·강화 비콘, 시설 상태, 유지·초기화와 오프라인 연결

### 제외

- 손님, 판매, 코인, 약탈, 방어와 치료 판정은 [`sales-defense.md`](sales-defense.md)가 소유한다.

  [`exploration-combat.md`](exploration-combat.md)가 소유한다.
- 코드, 데이터 형식, 저장 구조·시점, 구현 알고리즘, 런타임 오류 처리, 분석 이벤트와 개발·출시 절차는 다루지 않는다.

## 2. 전체 진행 순서

1. 플레이어가 숲에서 목재를 등에 싣고 동굴 출입구 가까운 숲 장터 자리로 이동한다.
2. 첫 목재로 가판대를 짓고 남은 목재를 장작 묶음으로 직접 판매한다.
3. 가판대 옆 네모난 코인 적재칸에서 번 코인을 회수한 뒤 동굴의 네모난 대장간 건설 영역에 투입해 대장간과 곡괭이를 완성한다.
4. 돌로 야영지 코어를, 목재로 동료 보관소를 같은 방식으로 건설한 뒤 첫 영입을 진행한다.
5. 첫 영입 동료는 탐험 역할을 추천해 한 단계 강한 생물을 함께 사냥한다.
6. 두 번째 영입 뒤 동굴의 동료 보관소에서 작업 적성을 비교하고 벌목 운반 또는 판매 보조를 맡겨 직접 해 본 반복부터 자동화한다.
7. 첫 자동화가 만든 자원·코인을 동행 수용량과 장비에 사용해 2인 군단과 중거리·엘리트 원정을 준비한다.
8. 숲 장터의 장터 관리대를 복구하고 메인 기지를 성장시켜 채석장·벌목장, 추가 채집 시설, 물류 관리소와 주문 게시판을 공개한다.
9. 시설별 담당 동료를 배치하고, 막힌 구간을 확인해 시설 강화 또는 역할 교체를 선택한다.
10. 장기 완료 조건은 재설계 중이며, 현재 공개된 성장 목표를 마쳐도 진행을 초기화하지 않는다.

자동화는 시설을 공개하는 것만으로 작동하지 않는다. 건설, 필요한 자리 활성화와 담당 동료 배치가 모두
완료된 연결만 작동하며, 담당자가 없는 구간은 플레이어가 직접 처리하거나 멈춘다.

자동화의 제품 목적은 방치 수익 자체가 아니라 다음 군단 원정의 준비 시간을 줄이는 것이다. 플레이어가
이미 한 번 직접 수행한 채집·회수·운반·판매부터 맡길 수 있으며, 자동화 결과는 장비·도구·동행 수용량·
엘리트 준비 중 하나로 되돌아가야 한다.

### 2.1 작업 적성과 시설 효율

| 작업 적성 | 대표 배치 | 실제로 바꾸는 값 |
| --- | --- | --- |
| 벌목·채광·채집 | 벌목장·채석장·채집 시설 | 작업 대상 하나의 완료 시간 |
| 운반 | 자원 적재칸·공방·장터 물류 | 한 번에 옮기는 수량 |
| 판매 | 가판대 판매 자리 | 손님 한 명의 응대 시간 |
| 제작 | 공방 생산 자리 | 상품 하나의 제작 시간 |

- 적성이 일치하면 동료의 작업력 1~5에 따른 보너스를 적용하고, 시설 팝업에 배치 전후 예상값을 표시한다.
- 적성이 일치하지 않아도 기본 속도로 작업할 수 있다. 잘못 배치한 동료를 무효로 만들지 않되, 적합한
  동료를 새로 영입했을 때 교체 가치가 분명해야 한다.
- 한 시설에서 작업 시간과 1회 처리량을 동시에 올리지 않는다. 어떤 값을 바꾸는지는 위 표를 따른다.
- 첫 자동화는 작업력 차이를 설명만 하지 않는다. 동료가 실제로 이동해 최소 한 번의 운반 또는 판매를
  끝내고, 플레이어가 결과 자원이나 코인을 회수해야 완료로 본다.

## 3. 보류된 메인 기지 12단계안

> 아래 표는 장기 경제 재설계 때 비용·콘텐츠 의존성을 추적하기 위한 과거안이다. 모닥불은 표의 외형 단계로
> 성장하지 않으며, 아래 단계·공개 조건은 새 중심 건물과 안전 입고 지점이 승인되기 전에는 구현하지 않는다.

| ---: | --- | --- | --- |
| 1 | 꺼져 가는 모닥불 | 동굴에는 모닥불·깔개·출입구만, 숲 장터에는 첫 가판대 자리만 보임 | - |
| 두 번째 장작 판매 뒤 | 모닥불 유지 | 대장간 건설 영역 공개. 완성 뒤 야영지 코어, 이어 동료 보관소 건설 영역과 첫 영입 동선을 순차 공개 | - |

| 6 | 돌 거점·완성 | 해금 시설 강화 상한 상승 | - |

  각 시설의 최종 상한에서 멈춘다. 최종 상한은 [시설 단계·비용·효과](progression-balance.md#5-시설-단계비용효과)를 따른다.
- 나중에 지은 2·3호 채집 시설도 현재 해당 시설 종류의 상한까지 단계별 비용을 내고 따라잡을 수 있다.
- 새 공간은 고정 시설 자리를 제공한다. 기능 시설과 완료 보상 외형은 자유 배치하지 않는다.
- 12단계 이후 환생이나 기지 초기화는 없으며 16종 수집과 주문 운영으로 이어진다.

### 동료 보관소와 동료 명단

- 동료 보관소는 메인 기지와 분리된 동굴의 고정 건물이다. 첫 영입 동선이 공개될 때 함께 활성화되며,
  영입한 생물은 현장에서 바로 따라오지 않고 이 건물의 `동료 명단`에 대기 상태로 등록된다.
- 플레이어가 동료 보관소 가까이에서 동료 명단을 열면 대기·탐험·작업·방어 상태, 선호 역할과 세 수용량을 확인하고 역할을 바꿀 수 있다.
- 완성된 동료 보관소 범위에 들어가면 명단 팝업을 자동으로 열며, 닫은 뒤에는 범위를 벗어났다 다시 들어올 때 재개한다.
- 보관소 강화 비콘은 전체 소유 한도인 보관 수용량만 늘린다. 동행·기지 활동 수용량은 야영지 코어에서 별도로 강화한다.
- 보관소가 가득 차면 이유·현재/최대·다음 강화 비용을 표시하며 동료를 조용히 잃지 않는다.
- 대기 동료를 역할에 배치하면 동료 보관소 앞에 나타난 뒤 탐험 동료는 플레이어에게, 일꾼과 방어 동료는
  지정한 시설까지 실제로 이동한다.
- 동료를 대기 상태로 바꾸면 현재 역할의 종료 처리를 마친 뒤 동료 보관소로 돌아와 명단에 머문다.
- 역할, 수용량과 전환 중 운반물의 정확한 판정은
  [`creatures-and-recruitment.md`](creatures-and-recruitment.md#5-선호-역할과-역할-변경)를 따른다.

### 기지 확장 연출

1. 단계 상승 완료 뒤 조작을 잠시 멈추고 카메라가 확장 방향을 비춘다.
2. 벽의 발광 균열을 강조한 뒤 동굴 벽을 무너뜨린다.
3. 새 공간의 안개를 걷고 고정 시설 자리의 윤곽을 보여 준다.
4. 기존 공방·숲 장터·시설·운반물과 자유 장식은 이동하거나 초기화하지 않는다.
5. 카메라가 메인 기지로 돌아오면 조작을 재개하고 새 기능을 표시한다.

카메라 자동 이동을 꺼 둔 경우 화면은 이동하지 않고 가장자리 강조와 문구로 같은 정보를 전달한다.

### 동굴 기지와 숲 장터의 고정 배치

- 시작 공간은 28×36칸이고 남북 중앙길은 폭 6칸이다.
- 동굴에는 `동굴 출입구 → 메인 기지 → 대장간·야영지 코어·동료 보관소·공방 → 확장방`을 잇는 내부 물류축만 둔다. 손님 진입로,
  가판대, 장터 관리대와 장터 방어선은 동굴 안에 두지 않는다.
- 숲 장터는 숲 쪽 동굴 출입구 가까운 안전 공터에 둔다. 안쪽부터 `동굴 출입구 → 공용 판매대·장터 관리대 →
  단일 가판대 → 벽·출입문 → 손님 진입·퇴장 숲길` 순으로 배치한다.
- 각 확장방은 14×16칸이며 중앙길과 연결되는 안전 물류길은 폭 3칸이다.
- 동굴 확장방은 치료소, 추가 생활·공방 공간, 물류 관리소, 주문 게시판 순으로 연다. 감시탑은 기지 4단계에
  숲 장터 외곽의 고정 자리에서 공개한다.
- 숲 장터의 판매대·장터 관리대·단일 가판대와 벽 연결부는 고정 판매 구역에 예약한다. 가판대 강화는
  같은 자리에서 외형과 응대 연출을 개선하며 추가 건물 자리를 요구하지 않는다.
- 방어 야영지는 숲 장터 출입문 안쪽 고정 자리에 두어 방어 동료가 장터 방어선으로 바로 이동하게 한다.
- 잠긴 확장 벽, 최대 시설 자리, 모든 비콘·입출고점·작업 자리, 중앙길, 안전 물류길, 동굴 출입구와 숲 장터
  방어·손님 구역은 다른 시설이나 자유 장식이 침범할 수 없는 보호 공간이다.

| 시설 | 처음부터 예약하는 최대 자리 |
| --- | ---: |
| 메인 기지 | 10×10칸 |
| 공방 | 8×8칸 |
| 동료 보관소 | 8×8칸 |
| 숲 장터 판매대·장터 관리대·가판대 1곳 | 고정 판매 구역 1곳 |
| 방어 야영지·치료소·물류 관리소 | 각각 8×8칸 |
| 감시탑·주문 게시판 | 각각 6×6칸 |
| 채석장 3곳 묶음·벌목장 3곳 묶음 | 각각 16×12칸 |

### 입출고점과 이동 충돌

- 메인 기지는 자원 입고, 공방 반출용 자원 출고와 숲 장터 코인 입고 지점을 서로 나눈다.
- 공방은 재료 입고와 상품 출고를, 숲 장터 판매대는 상품 입고와 장터 관리대 코인 반출을 서로 다른 지점으로 나눈다.
- 모든 물류 지점은 중앙길 또는 안전 물류길을 향하고, 플레이어가 사용하는 비콘은 물류 지점의 반대쪽에 둔다.
- 플레이어와 동료는 서로 통과한다. 손님과의 통과 규칙은 [`sales-defense.md`](sales-defense.md#3-공용-판매대와-손님)를 따른다.
- 적재·하역 같은 작업 자리만 한 명이 사용한다. 플레이어가 접근하면 일꾼은 현재 적재 또는 하역 한 번을 끝낸 뒤
  자리를 비우고, 플레이어가 떠나면 중단한 요청을 다시 처리한다.
- 건물에 플레이어·동료·손님이 가려지면 해당 대상 주변의 지붕과 앞벽만 자동 투명해진다. 가려진 대상의
  윤곽은 투명 처리 중에도 유지한다.

## 4. 첫 가판대와 수동 판매 흐름

첫 판매는 공방·장터 관리대·동료가 없어도 반드시 완료할 수 있다.

1. 플레이어가 숲의 첫 벌목 군락에서 목재를 등에 싣는다.
2. 목재를 입고하지 않고 같은 숲 화면의 장터 가판대 건설 비콘에 직접 투입한다.
3. 가판대가 기초·기둥·천막 순으로 완성되고 등에 첫 판매용 목재가 남는다.
4. 플레이어가 남은 목재를 가판대 진열칸에 내려 장작 묶음으로 만든다.
5. 재고를 본 첫 손님이 장터 바깥 숲길에서 걸어와 장작을 구매한다.
6. 판매 코인은 가판대 옆 네모난 적재칸에 실제로 쌓인다. 플레이어가 적재칸에 접근하면 전량을 보유 코인으로 회수한다.
7. 두 번째 판매 뒤 대장간에서 곡괭이를 제작하고 야영지 코어를 활성화한 뒤, 공방·장터 관리대와 가판대 강화의 가공 상품 판매로 확장한다.

- 건설·진열·적재·하역은 대상 가까이에 있는 동안 진행하며, 범위에서 벗어나면 즉시 멈춘다.
- 가판대 건설 중에는 완성 가판대를 반투명하게 미리 보여 주지 않는다. 네모난 건설 영역, `목재 현재/5`, 진행 바와 현재까지 조립된 골조만 보이고 마지막 목재가 들어간 순간 완성 외형으로 교체한다.
- 첫 장작 판매에는 공방 물류 동료, 판매 동료와 코인 운반 동료가 필요하지 않다.
- 가공 상품이 공개된 뒤에는 `동굴 메인 기지 재료 → 동굴 공방 → 숲 장터 판매대 → 가판대 판매 →
  장터 관리대 코인 → 동굴 메인 기지 안전 코인`의 실제 왕복 물류를 사용한다.
- 첫 판매의 목표 시간과 통과 범위는 [플레이테스트 표](progression-balance.md#12-검증-필요와-수치-조정-순서)를 따른다.
- 플레이어가 중간에 다른 행동을 해도 완성한 가판대와 진열 재고는 유지된다. 등에 든 물품의 로그아웃 처리는 10절을 따른다.

## 5. 채석장과 벌목장

### 5.1 건설과 배치

- 채석장과 벌목장은 화면에 존재하는 실제 시설이다. 건설 비콘을 완료한 뒤 별도의 배치 비콘에서 채집 동료 한 명을 선택한다.
- 배치 비콘과 물류 관리소에서 고르는 동료는 동료 보관소 명단의 대기 동료 또는 기존 역할 변경 대상이다.
  일꾼·방어 동료의 합산 인원이 기지 수용량에 도달하면 새 기지 배치를 시작하지 않는다.
- 채석장은 첫 가공 상품 판매 뒤 1호, 기지 7단계에 2호, 10단계에 3호를 공개한다.
- 벌목장은 기지 4단계에 1호, 7단계에 2호, 10단계에 3호를 공개한다.
- 추가 시설은 기존 같은 시설 옆에 생기며 모든 시설에서 메인 기지까지 같은 편도 경로를 사용한다.
- 채석장 세 곳은 동굴 전용 작업 구역의 16×12칸 안에, 벌목장 세 곳은 숲의 동굴 출입구 근처 전용 작업 구역의
  16×12칸 안에 서로 인접하게 배치한다.
- 각 채석장과 벌목장은 작업 대상 옆에 자원 적재칸 하나를 별도로 둔다. 적재칸은 작업 대상·안전 물류길·
  배치 비콘과 겹치지 않으며 플레이어와 담당 동료가 같은 쪽에서 접근할 수 있어야 한다.
- 각 작업장부터 메인 기지까지 편도 18칸 경로 전체는 폭 3칸의 안전 물류길이며 야생 생물의 공격이 발생하지 않는다.
  벌목장 경로에는 숲과 동굴의 출입구 전환 구간도 포함한다.
- 벌목장 채집 동료는 동굴 출입구를 자동 통과한다. 플레이어 확인이나 지역 이동 입력을 요구하지 않는다.
- 시설마다 동료 한 명만 배치한다. 담당자가 없으면 시설은 대기하며 자원을 만들거나 운반하지 않는다.

### 5.2 채집과 입고

1. 배치된 동료가 시설의 가장 가까운 작업 대상으로 이동한다.
2. 자신의 공격력과 공격 간격을 사용해 직접 채집한다.
3. 완료 보상 1개를 시설의 자원 적재칸에 놓고 다음 대상을 이어서 채집한다.
4. 적재칸 수량이 담당 동료의 운반능력이나 적재칸 상한에 도달하거나 모든 대상이 고갈되면 적재칸으로
   이동해 실을 수 있는 만큼 등에 싣는다.
5. 적재량이 1개 이상이면 메인 기지에 돌아가 전부 입고한다.
6. 입고 뒤 작업 대상이 하나 이상이고 자원 적재칸에 빈자리가 있으면 다시 출발한다.

- 작업 대상은 플레이어 현장 자원과 별개지만 내구도와 완료 보상 기본값은
  [`exploration-combat.md`](exploration-combat.md#51-자원-노드)의 현장 자원과 같게 사용한다. 시설 대상을
  채집해도 플레이어 탐험 지역의 자원이 사라지지 않는다.
- 대상 하나의 상태, 재생, 시설 단계별 수량과 운반 단위는
  [채집·운반·생산 기본값](progression-balance.md#6-채집운반생산-기본값)을 따른다.
- 플레이어도 자원 적재칸에 접근해 빈 운반 한도만큼 직접 회수할 수 있다. 플레이어가 먼저 회수하면 담당
  동료는 남은 수량을 기준으로 다음 행동을 다시 정한다.
- 자원 적재칸에는 자원이 [보관 상한](progression-balance.md#61-채석장과-벌목장)까지 실물로 하나씩
  쌓인다. 상한에 도달하면 해당 시설의 채집만 멈추고, 플레이어나 담당 동료가 하나 이상 반출하면 자동 재개한다.
- 모든 대상이 고갈됐고 적재칸·담당 동료의 적재량이 모두 0이면 메인 기지에서 기다린다. 대상 하나가
  재생되면 자동 출발한다.
- 적재칸과 입고 전 운반물은 안전 자원이 아니다. 다만 일반 약탈자는 판매대 상품과 미입고 코인만 훔치므로
  채집 동료의 원자재를 훔치지 않는다.

### 5.3 배치 변경

- 플레이어는 기지에서 비용 없이 동료의 전담 배치를 바꿀 수 있다.
- 변경을 선택한 동료는 현재 운반물을 기존 목적지에 먼저 입고하고 나서 새 배치로 이동한다.
- 채집 중이지만 아직 보상을 얻지 못한 작업은 중단한다. 작업 대상의 남은 내구도는 유지되고 다음 담당자가 이어서 작업할 수 있다.
- 새 시설 자리가 가득 찼으면 변경을 시작하지 않고 `배치 자리 없음`과 필요한 시설을 표시한다.

## 6. 공방과 실제 물류

### 6.1 공방 생산

- 공방은 하나이며 단계에 따라 동시 생산 자리와 완성품 보관 상한이 증가한다. 공방 5단계는 기지
  10단계에 도달해야 강화할 수 있다.
- 플레이어는 생산 자리마다 `빛문양 돌장식`, `숲빛 등불`, `교대 생산` 중 하나를 선택한다. 숲빛 등불 공개 전에는 빛문양 돌장식만 선택할 수 있다.
- 각 상품 설정은 선택 상품을 반복한다. `교대 생산`은 처음 빛문양 돌장식을 만들고, 완료할 때마다 숲빛 등불과 빛문양 돌장식을 번갈아 만든다.
- 설정을 바꿔도 진행 중인 상품은 끝까지 완성한다. 변경은 다음 생산부터 적용하며 `교대 생산`으로 바꾸면 다음 상품은 빛문양 돌장식부터 시작한다.
- 교대 차례의 상품 재료가 부족하면 다른 상품을 대신 만들지 않고 해당 재료가 입고될 때까지 기다린다.
- 생산을 시작할 재료가 부족하면 어떤 재료도 먼저 소비하지 않는다. 부족 종류와 수량을 표시하고 입고 뒤 자동 재개한다.
- 완성품 상한에 도달하면 새 생산을 시작하지 않는다. 상품이 반출돼 빈자리가 생기면 자동 재개한다.
- 레시피, 생산 시간, 동시 자리와 보관 상한은
  [공방과 상품](progression-balance.md#63-공방과-상품)을 따른다.

### 6.2 공방 물류 동료

- 첫 가공 상품 판매 뒤 공방 물류 자리를 활성화할 수 있다. 동료 한 명이 메인 기지→공방 재료 반입과
  공방→동굴 출입구→숲 장터 판매대 상품 반출을 모두 맡는다.
- 완성 상품과 투입 재료가 동시에 기다리면 완성 상품 반출을 먼저 한다. 그다음 재료를 가져온다.
- 같은 우선순위 안의 요청 선택은
  [`creatures-and-recruitment.md`](creatures-and-recruitment.md#62-일꾼)의 공통 순서를 따른다.
- 담당자가 없으면 두 이동 모두 멈추지만 플레이어가 같은 물품을 직접 운반할 수 있다.
- 판매대가 상품 종류별 상한에 도달하면 해당 상품 반출을 멈추고, 반출 가능한 다른 상품이나 재료 반입을 처리한다.
- 역할 변경을 선택하면 들고 있던 물품을 기존 목적지에 내려놓은 뒤 새 배치로 이동한다.

### 6.3 물류 우선순위

`완성 상품 반출 → 현재 생산에 필요한 재료 반입 → 다음 생산에 필요한 재료 반입`

- 한 번에 옮기는 양은 담당 동료의 운반능력을 넘지 않는다.
- 적재·하역 중 상한에 도달하면 들어갈 수 있는 양까지만 내려놓고 남은 물품을 출발지로 되돌린다.
- 약탈 경보 중에도 동굴 내부 재료 반입, 장터로 향하는 상품 반출과 장터에서 동굴로 향하는 코인 운반은 계속한다.
- 판매대에 도착한 상품만 손님 재고이자 약탈 대상으로 취급한다.

## 7. 물류 관리소

- 기지 7단계에서 고정 자리가 공개되며, 건설 뒤 모든 전담 배치와 막힘을 한곳에서 확인하고 교체할 수 있다.
- 채석장, 벌목장, 공방 물류, 단일 가판대 판매 자리, 장터 코인 운반, 방어 야영지의 담당자와 현재 목적지를 보여 준다.
- `담당자 없음`, `재료 부족`, `출력 가득 참`, `경로 이동 중`, `정상 작동`을 구분한다.
- 플레이어가 교체를 선택하면 각 시설의 배치 비콘에서 선택한 것과 같은 배치 변경 규칙을 사용한다.
- 자동 인력 분배, 자동 최적화, 물품 순간 이동과 시설 원격 건설은 하지 않는다.
- 물류 관리소를 짓지 않아도 각 시설의 배치 비콘에서 모든 자동화 기능을 계속 사용할 수 있다.

## 8. 비콘과 시설 상태

### 8.1 건설·강화

- 시설이 공개되면 완성 건물 대신 고정 위치의 네모난 건설 영역, 필요 재화 아이콘·현재/필요 수량과 진행 바를 표시한다.
- 플레이어가 건설 영역 위에 머무르면 자원을 한 개씩 확정 투입한다. 투입마다 진행 바와 기초→기둥→외형을 갱신하며,
  영역에서 나가도 이미 투입한 자원과 진행은 유지한다.
- 마지막 재화를 투입하면 건설 영역을 제거하고 완성 건물과 기능을 활성화한다. 이미 있는 시설은 현재 강화 상한 안에서 강화 비콘을 표시한다.
- 강화 비콘 위에 머무르면 안전 자원을 투입하며, 정확한 비용과 투입 시간은
  [`progression-balance.md`](progression-balance.md#5-시설-단계비용효과)를 따른다.
- 강화가 여러 재화를 요구하면 동시에 투입한다. 하나라도 부족하거나 완료 전에 나가면 임시 투입분 전부를 반환한다.
- 건설은 한 개씩 확정 투입하므로 재화가 부족하면 현재 진행도에서 멈추고 부족 수량·획득 위치를 표시한다.
- 완료 시 건설·강화를 즉시 적용한다. 계속 서 있어도 다음 강화는 시작하지 않으며 완전히 나갔다가 재진입해야 한다.
- 약탈 경보부터 약탈 종료까지 건설은 일시정지하되 확정 투입 진행도는 유지한다. 성장·강화 비콘의 잠금과
  미완료 임시 투입분 반환은 [`sales-defense.md`](sales-defense.md#71-60초-경보)를 따른다.

### 8.2 시설 상태

| 상태 | 조건 | 결과와 피드백 |
| --- | --- | --- |
| 정상 | 담당자·재료·출력 공간이 준비됨 | 현재 작업과 목적지를 표시하고 계속 작동 |
| 담당자 없음 | 전담 자리가 비어 있음 | 시설 정지, 사람 모양 상태 아이콘과 배치 안내 |
| 재료 부족 | 다음 생산 재료가 모자람 | 생산 시작 안 함, 부족 종류·수량 표시 |
| 출력 가득 참 | 자원 적재칸, 공방 또는 판매대 상한 도달 | 앞 구간 정지, 현재량·상한과 필요한 반출 위치 표시 |
| 작업 대상 대기 | 모든 시설 대상이 재생 중 | 고장으로 표시하지 않고 정상 대기와 다음 재생 표시 |
| 강화 잠김 | 메인 기지 또는 시설 상한 미충족 | 비용 차감 없음, 필요한 기지 단계 표시 |
| 건설 재료 부족 | 건설 영역 요구량 미충족 | 확정 진행 유지, 부족 수량·획득 위치 표시 |
| 강화 비용 부족 | 강화 비콘 요구량 미충족 | 완료 안 함, 임시 투입 반환과 부족 수량 표시 |

시설 막힘은 해당 시설 위 아이콘으로만 알리고 전역 경보를 만들지 않는다. 화면 표현 세부는
[`onboarding-ui.md`](onboarding-ui.md#6-hud와-시설-피드백)를 따른다.

## 9. 선택·실패·종료 우선순위

1. 동료가 운반 중이면 기존 목적지 입고를 완료한다.
2. 출력 상한과 목적지 수용 가능 여부를 확인한다.
3. 완성 상품 반출을 재료 반입보다 먼저 처리한다.
4. 재료와 생산 자리가 모두 준비된 생산만 시작한다.
5. 시설 막힘이 해소되면 별도 확인 없이 자동 재개한다.

- 담당 동료가 부상·이탈하면 해당 전담 구간만 멈춘다. 다른 시설과 플레이어 직접 운반은 계속한다.
- 상한 때문에 실을 수 없거나 내릴 수 없는 물품은 사라지지 않는다.
- 기지 확장, 시설 강화와 역할 변경은 진행 중 생산을 취소하지 않는다. 강화 효과는 다음 생산·운반부터 적용한다.
- 이전 12단계 완료 조건은 구현하지 않는다. 새 장기 완료 조건이 정해져도 기지 운영을 초기화하지 않는다.

## 10. 유지·초기화와 오프라인

- 메인 기지·시설 단계, 공개 상태, 건설 완료와 동료 배치는 접속 종료 뒤 유지한다.
- 배치된 채집, 운반과 생산 구간만 최대 24시간 오프라인 진행한다. 담당자 없는 구간과 플레이어 직접 행동은 진행하지 않는다.
- 로그아웃 때 플레이어가 든 안전 자원은 메인 기지 출발 지점, 완성 상품은 공방 완성품 자리, 코인은
  장터 관리대의 안전하지 않은 코인 자리로 반환한다. 어디에도 자동 입고하지 않는다.
- 동료가 운반 중인 물품은 같은 목적지를 향해 계속 이동한다.
- 채석장·벌목장의 자원 적재칸 수량은 접속 종료 뒤에도 시설에 남는다. 오프라인에는 담당 동료가 같은
  채집·적재·반출 순서를 반복하며, 적재칸이 가득 차면 반출될 때까지 해당 시설만 멈춘다.
- 새 게임에서만 기지와 시설을 시작 상태로 초기화한다. 캠페인 완료 뒤 선택 초기화는 없다.

## 11. 자유 장식

- 자유 장식은 보호 공간을 제외한 기지 바닥에 배치하며 동시에 최대 24개까지 놓는다.
- 각 장식은 실제 충돌이 있지만 언제든 무료로 회수해 다시 배치할 수 있다. 회수해도 제작에 사용한 돌·나무는 반환하지 않는다.
- 플레이어는 장식을 양손으로 직접 운반한다. 이 상태에서는 이동만 가능하고 다른 화물을 들거나 공격하거나 동굴 출입구를 사용할 수 없다.
- 운반 중에는 플레이어 앞에 배치 미리보기와 `놓기`, 네 방향 회전, `보관`을 표시한다. 유효하지 않은 위치에서는
  재화를 소비하지 않고 바닥 윤곽과 문구로 막힌 이유를 알린다.
- 약탈 경보가 시작되면 운반 중인 장식과 배치된 자유 장식을 모두 자동 보관한다. 약탈 종료 뒤 자동 재배치하지 않는다.
- 장식 종류, 공개 단계와 제작 비용은
  [`progression-balance.md`](progression-balance.md#64-자유-장식)를 따른다.

## 12. 시각·연출·사운드

- 기지는 불빛, 천, 목재와 작업 흔적으로 따뜻한 생활감을 주고, 발광 버섯·식물·결정의 차가운 빛을 은은하게 섞는다.
- 모닥불·텐트 단계에는 메인 기지 북동쪽 한곳에 돌·나무·코인·뼈를 물리 더미로 모아 보여 주고,
  소울은 같은 구역의 빛나는 전용 용기에 보관한다. 다섯 자원은 모양과 재질로 서로 구분한다.
- 채석장·벌목장의 자원 적재칸은 네모난 바닥 윤곽 안에 돌 또는 나무 모델을 1개씩 더해 실제 수량과
  더미 높이가 함께 늘어나게 한다. 보관 상한이 되면 더 쌓지 않고 가득 참 아이콘을 표시한다.
- 돌 거점부터 같은 자리에 닫힌 부속 창고가 나타나 실제 더미를 숨긴다. 일꾼은 부속 창고 문까지 운반하고,
  정확한 보유량은 HUD로 확인한다. 부속 창고는 별도 시설·비용·단계·용량·비콘 없이 메인 기지 외형과 함께 성장한다.
- 각 단계는 구조물·지붕·창고·발광 장식 중 하나 이상이 추가돼 직전 단계와 실루엣으로 구분된다.
- 공방·장터 관리대·채석장·벌목장·벽·출입문·방어 야영지·치료소·감시탑·주문 게시판은 강화 효과가
  작업대·자리·침상·벽 두께·정보판의 증가로 먼저 보이고, 높은 단계에 뿌리·잎·룬 같은 자연 판타지 소재를 더한다.
- 감시탑은 공격 기능과 내구도·방어 자리가 없는 실제 탑이다. 낮은 목재 감시대에서 시작해 석재·목재와
  살아 있는 뿌리로 보강된 높은 탑으로 성장한다.
- 발광 표현은 블룸을 사용하지 않고 밝은 부분색, 어두운 주변색, 윤곽, 작은 입자와 매우 약한 명암 변화로 만든다.
- 평상시 환경음과 반복 작업음은 낮게 유지한다. 입고, 상품 완성, 시설 완료만 짧고 구별되는 소리를 사용한다.
- 자원과 시설 상태는 색뿐 아니라 재질, 모양, 아이콘과 문구로 함께 구분한다.
- 이미지 파일은 이 기획 작업에서 만들지 않는다.
