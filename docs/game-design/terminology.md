# 새 게임 공식 용어집

> 문서 상태: 확정
>
> 적용 범위: 새 게임 기획 문서와 협업 대화
>
> 작성 기준: [`game-design-authoring-rules.md`](../guidelines/game-design-authoring-rules.md)

## 1. 사용 원칙

- 반복 사용하는 이름과 개념은 이 문서를 단일 원본으로 삼는다.
- 다른 기획 문서는 같은 개념을 임의 별칭으로 바꾸지 않는다.
- `사용하지 않을 표현`은 과거 문서 교정에만 쓰고 새 규칙에는 사용하지 않는다.
- `허용 표현`은 같은 문단에서 공식 용어를 먼저 밝힌 경우에만 쓴다.
- 생물 종명과 새 공식 용어는 사용자가 직접 승인한 경우에만 등록한다.

| 자동 목표 | 자동 행동이 향하는 현재 대상 | 우선순위·거리·마지막 이동 방향으로 정하며 플레이어가 수동 변경하지 않는 대상 | 적대 생물이 나타나 현재 행동 뒤 자동 목표가 바뀐다 | 현재 목표 | 타겟, 어그로, 수동 목표 | Auto Target | 확정 |

## 5. 구분 규칙

- `메인 기지`는 중심 건물 하나이고 `기지`는 동굴의 전체 운영 공간이다.
- `등짐`은 탐험 중 잃을 수 있는 운반 공간이고 `안전 자원`은 입고 뒤 잃지 않는 재화다.
- `동행 수용량`은 탐험 편성 한도이고 `기지 수용량`은 전체 동료 보유 한도다.
- `중립 생물`·`적대 생물`은 태도이고 `일반 생물`·`엘리트 생물`·`보스 생물`은 등급이다.
- `자동 목표`는 플레이어가 직접 탭하는 대상이 아니다.
- `영입 기회`는 영입 자격이고 `영입·재화 선택`은 그 자격이 있을 때 내리는 결과 선택이다.
- `선호 역할`은 역할 하나에만 적용되는 종별 강점이며 여러 등급으로 나누지 않는다.
- `비콘`은 자동 재화 투입 지점이다. 플레이어 강화 화면의 버튼은 비콘 투입 전에 성장 경로를
  고르는 UI이며 버튼 자체가 비콘은 아니다.
- 장르 설명에서는 테이밍을 쓸 수 있지만 게임 안에서 생물을 동료로 만드는 행동은 `영입`이다.

## 6. 용어 병합 메모

- 작업 세션: 세션 1 — 탐험·전투·생물·표현
- 작업 브랜치: `codex/complete-exploration-creatures`
- 신규·변경 공식 용어: 운반능력, 자동 목표, 보스 보금자리, 재등장 시간, 영입 기회,
  영입·재화 선택, 선호 역할, 회복 우물과 이 문서 4절의 생물 16종
- 변경 공식 용어: 기존 제안 초안의 `생물 결과 선택`은 `영입·재화 선택`으로, `적성`은
  `선호 역할`로 교체한다. 기존 제안 초안의 16종 이름은 이 문서 4절 이름으로 전부 교체한다.
- 변경 이유: 사용자와 18개 전제 항목을 세부적으로 다시 논의해 직접 승인한 결과만 공식화했다.
- 관련 문서 영향: 세션 1의 네 상세 문서는 새 용어로 교정했다. 수정 금지 범위인
  [`core-gameplay.md`](core-gameplay.md)의 `운반력`·`역할 적성`은 `운반능력`·`선호 역할`로
  교정해야 한다. 같은 문서의 후속 결정 목록에 남은 선택 제한 시간은 `제한시간 없음`,
  플레이어 패배 뒤 흐름은 `3초 뒤 최대 체력 귀환`, 플레이어 강화는 운반능력 경로 추가로
  닫아야 한다.
- 이력 처리: `cbac2c2`는 참고용 제안 초안 이력으로 보존하며 최종 확정 근거로 사용하지 않는다.
- 병합 처리: 통합 브랜치에서 중복 용어, 사용하지 않을 표현과 코어 문구 영향을 확인한 뒤 이
  임시 메모를 제거한다.
