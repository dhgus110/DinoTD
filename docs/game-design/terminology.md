# 새 게임 공식 용어집

> 문서 상태: 검토 중
>
> 적용 범위: 새 게임 기획 문서와 협업 대화
>
> 작성 기준: `../guidelines/game-design-authoring-rules.md`

## 1. 사용 원칙

- 이 문서는 새 게임에서 반복 사용하는 용어의 단일 원본이다.
- 다른 기획 문서는 같은 개념을 임의의 별칭으로 바꾸지 않고 이 문서의 공식 용어를 사용한다.
- `사용하지 않을 표현`은 과거 문서 검색과 교정에만 사용하며 새 문서에는 작성하지 않는다.
- `허용 표현`은 공식 용어를 먼저 밝힌 뒤 같은 문단이나 표에서 의미가 분명할 때만 사용한다.
- 생물 종명, 시설의 출시용 이름과 프로젝트 이름은 사용자 승인 전까지 등록하지 않는다.
- 이전 프로젝트의 장르 전용 용어는 새 게임의 공식 용어로 가져오지 않는다.

## 3. 구분 규칙

- `메인 기지`는 중심 건물 하나를 뜻하고, `기지`는 동굴 안의 전체 운영 공간을 뜻한다.
- `등짐`은 탐험 중 잃을 수 있는 운반 공간이고, `안전 자원`은 메인 기지 입고 뒤 잃지 않는 재화다.
- `동행 수용량`은 탐험 편성 한도이고, `기지 수용량`은 전체 보유·배치 한도다. 영입에는 두 한도를 모두 확인한다.
- `중립 생물`은 야생 상태의 태도이고, `일반 생물`·`엘리트 생물`·`보스 생물`은 보상과 출현을 나누는 등급이다.
- `약탈 무리`는 번호가 붙은 전투 단계가 아니며, 운영 상태에 따라 간헐적으로 찾아오는 공격 집단이다.
- `비콘`은 자동 재화 투입 지점이며 별도의 화면 버튼이나 메뉴를 뜻하지 않는다.
- `판매대`는 상품 재고를 두는 공간이고, `계산대`는 손님이 줄을 서고 코인을 남기는 시설이다.
- `계산대`는 통합 시설 전체이고, `계산 창구`는 그 안에서 손님 한 명을 응대하는 개별 자리다.
- `창구 셔터`는 판매 중단과 정면 폐쇄를 보여 주는 장치이며, `벽·출입문`처럼 약탈을 막는 방어 시설이 아니다.
- `테이밍`은 장르를 설명할 때만 사용할 수 있으며 게임 안에서 생물을 동료로 만드는 행동은 `영입`이라 한다.
