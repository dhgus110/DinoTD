# 새 게임 공식 용어집

> 문서 상태: 확정
>
> 적용 범위: 새 게임 기획 문서와 협업 대화
>
> 작성 기준: [`game-design-authoring-rules.md`](../guidelines/game-design-authoring-rules.md)

## 1. 사용 원칙

- 반복 사용하는 이름과 개념은 이 문서를 단일 원본으로 삼는다.
- 다른 기획 문서는 같은 개념을 임의 별칭으로 바꾸지 않는다.
- `사용하지 않을 표현`은 과거 문서 교정에만 쓰고 새 규칙에는 사용하지 않는다.
- `허용 표현`은 같은 문단에서 공식 용어를 먼저 밝힌 경우에만 쓴다.
- 생물 종명과 새 공식 용어는 사용자가 직접 승인한 경우에만 등록한다.

## 5. 구분 규칙

- `메인 기지`는 중심 건물 하나이고 `기지`는 동굴의 전체 운영 공간이다.
- `등짐`은 탐험 중 잃을 수 있는 운반 공간이고 `안전 자원`은 입고 뒤 잃지 않는 재화다.
- `동행 수용량`은 탐험 편성 한도이고 `기지 수용량`은 전체 동료 보유 한도다.
- `중립 생물`·`적대 생물`은 태도이고 `일반 생물`·`엘리트 생물`·`보스 생물`은 등급이다.
- `자동 목표`는 플레이어가 직접 탭하는 대상이 아니다.
- `영입 기회`는 영입 자격이고 `영입·재화 선택`은 그 자격이 있을 때 내리는 결과 선택이다.
- `선호 역할`은 역할 하나에만 적용되는 종별 강점이며 여러 등급으로 나누지 않는다.
- `비콘`은 자동 재화 투입 지점이다. 플레이어 강화 화면의 버튼은 비콘 투입 전에 성장 경로를
  고르는 UI이며 버튼 자체가 비콘은 아니다.
- `판매대`는 상품 재고를 두는 공용 공간이고 `계산대`는 손님 응대와 코인 보관을 묶은 시설이다.
- `계산대`는 통합 시설 전체이고 `계산 창구`는 그 안에서 손님 한 명을 응대하는 개별 자리다.
- `창구 셔터`는 판매 중단을 보여 주는 장치이고 `벽·출입문`은 약탈자를 막는 방어 시설이다.
- `채석장`과 `벌목장`은 실제 시설이며 동료는 원정·파견이 아니라 전담 자리에 `배치`한다.
- `상품 요청 말풍선`은 손님의 요구를, `대상 기능 말풍선`은 선택 대상에 실행할 기능을 보여 준다.
- `교대 생산`은 생산 자리 하나의 명시적 반복 설정이며 자동 인력 분배나 자동 최적화를 뜻하지 않는다.
- 장르 설명에서는 테이밍을 쓸 수 있지만 게임 안에서 생물을 동료로 만드는 행동은 `영입`이다.
