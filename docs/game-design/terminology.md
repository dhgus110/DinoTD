# Wild Survival 공식 용어집

> 문서 상태: 확정
>
> 적용 범위: Wild Survival 기획 문서와 협업 대화
>
> 작성 기준: [`game-design-authoring-rules.md`](../guidelines/game-design-authoring-rules.md)

## 1. 사용 원칙

- 반복 사용하는 이름과 개념은 이 문서를 단일 원본으로 삼는다.
- 공식 게임 이름은 `Wild Survival`로 표기한다.
- 다른 기획 문서는 같은 개념을 임의 별칭으로 바꾸지 않는다.
- `사용하지 않을 표현`은 과거 문서 교정에만 쓰고 새 규칙에는 사용하지 않는다.
- `허용 표현`은 같은 문단에서 공식 용어를 먼저 밝힌 경우에만 쓴다.
- 생물 종명과 새 공식 용어는 사용자가 직접 승인한 경우에만 등록한다.

## 6. 구분 규칙

- `모닥불`은 장식이고 `야영지 코어`는 스탯 성장 건물이다. 재설계 중인 `메인 기지`를 둘 중 하나의 별칭으로 사용하지 않는다.
- `등짐`은 탐험 중 잃을 수 있는 운반 공간이고 `안전 자원`은 입고 뒤 잃지 않는 재화다.
- `동료 보관소`는 영입 도착지인 실제 건물, `동료 명단`은 그 건물 안의 관리 화면이다. `보관 수용량`은 전체 소유 한도이고, `동행 수용량`과 `기지 수용량`은 실제로
  탐험 또는 기지에 배치해 활동시키는 인원 한도다.
- `중립 생물`·`적대 생물`은 태도이고 `일반 생물`·`엘리트 생물`·`보스 생물`은 등급이다.
- `자동 목표`는 플레이어가 직접 탭하는 대상이 아니다.
- `영입 기회`는 영입 자격이고 `영입·재화 선택`은 그 자격이 있을 때 내리는 결과 선택이다.
- `선호 역할`은 역할 하나에만 적용되는 종별 강점이며 여러 등급으로 나누지 않는다.
- `비콘`은 자동 재화 투입 지점이다. 플레이어 강화 화면의 버튼은 비콘 투입 전에 성장 경로를
  고르는 UI이며 버튼 자체가 비콘은 아니다.
- `건설 영역`은 최초 건설 진행을 유지하는 네모 구역이고, `강화 비콘`은 이탈 시 임시 투입분을 반환하는 기존 시설의 강화 지점이다.
- `대장간`은 도구·무기, `야영지 코어`는 캐릭터·동료 운영 능력치를 담당한다. 두 건물과 `메인 기지`를 하나의 통합 강화소로 부르지 않는다.
- `도구 단계`는 도끼와 곡괭이에 따로 적용한다. `상황별 도구 장착`은 화면 표현과 자동 선택 규칙이며 도구를 잃거나 소비한다는 뜻이 아니다.
- `숲 장터`는 판매 구역 전체, `가판대`는 한 채만 두고 강화하는 판매 시설, `판매대`는 그 가판대가 사용하는 상품 재고 공간이다.
- `가판대 판매 자리`는 가판대 한 채의 손님 응대 위치이고 `장터 관리대`는 공용 코인·물류 상태를 묶어 보여 주는 시설이다.
- `가판대 덮개`는 판매 중단을 보여 주는 장치이고 `벽·출입문`은 숲 장터를 약탈자로부터 지키는 방어 시설이다.
- `채석장`과 `벌목장`은 실제 시설이며 동료는 원정·파견이 아니라 전담 자리에 `배치`한다. 채집 결과는
  즉시 지급하지 않고 각 작업 구역의 `자원 적재칸`을 거쳐 운반한다.
- `상품 요청 말풍선`은 손님의 요구를, `대상 기능 말풍선`은 선택 대상에 실행할 기능을 보여 준다.
- `교대 생산`은 생산 자리 하나의 명시적 반복 설정이며 자동 인력 분배나 자동 최적화를 뜻하지 않는다.
- `부속 창고`는 메인 기지 외형의 일부이고 별도 기능 시설이 아니다.
- `자유 장식`은 실제 충돌이 있지만 `안전 물류길`, 시설 최대 자리와 기능 대상에는 놓을 수 없다.
- 장르 설명에서는 테이밍을 쓸 수 있지만 게임 안에서 생물을 동료로 만드는 행동은 `영입`이다.
