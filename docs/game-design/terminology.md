# Dino TD 공식 용어집

> 문서 상태: 확정
>
> 적용 범위: Dino TD의 기획 문서, 개발 명세, 데이터 이름, 화면 문구와 협업 대화
>
> 작성 기준: `../guidelines/game-design-authoring-rules.md`

## 1. 사용 원칙

- 이 문서는 Dino TD에서 반복 사용하는 용어의 단일 원본이다.
- 다른 기획 문서는 같은 개념을 임의의 별칭으로 바꾸지 않고 이 문서의 공식 용어를 사용한다.
- `사용하지 않을 표현`은 과거 문서 검색과 교정에만 사용하며 새 문서에는 작성하지 않는다.
- `허용 표현`은 공식 용어를 먼저 밝힌 뒤 같은 문단이나 표에서 의미가 분명할 때만 사용할 수 있다.
- 카드 이름과 공룡 종명처럼 화면에 표시되는 고유명사는 해당 콘텐츠 명세의 표기를 유지한다.
- 새로운 용어가 필요하면 먼저 이 문서에 정의한 뒤 다른 문서에서 사용한다.

## 2. 게임 구조

| 공식 용어 | 쉬운 정의와 Dino TD 예시 | 허용 표현 | 사용하지 않을 표현 | 영문 표준 |
| --- | --- | --- | --- | --- |
| 월드 | 같은 계절과 제작 주제를 공유하는 스테이지 묶음. 예: 봄 월드는 1-1부터 1-10까지다. | 없음 | 챕터, 시즌 | World |
| 스테이지 | 플레이어가 진입해 승리 또는 실패할 수 있는 한 개의 플레이 단위. 예: 1-1. | 없음 | 레벨, 맵 | Stage |
| 맵 | 한 스테이지에서 사용하는 전장의 지형과 배치. | 전장 | 스테이지 | Map |
| 타일 | 맵의 크기, 배치 공간과 경로 길이를 셀 때 사용하는 정사각형 기본 단위. 예: 타워 슬롯 하나는 여러 타일을 차지한다. | 없음 | 칸, 그리드 | Tile |
| 출현 지점 | 웨이브가 진행될 때 공룡이 맵에 처음 나타나는 공룡 경로의 시작 위치. | 없음 | 스폰 지점, 생성 지점 | Spawn Point |
| 웨이브 | 한 차례에 출현해 관문으로 이동하는 공룡 묶음. | 없음 | 라운드, 턴 | Wave |
| 한 판 | 스테이지 진입부터 승리·실패·중도 이탈까지의 한 번의 도전. | 현재 판 | 런, 세션 | Run |
| 정비 시간 | 웨이브가 끝난 뒤 다음 웨이브를 시작하기 전까지의 준비 상태. | 정비 | 휴식 시간 | Preparation Phase |
| 게임 시간 | 공룡 이동, 공격 준비, 포탄과 상태 효과처럼 일시정지와 1배·2배 전투 속도의 영향을 받는 시간. | 없음 | 실제 시간 | Game Time |
| 해금 | 이후 판에서도 특정 콘텐츠를 사용할 자격을 얻는 것. 예: 1-2 시작 시 블레이드 타워 해금. | 없음 | 오픈, 활성화 | Unlock |
| 활성화 | 해금된 타워 종류가 현재 판의 카드 및 업그레이드 적용 대상이 된 상태. | 활성 | 해금, 건설 | Activate |

## 3. 전투와 공룡

| 공식 용어 | 쉬운 정의와 Dino TD 예시 | 허용 표현 | 사용하지 않을 표현 | 영문 표준 |
| --- | --- | --- | --- | --- |
| 공룡 | 공룡 경로를 따라 개척지 관문으로 이동하는 적대 생명체 전체. | 없음 | 적, 적군, 몬스터, 미니언 | Dinosaur |
| 일반 공룡 | 알파 공룡이나 보스 공룡이 아닌 기본 공룡. | 없음 | 일반 몬스터, 잡몹 | Normal Dinosaur |
| 알파 공룡 | 기존 공룡 종을 더 크고 강하게 만든 특별 변형이며 처치 시 알파 카드 세트를 발생시킨다. | 알파 | 엘리트, 정예 몬스터 | Alpha Dinosaur |
| 보스 공룡 | 스테이지의 핵심 위협으로 배치되는 대형 공룡. 예: 1-10의 티라노사우루스. | 같은 문단의 `보스` | 보스 몬스터 | Boss Dinosaur |
| 공격 대상 | 타워나 효과가 현재 조준하거나 피해를 적용하려는 공룡. | 대상 | 적 | Target |
| 공룡 경로 | 공룡이 출현 지점에서 개척지 관문까지 이동하는 길. | 경로 | 몬스터 길, 적 이동로 | Dinosaur Path |
| 개척지 관문 | 공룡이 도달하면 라이프를 감소시키는 방어 목표. | 같은 문단의 `관문` | 기지, 성, 목표 지점 | Frontier Gate |
| 라이프 | 공룡의 관문 도달을 몇 번 더 허용할 수 있는지를 나타내는 플레이어 측 수치. | 없음 | 생명력, HP, 관문 체력 | Life |
| 체력 | 공룡이나 방벽이 피해를 견딜 수 있는 수치. | 없음 | 라이프 | Health |
| 장갑 | 공룡이 받는 피해를 줄이는 방어 수치 또는 속성. | 없음 | 방어력 | Armor |
| 이동 속도 | 공룡이나 일꾼이 단위 시간에 이동하는 정도. | 없음 | 이속 | Move Speed |
| 공격 속도 | 타워가 단위 시간에 공격하는 빈도. | 없음 | 공속 | Attack Speed |
| 재장전 속도 | 캐논 타워의 다음 포탄 준비 속도를 나타내는 카드 표현. 별도 능력치가 아니며 공통 공격 속도의 초당 공격 횟수 증가 공식을 사용한다. | 없음 | 재장전 시간 감소 | Reload Speed |
| 공격 준비 | 타워 또는 공룡이 다음 공격을 수행할 수 있을 때까지 진행되는 게임 시간. 예: 공격 준비를 마친 건 타워는 공룡이 사거리에 들어오면 즉시 공격한다. | 없음 | 공격 쿨타임 | Attack Readiness |
| 직접 피해 | 타워의 기본 공격이나 순간 폭발이 적중한 시점에 한 번 적용하는 피해. 예: 건 타워 탄환과 캐논 폭발. | 없음 | 즉발 피해 | Direct Damage |
| 포탄 직격 피해 | 캐논 포탄이 처음 공격한 공룡에게 주는 별도 직접 피해. 같은 공룡이 폭발 위치에 남아 있으면 폭발 피해도 함께 받는다. | 없음 | 직격 피해 | Cannon Impact Damage |
| 지속 피해 | 일정 시간 또는 일정 영역에서 정해진 간격마다 반복 적용하는 피해. 예: 화상, 중독, 불타는 지면과 가시 방벽. | 없음 | 도트 피해 | Damage over Time |
| 판정 영역 | 공룡 그림 전체가 아니라 사거리·공격 범위·충돌이 닿았는지 판단하는 공룡의 공간. | 없음 | 히트박스, 충돌체 | Hit Area |
| 상태 효과 | 일정 시간 대상의 상태를 바꾸는 효과. 예: 화상, 중독, 감속, 경직. | 없음 | 디버프, 이상 상태 | Status Effect |
| 처치 경험치 가중치 | 스테이지의 경험치 총량을 공룡별로 나눌 때 사용하는 상대적 몫. 예: 가중치 4인 공룡 한 마리는 가중치 1인 공룡 네 마리와 같은 처치 경험치를 배정받는다. | 같은 문단의 `경험치 가중치` | 경험치 배율, 경험치 점수 | Defeat Experience Weight |

## 4. 방어 시설과 경제

| 공식 용어 | 쉬운 정의와 Dino TD 예시 | 허용 표현 | 사용하지 않을 표현 | 영문 표준 |
| --- | --- | --- | --- | --- |
| 타워 | 타워 슬롯에 건설되어 공룡을 자동 공격하는 방어 시설. | 없음 | 포탑, 건물 | Tower |
| 기본 타워 | 초기 배치 카드 세트에 등장할 수 있는 건·블레이드·캐논·파이어 타워. | 없음 | 초기 타워 | Basic Tower |
| 주력 타워 | 한 판에 최대 3종까지 활성화할 수 있고 일반·고급·궁극 업그레이드를 가진 타워. | 없음 | 메인 타워 | Main Tower |
| 보조 타워 | 한 판에 아이스·독 중 1종만 활성화할 수 있는 타워. | 없음 | 서브 타워 | Support Tower |
| 고지대 | 공룡 경로보다 높아 보이며 타워와 채집 관련 요소를 배치하는 맵 구획. 고지대 자체에는 타워 피해나 공격 범위 보너스가 없다. | 없음 | 언덕, 상단 지형 | High Ground |
| 타워 슬롯 | 타워 한 개를 건설할 수 있는 고지대의 지정된 설치 자리. | 같은 문단의 `빈 슬롯` | 칸, 자리 | Tower Slot |
| 방벽 | 공룡 경로 위에서 공룡을 멈추고 공격받는 방어 시설. | 없음 | 벽, 바리케이드 | Barricade |
| 방벽 슬롯 | 방벽 한 개를 설치할 수 있는 공룡 경로 위의 지정된 자리. | 없음 | 방벽 칸 | Barricade Slot |
| 채집 건물 | 일꾼과 목재 관련 기능을 관리하는 고지대 시설. | 없음 | 자원 건물, 경제 건물 | Gathering Building |
| 일꾼 | 나무와 채집 건물 사이를 왕복해 목재를 운반하는 유닛. | 없음 | 작업자, 주민 | Worker |
| 나무 | 일꾼이 목재를 채집하는 맵의 자원 지점. | 없음 | 자원, 자원 노드 | Tree |
| 목재 | 현재 판에서 획득하고 타워 이동·경제·방벽에 소비하는 자원. | 없음 | 돈, 골드, 재화 | Wood |
| 나무 예약 | 일꾼이 선택한 나무를 목재 운반 완료까지 다른 일꾼이 선택하지 못하게 하는 상태. 예: 첫 일꾼이 가까운 나무를 예약하면 다음 일꾼은 다른 빈 나무를 찾는다. | 예약 | 나무 점유, 자원 선점 | Tree Reservation |
| 채집 효율 | 모든 일꾼이 한 번에 운반하는 목재량을 현재 판에서 높이는 전역 단계. 예: 2단계에서는 일꾼 한 명이 15목재를 운반한다. | 없음 | 생산성, 채집 속도 | Gathering Efficiency |
| 방벽 전역 단계 | 현재 설치된 방벽과 이후 설치·재건되는 모든 방벽의 최대 체력을 함께 정하는 현재 판의 강화 단계. | 같은 문단의 `전역 단계` | 방벽 레벨, 개별 방벽 단계 | Global Barricade Tier |

## 6. 화면과 개발

| 공식 용어 | 쉬운 정의와 Dino TD 예시 | 허용 표현 | 사용하지 않을 표현 | 영문 표준 |
| --- | --- | --- | --- | --- |
| 화면 구성 | 버튼, 수치, 카드 등 플레이어가 보고 조작하는 요소의 구성. | UI | 유아이 | User Interface |
| 전투 정보 화면 | 라이프, 웨이브, 목재와 조작 버튼을 전투 중 표시하는 화면 영역. | 개발 문맥의 HUD | 전투 HUD | Heads-Up Display |
| 화면 밖 알림 | 현재 카메라에 보이지 않는 맵 사건의 방향과 발생 수를 화면 가장자리에서 알려주는 표시. 구체적인 대상과 우선순위는 스테이지·맵 규칙을 따른다. | 없음 | 오프스크린 알림, 가장자리 알림 | Off-screen Alert |
| 체크포인트 | 앱 종료 후 복원할 수 있도록 저장한 안전한 시점의 상태. 예: 웨이브 시작 상태. | 없음 | 세이브 포인트 | Checkpoint |
| 고유 식별자 | 이름이 바뀌어도 콘텐츠를 구분하기 위해 유지하는 내부 값. 예: `TOWER_GUN`. | ID | 코드명 | Identifier |
| 밸런스 | 선택지의 가치와 난이도를 목표 경험에 맞도록 수치로 조정하는 작업. | 없음 | 밸런싱 | Balance |
| 검증 필요 | 플레이테스트, 성능 측정 또는 데이터 확인 후 확정해야 하는 상태. | 없음 | 테스트 필요 | Requires Validation |
| D1 재방문율 | 첫 이용일 이후 다음 날 다시 이용했는지를 보는 지표. 제품 목표는 40%이며, 정확한 동일 조건 사용자 집단과 시간 기준은 분석 기획에서 확정한다. | 분석 문맥의 D1 리텐션 | D1만 단독 사용 | Day-1 Retention |

## 7. 구분 규칙

- `월드`, `스테이지`, `맵`은 서로 바꿔 쓰지 않는다. 예: 봄 월드의 1-1 스테이지가 봄 숲 맵을 사용한다.
- `라이프`는 플레이어 측 관문 방어 여유, `체력`은 공룡과 방벽의 피해 내구 수치에만 사용한다.
- `해금`은 이후 사용할 자격을 얻는 것, `활성화`는 현재 판의 적용 대상이 되는 것, `건설`은 실제 타워 한 개를 슬롯에 놓는 것이다.
- `일반 카드 세트`는 제시 방식이고 `일반 등급 업그레이드 카드`는 개별 카드 등급이므로 줄여서 같은 이름으로 부르지 않는다.
- `카드 풀`은 전체 보유 목록, `카드 후보`는 현재 조건으로 걸러진 목록, `카드 세트`는 화면에 실제 제시된 결과다.
- 공룡 한 마리를 조준하는 문장에서는 `공격 대상`을 사용할 수 있지만, 공룡 전체의 명칭을 `대상`이나 `적`으로 바꾸지 않는다.
