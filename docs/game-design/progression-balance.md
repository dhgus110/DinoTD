## 1. 목적과 소유 범위

플레이어가 짧게 접속해도 생산과 판매의 진전을 확인하고, 장시간 집중해서 플레이할 때는 강제 대기 없이
다음 기지 단계에 도전할 수 있게 한다. 메인 기지, 시설, 방어 중 어디에 먼저 코인을 쓸지 선택하게 하되,
어느 선택도 핵심 순환을 영구히 막지 않는 것이 목적이다.

### 포함

- 안전 자원 5종의 세션 2 공급처와 소비처
- 메인 기지 1~12단계 비용, 공개 순서, 시설 강화 상한과 장기 진행 속도
- 시설 건설·활성화·강화 비용과 단계별 효과
- 시설 작업 대상, 운반, 생산, 판매, 주문, 약탈, 벽, 치료와 오프라인 진행 수치
- 정상·예외·실패 상황의 경제 결과와 플레이테스트 통과 기준

### 제외

- 생물 능력치, 영입 확률·보상, 플레이어 현장 자원과 동료 수용량 수치는 세션 1 원본이 소유한다.
- 공간·배치·작업 흐름은 [`base-automation.md`](base-automation.md), 판매·방어 판정은
  [`sales-defense.md`](sales-defense.md), 첫 사용자 경험과 화면 표현은
  [`onboarding-ui.md`](onboarding-ui.md)가 소유한다.
- 코드, 데이터 컬럼·자료형, 저장 구조·시점, 구현 알고리즘, 런타임 오류 처리, 분석 이벤트와 개발·출시 절차는 다루지 않는다.

### 결정 상태

- **확정**: 이 문서의 모든 출시 기본값과 계산 규칙은 사용자 승인 내용이며 구현 기준으로 사용한다.
- **가정**: 없음.
- **미정**: 없음. 세션 2 출시 필수 범위에는 빈 값이 없다.
- **검증 필요**: 수치가 목표 재미와 성장 속도를 만드는지는 12절의 플레이테스트로 확인한다. 실패해도
  현재 값이 기준이며, 승인 없이 자동 조정하지 않는다.

## 2. 플레이 시간과 장기 진행

- 기본 이용 형태는 한 번에 `10~20분`, 하루 `2~3회`다. 장시간 집중 플레이에는 횟수 제한이나 강제 대기 시간을 두지 않는다.
- 집중 플레이 누적 `4시간` 안에 메인 기지 4단계, `8시간` 안에 6단계 도달을 목표로 검증한다.
- 6단계 이후 표의 기간은 같은 단계를 시작해 필요한 자원을 얻는 데 걸리는 상한 참고값이다. 달력 잠금이나
  대기 시간이 아니므로 자원을 먼저 모으면 즉시 상승할 수 있다.

| 상승 | 자원 획득 상한 참고 기간 |
| --- | ---: |
| 6→7 | 2일 |
| 7→8 | 3일 |
| 8→9 | 3.5일 |
| 9→10 | 4일 |
| 10→11 | 4.5일 |
| 11→12 | 5일 |

- 12단계 완료가 메인 캠페인의 완료다. 환생, 진행 초기화와 무한 능력치 성장은 사용하지 않는다.
- 완료 뒤에는 16종 수집과 주문 운영을 선택형 반복 목표로 제공한다. 이 목표는 기지·동료 능력치를 올리지 않는다.

## 3. 재화 공급과 소비

| 재화 | 세션 2 주요 공급 | 세션 2 주요 소비 | 안전 경계 | 보유 상한 |
| --- | --- | --- | --- | ---: |
| 돌 | 동굴 현장 채집, 채석장 | 돌 상품, 혼합 상품 | 메인 기지 입고 완료 | 없음 |
| 나무 | 숲 현장 채집, 벌목장 | 혼합 상품 | 메인 기지 입고 완료 | 없음 |
| 코인 | 상품 판매, 주문 보상 | 기지·시설 건설과 강화, 벽 수리, 치료 | 메인 기지 입고 완료 | 없음 |
| 뼈 | 세션 1 생물 결과 | 메인 기지 3→4 이후, 시설 4단계 이상 강화 | 메인 기지 입고 완료 | 없음 |
| 소울 | 세션 1 생물 결과 | 세션 1의 동행·기지 수용량 확장 | 획득 즉시 | 없음 |

- 돌·나무는 기지와 시설 건설 비용으로 사용하지 않는다. 건설은 코인, 높은 단계 강화는 코인과 뼈를 사용한다.
- 메인 기지는 1→2와 2→3에 코인만, 3→4부터 코인과 뼈를 사용한다.
- 시설은 1~3단계에 코인만, 4단계 이상에 코인과 뼈를 사용한다. 주문 게시판은 예외로 1~3단계 모두 코인만 사용한다.
- 벽 수리와 치료는 코인을 지속 소비해 판매 이후에도 코인의 소비 목적을 유지한다.
- 안전 자원은 탐험 패배와 약탈로 잃지 않는다. 판매대 상품, 계산대 코인과 운반 중 코인만 방어 실패의 손실 후보가 된다.

## 5. 시설 단계·비용·효과

### 5.1 상한 규칙

- 공방, 계산대, 채석장, 벌목장, 벽·출입문, 치료소와 감시탑의 최종 상한은 4단계다.
- 방어 야영지는 5단계, 주문 게시판은 3단계, 물류 관리소는 1단계가 최종 상한이다.
- 시설은 공개될 때 1단계다. 이후 메인 기지가 한 단계 오를 때 그 시설 종류의 강화 상한이 1씩 오르며,
  시설별 최종 상한에서 멈춘다.
- 나중에 지은 같은 종류의 2·3호 시설도 현재 시설 종류 상한까지 강화할 수 있다. 건설과 각 강화 비용은 모두 따로 낸다.
- 강화가 잠겨 있거나 비용이 부족하면 어떤 재화도 소비하지 않고 필요한 메인 기지 단계 또는 부족 수량을 표시한다.

### 5.2 건설·활성화 비용

| 대상 | 비용 |
| --- | ---: |
| 채석장 1호 / 2호 / 3호 | 코인 10 / 50,000 / 250,000개 |
| 벌목장 1호 / 2호 / 3호 | 코인 1,000 / 50,000 / 250,000개 |
| 공방 물류 자리 | 코인 10개 |
| 판매 동료 1~5번 자리 | 코인 10 / 500 / 5,000 / 50,000 / 250,000개 |
| 벽·출입문 | 코인 300개 |
| 방어 야영지 | 코인 200개 |
| 치료소 | 코인 500개 |
| 감시탑 | 코인 5,000개 |
| 물류 관리소 | 코인 100,000개 |
| 주문 게시판 | 코인 300,000개 |

### 5.3 강화 비용과 단계 효과

| 시설 | 2단계 비용·효과 | 3단계 비용·효과 | 4단계 비용·효과 | 5단계 비용·효과 |
| --- | --- | --- | --- | --- |
| 공방 | 코인 100개 · 동시 생산 2자리 | 코인 500개 · 3자리 | 코인 3,000개 + 뼈 30개 · 4자리 | - |
| 계산대 | 코인 200개 · 공용 코인 운반 동료 자리 | 코인 1,000개 · 코인 운반량 +50% | 코인 5,000개 + 뼈 50개 · 총 +100% | - |
| 채석장, 각 시설 | 코인 100개 · 작업 대상 10개 | 코인 500개 · 15개 | 코인 3,000개 + 뼈 30개 · 21개 | - |
| 벌목장, 각 시설 | 코인 2,000개 · 작업 대상 10개 | 코인 10,000개 · 15개 | 코인 50,000개 + 뼈 100개 · 21개 | - |
| 벽·출입문 | 코인 1,500개 · 내구도 175 | 코인 7,500개 · 내구도 275 | 코인 40,000개 + 뼈 150개 · 내구도 400 | - |
| 방어 야영지 | 코인 1,000개 · 2명 | 코인 5,000개 · 3명 | 코인 25,000개 + 뼈 100개 · 4명 | 코인 100,000개 + 뼈 300개 · 5명 |
| 치료소 | 코인 2,500개 · 동시 3명 | 코인 12,000개 · 동시 4명 | 코인 60,000개 + 뼈 200개 · 동시 4명, 치료 시간 50% | - |
| 감시탑 | 코인 20,000개 · 정확한 수 | 코인 80,000개 · 종과 원·근거리 구성 | 코인 300,000개 + 뼈 300개 · 예상 벽 피해와 최대 손실 | - |
| 주문 게시판 | 코인 600,000개 · 주문 2칸 | 코인 1,000,000개 · 주문 3칸 | - | - |

- 1단계 효과는 공방 동시 생산 1자리, 채석장·벌목장 작업 대상 5개, 벽 내구도 100, 방어 야영지 1명,
  치료소 동시 2명, 감시탑 규모 정보, 주문 게시판 주문 1칸이다.
- 물류 관리소는 강화하지 않는다. 자동 인력 분배나 순간 이동 효과도 없다.

### 5.4 비콘 투입 시간

- 재화 종류마다 기본 `초당 10개`를 동시에 투입한다.
- 한 재화의 기본 투입 시간이 5초를 넘으면 그 재화의 전체 요구량을 정확히 5초 동안 나누어 투입한다.
- 비용 10개는 1초, 30개는 3초, 50개 이상은 5초가 걸린다. 코인과 뼈를 함께 요구하면 둘을 동시에 진행한다.
- 완료 전에 비콘에서 나가거나 한 재화가 부족하면 임시 투입분을 모두 반환한다. 완료 뒤 다음 단계는
  비콘에서 완전히 나갔다 재진입해야 시작한다.

## 6. 채집·운반·생산 기본값

### 6.1 채석장과 벌목장

| 항목 | 출시 기본값 |
| --- | ---: |
| 시설별 배치 인원 | 채집 동료 1명 |
| 메인 기지까지 거리 | 편도 18칸 |
| 작업 대상 내구도 | 20 |
| 대상 하나 완료 보상 | 돌 또는 나무 1개 |
| 대상별 재생 시간 | 30초 |
| 시설 1/2/3/4단계 대상 수 | 5 / 10 / 15 / 21개 |
| 채석장·벌목장 최대 수 | 종류별 3곳 |

- 동료는 자신의 공격력과 공격 간격으로 작업 대상을 직접 채집한다. 생물 능력치 원본은 세션 1을 따른다.
- 운반 한도가 차거나 모든 작업 대상이 고갈되면 메인 기지로 돌아와 입고한다. 부분 적재 상태도 입고한다.
- 입고 뒤 작업 대상이 없으면 기지에서 기다리고, 하나 이상 재생되면 자동 출발한다.

### 6.2 운반

| 항목 | 출시 기본값 |
| --- | ---: |
| 운반력 1칸 | 자원 1개, 상품 1개 또는 코인 10개 |
| 적재 속도 | 초당 10칸 |
| 하역 속도 | 초당 10칸 |
| 계산대 코인 보관 상한 | 창구당 코인 200개 |

- 계산대 3단계의 +50%, 4단계의 총 +100%는 코인 운반 동료의 기본 운반력에 적용한다. 소수점은 버린다.
- 배치 변경 중인 동료는 현재 운반물을 기존 목적지에 입고한 뒤 새 배치로 이동한다.

### 6.3 공방과 상품

| 상품 | 재료 | 생산 시간 | 판매가 | 공개 |
| --- | --- | ---: | ---: | --- |
| 돌 상품 | 돌 3개 | 30초/개 | 코인 10개/개 | 시작 |
| 혼합 상품 | 돌 2개 + 나무 2개 | 45초/개 | 코인 25개/개 | 기지 4단계 |

| 공방 단계 | 동시 생산 자리 | 완성품 보관 상한 |
| ---: | ---: | ---: |
| 1 | 1개 | 10개 |
| 2 | 2개 | 20개 |
| 3 | 3개 | 30개 |
| 4 | 4개 | 40개 |

- 모든 생산 자리는 현재 선택한 한 상품을 만든다. 상품 변경은 진행 중인 생산을 마친 뒤 다음 생산부터 적용한다.
- 완성품 상한에 도달하면 새 생산을 시작하지 않고, 공방 물류 동료가 상품을 반출하면 자동 재개한다.

## 7. 판매·주문 기본값

### 7.1 손님과 판매

| 창구 수 | 줄 상한 `창구 수×4+3` | 상품 종류별 판매대 상한 | 계산대 코인 상한 |
| ---: | ---: | ---: | ---: |
| 1 | 7명 | 14개 | 코인 200개 |
| 2 | 11명 | 22개 | 코인 400개 |
| 3 | 15명 | 30개 | 코인 600개 |
| 4 | 19명 | 38개 | 코인 800개 |
| 5 | 23명 | 46개 | 코인 1,000개 |

- 각 공개 창구는 `6초마다 손님 1명`을 발생시킨다. 줄이 상한이면 새 도착만 멈추고 자리가 생기면 재개한다.
- 손님은 재고가 없어도 오며, 해금된 상품 중 하나를 균등하게 요청한다. 돌 상품만 해금됐으면 100%,
  혼합 상품도 해금됐으면 각 50%다.
- 손님은 요청 상품이 없어도 무기한 기다린다. 최대 대기 시간과 품절 이탈은 없다.
- 재고와 창구 담당자가 모두 준비되면 판매 시간 없이 즉시 상품 1개를 코인으로 바꾼다.

### 7.2 주문 게시판

| 게시판 단계·주문 칸 | 요구 상품 | 코인 보상 |
| --- | --- | --- |
| 1단계·1번 칸 | 돌 상품 또는 혼합 상품을 번갈아 20개 | 요구 상품 정상 판매 총액의 1.25배 |
| 2단계·2번 칸 | 돌 상품 25개 + 혼합 상품 25개 | 정상 판매 총액의 1.5배 |
| 3단계·3번 칸 | 돌 상품 50개 + 혼합 상품 50개 | 정상 판매 총액의 2배 |

- 판매대 재고를 버튼으로 즉시 부분 납품한다. 납품한 수량은 유지되며 수락한 주문에는 시간 제한이 없다.
- 수락 전 주문은 실제 시간 `6시간`마다 교체하며 오프라인에서도 같은 시간이 흐른다.
- 누적 10·25·50회 완료 시 각각 간판·깃발·은은한 빛의 고정 기지 외형을 해금한다. 능력치와 자유 배치 효과는 없다.

## 8. 약탈·방어·치료 기본값

### 8.1 발생과 구성

| 큰 단계 | 위험도 기준 | 일반 | 엘리트 |
| --- | ---: | ---: | ---: |
| 모닥불 | 100 | 1 | 0 |
| 텐트 | 200 | 2 | 0 |
| 돌 거점 | 300 | 2 | 1 |
| 돌·나무 거점 | 400 | 2 | 2 |
| 판타지 완성 거점 | 500 | 2 | 3 |

- 상품 완성 때 해당 판매가만큼 위험도가 오르고, 시간 경과로 분당 10씩 오른다. 판매하거나 안전 입고해도
  이미 오른 위험도는 줄지 않으며 약탈 종료 때 0으로 초기화한다.
- 첫 약탈은 벽·출입문과 방어 야영지가 모두 완성된 시점부터 정확히 3분 뒤 경보를 시작한다. 가장 약한
  일반 생물 1마리로 고정한다.
- 이후 약탈 종료 때 `40~60분`의 정수 분 하나를 21개 값에서 같은 확률로 정한다. 보호 중에도 위험도는
  계속 오르며, 보호 종료 때 기준 이상이면 바로 경보를 시작한다.
- 경보 시간은 감시탑 단계와 관계없이 60초다. 일반 약탈에 보스는 나오지 않는다.

### 8.2 벽·도난·치료

| 항목 | 출시 기본값 |
| --- | ---: |
| 벽 1/2/3/4단계 내구도 | 100 / 175 / 275 / 400 |
| 벽 수리비 | 내구도 1당 코인 3개 |
| 일반 생물 치료 | 60초 + 코인 20개 |
| 엘리트 생물 치료 | 180초 + 코인 60개 |
| 보스 생물 치료 | 600초 + 코인 200개 |
| 치료소 1/2/3/4단계 동시 치료 | 2 / 3 / 4 / 4명 |
| 치료소 4단계 시간 배율 | 기본 시간의 50% |

- 약탈자는 자신의 운반력 50%를 버린 칸 수만큼 가장 가까운 판매대 상품과 계산대·운반 중 코인을 훔친다.
  상품 1개 또는 코인 10개가 1칸이다.
- 약탈자가 남쪽 경계를 벗어나기 전에 쓰러지면 훔친 물품 전부를 떨어뜨려 회수할 수 있다. 경계를 벗어난
  물품만 최종 손실이다.
- 온라인 치료는 치료 시작 때 안전 코인을 소비한다. 코인이 부족하면 대기열에서 무기한 기다린다.
- 오프라인 치료는 안전 코인을 자동 소비하며, 부족하면 치료를 시작하지 않고 기다린다.

## 9. 오프라인 진행 수치와 종료

- 마지막 접속 뒤 실제 시간 중 최대 `24시간`을 적용한다.
- 배치된 자동화 구간만 온라인과 같은 이동·채집·생산·판매·약탈·치료 속도로 진행한다. 플레이어 직접
  채집·운반·판매·주문 납품은 대신 수행하지 않는다.
- 방어에 성공하면 보호 시간 뒤 다음 약탈도 진행한다. 약탈자가 처음 기지 안에 침입한 약탈은 끝까지
  처리하고, 그 뒤 남은 오프라인 시간에는 추가 경보와 약탈만 중단한다. 생산·판매·치료는 계속한다.
- 로그아웃 전에 안전해진 자원과 오프라인 중 메인 기지에 도착한 코인은 잃지 않는다.
- 로그아웃 때 플레이어 운반물은 출발 지점으로 반환하며 안전 입고로 바꾸지 않는다.
- 오프라인 결과는 경과 시간, 자원 입고, 생산·판매, 안전 코인, 약탈별 결과, 최종 손실, 부상·치료,
  약탈 중단 이유 순으로 표시한다.

## 10. 우선순위·실패·유지 규칙

1. 안전 자원 보호를 가장 먼저 판정한다.
2. 생산 완료와 상품 위험도 증가를 반영한 뒤 판매 가능 여부를 확인한다.
3. 경보가 시작되면 손님·판매를 멈추고, 경보 중 허용 행동을 처리한다.
4. 약탈자는 벽 파괴 뒤 가장 가까운 손실 후보부터 훔친다.
5. 방어 결과 뒤 벽 손상, 부상·치료, 보호 시간과 판매 재개를 반영한다.

- 메인 기지 단계, 시설 단계, 공개 상태, 안전 자원, 주문 진행·완료 횟수와 고정 외형은 세션 종료 뒤 유지한다.
- 재고, 미입고 코인, 작업 대상 재생, 생산·운반, 약탈 위험도·보호 시간, 벽 손상과 치료 대기 상태도
  오프라인 진행으로 이어진다.
- 새 게임에서만 메인 기지 1단계와 시작 시설 상태로 초기화한다. 12단계 이후 진행만 초기화하는 기능은 없다.
- 비용 부족, 보관 상한, 담당 동료 없음, 벽 파괴와 치료 코인 부족은 진행을 멈출 수 있지만 이미 완료된
  진행과 안전 자원을 되돌리지 않는다.

## 11. 상황별 확인 사례

| 구분 | 상황 | 기대 결과 |

| 정상 | 돌 3개가 공방에 있고 생산 자리가 비어 있음 | 30초 뒤 돌 상품 1개가 완성되고 위험도가 10 오른다 |
| 정상 | 재고와 담당자가 있는 창구에 손님 도착 | 대기 시간 없이 상품 1개가 코인으로 바뀐다 |
| 예외 | 손님 요청 상품 재고가 0개 | 손님이 요청을 유지하고 무기한 기다리며 뒤 손님도 한 줄 순서를 유지한다 |
| 예외 | 비콘에 코인과 뼈를 함께 투입 | 두 재화가 동시에 진행되고 긴 쪽도 5초 안에 끝난다 |
| 실패 | 공방 완성품이 상한에 도달 | 새 생산을 시작하지 않고 반출 뒤 자동 재개한다 |
| 실패 | 치료 코인이 부족 | 동료가 이탈하지 않고 대기열에 남으며 부족 코인을 표시한다 |
| 경계 | 위험도가 기준보다 1 낮음 | 보호가 끝나도 경보를 시작하지 않고 위험도 증가를 기다린다 |
| 경계 | 위험도가 기준과 같음 | 보호가 끝났다면 즉시 60초 경보를 시작한다 |
| 오프라인 | 30시간 뒤 복귀 | 24시간만 진행하고 초과 6시간에는 보상·손실을 만들지 않는다 |
| 장기 | 기지 12단계 완료 | 캠페인 완료를 표시하고 초기화 없이 16종 수집과 주문을 계속한다 |

## 12. 검증 필요와 수치 조정 순서

| 검증 | 표본과 조건 | 통과 기준 |
| --- | --- | --- |
| 첫 판매 | 신규 플레이어 10명 | 9명 이상이 시작 후 1~3분 안에 첫 판매 완료, 목표 중앙값 2분 |
| 첫 영입 | 신규 저장 30개 | 27개 이상이 영입 가능한 처치 5회 안에 기회를 보고, 첫 배치를 20분 안에 시도 |
| 집중 성장 | 독립 집중 플레이 3회 | 2회 이상 기지 4단계 4시간 이내, 6단계 8시간 이내 |
| 후반 성장 | 하루 3회×15분과 오프라인을 쓰는 저장 3개 | 6→12 각 단계의 중앙값이 2·3·3.5·4·4.5·5일 이내 |
| 자동화 60분 | 현재 최대 시설과 필요한 동료를 배치 | 공방 재료·판매대 상품·계산대 코인 막힘이 각각 측정 시간의 10% 이하 |
| 첫 방어 | 1단계 벽과 건강한 일반 방어 동료, 10회 | 10회 모두 벽 침입과 영구 이탈 없이 승리 |
| 단계별 방어 | 각 큰 단계 최대 방어 시설, 종 순환 1회 | 자동 방어 침입 10~30%, 직접 방어 침입 0~15% |
| 실패 회복 | 방어 실패 직전 60분 평균 안전 코인 수입 | 수리 또는 치료 시작 비용이 수입의 25% 이하 |
| 오프라인 24시간 | 완전·부분·무방어 자동화 각 저장 3개 | 안전 자원 손실 0, 완전 자동화는 치료비 후 안전 코인 순증가, 첫 침입 뒤 추가 약탈 0 |

- 통과하지 못하면 구조를 자동 변경하지 않는다. 변경안은 `이동·운반 → 생산·손님 → 보관량 → 시설 비용
  → 메인 기지 비용 → 방어 수치` 순서로 한 축씩 검토해 다시 사용자 승인을 받는다.
- 생물 능력치, 영입 확률, 현장 자원과 동료 수용량은 세션 1 원본이므로 이 조정 순서에서 바꾸지 않는다.
