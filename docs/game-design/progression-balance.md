# 진행·경제·밸런스 기획서

> 문서 상태: 검토 중
>
> 담당 범위: 메인 기지 12단계의 비용과 공개 순서, 기지·시설 성장 상한, 모든 재화의 소스와 싱크,
> 생산·판매·약탈·치료·오프라인 진행의 출시 기본값, 장기 목표와 막힘 방지
>
> 규칙 원본: 이 문서는 반복되는 비용·시간·확률·수용량의 단일 원본이다.
>
> 상위 규칙: [`core-gameplay.md`](core-gameplay.md)의 코어 순환과 확정 규칙을 따른다.

## 1. 목적과 범위

### 1.1 플레이어 가치

플레이어가 탐험으로 얻은 돌·나무·뼈·소울을 기지의 다음 선택으로 연결하고, 접속 시간이 짧아도
기지의 변화와 안전 자원의 증가를 확인하게 하는 문서다. 비용을 모아 메인 기지를 한 단계 올릴지,
공방·계산대·방어·치료 중 막힌 흐름을 먼저 보강할지는 플레이어가 선택한다.

### 1.2 포함 범위

- 돌·나무·코인·뼈·소울의 획득, 보관, 소비와 안전 경계
- 메인 기지 1~12단계의 비용, 큰 단계, 네 차례 기지 확장과 공개 순서
- 시설 강화 상한과 공방·계산대·방어 야영지·치료소의 출시 강화 비용
- 동행 수용량·기지 수용량의 시작값, 확장값과 상한
- 파견·물류·생산·판매·약탈·치료·오프라인 진행에 공통으로 쓰는 출시 기본값
- 영입·소울·약탈 발생에 쓰는 확률의 표본 공간과 표시 규칙
- 장기 성장 이후의 반복 목표, 막힘 방지와 플레이테스트 조정 기준

### 1.3 제외 범위

- 생물 종별 이름·외형·세부 능력치와 전투 계산
- 코드, 데이터 컬럼·자료형, 저장 구조·저장 시점의 구현 방법
- 분석 이벤트, 성과 지표, 네트워크·런타임 오류 처리
- 레이아웃 좌표와 최종 색상·생물·건축물 외형

세부 플레이 흐름은 [`base-automation.md`](base-automation.md), 판매와 약탈은
[`sales-defense.md`](sales-defense.md), 첫 사용자 경험과 화면 정보는
[`onboarding-ui.md`](onboarding-ui.md)가 각각 소유한다.

## 2. 상태와 결정 원칙

### 2.1 상태 구분

- **확정**: [`core-gameplay.md`](core-gameplay.md)의 확정 규칙과 이 문서가 소유하는 출시 필수 항목의
  적용 범위다.
- **가정**: 플레이 가능한 출시 기본값을 만들기 위해 우선 채택한 수치다. 표의 `출시 기본값`을 먼저
  적용하고 플레이테스트 결과에 따라 같은 표 안에서 조정한다.
- **검증 필요**: 아래 기본값으로 확인할 질문과 통과 기준이다. 검증 전까지 별도 값으로 대체하지 않는다.
- **미정 없음**: 출시 필수 항목은 모두 기본값·단위·확인 방법을 가진다. 후속 콘텐츠는 이 문서의
  출시 필수 범위에 포함하지 않는다.

### 2.2 결정 순서

1. 메인 기지 단계가 열 수 있는 시설과 계산 창구 수를 확인한다.
2. 플레이어가 선택한 시설의 비용과 현재 시설 강화 상한을 확인한다.
3. 탐험·파견·판매·방어에서 재화가 어느 경계에 있는지 확인한다.
4. 안전 자원은 유지하고, 등짐·판매대·계산대의 안전하지 않은 자원만 위험에 노출한다.
5. 오프라인 진행은 동일한 플레이어 규칙을 최대 24시간 적용한 뒤 결과를 요약한다.
6. 목표 단계에 필요한 자원이 부족하면 가장 짧은 대체 소스와 다음 행동을 표시한다.

동일한 순간에 규칙이 겹치면 `플레이어 패배·약탈 손실 판정 → 안전 자원 경계 확정 → 생산·판매·치료
결과 반영 → UI 요약` 순서로 플레이어 결과를 정한다. 안전 자원은 어떤 실패보다 먼저 보호한다.

## 3. 재화와 안전 경계

| 재화 | 쉬운 뜻 | 주요 소스 | 주요 싱크 | 안전해지는 시점 | 출시 기본 보유 상한 |
| --- | --- | --- | --- | --- | ---: |
| 돌 | 공방과 기지에 쓰는 기본 자원 | 동굴 현장 채집, 채석장 파견 | 돌 상품, 메인 기지·시설 비용 | 메인 기지 입고 완료 | 상한 없음 |
| 나무 | 상위 상품과 기지에 쓰는 자원 | 숲 현장 채집, 숲 벌목 파견 | 돌·나무 상품, 메인 기지·시설 비용 | 메인 기지 입고 완료 | 상한 없음 |
| 코인 | 건설·강화·치료에 쓰는 판매 재화 | 상품 판매 | 메인 기지·시설 건설·강화, 수리, 치료 | 메인 기지 도착 완료 | 상한 없음 |
| 뼈 | 생물 처리와 높은 단계 강화에 쓰는 재화 | 생물 재화 선택, 직접 방어 결과 | 높은 단계 강화, 일부 시설 건설·강화 | 메인 기지 입고 완료 | 상한 없음 |
| 소울 | 수용량 확장에 쓰는 희귀 재화 | 생물 등급별 확률 보상, 보스 보상 | 동행·기지 수용량 확장 | 획득 즉시 | 상한 없음 |

- 돌·나무·뼈는 [`core-gameplay.md`](core-gameplay.md#5-등짐-입고와-탐험-실패)의 등짐을 거친다.
  등짐을 잃는 상황에서는 이 세 재화만 잃을 수 있다.
- 코인은 판매 직후 계산대와 운반 중인 상태에서는 안전하지 않으며, 메인 기지 도착 뒤 안전 자원이
  된다. 오프라인 결과도 같은 경계를 사용한다.
- 소울은 획득 즉시 안전 자원이므로 등짐·약탈·플레이어 패배의 대상이 아니다.
- 안전 자원 상한은 출시 범위에서 두지 않는다. 자원 더미의 외형 구간은 실제 수량을 대체하지 않는다.

## 4. 출시 기본값: 획득·생산·판매·방어

아래 값은 이 문서가 소유하는 반복 수치다. 다른 문서는 숫자를 복사하지 않고 이 절을 참조한다.

### 4.1 플레이어 현장 채집과 생물 결과

| 항목 | 출시 기본값 | 단위 | 적용 규칙 |
| --- | ---: | --- | --- |
| 플레이어 기본 운반력 | 12 | 개 | 공유 등짐의 시작 한도이며 탐험 동료 운반력은 여기에 더한다 |
| 돌·나무 현장 채집 | 1 | 개/2초 | 자원 채집 대상이 범위에 있는 동안 자동으로 적용한다 |
| 일반 생물 재화 선택 뼈 | 2 | 개/마리 | 영입하지 않고 재화를 선택했을 때 지급한다 |
| 엘리트 생물 재화 선택 뼈 | 5 | 개/마리 | 영입하지 않고 재화를 선택했을 때 지급한다 |
| 보스 생물 재화 선택 뼈 | 15 | 개/마리 | 보스는 재화 선택 시 항상 지급한다 |
| 일반 생물 소울 확률 | 10 | % | 재화 선택 시 독립 추첨 1회, 성공하면 1개 지급 |
| 엘리트 생물 소울 확률 | 25 | % | 재화 선택 시 독립 추첨 1회, 성공하면 2개 지급 |
| 보스 생물 소울 | 5 | 개/마리 | 재화 선택 시 항상 지급 |
| 일반·엘리트 생물 영입 확률 | 40 | % | 쓰러뜨릴 때 1회 추첨하며 두 등급에 같은 확률 적용 |
| 첫 영입 온보딩 보정 | 100 | %/다음 동굴 일반 생물 | 첫 영입 전 영입 추첨이 2회 실패하면 1회만 적용 |
| 보스 생물 재등장 시간 | 20 | 분/마리 | 같은 지역의 같은 보스가 다시 나타나는 기본 시간 |

- 확률은 모두 0~100% 범위의 백분율이며 화면에는 정수 백분율로 표시한다.
- 일반·엘리트 생물의 영입 추첨이 성공했을 때만 `영입`과 `재화` 선택을 보여 준다. 플레이어가
  `재화`를 택하면 해당 행의 뼈·소울을 적용하고, `영입`을 택하면 재화 결과를 지급하지 않는다.
- 보스 생물은 [`core-gameplay.md`](core-gameplay.md#62-쓰러뜨린-생물의-결과)의 확정 규칙대로
  영입·재화 선택을 항상 제공한다. 보스 재등장 시간은 출시 기본값 20분이며, 지역별 차이를 두지 않는다.
- 소울 확률은 뼈 지급과 별개의 1회 추첨이다. 성공한 소울은 개별 오브젝트가 아니라 즉시 안전 자원으로
  처리한다.

### 4.2 파견과 실제 운반

| 파견 | 출시 기본 공급 | 단위 | 일꾼 1명 기본 운반량 | 현장 보유 상한 |
| --- | ---: | --- | ---: | ---: |
| 채석장 | 4 | 돌/60초 | 4개/회차 | 12개 |
| 숲 벌목 파견 | 4 | 나무/75초 | 4개/회차 | 12개 |

- 공급 회차가 끝나면 해당 파견의 현장 더미가 늘고, 일꾼은 더미에 도착해 자신의 운반력까지 싣는다.
- 일꾼은 파견 장소에서 메인 기지까지 실제로 이동한 뒤 입고한다. 이동 중 자원은 안전 자원이 아니며,
  일꾼이 약탈에 휘말려 자원을 잃는 상황은 [`base-automation.md`](base-automation.md#7-파견과-실제-물류)의
  실패 규칙을 따른다.
- 현장 보유 상한에 도달하면 공급은 멈추고, 일꾼이 운반을 마쳐 빈자리가 생긴 뒤 다시 시작한다.
- 숲 벌목 파견은 메인 기지 4단계에서 노출한다. 숲 현장 채집과 고정 포탈의 이용은 이 조건과 무관하다.
- 파견 자리를 추가로 열 때마다 일꾼 한 명을 추가 배치할 수 있다. 기본값은 메인 기지 1단계에서
  채석장 1자리, 4단계에서 숲 벌목 1자리, 7단계에서 채석장·숲 벌목 각 1자리 추가다.

### 4.3 공방과 판매

| 상품 종류 | 재료 | 생산 시간 | 판매가 | 처음 사용 가능한 메인 기지 단계 |
| --- | --- | ---: | ---: | ---: |
| 돌 상품 | 돌 2개 | 20초/개 | 코인 3개/개 | 1단계 |
| 돌·나무 상품 | 돌 2개 + 나무 1개 | 30초/개 | 코인 6개/개 | 4단계에서 공방 2단계 강화 완료 |

| 판매 항목 | 출시 기본값 | 단위 |
| --- | ---: | --- |
| 손님 1명 응대 시간 | 4 | 초/명 |
| 손님 도착 간격 | 8 | 초/명 |
| 손님 최대 대기 시간 | 45 | 초/명 |
| 시작 대기 줄 상한 | 4 | 명 |
| 계산 창구 5개일 때 대기 줄 상한 | 12 | 명 |
| 공방 생산 대기 슬롯 시작값 | 1 | 개 |

- 손님 대기 줄 상한은 `계산 창구 수 1개당 2명 + 추가 2명`으로 정하며, 시작 1개에서 4명,
  최대 5개에서 12명이다. 이 식은 다른 문서에서 반복하지 않는다.
- 공방 생산 대기 슬롯은 시작 1개이며 공방 3단계와 5단계 강화에서 각각 1개씩 늘어난다.
- 판매 가능한 상품이 하나일 때 손님 요청 선택 확률은 100%다. 두 상품이 모두 재고에 있을 때는
  각 상품을 50%로 독립 선택하지 않고, 판매 가능한 종류 목록에서 한 종류를 균등하게 한 번 선택한다.
- 손님이 줄에 들어온 뒤 원하는 상품이 품절되어도 요청 말풍선과 줄 순서를 유지한다. 대기 시간 45초가
  먼저 끝나면 상품을 소비하지 않고 줄을 떠난다.
- 생산 시간과 응대 시간은 실제 시간이다. 앱을 꺼도 오프라인 진행의 누적 시간 안에서 흐른다.

### 4.4 공통 건설·시설 효과

| 항목 | 출시 기본값 | 단위 | 적용 규칙 |
| --- | ---: | --- | --- |
| 비콘 재화 투입 속도 | 1 | 개/초/재화 종류 | 플레이어가 비콘 위에 머무는 동안 필요한 재화 종류마다 적용 |
| 방어 야영지 출동 준비 시간 | 5 | 초/약탈 | 방어 경보 뒤 방어 동료가 출입문에 도착해 전투를 시작하기 전의 준비 시간 |

- 같은 시설의 비율 효과는 기본값에 더해 적용한다. 계산대 3단계와 5단계의 운반력 증가는 합계 50%이며,
  비율을 서로 곱하지 않는다.
- 공방 생산 시간 단축, 손님 응대 시간 단축, 치료 시간 단축도 같은 종류의 효과를 중복해서 곱하지 않고
  합산한다. 현재 출시 표에 같은 종류의 추가 효과는 없다.

### 4.5 약탈과 치료

| 항목 | 출시 기본값 | 단위 | 적용 규칙 |
| --- | ---: | --- | --- |
| 약탈 경보 최소 간격 | 180 | 초 | 직전 약탈 종료부터 다음 경보 조건 검사까지의 보호 시간 |
| 약탈 조건 확인 간격 | 30 | 초 | 보호 시간이 끝난 뒤 조건을 확인하는 주기 |
| 약탈 발생 확률 | 25 | %/확인 | 양쪽 방어 시설 완성, 안전하지 않은 가치 20코인 이상일 때 1회 추첨 |
| 첫 방어 온보딩 보정 | 100 | %/첫 조건 확인 | 두 시설 완성 뒤 처음으로 기준 가치에 도달한 확인 1회에만 적용 |
| 약탈 경보 최소 안전하지 않은 가치 | 20 | 코인 환산 | 판매대 상품 판매가 합계 + 계산대·운반 중 코인 |
| 실패 시 상품 손실 | 50 | % | 벽·출입문이 파괴된 약탈 종료 때 판매대 재고의 절반을 버림해 잃는다 |
| 실패 시 코인 손실 | 50 | % | 같은 조건에서 안전하지 않은 코인의 절반을 버림해 잃는다 |
| 벽·출입문 최대 체력 | 100 | 내구도 | 손상과 수리의 기준값 |
| 수리 비용 | 1 | 코인/내구도 | 수리 비콘에 투입하면 같은 내구도를 회복한다 |
| 치료소 치료 시간 | 60 | 초/동료 | 치료 시작부터 완료까지의 실제 시간 |
| 치료 비용 | 5 | 코인/동료 | 치료 시작 시 한 번 지불하며 부족하면 대기열에서 기다린다 |

- `안전하지 않은 가치`는 새로운 공식 용어가 아니라 약탈 조건을 설명하는 표시 문구다. 화면에는
  상품가와 미입고 코인을 분리해 보여 주고, 합계가 20코인 이상인지 함께 표시한다.
- 약탈 경보는 조건을 만족한 확인 시점에 25%로 1회 추첨한다. 실패하면 다음 30초 확인으로 넘어가며,
  안전하지 않은 가치가 기준 아래로 내려가면 추첨하지 않는다.
- 약탈 무리의 수는 안전하지 않은 가치가 20~39코인이면 1마리, 40~79코인이면 2마리,
  80코인 이상이면 3마리다. 최대 3마리이며, 실제 생물 능력치는 콘텐츠 원본이 소유한다.
- 벽·출입문이 파괴되지 않으면 상품·코인 손실은 0이다. 파괴되면 판매대 상품과 안전하지 않은
  코인에만 각 50% 손실을 적용한다. 메인 기지에 입고된 자원과 소울은 손실 대상이 아니다.
- 치료소는 한 번에 1명을 치료하고, 치료 대기열에는 인원 제한을 두지 않는다. 치료 중인 동료는
  방어 동료로 출동하지 않지만 기지 수용량은 계속 사용한다.

### 5.1 메인 기지 단계 비용

- 메인 기지 단계 비용은 비콘에 투입하는 안전 자원이다. 비콘의 투입·중도 이탈·반환은

  [`base-automation.md`](base-automation.md#5-비콘-건설강화수리-흐름)를 따른다.
- 단계가 완료되는 즉시 외형, 시설 강화 상한과 해당 단계의 계산 창구 수를 적용한다.
- 1차·2차·3차·4차 기지 확장은 각각 1→2, 3→4, 6→7, 9→10 완료 시 발생한다. 네 번 모두 새 공간,
  고정 시설 자리와 열린 단면을 공개한다.
- 1차 확장 공간에는 치료소 전용 자리가 노출된다. 치료소 건설 자체는 코인 비용을 별도로 낸다.

### 5.2 시설 건설과 강화 비용

| 시설 | 건설 또는 시작 상태 | 강화 단계 | 비용 | 효과 |
| --- | --- | ---: | --- | --- |
| 공방 | 1단계에 1단계로 시작 | 2 | 코인 15개 | 돌·나무 상품 생산 공개 |
| 공방 | - | 3 | 코인 35개 | 생산 대기 슬롯 1개 추가 |
| 공방 | - | 4 | 코인 60개 + 뼈 5개 | 생산 시간 10% 단축 |
| 공방 | - | 5 | 코인 100개 + 뼈 10개 | 생산 대기 슬롯 1개 추가 |
| 계산대 | 1단계에 1단계로 시작 | 2 | 코인 25개 | 코인 운반 전용 일꾼 자리 1개 공개 |
| 계산대 | - | 3 | 코인 50개 | 코인 운반 일꾼 운반력 25% 증가 |
| 계산대 | - | 4 | 코인 90개 + 뼈 10개 | 손님 응대 시간 10% 단축 |

| 방어 야영지 | 첫 판매 뒤 건설 비콘 공개 | 1 | 코인 40개 | 방어 동료 배치와 출동 공개 |
| 방어 야영지 | - | 2 | 코인 80개 + 뼈 10개 | 방어 동료 회복 후 출동 준비 시간 10% 단축 |
| 치료소 | 1차 기지 확장 때 자리 공개 | 1 | 코인 50개 | 온라인·오프라인 치료 시작 |
| 치료소 | - | 2 | 코인 90개 + 뼈 15개 | 치료 시간 15% 단축 |
| 벽·출입문 | 첫 판매 뒤 건설 비콘 공개 | 1 | 코인 60개 | 약탈 무리의 기지 진입을 막는 방어선 |
| 벽·출입문 | - | 2 | 코인 120개 + 뼈 15개 | 최대 체력 25% 증가 |

- 위 시설의 실제 강화 가능 최고 단계는 현재 메인 기지 세부 단계와 시설의 해금 상태 중 낮은 쪽이다.
  즉, 메인 기지 단계보다 높은 시설 강화는 비활성화한다.
- 메인 기지 단계가 오를 때 현재 해금된 시설의 강화 상한이 1단계씩 오른다는 코어 규칙을 적용하되,
  공방·계산대는 출시 최대 5단계, 방어 야영지·치료소·벽·출입문은 출시 최대 2단계에서 상한을
  멈춘다. 위 표에 없는 추가 효과는 출시 범위에 넣지 않는다.
- 계산 창구 수는 계산대 시설 강화가 아니라 메인 기지의 큰 단계가 결정한다. 계산대 강화는 상품·코인
  흐름의 효율만 바꾼다.
- 벽·출입문과 창구 셔터의 역할을 섞지 않는다. 셔터는 비용·체력·강화가 없고, 벽·출입문만 비용과
  손상 상태를 가진다.

## 6. 수용량과 장기 성장

### 6.1 동료 수용량

| 수용량 | 시작값 | 출시 최대값 | 확장 단위 | 확장 비용 순서 |
| --- | ---: | ---: | --- | --- |
| 동행 수용량 | 1명 | 8명 | 1명 | 소울 2, 4, 6, 10, 15, 22, 30개 |
| 기지 수용량 | 2명 | 24명 | 1명 | 소울 2, 4, 6, 10, 15, 22, 30, 40, 52, 68, 86, 108, 134, 164, 198, 236, 278, 324, 374, 428, 486, 548개 |

- 확장 비용 순서는 시작값 다음 칸부터 적용하며, 각 값의 단위는 소울 개수다.
- 동행 수용량은 탐험 편성 한도, 기지 수용량은 영입 후 보유·배치 한도다. 영입 선택은 두 한도가
  모두 남아 있을 때만 활성화한다.
- 기지 수용량이 가득 차도 기존 동료는 이탈하지 않는다. 영입만 잠그고, 소울 확장·기존 동료의
  재배치·재화 선택을 다음 행동으로 안내한다.
- 방어 동료가 부상 또는 치료 중이어도 기지 수용량을 사용한다. 치료 완료 뒤 자동 복귀한다.

### 6.2 장기 목표

1. **초기 목표**: 첫 생물을 영입해 일꾼으로 배치하고 돌 상품 1개를 판매한다.
2. **중기 목표**: 방어 시설 두 개를 완성해 약탈을 견디고, 공방·계산대·치료소를 강화한다.
3. **장기 목표**: 메인 기지 12단계, 동행 수용량 8명, 기지 수용량 24명을 달성하고 16종 생물의
   영입 선택을 반복한다.
4. **최종 성장 이후 반복 목표**: 안전 자원을 모아 시설 강화 상한 안에서 공방·계산대·방어·치료의
   조합을 바꾸고, 생물 영입·재화 선택·파견 배치를 바꿔 더 짧은 접속 시간에 다음 메인 기지 단계의
   비용을 모으는 운영을 반복한다.

최종 단계 이후 새 단계나 능력치형 도감 보너스를 추가하지 않는다. 새로운 생물 종이나 새 상품은
출시 후 별도 콘텐츠 기획으로 다루며, 이 문서의 출시 필수 목표를 대체하지 않는다.

## 7. 오프라인 진행의 경제 규칙

- 마지막 접속 이후 경과한 실제 시간 중 `최대 24시간`만 적용한다. 24시간을 넘은 경과분은 누적하지
  않는다.
- 파견 생산, 일꾼 운반, 공방 생산, 손님 판매, 약탈, 치료는 온라인과 같은 비용·시간·확률을 사용한다.
  플레이어의 현장 탐험·자동 공격·현장 채집은 오프라인으로 진행하지 않는다.
- 메인 기지에 입고된 돌·나무·뼈·코인은 안전 자원으로 유지한다. 소울은 획득 즉시 유지한다.
- 오프라인 약탈에서는 영입 선택을 만들지 않고, 약탈 결과의 뼈·소울만 자동 안전 보관한다.
- 오프라인 방어 실패 때는 로그아웃 뒤 생산된 상품과 메인 기지에 도착하지 않은 코인에만 손실을
  적용한다. 오프라인 방어에서 쓰러진 방어 동료는 영구 이탈하지 않고 치료 대기열에 들어간다.
- 결과 화면은 `적용 시간 → 입고된 자원 → 생산·판매 → 약탈·손실 → 부상·치료 → 현재 부족 항목`
  순으로 요약한다. 세부 화면과 시각 표현은 [`onboarding-ui.md`](onboarding-ui.md#7-오프라인-복귀-요약)가
  소유한다.

## 8. 막힘 방지와 밸런스 기준

### 8.1 공급·소비 기준

- 첫 상품까지는 돌만 필요하도록 유지한다. 첫 공방 생산은 돌 2개와 20초만 사용하며 나무·뼈·소울을
  요구하지 않는다.
- 첫 방어 시설 건설 전까지는 플레이어 현장 채집과 첫 일꾼의 채석장 파견만으로 돌 상품을 반복할 수
  있어야 한다. 첫 방어 건설 비용은 첫 판매 코인으로 모으는 구조를 기준으로 한다.
- 공방의 돌·나무 상품은 코인 수입을 높이지만 숲 벌목 파견, 메인 기지 4단계와 공방 2단계가 모두
  필요하다. 나무가 부족해도 돌 상품은 계속 선택할 수 있다.
- 소울은 수용량 확장 외에는 소비하지 않는다. 소울이 부족해도 이미 보유한 동료의 역할 변경,
  생산·판매·방어를 막지 않는다.
- 뼈는 높은 단계 강화의 보조 재화다. 뼈가 부족해도 코인만 쓰는 낮은 단계 강화와 돌 상품 판매는
  유지한다.

### 8.2 조정 기준

| 확인 질문 | 출시 기본값 통과 기준 | 조정 우선순위 |
| --- | --- | --- |
| 첫 생물 영입까지 너무 오래 걸리는가? | 첫 3회 탐험 안에 영입 선택을 보고, 10분 이내 첫 일꾼 배치를 시도한다 | 현장 채집 시간 → 영입 확률 → 첫 비용 순 |
| 첫 판매가 막히는가? | 첫 영입 뒤 5분 이내 돌 상품 재고 1개와 코인 3개가 생긴다 | 파견량 → 생산 시간 → 손님 응대 시간 순 |
| 첫 약탈이 기지를 멈추는가? | 첫 약탈 실패 뒤에도 돌 상품 생산 또는 벽 수리 중 하나를 즉시 선택할 수 있다 | 약탈 최소 가치 → 손실률 → 경보 간격 순 |
| 장기 단계가 과도하게 늘어지는가? | 일반적인 하루 3회 접속에서 7일 안에 메인 기지 4단계에 도달할 수 있다 | 코인 소스 → 단계 비용 → 뼈 요구량 순 |
| 오프라인 복귀가 손실만 남기는가? | 24시간 미접속 뒤에도 안전 자원 증가 또는 치료 진행 중 하나를 확인한다 | 파견 운반량 → 약탈 확률 → 손실률 순 |

위 기준은 플레이테스트로 확인할 값이다. 통과하지 못해도 새로운 재화를 만들지 않고, 같은 원본 표의
값만 조정한다.

## 9. 유지·초기화와 예외

- 메인 기지 단계, 안전 자원, 보유 동료·수용량, 시설 강화 단계, 해금한 판매·방어·치료 시설은
  세션이 끝나도 유지되는 플레이어 진행이다.
- 등짐, 파견 현장 더미의 아직 입고되지 않은 자원, 판매대 재고, 계산대와 운반 중인 코인,
  약탈 경보·대피·창구 셔터의 현재 상태는 진행 중인 운영 상태로 취급한다.
- 플레이어 패배 때 등짐만 잃고 안전 자원·소울·메인 기지 단계는 유지한다.
- 약탈 실패 때 판매대 상품과 메인 기지에 도착하지 않은 코인만 위 표의 손실을 적용하고, 벽·출입문
  손상과 부상은 치료·수리 대상으로 남긴다.
- 비콘의 일부 투입분 반환, 영입 선택 취소, 손님 대피와 약탈 종료 후 복귀는 각각
  [`core-gameplay.md`](core-gameplay.md#9-비콘과-비용-규칙),
  [`core-gameplay.md`](core-gameplay.md#62-쓰러뜨린-생물의-결과),
  [`sales-defense.md`](sales-defense.md#6-약탈-경보방어-결과)의 규칙을 따른다.
- 새 게임에서는 메인 기지 1단계, 동행 수용량 1명, 기지 수용량 2명, 공방·판매대·계산대 시작 상태로
  돌아간다. 이후 진행 결과를 유지한 채 초기화하는 선택은 출시 범위에 넣지 않는다.

## 10. 화면에 보여 줄 경제 정보

- 모든 비용은 `현재 보유량/필요량`과 재화 아이콘으로 표시한다. 부족한 항목은 `돌 2개 부족`처럼
  남은 수량을 함께 표시한다.
- 확률은 `40%`처럼 정수 백분율로 표시하며, 보스처럼 항상 가능한 선택은 `100%`로 표시한다.
- 시간은 `20초`, `1분`처럼 실제 시간을 사용하고, 오프라인 요약은 `적용 24시간`처럼 상한을
  명시한다.
- 수용량은 `동행 1/1`, `기지 2/2`처럼 서로 분리해 표시한다.
- 안전하지 않은 상품·코인과 안전 자원을 같은 숫자로 합치지 않는다. 판매대와 계산대에는 각각 현재
  수량과 `메인 기지 입고 전` 상태를 표시한다.

## 12. 검증 필요 항목과 완료 조건

### 12.1 플레이테스트 검증

- 첫 영입·첫 판매·첫 방어까지의 목표 시간이 위 조정 기준을 통과하는지 확인한다.
- 20초·30초 생산과 4초 응대가 세로 화면에서 자동 물류를 읽기 쉽게 만드는지 확인한다.
- 25% 약탈 추첨과 50% 손실이 방어 동료를 배치할 이유를 만들되, 첫 실패 뒤 재시도를 막지 않는지 확인한다.
- 24시간 오프라인 결과가 접속 보상처럼 느껴지면서도 안전 자원과 위험 자원을 구분하는지 확인한다.
- 소울 확장 비용이 동료 영입 선택을 지나치게 막지 않는지, 기지 수용량 24명이 장기 반복에 충분한지 확인한다.

### 12.2 문서 완료 조건

- 출시 필수 비용·시간·확률·수용량은 모두 위 표에 기본값과 단위가 있다.
- 모든 재화에 최소 하나의 소스와 싱크가 있고, 약탈·패배에서 안전 경계가 명확하다.
- 메인 기지 12단계의 비용, 큰 단계, 계산 창구 수와 네 차례 확장이 빠지지 않았다.
- 정상·부족·경계·실패·오프라인 확인 사례를 모두 통과시킬 수 있다.
- 검증 필요 항목은 기본값과 확인 방법을 가진다. 출시 필수 범위에 미정 항목은 없다.
