# Dino TD 궁극 카드 명세

> 문서 상태: 확정
>
> 적용 범위: 주력 타워 6종의 궁극 카드 12종과 전술 궁극 가시 방벽의 기능·전투 적용 규칙
>
> 카드 생성 원본: `card-draw-rules.md`
>
> 전투 판정 원본: `combat-system-rules.md`
>
> 공식 용어 기준: `terminology.md`

## 1. 목적과 범위

이 문서는 궁극 카드가 주력 타워의 자동 전투를 어떻게 강화하는지 정의하는 단일 원본이다. 궁극의 등장 확률·후보 제외·선택 제한은 `card-draw-rules.md`, 기본 공격·피해·장갑·상태 효과의 공통 판정은 `combat-system-rules.md`를 따른다.

목재·방벽 경제, 스테이지별 맵·웨이브 구성, 구현용 클래스와 데이터 구조는 포함하지 않는다.

## 2. 공통 규칙

- 궁극 카드를 선택하면 현재 및 이후 건설되는 같은 종류의 모든 타워가 해당 궁극을 자동으로 사용한다.
- 플레이어가 직접 누르는 궁극 버튼, 공통 비용, 공통 재사용 대기시간과 공통 판당 발동 제한은 사용하지 않는다.
- 궁극은 기본 공격을 없애지 않고 기본 공격을 강화하거나 후속 공격을 추가한다.
- 기본 직접 피해와 기존 상태 효과 적용을 끝낸 뒤 살아 있는 공룡에게 궁극 후속 효과를 적용한다.
- 궁극은 관련 일반·고급 등급 업그레이드 카드가 바꾼 현재 피해·속도·범위·상태 효과 수치를 반영한다.
- 순간 직접 피해와 순간 폭발은 장갑을 적용하고, 지속 피해는 장갑을 무시한다.
- 궁극 획득은 한 판 종료까지 유지한다. 발동 준비, 적중 누적, 집중 단계와 진행 중 궁극 효과는 웨이브 종료 시 제거하고 다음 웨이브에서 처음부터 시작한다.
- 후보로 확정한 공룡이 효과 적용 전에 처치되면, 카드별로 재탐색을 명시한 경우가 아니면 다른 공룡을 다시 찾지 않는다.
- 거리 비교가 같으면 `관문까지 남은 경로 거리 → 먼저 출현한 공룡` 순으로 결정한다.

## 3. 건 타워

### 3.1 오버드라이브

- 웨이브 시작 후 게임 시간 10초, 20초, 30초처럼 10초마다 자동 발동한다.
- 발동 후 4초 동안 공격 속도 증가율에 `+100%p`를 더한다.
- 공격 대상이 없어도 웨이브 게임 시간을 기준으로 발동하고 지속시간이 흐른다.
- 일반 카드의 공격 속도 증가율과 기본 공격 속도 기준으로 합산한다.
- 웨이브 종료 시 진행 중인 효과를 즉시 끝내고 다음 웨이브의 시간을 0초부터 센다.

### 3.2 도탄 탄환

- 기본 탄환과 `추가 탄환`의 각 탄환이 공룡에게 적중한 뒤 도탄을 한 번 발생시킨다.
- 첫 적중 위치를 중심으로 건 타워의 현재 최종 공격 사거리 안에 있는 가장 가까운 다른 공룡 1마리를 고른다.
- 도탄은 원래 탄환 현재 피해의 70%를 별도 직접 피해로 주며 장갑과 장갑 무시를 적용한다.
- 원래 공룡에게 돌아오거나 두 번째 공룡 이후로 이어지지 않는다.
- 후보가 없거나 확정한 후보가 먼저 처치되면 피해 없이 종료한다.

## 4. 블레이드 타워

### 4.1 칼날 폭풍

- 획득 즉시 현재 칼날 수에 4개를 더하고 한 판 동안 유지한다.
- 회전 속도 증가율에 `+100%p`를 더한다.
- `추가 칼날`과 `회전 속도 증가` 카드로 바뀐 현재 수치에 각각 합산한다.

### 4.2 귀환 칼날

- 각 블레이드 타워는 웨이브 시작 또는 직전 귀환 완료 후 게임 시간 5초를 준비한다.
- 준비를 마쳤을 때 현재 최종 공격 반경 안에서 관문에 가장 가까운 공룡 방향으로 자동 발동한다. 공룡이 없으면 준비 완료 상태를 유지하고 공룡이 들어오는 즉시 발동한다.
- 발동 순간 정한 직선 방향으로 현재 최종 공격 반경만큼 0.2초 동안 이동하고 같은 경로로 0.2초 동안 돌아온다.
- 처음 방향을 정한 공룡이 처치되거나 범위를 벗어나도 경로를 바꾸지 않는다.
- 판정 폭은 현재 칼날 판정 지름을 사용하며 `칼날 크기 증가`를 반영한다.
- 공룡 한 마리는 출발 중 1회, 귀환 중 1회까지 각각 현재 칼날 피해의 100%를 직접 피해로 받는다.
- 귀환 완료 후 다음 5초 준비를 시작한다.

## 5. 캐논 타워

### 5.1 집속탄

- 각 포탄의 기본 폭발 처리가 끝난 뒤 소형 폭발 4개를 동시에 만든다.
- 소형 폭발 중심은 기본 폭발 중심에서 현재 최종 폭발 반경만큼 떨어진 상·하·좌·우 지점이다.
- 각 소형 폭발은 현재 최종 폭발 반경의 50%, 현재 폭발 피해의 40%를 사용한다.
- 공룡은 소형 폭발마다 최대 한 번씩 피해를 받을 수 있다.
- 같은 포탄이 새로 부여한 장갑 감소는 기본 폭발과 소형 폭발 전체가 끝난 뒤 다음 공격부터 적용한다.
- `연속 포격`의 기본 포탄과 모든 추가 포탄에 각각 적용한다.

### 5.2 공성탄

- 모든 포탄의 현재 최종 폭발 반경을 50%로 줄인다.
- 포탄 직격 피해 증가율에 `+200%`를 더해 카드 적용 전 기본값 대비 총 3배가 되게 하고, 직격에 장갑 무시 `30%p`를 적용한다.
- 폭발 피해량과 폭발의 장갑 계산은 바꾸지 않는다.
- `연속 포격`의 기본 포탄과 모든 추가 포탄에 각각 적용한다.
- 공격 대상이 포탄 도착 전에 처치돼도 고정된 예정 위치에서 기존 폭발과 궁극 효과를 처리한다.

## 6. 파이어 타워

### 6.1 화염 폭풍

- 각 기본 공격이 공격 순간의 타워 위치와 방향에 고정된 화염 폭풍 영역을 생성한다.
- 영역은 현재 최종 화염 사거리와 끝 폭의 150%이며 3초 동안 유지한다.
- 같은 파이어 타워는 영역 하나만 유지한다. 다음 기본 공격이 기존 영역을 제거하고 새 방향에 다시 생성한다.
- 생성 1초 후부터 1초마다 현재 직접 화염 피해의 100%를 지속 피해로 준다.
- 각 지속 피해 후 살아남은 공룡에게 현재 화상을 적용하거나 지속시간을 갱신하고 화염 적중 횟수를 1회 올린다.

### 6.2 전염 화상

- 화상 상태인 공룡이 원인과 관계없이 처치되면 처치 위치에서 전염을 발생시킨다.
- 파이어 타워의 현재 최종 사거리 50% 안에서 가까운 공룡 최대 3마리에게 현재 화상 피해와 전체 지속시간을 새로 적용한다.
- 이미 화상인 공룡도 후보에 포함하며 선택되면 현재 수치로 지속시간을 갱신한다.
- 전염으로 화상을 얻은 공룡도 처치 시 같은 규칙으로 다시 전염한다.
- 전염 적용 순간에는 피해를 주지 않으므로 전염만으로 같은 순간 처치가 발생하지 않는다.

## 7. 레이저 타워

### 7.1 프리즘 광선

- 주 광선의 첫 공격 대상 중심으로 레이저 타워의 현재 최종 사거리 50% 안에 있는 가까운 다른 공룡 최대 2마리를 고른다.
- 각 추가 광선은 현재 기본 광선 피해의 60%를 별도 직접 피해로 주고 다시 분산하지 않는다.
- `보조 광선` 카드가 있으면 프리즘 2갈래와 보조 광선 1개가 각각 발동한다. 같은 공룡도 서로 다른 효과로 한 번씩 맞을 수 있다.

### 7.2 과충전 광선

- 같은 공격 대상에게 기본 광선을 5회 적중하면 다음 공격을 과충전 광선으로 바꾸고 적중 횟수를 0으로 초기화한다.
- 공격 대상을 잃거나 바꾸면 과충전 적중 횟수를 즉시 0으로 초기화한다.
- 과충전 광선은 현재 기본 광선 피해의 250%, 현재 광선 폭의 200%, 기존과 같은 현재 최종 사거리를 사용해 직선상의 공룡을 관통한다.
- `집중 광선`이 있으면 현재 집중 단계 피해 증가를 적용한다. 공격 대상이 유지되면 과충전 발동 뒤에도 집중 단계를 유지한다.

## 8. 일렉트릭 타워

### 8.1 연쇄 폭풍

- 현재 추가 연쇄 대상 수에 4마리를 더한다.
- 일반 카드까지 반영한 현재 연쇄 거리를 50% 늘린다.
- 모든 연쇄 단계는 최초 전격과 같은 현재 피해를 사용하며 연쇄 피해 감소율을 0%로 만든다.
- 대상 선택과 한 공격 안의 중복 방지는 기본 연쇄 전격 규칙을 따른다. 새 공룡이 없으면 남은 연쇄 수를 사용하지 않고 종료한다.

### 8.2 과부하

- 최초 대상과 각 연쇄 대상이 전격 직접 피해를 받을 때 해당 공룡의 과부하 횟수를 1회 올린다.
- 모든 일렉트릭 타워가 공룡별 과부하 횟수를 공유한다.
- 5회에 도달하면 횟수를 0으로 초기화하고, 공룡이 살아 있으면 해당 위치를 중심으로 현재 연쇄 거리 50% 안에 순간 폭발을 일으킨다.
- 폭발은 중심 공룡을 포함한 범위 안 공룡에게 현재 최초 전격 피해의 200%를 직접 피해로 준다.
- 다섯 번째 전격 피해 직후 폭발을 처리하고 남은 연쇄 전격을 계속한다.
- 폭발 피해는 과부하 횟수와 감전 경직 횟수를 올리지 않는다.
- 과부하와 감전 경직은 별도 횟수이며, 한 전격 적중은 두 횟수를 각각 올릴 수 있다. 어느 한쪽의 발동과 초기화는 다른 쪽에 영향을 주지 않는다.

## 9. 전술 궁극

### 9.1 가시 방벽

- 획득하면 현재 설치된 방벽과 이후 설치·재건하는 모든 방벽에 적용한다.
- 방벽을 공격 대상으로 유지하며 해당 방벽을 공격 중인 각 공룡에게 최초 공격 대상 지정 후
  게임 시간 1초가 지난 시점부터 1초마다 `15` 피해를 준다.
- 가시 방벽 피해는 장갑을 무시한다.
- 공룡이 경직되어 방벽 공격이 멈춰도 해당 방벽을 공격 대상으로 유지하는 동안 피해 주기를 계속한다.
- 방벽이 파괴되거나 공룡이 공격 대상을 해제하거나 공룡이 처치되면 해당 공룡에 대한 피해 주기를 즉시 종료한다.
- 방벽 가까이에 있지만 해당 방벽을 공격 중이지 않은 공룡에게는 피해를 주지 않는다.

## 10. 상황별 확인 사례

| 상황 | 기대 결과 |
| --- | --- |
| 오버드라이브 발동 중 공격 대상이 사라짐 | 효과 시간은 계속 흐르고 다음 고정 10초 시점 규칙을 유지한다. |
| 추가 탄환 3발이 각각 다른 도탄 후보를 가짐 | 각 탄환이 독립적으로 도탄 대상을 정하고 피해를 준다. |
| 귀환 칼날 준비 완료 시 범위 안 공룡 없음 | 준비를 소모하지 않고 첫 공룡이 들어오는 즉시 발동한다. |
| 귀환 칼날 목표가 출발 중 처치됨 | 처음 정한 직선 경로를 끝까지 왕복한다. |
| 집속탄 소형 폭발 2개가 같은 공룡과 겹침 | 서로 다른 폭발이므로 각각 한 번씩 피해를 준다. |
| 공성탄 대상이 포탄 도착 전에 처치됨 | 예정 위치에서 축소된 범위로 폭발하며 직격 대상이 없으면 직격 피해는 주지 않는다. |
| 같은 파이어 타워가 화염 폭풍 유지 중 다시 공격 | 기존 영역을 제거하고 새 공격 방향에 3초 영역을 만든다. |
| 전염 화상을 받은 공룡이 처치됨 | 새 처치 위치에서 다시 최대 3마리에게 전염한다. |
| 프리즘 후보가 한 마리뿐임 | 해당 공룡에게만 추가 광선을 주고 남은 한 갈래는 발생하지 않는다. |
| 과충전 광선 준비 직전에 공격 대상 변경 | 적중 횟수를 0으로 초기화하고 새 공격 대상을 다시 5회 적중해야 한다. |
| 연쇄 폭풍의 연결 거리 안에 새 공룡 없음 | 남은 추가 연쇄를 다른 공룡에 재사용하지 않고 공격을 종료한다. |
| 과부하 폭발이 다른 공룡의 과부하 횟수를 5회로 만들 수 있는 상황 | 폭발은 횟수를 올리지 않으므로 추가 과부하가 발생하지 않는다. |
| 공룡이 방벽 공격을 시작한 뒤 1초가 지나지 않음 | 가시 방벽 피해를 아직 주지 않는다. |
| 공룡 여러 마리가 같은 방벽을 공격 중 | 각 공룡에게 독립적으로 1초마다 장갑 무시 15 피해를 준다. |
| 방벽을 공격 중인 공룡이 경직됨 | 공격 대상을 유지하므로 가시 방벽 피해 주기는 계속된다. |
| 가시 방벽 피해 시점 전에 방벽이 파괴됨 | 피해 주기를 즉시 종료하고 이후 피해를 주지 않는다. |
| 궁극 효과 진행 중 웨이브 종료 | 진행 중 공격·영역·누적·집중을 제거하고 다음 웨이브에서 초기화한다. |

## 11. 화면 피드백

- 궁극 카드는 일반·고급 등급 업그레이드 카드와 구분되는 궁극 프레임, 등장 연출과 소리를 사용한다.
- 궁극 획득 후 별도 발동 버튼이나 공통 재사용 대기시간 표시는 만들지 않는다.
- 자동 발동형 궁극은 기본 공격과 구분되는 전용 공격·영역 연출로 실제 판정 범위와 지속 여부를 보여준다.
- 후보가 없거나 확정한 공룡이 먼저 처치되어 후속 공격이 끝난 경우 별도의 실패 문구를 띄우지 않고 공격 연출도 생성하지 않는다.
- 웨이브 종료로 진행 중 궁극 효과가 제거되면 남은 공격·영역 연출도 함께 제거한다.

## 12. 검증 필요

- 무제한 일반·고급 카드 누적과 궁극 조합이 모바일 전투 가독성과 판정 수에 미치는 영향을 측정한다.
- 화염 폭풍과 전염 화상의 다수 공룡 처리, 집속탄과 귀환 칼날의 중복 적중이 목표 프레임을 유지하는지 확인한다.
- 궁극별 피해 기여도가 일반·고급 카드 선택을 무의미하게 만들지 않는지 플레이테스트한다.
