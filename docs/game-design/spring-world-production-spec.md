## 1. 목적과 원본 경계

이 문서는 봄 월드의 확정된 콘텐츠 수량과 공통 규칙을 실제 맵·화면·튜토리얼 제작에 연결하는 단일 원본이다. 1-1~1-10의 경로 형태와 상대 배치, 초기 카메라에서 반드시 보여야 하는 영역, 기능별 튜토리얼 흐름, 화면 문구와 아트·사운드가 전달할 정보를 정의한다.

### 1.1 포함

- 1-1~1-10의 경로 형태와 기획상 경로 길이
- 출현 지점, 개척지 관문, 타워 슬롯, 방벽 슬롯, 채집 건물과 나무의 상대 배치
- 초기 카메라 위치와 반드시 완전히 보여야 하는 영역
- 튜토리얼 시작, 진행, 완료, 실패, 취소와 재안내 흐름
- 카드·경제·방벽·승리·실패·중도 이탈 화면 문구
- 봄 월드 아트·사운드의 제작 콘셉트와 전달 정보
- 정상·실패·취소·경계 상황의 확인 사례

### 1.2 제외

- 엔진 좌표 형식, 데이터 구조, 내부 식별자와 구현 코드
- 공통 전투·카드·맵·경제 규칙과 기존 수치 변경
- 여름·겨울 월드 콘텐츠
- 저장 구조, 분석 이벤트와 기술 성능 기준
- 개별 이미지·음원 파일 수와 구체적인 제작 기법

### 1.3 제작 기준과 개발 조정 가능

- `제작 기준`은 경로 형태와 길이, 요소의 상대 배치, 필수 화면 영역, 튜토리얼 흐름과 화면 문구처럼 플레이어 경험을 유지하기 위해 그대로 따라야 하는 확정 내용이다.
- `개발 조정 가능`은 제작 기준을 바꾸지 않는 범위의 정확한 엔진 좌표, 요소 사이의 세부 간격, 장식 배치, 카메라 중심점과 아트·사운드 제작 기법이다.
- 개발 조정 결과로 필수 요소가 화면 밖으로 밀리거나, 가까운 나무와 먼 나무의 순서가 바뀌거나, 경로·슬롯 수와 길이 제한이 달라지면 제작 기준을 충족하지 못한 것으로 본다.

## 2. 경로·배치 표기와 공통 제작 기준

### 2.1 표기 방식

- 맵을 `왼쪽·중앙·오른쪽 × 위·가운데·아래`의 9개 구역으로 나눠 상대 위치를 기록한다.
- 경로 길이는 `stage-map-rules.md`와 같이 가로·세로·대각선으로 인접한 타일에 한 번 이동하는 구간을 모두 1타일로 세는 기획상 길이다.
- 전반은 출현 지점과 가까운 구간, 중앙은 맵의 주 교전 구간, 후반은 개척지 관문과 가까운 구간을 뜻한다.
- 위 표기는 엔진 좌표나 내부 경로 데이터 형식을 정하지 않는다.

### 2.2 경로와 지형

- 공룡은 맵 왼쪽의 출현 지점에서 오른쪽의 개척지 관문으로 이동한다.
- 모든 경로는 오른쪽으로 전진하며 개척지 관문 반대쪽으로 되돌아가는 구간을 만들지 않는다.
- 경로 폭은 기본 2타일로 제작한다. 가독성을 위해 직선 연결부를 1타일까지 좁힐 수 있지만 회전·합류 구간을 포함해 2타일을 넘지 않는다.
- 1-1~1-7은 출현 지점 1개와 단일 경로, 1-8~1-10은 출현 지점 2개와 합류하는 두 경로를 사용한다.
- 두 경로는 합류 뒤 다시 갈라지지 않는다. 두 경로의 길이 차이는 짧은 경로 길이의 25% 이내로 유지한다.
- 경로와 타워 슬롯은 특정 타워만 정답이 되도록 만들지 않는다. 각 주요 방어 구간에서 공격 형태가 다른 여러 타워를 사용할 수 있어야 한다.

### 2.3 배치 요소

- 스테이지별 타워 슬롯·방벽 슬롯·채집 건물·나무 수는 `spring-stage-content.md`의 확정 수량과 정확히 일치시킨다.
- 방벽 슬롯은 출현 지점, 회전·합류 지점과 개척지 관문에서 경로를 따라 2타일 이상 떨어뜨린다.
- 같은 공룡 경로의 방벽 슬롯끼리는 경로를 따라 4타일 이상 떨어뜨린다.
- 모든 나무는 주변 8타일 중 최소 1타일의 채집 공간을 가진다. 일꾼은 채집 건물에서 공룡 경로를 건너지 않고 해당 공간까지 도달할 수 있어야 한다.
- 가까운 나무와 먼 나무의 정확한 이동 거리는 개발 과정에서 정할 수 있지만 이 문서가 정한 거리 순서와 군 분리는 유지한다.

- 출현 지점 A는 왼쪽 위, 출현 지점 B는 왼쪽 아래에 두고 개척지 관문은 오른쪽 가운데에 둔다.
- A·B 경로는 서로 다른 높이에서 긴 독립 전선을 만들고, 각 경로 진행 구간 약 60%에서 합류한다.
- A 경로 총길이는 62타일, B 경로 총길이는 64타일이다. 합류 뒤에는 하나의 경로로 관문까지 이어진다.
- 타워 슬롯 13개는 A 전반 2개, B 전반 2개, 합류 전 A·B에 각각 2개, 합류 주변 3개, 관문 전 2개로 나눈다.
- 방벽 슬롯은 A 합류 전 1개, B 합류 전 1개, 합류 후 1개를 둔다.
- 채집 건물은 왼쪽 중앙 고지대에 둔다.
- 나무 8그루는 가까운 군 3그루와 A·B 경로 및 합류 주변 고지대의 먼 군 5그루로 나눈다.

#### 초기 카메라

- 1.0배에서 맵 왼쪽부터 32타일 범위를 보여준다.
- 두 출현 지점, 두 경로의 초반 구간, 초기 건설권에 사용할 수 있는 타워 슬롯 4개 이상과 채집 건물이 완전히 보여야 한다.
- 합류 지점과 개척지 관문의 오른쪽 방향 표시를 함께 보여준다.

## 4. 튜토리얼 흐름

### 4.1 공통 시작과 표시

- 각 튜토리얼은 해당 기능이 처음 해금되는 스테이지에 처음 진입했을 때 자동으로 시작한다.
- 안내는 짧은 말풍선과 관련 버튼·카드·슬롯·시설의 테두리 강조를 함께 사용한다.
- 안내 중에도 카메라, 배치, 카드 선택과 웨이브 시작을 포함한 정상 조작을 차단하지 않는다.
- 카드가 확률 후보인 기능은 해당 카드가 화면에 실제로 표시된 시점에 설명한다. 설명을 위해 카드를 강제로 표시하거나 선택하게 하지 않는다.

### 4.2 진행과 완료

- 안내가 요구한 행동을 정상 완료하면 해당 단계를 완료하고 다음 안내를 표시한다.
- `카드 확인` 단계는 해당 카드가 화면에 표시됐을 때 설명을 읽거나 닫으면 완료한다. 특정 카드 선택은 완료 조건이 아니다.
- 여러 단계로 구성된 튜토리얼은 모든 필수 단계를 완료했을 때 전체 완료로 처리한다.
- 이미 완료한 튜토리얼은 이후 도전에서 자동으로 다시 표시하지 않는다.

### 4.3 실패·취소·재안내

- 안내와 다른 카드나 슬롯을 선택해도 실제 선택 결과를 유지하며 행동을 되돌리지 않는다.
- 조건 미충족 행동에는 관련 공통 실패 문구를 먼저 표시하고 현재 튜토리얼 말풍선은 유지한다.
- 플레이어가 닫기를 선택하거나 요구 행동 없이 다음 흐름으로 진행하면 현재 안내와 강조를 종료한다. 완료로 처리하지 않고 자동으로 다시 표시하지 않는다.
- 일시정지 메뉴의 `도움말`에서 현재까지 해금된 기능의 튜토리얼을 처음 단계부터 다시 볼 수 있다.
- 도움말에서 다시 연 튜토리얼도 정상 플레이를 차단하지 않는다.
- 승리, 실패, 재시작 또는 로비 이동으로 한 판이 끝나면 열려 있던 안내를 닫는다.

### 5.1 카드 화면

- `채집 가능한 나무가 없습니다`
- `채집 효율이 최대 단계입니다`
- `방벽이 최대 단계입니다`
- `정비 시간에 설치할 수 있습니다`
- `공룡이 지나간 뒤 설치할 수 있습니다`

목재 부족은 `목재가 부족합니다. 보유 {currentWood}, 필요 {requiredWood}, 부족 {missingWood}입니다.`라고 표시한다.

| 행동 | 확인 문구 |
| --- | --- |
| 타워 이동 | `목재 20을 사용해 이 슬롯으로 이동할까요?` |

| 채집 효율 강화 | `목재 {cost}을 사용해 채집 효율을 높일까요?` |

### 5.3 승리 화면

- 제목: `개척지 방어 성공`
- 결과: `라이프 {remainingLife}을 남기고 스테이지를 완료했습니다.`
- 평가: `클리어 평가: {clearGrade}`
- 첫 클리어 해금이 있을 때: `{unlockName}을 사용할 수 있게 되었습니다.`
- 버튼: `다음 스테이지`, `다시 도전`, `로비로 이동`
- 1-10에서는 `다음 스테이지` 대신 `봄 월드 완료`를 표시하고 `로비로 이동`, `다시 도전`을 제공한다.

### 5.4 실패 화면

- 제목: `개척지 방어 실패`
- 이유: `라이프가 0이 되어 방어에 실패했습니다.`
- 결과: `도달 웨이브: {reachedWave}/{totalWave}`
- 통계: `관문에 도달한 공룡: {leakedCount}마리`
- 도움 문구: `타워 배치와 목재 사용 순서를 바꿔 다시 도전해 보세요.`
- 버튼: `즉시 재도전`, `로비로 이동`

### 5.5 중도 이탈 확인

- 재시작: `현재 한 판의 진행을 포기하고 처음부터 다시 시작할까요?`
- 로비 이동: `현재 한 판의 진행을 포기하고 로비로 이동할까요?`
- 공통 버튼: `확인`, `취소`

## 6. 봄 월드 아트·사운드 제작 방향

### 6.1 아트 콘셉트: 초록 개척지

#### 제작 기준

- 봄의 밝고 성장하는 자연과 새로 세운 개척 시설이 함께 보인다.
- 공룡 경로는 낮고 단단하게 다져진 땅, 고지대는 식생이 있는 높은 지형으로 구분한다.
- 경로와 고지대는 색만이 아니라 높이, 외곽선과 절벽 측면으로도 구분한다.
- 출현 지점은 공룡이 들어오는 방향, 개척지 관문은 반드시 지켜야 하는 방향을 형태만으로 알아볼 수 있어야 한다.
- 타워 슬롯, 방벽 슬롯, 채집 건물과 나무는 축소 화면에서도 서로 다른 기능임을 구분할 수 있어야 한다.
- 활성, 선택, 잠김과 설치 불가 상태는 색 외에도 외곽선, 무늬 또는 움직임 차이를 사용한다.
- 나무와 일꾼은 공룡 경로와 공격 연출을 가리지 않는다.
- 알파 공룡은 원종 실루엣을 유지하면서 크기, 장식과 오라 중 둘 이상으로 구분한다.
- 티라노사우루스는 봄 월드의 최종 위협으로 보이되 비유혈 카툰 표현을 유지한다.
- 장식 식생은 필수 경로, 슬롯, 방벽과 화면 밖 방향 표시보다 시각적 우선순위가 낮다.

#### 개발 조정 가능

- 구체적인 색상값과 팔레트 비율
- 풀, 꽃, 바위와 목재 구조물의 종류와 배치
- 타일 경계 표현과 질감 제작 방식
- 계절 장식의 밀도
- 카메라 거리에서 형태를 유지하기 위한 세부 단순화 방식

### 6.2 사운드 콘셉트: 경쾌한 탐험

#### 제작 기준

- 평상시에는 새로운 개척지를 탐험하는 가벼운 분위기를 전달한다.
- 웨이브가 시작되면 전투 진행을 즉시 알 수 있어야 하며, 후반 웨이브와 티라노사우루스 출현은 더 높은 긴장으로 구분한다.
- 두 경로의 화면 밖 위협, 알파 출현과 관문 누수 위험은 서로 혼동되지 않는 신호를 사용한다.
- 카드 선택, 궁극 카드, 목재 운반 완료, 타워 이동, 방벽 피격·파괴와 라이프 손실은 결과를 각각 구분할 수 있어야 한다.
- 일반 승리, 골드 평가가 포함된 승리, 실패와 봄 월드 완료는 정서적으로 구별한다.
- 반복되는 일꾼 이동과 일반 타워 공격은 장시간 들어도 핵심 경고음을 가리지 않는다.
- 음악과 환경음은 공룡 접근과 관문 위험 같은 전투 신호보다 앞서지 않는다.

#### 개발 조정 가능

- 구체적인 악기와 편성
- 음악 길이와 반복 구조
- 환경음의 종류와 녹음·합성 방식
- 효과음의 음높이, 길이와 겹 수
- 기기 진동 사용 여부와 구현 방식

### 7.2 검증 필요

- 48×18타일 맵에서 개척지 관문 위험과 알파 공룡을 놓치지 않고 필요한 카메라 이동 횟수가 과도하지 않은지 확인한다.
- 타워 슬롯 14개에서 빈 슬롯, 설치된 타워와 선택 상태를 구분하고 의도한 슬롯을 정확히 선택하는지 확인한다.
- 나무 8그루와 여러 일꾼의 표현이 공룡 경로, 방벽, 공격 연출과 핵심 경고를 가리지 않는지 확인한다.
- `combat-system-rules.md`의 봄 월드 대표 타워 조합으로 라이프 손실 없는 통과 여유를 충족하는지 플레이테스트한다.
- `card-draw-rules.md`와 `spring-stage-content.md`가 정한 예정 일반 카드 선택의 평균·최소 간격을 충족하는지 확인한다.
- 장시간 반복 플레이에서 음악, 일꾼과 일반 공격음이 알파 공룡, 개척지 관문 위험과 방벽 파괴 신호를 가리지 않는지 확인한다.

## 8. 관련 원본 영향

- 이 문서는 `spring-stage-content.md`의 콘텐츠 수량과 학습 목표를 실제 제작 형태로 연결하며 기존 수량을 변경하지 않는다.

- 튜토리얼과 화면 문구는 `combat-system-rules.md`, `card-draw-rules.md`와 `economy-barricade-rules.md`의 진행·실패 결과를 바꾸지 않는다.

- 신규·변경 게임 용어가 없으므로 `terminology.md`를 변경하지 않는다.
